# An Electron Acceptor with Broad Visible-NIR Absorption and Unique Solid State Packing for As-Cast High Performance Binary Organic Solar Cells

Xueliang Shi, Xunfan Liao, Ke Gao, Lijian Zuo, Jingde Chen, Jingbo Zhao, Feng Liu,\* Yiwang Chen,\* and Alex K.-Y. Jen\*

A novel acceptor-donor-acceptor (A-D-A) type electron acceptor 6TIC-4F with terthieno[3,2-b]thiophene (6T) as the core unit is rationally designed and synthesized, which exhibits an extraordinarily narrow bandgap $( \approx 1 . 2 4 \ \mathrm { e V } )$ and strong absorption between 650 and $1 0 0 0 \ \mathsf { n m }$ . X-ray crystallographic analysis reveals that it has unique intermolecular $\pi { - } \pi$ stacking. The solar cells based on the as-cast poly[(2,6-(4,8-bis(5-(2-ethylhexyl)thiophen-2-yl)-benzo[1,2-b:4,5. $\pmb { b } ^ { \prime }$ ]dithiophene))-alt-(5,5- $[ 7 ^ { \prime } , 3 ^ { \prime }$ -di-2-thienyl- $. 5 ^ { \prime } , 7 ^ { \prime }$ -bis(2-ethylhexyl)benzo[1',2'- $c : 4 ^ { \prime } , 5 ^ { \prime }$ c'ldithiophene-4,8-dione))) (PBDB-T):6TIC-4F binary blends exhibit an excellent power conversion efficiency (PCE) of $1 1 . 1 4 \%$ with a high $J _ { s \mathsf { c } }$ of $2 3 . 0 0 ~ \mathsf { m A c m } ^ { - 2 }$ , and a high fill factor of 0.67, which represents one of the best PCE values for low bandgap $( E _ { \mathrm { g } } < 1 . 3$ eV)-based organic solar cells.

# 1. Introduction

Bulk-heterojunction (BHJ) organic solar cells (OSCs) based on solution processable organic semiconductors have attracted considerable interests as potential alternative technology to conventional silicon solar cells for renewable energy. The distinct advantages of OsCs include low cost, lightweight, good flexibility, transparency, and printablility, which are important when compared with their inorganic counterparts.[1-4] However, there are also certain disadvantages in OsCs that need to be further improved, such as the much lower power conversion efficiency (PCE) compared to single crystalline silicon solar cells.l The silicon solar cells can harvest photons beyond $1 0 0 0 \ \mathrm { ~ n m }$ while typical top-performing OSCs only have absorption edge in the range of $7 0 0 { - } 8 0 0 \ \mathrm { n m } .$ [6-9] To harvest solar radiation more effectively, it is critical to extend the absorption of active layer materials toward the near-infrared (NIR) region. Therefore, it is important to develop novel donor (D)-acceptor (A) materials with absorption that can cover broadly in the visible-NIR region (Figure 1).

In the past few years, significant efforts have been devoted to develop low bandgap electron donors with NIR absorption over 900 or even $1 0 0 0 \ \mathrm { n m }$ to achieve enhanced short circuit current $( J _ { \mathsf { S C } } )$ and PCEs.0,11] However, these low bandgap donors can only afford quite limited PCEs $( < 5 \% )$ in fullerenebased OsCs.[12,13] The difficulty in achieving high efficiency fullerene-based OsCs lies on the low open-circuit voltage $( V _ { \mathrm { O C } } )$ with serious energy loss $( > 0 . 6 \mathrm { V } )$ and the low external quantum efficiency (EQE) in the NIR region. Recently, nonfullerene acceptor-based OsCs have achieved great progress, especially in A-D-A type fused-ring electron acceptors such as IEIC and IT1c.1421] Benefiting from strong intramolecular charge transfer (ICT), they can extend absorption to $8 0 0 \ \mathrm { n m }$ . Meanwhile, high PCEs with lower $V _ { \mathrm { O C } }$ loss $_ { ( < 0 . 6 \mathrm { ~ V ~ } ) }$ and higher EQE could be achieved in several of these materials.22-27] However, it is still very challenging to develop proper materials that can further extend the absorption edge to $9 0 0 { - } 1 0 0 0 \ \mathrm { n m }$ while maintaining high efficiency in devices. To date, very few efficient electron acceptors with strong absorption in the range between 900 and $1 0 0 0 \mathrm { n m }$ have been developed.[28-33]

Herein, we report a novel low bandgap acceptor 6TIC-4F with a strongly electron-donating core unit terthieno[3,2-b] thiophene (6T) and two fanking strongly electron-withdrawing acceptor units 2-(5,6-difluoro-3-oxo-2,3-dihydro-1Hinden-1-ylidene)malononitrile (IC-2F) (Figure 1). The strong ICT results in a broad and strong visible-NIR absorption in the range of $6 5 0 { - } 9 5 0 \ \mathrm { n m }$ , and an absorption edge of ${ \approx } 1 0 0 0$ nm, which is significantly redshifted compared to its analogs with 4T core unit (4TIC-4F) or nonfluorinated IC end groups (6TIC).[34-37] The result from the single crystal structure reveals close intermolecular $\pi - \pi$ stacking between both IC-2F units and IC-2F and thieno[3,2-b]thiophene (TT) units, which highlights the unique properties of both 6T and IC-2F units. The strong molecular packing contributes to efficient charge transport and favorable nanoscale fiber-like phase segregation when blend with polymer donors. Consequently, the as-cast solar cells based on poly(2,6-(4,8-bis(5-(2-ethylhexyl)thiophen2-yl)-benzo $[ 1 , 2 - b ; 4 , 5 - b ^ { \prime } ]$ dithiophene))-alt-(5,5- $^ { 1 ^ { \prime } , 3 ^ { \prime } }$ -di-2- thienyl- $. 5 ^ { \prime } , 7 ^ { \prime }$ -bis(2-ethylhexyl)benzo[1 $^ { \prime } , 2 ^ { \prime } { \cdot } c { : } 4 ^ { \prime } , 5 ^ { \prime } { \cdot } c ^ { \prime } ]$ dithiophene4,8-dione))l) (PBDB-T):6TIC-4F exhibit a high PCE of $1 1 . 1 4 \%$ and a high $J _ { \mathrm { S C } }$ of $2 3 . 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ and a fill factor (FF) of 0.67, which has the highest performance for OsCs with absorption over $9 0 0 \mathrm { n m }$

# 2. Results and Discussion

# 2.1. Material Synthesis, Optical and Electrochemical Properties

The synthesis of 6TIC-4F and its analog, 4TIC-4F were based on the Knoevenagel condensation reactions described in our recent reports (details in the Supporting Information).[34,36] The structures of 6TIC-4F and 4TIC-4F were fully characterized by $^ 1 \mathrm { H }$ nuclear magnetic resonance (NMR), $^ { 1 3 } \mathrm { C }$ NMR, and mass spectrometry (see the Supporting Information), and 6TIC-4F was unambiguously confirmed by X-ray crystallographic analysis (vide infra). Both the compounds have good solubility in chlorinated solvents such as dichloromethane, chloroform, and chlorobenzene, which is important for device fabrication. As shown in Figure 2a, the 6TIC-4F solution exhibits a strong absorption band between 600 and $9 0 0 \ \mathrm { n m }$ with a $\lambda _ { \mathrm { m a x } }$ at $7 7 4 \ \mathrm { n m }$ , which is redshifted ${ \approx } 2 0 \ \mathrm { n m }$ compared to that of 4TIC-4F $\lambda _ { \operatorname* { m a x } }$ at $7 5 2 \ \mathrm { n m }$ . In solid-state, the absorption of 6TIC-4F further redshifted to ${ \approx } 1 0 0 0 \ \mathrm { n m }$ , while 4TIC-4F had an absorption edge at ${ \approx } 9 4 0 ~ \mathrm { n m }$ . More importantly, compared with 4TIC-4F and other reported acceptors, 6TIC-4F film shows a much broader absorption range, covering from 650 to $9 5 0 ~ \mathrm { n m }$ which is very important for efficient light harvesting in devices. From their cyclic voltammetry (CV) plots in Figure 2b, the highest occupied molecular orbital (HOMO) and lowest unoccupied molecular orbital (LUMO) energy levels of 4TIC-4F and 6TIC-4F could be obtained from the onset of the first oxidation and reduction potential with values of $- 5 . 6 0$ $- 5 . 4 5$ , and $- 4 . 2 1$ $- 4 . 1 4 \ \mathrm { e V } ,$ respectively. Compared with 4TIC-4F, 6TIC-4F has a much higher lying HOMO energy level and a slightly higher LUMO energy level, which is ascribed to the more electron-rich nature of $^ \mathrm { 6 T }$ and its ICT with terminal IC-2F group. Consequently, 6TIC-4F has a much smaller electrochemically determined bandgap than 4TIC-4F, which is in accordance with its optical bandgap (Table S1, Supporting Information). To explore the bandgap difference between 4TIC-4F and 6TIC-4F, density functional theory (DFT) calculations at the B3LYP/6-31G(d,p) level were performed to calculate their HOMO and LUMO energy levels (Figure 2c). The trend of the calculated bandgap change between 4TIC-4F and 6TIC-4F is consistent with the findings from both photophysical and electrochemical studies.

# 2.2. X-Ray Crystallographic Analysis

To gain more insight of the largely redshifted absorption in solid-state, single crystals of 6TIC-4F suitable for X-ray crystallographic analysis were obtained by slow diffusion of methanol into its chloroform solution.38] The Oak Ridge Thermal Ellipsoid Plot (ORTEP) drawings and 3D packing structures of 6TIC-4F are shown in Figure 3. Interestingly, the rigid 6TIC-4F has a slight curvature with a wave shape (Figure 3a), which may be the reason contributes to its excellent solubility in the common organic solvents. The high rigidity of 6TIC-4F benefits from the unique interaction between the terminal IC-2F group and the central 6T group, with terminal IC-2F units and central 6T unit interlocked via the intimate [S...O] interactions (Figure 3b, red color highlighted in the top view), which also ensures an isomer-free molecular geometry.[34] No obvious intermolecular interaction could be found in the central TT unit of 6TIC-4F, probably due to the four hexylphenyl groups oriented almost perpendicularly to the backbone 6T, which disrupts the regular $\pi - \pi$ stacking or herringbone arrangements observed in common planar organic molecules.39] In return, the bulky hexylphenyl groups guarantee the solubility and processability of 6TIC-4F, which is of importance in the OSC device fabrication. Instead, stronger intermolecular $\pi - \pi$ stacking was observed between the terminal IC-2F groups and outmost TT units of 6T (3D packing in Figure 3c,d). Specifically, molecules 6TIC-4F crosswise arranged in the whole cell unit via $\pi - \pi$ interaction (distance: ${ \approx } 3 . 5 4 3 { \mathrm { ~ \AA ~ } }$ between adjacent outmost TT units; the adjacent IC-2F groups can form a close intermolecular $\pi - \pi$ stacking with a distance of ${ \approx } 3 . 5 2 2 \mathrm { ~ \AA ~ }$ : the IC-2F units can also interact with adjacent outmost TT unit of 6T via $\pi - \pi$ interaction (distance: ${ \approx } 3 . 3 5 9 ~ \mathrm { / }$ A). In addition, intermolecular $[ \mathrm { C - H . . . F } ]$ interaction was also observed. These impressive intermolecular interactions are important for acceptors to have efficient charge transport, which is one of the keys to high performance OSCs.

# 2.3. Photovoltaic Properties

To match the broad absorption of 6TIC-4F, a wide-bandgap donor polymer, PBDB-T with a strong absorption in the range of $5 0 0 { - } 6 5 0 ~ \mathrm { n m }$ was used to fabricate BHJ solar cells.[40] The perfectly matched absorption of the donor and acceptor is essential for photon harvesting. In addition, as shown in Figure 4a, their energy levels are also perfectly matched with a HOMO offset of $0 . 1 2 \ \mathrm { e V } ,$ which is shown to be enough for efficient charge transfer in nonfullerene OSCs.[41,42]

As shown in Figure 4b, OsCs with a device configuration of ITO/PEDOT:PSS/PBDB-T:acceptor/ $\mathrm { { C } _ { 6 0 } }$ bissalt/Ag were fabricated, where ITO is indium tin oxide, PEDOT:PSS is poly(3,4- ethylenedioxythiophene)-poly(styrenesulfonate), and ${ \mathrm { C } } _ { 6 0 }$ bissalt is bis-fulleropyrrolidium iodide salt.43] With a D:A blending ratio of 1:1, excellent performance with a $V _ { \mathrm { O C } }$ of $0 . 7 2 \mathrm { ~ V } ,$ $J _ { \mathrm { S C } }$ of $2 3 . 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ , a FF of 0.67, and a PCE as high as $1 1 . 1 4 \%$ could be achieved (Figure 4c and Table 1). This result represents one of the highest values obtained among low bandgap OSCs. It was found that further treatments with solvent additives and thermal annealing do not enhance the overall efficiency (Table S2, Supporting Information). The impressively high $J _ { \mathrm { S C } }$ is ascribed to the distinct NIR absorption of 6TIC-4F. Another particularly noteworthy is its relatively low $V _ { \mathrm { O C } }$ loss of $0 . 5 1 7 \mathrm { ~ V ~ }$ $( V _ { \mathrm { O C \ l o s s } } = e E _ { \mathrm { g } } ^ { \mathrm { \scriptsize ~ O P T } } - V _ { \mathrm { O C } } )$ . The high PCE and $J _ { \mathrm { S C } }$ with low $V _ { \mathrm { O C } }$ loss is very rare in small bandgap $( \approx 1 0 0 0 \ \mathrm { n m } )$ materials derived OSCs. Compared to 6TIC-4F, 4TIC-4F-derived device exhibited an inferior performance with a decreased $V _ { \mathrm { O C } }$ of $0 . 6 5 2 \mathrm { ~ V } ,$ $J _ { \mathrm { S C } }$ of $2 1 . 5 \mathrm { \ m A \ c m ^ { - 2 } }$ , a FF of 0.57, and a PCE of $7 . 9 9 \%$ (Figure 2c and Table 1). The inferior $V _ { \mathrm { O C } }$ with a higher $V _ { \mathrm { O C } }$ loss is due to its relatively lower lying LUMO level compared with that of 6TIC-4F shown in Figure 4a. The different FFs of 4TIC-4F and 6TIC-4F are likely due to their different carrier dynamics and charge mobilities (vide infra).

EQE curves of the best performing devices are shown in Figure 4d. The EQE responses of two devices start from $3 5 0 ~ \mathrm { n m }$ and cover the entire visible area to NIR region, indicating PBDB-T polymer donor and two acceptors simultaneously contribute to the generation of $J _ { \mathrm { S C } }$ . In addition, PBDBT:6TIC-4F exhibits higher EQE response $( > 6 0 \% )$ in the entire region between 450 and $9 0 0 \ \mathrm { n m }$ , indicating the importance of the broad absorption of 6TIC-4F. In contrast, previously reported electron acceptors with similar bandgap have poor absorption between 600 and $7 5 0 ~ \mathrm { n m }$ , which show a clear dip region when large bandgap donor polymers were used.[28,29] While a low bandgap donor polymer may be added to cover this absorption range, the fabrication of ternary solar cells increases the complexity and requires additional optimization work. With a broad absorption, 6TIC-4F enables binary solar cells to cover the whole visible-NIR range up to $1 0 0 0 \ \mathrm { n m }$ . The EQE plots illustrate that 6TIC-4F has an extended photoelectron response to ${ \approx } 1 0 0 0 \ \mathrm { n m }$ , which is redshifted ${ \approx } 1 0 0$ nm compared to that of 4TIC-4F. Consequently, the $J _ { \mathrm { S C } }$ values of 6TIC-4F calculated from the EQE curves are higher than 4TIC-4F, consistent with its improved $J _ { \mathrm { S C } }$ observed in $J { - } V$ curves (Table 1). The calculated $J _ { \mathrm { S C } } \mathrm { s }$ for both devices are also within the reasonable match with the $J _ { \mathrm { S C } }$ values obtained from the corresponding $J { - } V$ curves (Table 1).

To explore the carrier dynamics and charge mobilities of the devices, the light intensity-dependent $J _ { \mathrm { S C } }$ and $V _ { \mathrm { O C } } ,$ and space-charge-limited-current (SCLC) measurements were conducted. (details in the Supporting Information). The $J _ { \mathrm { S C } }$ for device based on 6TIC-4F exhibits an index of 0.974 with the light intensity, which is higher than 0.908 obtained for 4TIC-4F device (Figure S1, Supporting Information). The close to unity light intensity dependence ( $\alpha$ value) in 6TIC-4F device indicates less charge recombination loss during charge extraction, which further supports its higher FF compared with 4TIC-4F.[44,45] The $V _ { \mathrm { O C } }$ versus light intensity study revealed that there is no distinct difference between the two devices in the recombination process as they displayed the similar slope value (Figure S2, Supporting Information). The hole and electron mobility of PBDB-T:acceptor blended films were estimated to be $6 . 3 8 \times 1 0 ^ { - 5 }$ and $2 . 2 3 \times 1 0 ^ { - 4 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ for 4TIC-4F and $7 . 9 4 \times 1 0 ^ { - 5 }$ and $4 . 5 2 \times 1 0 ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ for 6TIC-4F, respectively, based on the SCLC measurements (Figure S3, Supporting Information). The higher mobility of 6TIC-4F is attributed to the unique ordered packing motif observed in its solid-state. Accordingly, the higher charge mobility of 6TIC-4F facilitates better charge extraction, resulting in a lower recombination loss and enhanced FF observed in its OSC devices.

# 2.4. Film Morphology Analysis

The structure order of acceptors and BHJ blends were investigated using grazing incidence wide-angle X-ray scattering (GIWAXS) methods.l46-48] Shown in Figure 5, 4TIC-4F in neat thin film showed a weak crystallinity as seen from a broad (100) diffraction at $0 . 3 7 \mathring { \mathrm { ~ A ~ } } ^ { - 1 }$ and pi-pi stacking peak at ${ \approx } 1 . 5$ $\mathring { \mathrm { A } } ^ { - 1 }$ [49] Thus, 4TIC-4F molecules cannot form close cofacial stacks that facilitate charge transport. This feature is quite different from the parent molecule 4TIC, which showed quite sharp diffraction spots in neat thin film.l34] The conventional consideration that adding fluorine atom into conjugated molecules could improve solid state packing that improve optoelectronic properties, which is quite on the contrary to the current case. 4TIC molecule is a small molecule block with limited size that can readily crystallize. The addition of 4 fluorine atoms most probably reduces intermolecular interactions due to less pronounced electronic couplings. Larger analog 6TIC-4F behaved quite differently and could form high quality crystalline packing. Single crystals were obtained that reveals detailed intermolecular interactions. And, several main diffraction features can be clearly observed in 2D thin film. A (100) peak at $0 . 4 6 \ \mathring { \mathrm { A } } ^ { - 1 }$ was seen in both in-plan and out-of-plan directions, corresponding to a distance of $\overset { \cdot } { 1 3 . 6 \mathrm { ~ \AA ~ } }$ Pi-pi stacking is highly face-on and located at $1 . 8 4 \textup { \AA } ^ { - 1 }$ . Thus, 6TIC-4F molecules could tightly packed at 3.41 A distance, owning to improved intermolecular interactions. The crystalline feature of BHJ thin film constituted of diffraction signals from both PBDB-T polymer and nonfullerene acceptors. For example, PBDB-T:4TIC-4F showed a quite broad (100) diffractions that aroused from combinatory feature of both donor and acceptor materials. 6TIC-4F in BHJ blend could still preserve its crystalline order, as seen from protruded $0 . 4 6 \mathring { \mathrm { ~ A ~ } } ^ { - 1 }$ scattering peak. The pi-pi stacking was also more obvious in PBDB-T:6TIC-4F that located at $\check { 1 . 7 5 \mathrm { ~ \AA ^ { - 1 } ~ } }$ . More contribution from PBDB-T moiety was seen, which comes from the major framework in BHJ thin film.50] Blended thin film phase separation was investigated using resonant soft X-ray scattering (RSOXS) using $2 8 5 \mathrm { e V }$ photon energy.51,52] A more pronounced scattering hump feature was seen at around $0 . 0 1 \bar { 1 } \ \mathring { \mathrm { A } } ^ { - 1 }$ giving a center-to-center distance of $6 0 ~ \mathrm { { n m } }$ . Improved crystallinity of acceptor materials as well as better-defined phase separation gave rise to improved electron/hole mobilities and the device performances. Thus, the interpreted results 4TIC-4F of and 6TIC-4F from both GIWAXS and RSOXS are consistent with their photovoltaic properties.

# 3. Conclusion

In summary, a novel NIR semiconductor 6TIC-4F as electron acceptor used in highly efficient OsC has been designed and synthesized. The 6TIC-4F shows a very small bandgap of $1 . 2 4 ~ \mathrm { e V }$ with NIR absorption to ${ \approx } 1 0 0 0 \ \mathrm { n m }$ . We have also successfully elucidated the crystal structure of 6TIC-4F and its unique packing motif through intermolecular $\pi - \pi$ stacking using X-ray crystallographic analysis. The systematic comparison of 6TIC-4F and its analogous 4TIC-4F showed that 6TIC-4F has several distinctive properties as nonfullerene acceptor for OsC application, including its extended and broader NIR absorption and EQE response, its good energy match with donor polymer, and its suitable charge mobility. Thus, OSC devices of PBDB-T:6TIC-4F without any solvent additive or post-treatment exhibit a high PCE of $1 1 . 1 4 \%$ with a high $J _ { \mathrm { S C } }$ of $2 3 . 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ a high fill factor of 0.67, and a small $V _ { \mathrm { O C } }$ loss of $0 . 5 1 7 \mathrm { ~ V } .$ The high PCE is one the highest value reported so far for any OSCs with NIR response over $1 0 0 0 \ \mathrm { n m }$ . Our work demonstrates rationally designing materials with broad absorption ranges for high-performance binary OSCs covering the whole visible and NIR to $1 0 0 0 \mathrm { n m }$ , and this study will shed light on a new perspective for future NIR nonfullerene acceptor molecular design.
