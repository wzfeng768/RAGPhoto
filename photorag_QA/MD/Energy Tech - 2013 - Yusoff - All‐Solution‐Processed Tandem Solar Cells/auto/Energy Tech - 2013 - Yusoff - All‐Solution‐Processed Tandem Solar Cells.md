# DOI: 10.1002/ente.201300012 All-Solution-Processed Tandem Solar Cells

Abd. Rashid bin Mohd Yusoff, Hyeong Pil Kim, and Jin Jang\*[a]

Organic solar cells are moving at a fast pace towards commercialization for large-scale applications. Yang et al. reported a high power conversion efficiency (PCE) of approximately $1 0 . 6 \%$ in an organic tandem solar cell based on a solution process.ll Organic solar cells have been intensively studied because they are cost effective, light weight, mechanically flexible, and fabricated through simple processes. Although the efficiency of organic solar cells has increased significantly, a few basic but critical issues must be overcome to achieve high efficiency, such as short lifetimes and narrow absorption windows. One of the approaches that is used to improve absorption is the stacking of two or more organic solar cells with different absorption characteristics in socalled tandem solar cells.2-9] The tandem device is known to have a few advantages over single solar cells (conventional or inverted structures), that is, it harnesses more of the solar spectrum and has a higher stability. Previously, it has been reported that tandem solar cells, with a complementary absorption, exhibit a high open circuit voltage $( V _ { \mathrm { o c } } )$ that is almost equal to the summation of the $V _ { \mathrm { o c } }$ values for top and bottom cells, and have a short circuit current density. $( J _ { \mathrm { s c } } )$ lower than that of each individual cell.68] It is generally accepted that for series-connected tandem organic solar cells, precise optimization of the absorption window and the photogenerated currents in the top and bottom cells can be realized by initially using a thin absorption layer with a large band-gap material and then a thick absorption layer with a narrow band-gap material. This methodology has both theoretically and experimentally resulted in well-balanced photogenerated currents in the top and bottom cells.

Other types of tandem solar cells have also been reported, which are connected in parallel.[10-12] Unlike in the seriesconnected tandem solar cells, the $J _ { \mathrm { s c } }$ in an ideal parallel-connected solar cell can be realized as the summation of the $J _ { \mathrm { s c } }$ in the two individual cells. For series-connected devices, choosing an interconnecting layer that electrically connects the top and bottom cells is critical so as to obtain the maximum $V _ { \mathrm { o c } }$ and fill factor $( F F )$ ; this interconnecting layer must be efficiently connected to a particular cell without creating any physical or chemical damage to the bottom cell.

Herein, we demonstrate the design, construction, and characterization of an organic tandem solar cell. The tandem solar cell produced was all-solution-processed, that is, each layer was deposited from solution except for the top and bottom contacts.

A ZnO/PEDOT:PSS layer was deposited by using a solution-processed method in which the layer attached to both the top and bottom cells simultaneously. The PEDOT:PSS was neutralized by using NaOH solution to prevent the acidity of the PEDOT from penetrating into the underlying ${ \mathrm { Z n O } }$ thin film.l Previous reports regarding tandem solar cells with a similar interconnecting layer[5,13,14] have showed comparable $V _ { \mathrm { o c } } ,$ higher $J _ { \mathrm { s c } }$ and improved PCE; however, our tandem device also demonstrated an improved $F F$ that could be attributed to low series resistance.14]

Our constructed tandem organic solar cell exhibited a $J _ { \mathrm { s c } }$ of $6 . 9 3 \mathrm { m A c m } ^ { - 2 }$ $V _ { \mathrm { o c } }$ of 1.45 V, FF of $6 3 . 3 6 \%$ ,and PCE of $6 . 3 8 \%$ . The fabricated tandem cell offered benefits such as long lifetime and stability (even though it involved the interface of ITO/PEDOT:PSS) with just $2 . 1 9 \%$ decrement in efficiency over $7 2 0 \mathrm { h }$ , high efficiency, and they were all-solutionprocessed, which did not involve a high annealing temperature.

The schematic structure of the fabricated tandem solar cell and the relevant chemical structures are shown in Figure 1. $\mathrm { P 3 H T : P C _ { 7 0 } B M }$ and PSBTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ were the photoactive layers for the top and bottom cells, respectively. The two photoactive layers were connected by a stacked transparent $n$ -type metal semiconductor $\mathbf { \left( Z n O \right) }$ and a conductive hole transport layer (PEDOT:PSS). The electrons from the top cell combined with the holes from the bottom cell at the ZnO/PEDOT:PSS interconnecting layer. The complete device consisted of ITO/PEDOT:PSS $( 4 0 \mathrm { n m } )$ P3HT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ $\mathrm { 8 0 } \mathrm { n m } ,$ ${ \mathrm { Z n O } }$ $( 2 0 \mathrm { n m } )$ , PEDOT:PSS $( 4 0 \mathrm { n m } )$ PSBTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ $( 1 1 0 \mathrm { n m } )$ , and LiF:Al $( 1 0 0 \mathrm { n m } )$

No damage or defects were observed or detected from these images. # Experimental Section

Device fabrication: We fabricated all-solution-processed organic   
tandem solar cells based on P3HT (TAKOMA Technology Co.   
Ltd.), PSBTBT (Solarmer), and $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ (Aldrich) photoactive   
materials. All devices were fabricated on an ITO-coated glass   
substrate, with a sheet resistance of approximately $1 5 \Omega \mathrm { c m } ^ { - 2 }$   
The pre-cleaned substrates were treated with UV-ozone for   
$1 5 \mathrm { { m i n } }$ prior to the coating of PEDOT:PSS (purchased from   
H. C. Stark, VP Al 4083, PEDOT, 4083) at $4 0 0 0 \mathrm { r p m }$ for $2 5 \mathrm { \bf s } ,$   
which were then annealed at $1 2 0 ^ { \circ } \mathrm { C }$ for $2 0 \mathrm { { m i n } }$ (inside a glove  
box). The $\mathrm { P 3 H T : P C _ { 7 0 } B M }$ $( 1 { : } 0 . 7 ~ w / w )$ in $1 \%$ chloroform solution   
was coated onto the PEDOT:PSS layer at $4 0 0 0 \mathrm { r p m }$ for $3 0 \mathrm { s }$ and   
then annealed at $1 3 0 ^ { \circ } \mathrm { C }$ for $3 0 \mathrm { { m i n } }$ (inside a glovebox). The inter  
connecting layer was fabricated through the deposition of an   
amorphous layer of $Z _ { \mathrm { { n O } . } }$ which consisted of zinc acetate dehy  
drate $( 0 . 5 \mathbf { M } )$ in monoethanolamine $( 0 . 5 \mathbf { M } )$ and 2-methoxyetha  
nol. The ${ \mathrm { Z n O } }$ solution was spun at $4 0 0 0 \mathrm { r p m }$ for $2 5 \mathrm { s }$ and an  
nealed at $1 5 0 ^ { \circ } \mathrm { C }$ for $5 \mathrm { { m i n } }$ under ambient air. PEDOT:PSS from   
the same solution as mentioned above was then coated onto the   
${ \mathrm { Z n O } }$ layer. The bottom cell fabrication process occurred by spin  
coatingPSBTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ at $4 0 0 0 \mathrm { r p m }$ for $2 5 \mathrm { \ : s } .$ The   
PSBTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ $( 1 { : } 1 ~ w / w )$ was prepared in chloroform solution - $\mathrm { 1 0 ~ m g }$ of PSBTBT per $1 \mathrm { m L }$ of solvent). Subsequently,  the PSBTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ layer underwent annealing for $5 \mathrm { { m i n } }$ at $1 5 0 ^ { \circ } \mathrm { C }$ Finally, the thermal evaporation of LiF $( 0 . 5 \mathrm { n m } )$ and Al $( 2 0 0 \mathrm { n m } )$ occurred at a base pressure of $1 0 ^ { - 7 }$ Torr. The active areas for all fabricated devices was $0 . 0 4 \mathrm { c m } ^ { 2 }$

Thin film and device characterizations: Absorption measurements were performed by using a SCINCO S4100 spectrophotometer. Surface morphologies of the photoactive layers were obtained by using tapping mode atomic force AFM (Digital Instrument Multimode equipped with a nanoscope IIIa controller). The XRD spectra were obtained in grazing incidence $2 \theta$ scan mode by using X'PERT PRO of PANalytical. $J { - } V$ characteristics of the tandem device were obtained by using a semiconductor characterization system (Keithley 2400 LV Source Meter under a simulated AM1.5 G spectrum with MAX-302, Asahi Spectra Co. Ltd, Japan). The EQE measurements were performed by using an EQE system (model 74000) obtained from Newport Oriel Instruments USA and a HAMAMATsU calibrated silicon cell photodiode was used as a reference diode. The wavelength was controlled by using a monochromator $2 0 0 { - } 1 6 0 0 \ \mathrm { n m }$ . All measurements were performed at room. temperature, that is, approximately $2 7 ^ { \circ } \mathrm { C }$ under a relative humidity of $6 0 { - } 7 0 \%$ . Stability measurements were performed with periodic exposure to AM1.5G conditions at $1 0 \bar { 0 } \mathrm { m W } \mathrm { m } ^ { - 2 }$ The $J { - } V$ characteristics were recorded every $2 4 0 \mathrm { h }$ up to $7 2 0 \mathrm { h }$ according to the ISOS-L-1 procedure.[18]
