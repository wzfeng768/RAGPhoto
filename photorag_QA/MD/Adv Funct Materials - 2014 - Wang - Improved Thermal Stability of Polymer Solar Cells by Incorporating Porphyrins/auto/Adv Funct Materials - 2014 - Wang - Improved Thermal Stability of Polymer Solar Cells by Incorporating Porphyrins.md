# Improved Thermal Stability of Polymer Solar Cells by Incorporating Porphyrins

Sisi Wang, Yunpeng Qu, Sijun Li, Feng Ye, Zhaobin Chen,\* and Xiaoniu Yang\*

Thermal stability has been the important issue in organic solar cell, especially for the large scale fabrication and application in the future. In this work, a new strategy involving the introduction of porphyrin compound (BL) is proposed to prevent the [6,6]-phenyl C61 butyric acid methyl ester $( \mathsf { P C } _ { 6 7 } \mathsf { B M } )$ aggregation. The supramolecular interactions between $\mathsf { P C } _ { 6 7 } \mathsf { B M }$ and BL are first demonstrated in $P C _ { 6 7 } \mathsf { B M : B L }$ binary blend, and then the effect of BL on $\mathsf { P 3 H T : P C } _ { 6 7 } \mathsf { B M }$ blend is qualitatively and quantitatively studied by differential scanning calorimetry, UV-vis absorption spectroscopy, atomic force microscopy, optical microscopy, and fluorescence techniques. It is found that the BL addition not only stabilizes the morphology of $\mathsf { P 3 H T : P C } _ { 6 7 } \mathsf { B M }$ blend films, but also shows a good ability to maintain the electron mobility by depressing the $\mathsf { P C } _ { 6 7 } \mathsf { B M }$ crystallization. And the thermal stability of the devices based on $\mathsf { P 3 H T : P C } _ { 6 7 } \mathsf { B M : }$ BL ternary blend films is therefore greatly improved. For example, $8 \%$ BL doping drops the power conversion efficiency by $10 . 5 \%$ relative to its peak value after $4 8 \ h$ of annealing at ${ \bf 1 3 0 } ^ { \circ } { \bf C }$ , while $7 1 . 5 \%$ of decrease is obtained for the device without BL after only $3 h$ of annealing. This strategy is preliminarily proved to be universal and will show great potentials in future commercialization of polymer solar cells.

# 1. Introduction

Polymer solar cells (PSCs) based on solution-processed bulkheterojunctions (BHJs) have been a world-wide field of interest as a source of renewable energy with outstanding advantages, such as low cost, light weight, and flexibility, as well as largearea feasibility.[1] Single BHJ structure has demonstrated the efficiency of up to $\scriptstyle \approx 9 \% , ^ { [ 2 ] }$ whereas for tandem BHJ structure this value exceeds the $10 \%$ watershed.3] Although a variety of low-band gap polymers has been the hot topic in the past two decades, the traditional BHJ structure composed of poly(3-hexylthiophene):phenyl-C61-butyric acid methyl ester $( \mathrm { P 3 H T : P C _ { 6 1 } B M } )$ is still the typical system used as the research model for organic photovoltaics due to its stability and reliable material source.!4l In addition, $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ is also one of the most promising candidates until now for large-scale production because of the commercial availability and easy processing in the interface area, increase the exciton recombination,10] and thus bring negative effect on the device efficiency. Even in stable $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blends, the issue of morphological instability induced by thermal stress should not be underestimated, because semicrystalline P3HT tends to expel $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ during its crystallization, and $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ molecules aggregate due to the strong driving force for crystallization.

Currently, much effort has been made by a number of research groups to stabilize the active layer morphology and some methods, for example, decreasing the crystallinity of polythiophenes,[11] constructing densely distributed P3HT nanofibers,12] adopting amorphous fullerene electron acceptor,[13] introducing compatibilizer,[14] cross-linking,[15] and other techniques restricting the movement of acceptor molecules,[16] have been developed and substantially improved the morphological stability of the BHJ-based solar cells.

Porphyrin is an attracting family of compounds that could interact with other compounds, like fullerenes, to form complexes due to $\pi { - } \pi$ interactions or Van der Waals forces.[17] This supramolecular interaction could be established universally and easily between porphyrins and fullerenes with no need of special conditions. In organic photovoltaics, it was reported that porphyrins and their derivatives could also be introduced into devices as photosensitizing agents due to their easy syntheses, high extinction coefficients, and broad absorption spectra.18] Based on these pioneering studies, the authors associate that the fullerene derivatives, such as $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , which is widely used as the acceptor in polymer solar cells, could interact with porphyrins and thus the thermal stability of the devices should be improved due to the inhibition of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ aggregation. To the best of our knowledge, this has never been reported before.

In this paper, the (zinc-5, 15-diethynyl-10, 20-di(4-dodecyloxyphenyl) porphyrin, named as BL (Scheme 1), was selected to demonstrate this novel strategy. Here, it should be noted that the porphyrin solution we used in this work must be prepared freshly due to the photochemical instability relative to the BL in solid state or blend film (Figures S1-S3, Supporting Information). Finally, the effect of BL on the performance and electron mobility of photovoltaic devices based on $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend film was provided and the mechanisms were elucidated.

# 2. Results and Discussion

# 2.1. Supramolecular Interaction between $\mathsf { P C } _ { 6 1 } \mathsf { B M }$ and BL

According to previous reports, the presence of the supramolecular interactions (electronic interactions in nature) between porphyrin and fullerene could be detected by UV-vis spectroscopy.19] As an illustration, the spectrum of $\mathrm { B L } { : } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ blend solution is depicted in Figure 1a together with the spectra of BL and $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ for comparison. It can be seen that the absorption spectrum of BL in $o$ dichlorobenzene (ODCB) changes upon the addition of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ (about 2 equivalent of BL), and the absorption of the Soret band is red shifted $( \Delta \lambda = 8 ~ \mathrm { { n m } }$ ) and broadened. This similar bathochromic-shift of absorption has been demonstrated to relate to the face-to-face porphyrinfullerene complexes.[20]

In conformationally fexible porphyrin/fullerene dyads, $\pi$ stacking interactions facilitate the throughspace attraction between the flat tetrapyrrole ring and the curved surface of the fullerene, which is accompanied by the formation of fullereneexcited states (by energy transfer) or generation of porphyrin+/ fullerene\~ ion-pair states (by electron transfer) and could be demonstrated by fluorescence quenching technique.[21] Figure 1b shows the curves of quenched BL solutions upon addition of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , showing the dramatically decreased band intensities at 640 and $6 8 4 ~ \mathrm { n m }$ with the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ introduction, which indicates the presence of the photo-induced energy transfer or electron transfer from BL to $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ due to the formation of BI $\small { . / \mathrm { P C } _ { 6 1 } \mathrm { B M } }$ complexes, although we could not figure out which one of them dominates at this stage. The red-shift in UV-vis spectra and the decreased intensity of BL peaks in fluorescence spectra reveal that the BL could interact with $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ to form complex due to the supramolecular interactions and the electronic structure of BL is perturbed to some extent upon blending with $\mathrm { P C } _ { 6 1 } \mathrm { B M }$

The presence of the supramolecular interaction between BL and $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ will bring effect on the crystallization of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and thus change the crystallization behavior of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ as shown in Figure 2, which gives the optical images of neat $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , neat BL, and $\mathrm { P C } _ { 6 1 } \mathrm { B M : B L }$ blend films with different blending ratios before and after annealing. In order to better resolve the small crystallites and assign the crystals, the blend films are also investigated by atomic force microscopy (AFM) and X-ray diffraction (XRD), shown in Figures S4 and S5, Supporting Information, separately. Figure 2a shows that the homogeneous $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ film is formed during the spin-coating process, while after annealing at $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $1 \textrm { h }$ , numerous needle-shaped micro-scale $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystals are formed, and the surface roughness of height image increases sharply to $2 1 1 \mathrm { n m }$ from initial $0 . 4 \mathrm { n m }$ (Figure S4a, Supporting Information). Once BL introduced $( \mathrm { P C } _ { 6 1 } \mathrm { B M : B L } = 1 { : } 0 . 2$ by weight), as expected, it could interact with $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and depress the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystallization. Although the pristine $\mathrm { P C } _ { 6 1 } \mathrm { B M : B L }$ blend film does not show differences in morphology in comparison with the neat $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , the annealed blend film shows much less $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystals (Figure 2b). If BL increases to an appropriate amount $( \mathrm { P C } _ { 6 1 } \mathrm { B M } { : } \mathrm { B L } \ = \ 1 { : } 0 . 5 $ in this case), no $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystals are observed both for pristine and annealed blend films, and the surface of the film keeps smooth $ { \langle 1 . 2 7 \ \mathrm { n m } }$ of roughness) even after $3 6 \mathrm { ~ h ~ }$ of heating (Figure S4c, Supporting Information), which indicates that the BL molecules are fully dispersed in and interacted with $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ molecules at this point, and the crystallization of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ is greatly depressed by supramolecular interactions between $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and BL.

# 2.2. Supramolecular Interactions in P3HT:PC6BM:BL Ternary System

The interactions of BL with $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ in $\mathrm { B L } { : } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ binary system have been demonstrated above. However, whether the electron donor in a typical active layer of the polymer solar cells affects or interferes the interaction between BL and $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ is unclear. In this section, a series of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend films containing $0 \%$ $4 \%$ $8 \%$ , and $1 6 \%$ of BL (relative to $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ weight) is prepared and the influence of BL on $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend is investigated.

The morphology evolution of $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ blend films with thermal annealing is first monitored by optical microscopy (OM), as shown in Figure 3, from which it can be seen that the morphology of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend film without BL is most sensitive to thermal annealing: macrographic phase separation appears after $2 5 ~ \mathrm { m i n }$ , evolves as time going, and finally fixes after $3 \mathrm { ~ h ~ }$ . The changes of the position of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystalline and melting peaks are attributed to the supramolecular interaction between $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and BL: more BL in $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend is, more $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ molecules interact with BL molecules, resulting in higher thermal energy needed for $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ to overcome barrier to crystallize, thus the crystalline peak shifts to higher temperature. In return, the presence of supramolecular interaction leads to the formation of impure $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystals interspersed with BL, therefore, the melting peak shifts to lower temperature with the increase in BL content. For $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ $( 1 6 \% )$ blends, the absence of crystalline peak does not imply no $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystallization during heating because the melting peak of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ is still observed. It is speculated that the crystalline peak perhaps right-shifts to overlap with the P3HT melting peak, leading to the widened P3HT melting region. While for $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ $( 3 2 \% )$ blend film, both crystalline and melting peaks are unobserved. Two possible reasons are accounted for this: (1) $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ does not crystallize during heating; (2) $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystallizes during heating with its crystalline peak right-shifting and melting peak left-shifting to overlap with the P3HT melting peak. No matter which one is accounted for, it is concluded that $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ is more struggling to crystallize with addition of $3 2 \%$ BL.

# 2.3. Supramolecular Interactions Benefit Stable Percolating Electron Transport Pathways

In photovoltaic devices, the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ component in the active layer carries electron transport.[22] The influence of BL on the electron mobility of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend film is investigated, and the results are given in Figure 7 and the processed data are shown in Figure S9, Supporting Information. It can be seen that the electron mobility of the device without thermal annealing monotonically decreases with BL content (from $1 . 3 6 \times 1 \bar { 0 } ^ { - 4 } \mathrm { ~ c m } ^ { 2 } \mathrm { ~ s } ^ { - 1 } \mathrm { ~ V } ^ { - 1 }$ to $0 . 4 6 \times 1 0 ^ { - 4 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } \ \mathrm { V } ^ { - 1 }$ , Figure 7a), which is speculated to be caused by the fact that the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ phase is uniformly dispersed due to the restriction by the $\mathrm { B L } { \cdot } \mathrm { C } _ { 6 0 }$ supramolecular interactions.[24] To investigate the influence of incorporating BL on electron mobility under thermal stress, $\mathrm { P 3 H T : P C _ { 6 1 } B M : B I }$ $( 8 \% )$ devices as well as $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ devices were thermally annealed at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for $2 5 ~ \mathrm { m i n }$ , 1, and $3 \mathrm { { h } }$ separately before evaporation of top electrode. It can be seen that the electron mobility for $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ $( 8 \% )$ device increases ceaselessly as thermal annealing time prolonged, reaching $1 . 9 1 \times 1 0 ^ { - 4 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } \ \mathrm { V } ^ { - 1 }$ after $^ { 3 \mathrm { ~ h ~ } }$ heating (Figure 7b). This indicates that a long-time treatment is needed for $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ to overcome $\mathrm { B L } { \cdot } \mathrm { C } _ { 6 0 }$ supramolecular attractions and form continuous percolating electron transport pathways. In contrast, the electron mobility for $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ device increases first to $1 . 8 2 \times 1 0 ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { s } ^ { - 1 } \mathrm { V } ^ { - 1 }$ by short thermal annealing but decreases to $0 . 3 6 \times 1 0 ^ { - 4 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } \ \mathrm { V } ^ { - 1 }$ by further heating (Figure 7c). This indicates that good percolating electron transport pathways can be formed by short thermal treatment but deteriorated quickly by a further treatment. It is believed that the different trends of electron mobility as annealing time relates closely to their corresponding morphological stability shown in Figure 3.

# 2.4. Supramolecular Interactions Enhance Thermal Stability of PSCs

To investigate the influence of BL incorporation on the thermal stability of photovoltaic devices, a series of devices based on $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blend films with different BL content were fabricated. The effect of BL on the stability of PSC devices was investigated by isothermal annealing at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for different time. Electron buffer layer (LiF) and an aluminum electrode were evaporated onto the active layer after thermal treatment, for eliminating interference of thermal treatment on buffer layer and electrode. The detailed photovoltaic parameters of all the devices are summarized in Tables S1 and s2, Supporting Information. The $J { - } V$ curves (Figure 8a) and corresponding photovoltaic parameters in Table S1, Supporting Information, show that the PCE decreases from $3 . 2 0 \%$ to $2 . 0 2 \%$ as BL content increases from $0 \%$ to $1 6 \%$ . And the decay of PCE values mainly results from the decreased $J _ { \mathrm { s c } }$ (from 8.83 to $7 . 7 2 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ ) and FF (from $6 7 . 1 0 \%$ to $5 1 . 3 0 \%$ , which can be attributed to the lower electron mobility as discussed above. To exclude the difference in initial efficiency, the relative efficiency $\eta _ { \mathrm { : } }$ which is defined as the ratio of $\mathrm { P C E } _ { \mathrm { t } }$ to $\mathrm { P C E } _ { 0 }$ $\mathrm { P C E } _ { \mathrm { t } }$ and $\mathrm { P C E } _ { 0 }$ are the efficiencies of the devices with active layers isothermally annealed at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for $t$ and $2 5 \ \mathrm { m i n }$ , respectively), is used to indicate the maintenance of the device performance instead of absolute efficiency. Figure 8b clearly illustrates that the curve of efficiency decaying as a function of thermal annealing time changes gently for device with higher BL-loading, which indicates that the ability to preserve efficiency becomes stronger. Without addition of BL, the PCE decays rapidly and remains $2 8 . 4 \%$ $( \mathrm { P C E } = 0 . 9 1 \% )$ of the original value after $3 \mathrm { ~ h ~ }$ Of heating. In contrast, 12, 24, and more than $4 8 \mathrm { ~ h ~ }$ of heating are needed for the devices loaded with $2 \%$ $4 \%$ , and $8 \%$ BL, respectively, to decay to the similar $\eta$ (Table S2, Supporting Information). A special attention should be paid to device loaded with $8 \%$ BL, although the original PCE $( 2 . 4 3 \% )$ is lower relative to $3 . 2 0 \%$ (in case of no BL), it does not decrease after $4 8 \mathrm { ~ h ~ }$ of heating. Interestingly, its best peak PCE, $2 . 7 5 \%$ , occurs after $3 \mathrm { { h } }$ of annealing, which is in good agreement with the fact that the $3 \mathrm { { h } }$ of heating is needed for the ${ \mathrm { P 3 H T : P C } } _ { 6 1 } { \mathrm { B M : B L } } ( 8 \% )$ blend films to form optimized percolating electron transport pathways and achieve a high electron mobility.[28]

The performance data shown in Figure 8b and Table S1, Supporting Information, reveal that the incorporation of BL into $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ solar cells improves the thermal stability of devices. The performance change is also consistent with the corresponding morphological evolution shown in Figure 3. It is important to note that all the devices were fabricated under the conditions that are optimal for the $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ blends, which may not be the best for $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ blends. In other words, higher initial efficiencies of the devices incorporated with varied content of BL could be achieved by further optimizing the individual fabrication conditions.

# 2.5. Mechanism for Enhancement of Thermal Stability

Based on the facts and analysis, a possible mechanism is proposed for the morphological evolution of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ and $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ blend films,[29] as given in Figure 9. Upon thermal annealing of the as-cast $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ thin film at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for $2 5 \mathrm { { m i n } }$ , the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ molecules, originally dispersed and intercalated in the P3HT domains (Figure ${ \mathfrak { g } } _ { \mathrm { a } _ { 0 } } )$ , can freely diffuse out of these mixed regions to aggregate into pure $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ clusters. The $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ diffusion induces simultaneously more ordered packing of P3HT, leading to an optimized morphology for efficient exciton dissociation and charge transport (Figure $9 \mathrm { b } _ { 0 } \mathrm { \vert }$ . However, over-long thermal annealing causes the formation of large size $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ aggregates, which reduces the percolating electron transport pathways within the mixed regions and thus increases the charge recombination losses (Figure $9 \mathrm { c } _ { 0 }$ . Therefore, although the $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ device delivers the highest PCE value of $3 . 2 \%$ at the beginning, its morphological stability, electron mobility, and device performance against heating turns out to be the worst.

# 2.6. Applicability of Porphyrin

From above we can see that the porphyrin with the given structure significantly increases the thermal stability of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ based Psc device. In fact, this method could also be applied to other porphyrins. For example, our preliminary data show that the porphyrins with different core metal ions (Mn, Zn, Cu) and substituted groups (nitro, 4-chlorooctafluorobutyl) have different effects on the performance of $\mathrm { P 3 H T : P C _ { 6 1 } B M }$ devices: some of them with specific structure not only maintain the original PCE $3 . 1 4 \% - 3 . 3 4 \% )$ , but also keep the values unchanged up to $^ { 3 \mathrm { ~ h ~ } }$ at $1 3 0 ~ ^ { \circ } \mathrm { C }$ Furthermore, encouraging results also emerge for low band gap based devices (all these data will be reported later). Therefore, this strategy of incorporating porphyrin into active layer to increase the PSC thermal stability is universal and would show great potentials in scientific research and real application of polymer solar cells.

# 3. Conclusion

In this paper, the porphyrin compound is smartly utilized as a new kind of additive materials to control BHJ morphology and enhance the thermal stability of PSCs. It is found that the BL could effectively suppress the n-type $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ materials from extensive thermal-driven aggregation to overcome the morphological instability through supramolecular $\mathrm { B L } { \cdot } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ interactions. The extent of the physical interaction can be adjusted by simply varying the content of porphyrin. In $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ : BL binary system, $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ could not crystallize by addition of 0.5 equivalent amount of BL even after $3 6 \mathrm { ~ h ~ }$ of heating at $1 5 0 ~ ^ { \circ } \mathrm { C }$ In $\mathrm { P 3 H T : P C _ { 6 1 } B M : B L }$ ternary system, the effect of BL on the morphological stability is reflected from the mitigated morphological evolution, reduced rate of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ crystallization, and increased crystallization and decreased melting temperature of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , respectively, which heavily depends on BL content. This stabilized morphology is of beneficial for devices maintaining high electron mobility and favorable performance even after a long-time heating. For example, doping $8 \%$ porphyrin BL (relative to the weight of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ makes the device only decaying $1 0 . 5 \%$ of its original PCE after $^ { 4 8 \mathrm { ~ h ~ } }$ of annealing at $1 3 0 ~ ^ { \circ } \mathrm { C }$ while no BL addition results in $7 1 . 5 \%$ decaying after only $^ \textrm { \scriptsize 3 h }$ of annealing. Our preliminary data show that this strategy could also be applied to other porphyrins. Given the nature of supramolecular interaction ( $\pi$ system of porphyrin interacting with $\pi$ system of $\mathrm { C } _ { 6 0 }$ cage), it is reasonable that this strategy will promote the extensive application of other macrocyclic compounds to achieve stabilization of PSCs.
