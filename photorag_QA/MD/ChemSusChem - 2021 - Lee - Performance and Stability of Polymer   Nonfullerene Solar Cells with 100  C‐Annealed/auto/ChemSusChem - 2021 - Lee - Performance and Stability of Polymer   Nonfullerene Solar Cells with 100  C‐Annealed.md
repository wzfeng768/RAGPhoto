# Introduction

Organic solar cells (Oscs) have been extensively spotlighted because of their potentials, including continuous roll-to-roll fabrication of flexible solar modules at low temperatures.1-3] Since the concept of bulk heterojunction (BHJ) has been introduced into ${ \mathsf { O S C s } } ,$ the power conversion efficiency (PCE) of single-junction polymer:fullerene-based OsCs has been remarkably improved up to $1 4 \%$ thanks to novel light-absorbing conjugated polymers.4-8] In recent years, the fullerene derivatives as electron acceptor have been replaced by nonfullerene materials with extended light absorption characteristics.9-15] Such brand-new polymer:nonfullerene solar cells showed PCEs around $1 8 \%$ due to the extended light absorption toward near infrared (NIR) range and improved charge transport characteristics of nonfullerene acceptors.16-18] Most high-efficiency polymer:nonfullerene solar cells so far have been fabricated with an junction layers. Results showed that the power conversion efficiency of solar cells reached approximately 9.38 and $1 0 . 1 1 \%$ (average) in case of the ZnO/PEOz and $Z n { \mathsf { O } } { : } { \mathsf { P E O z } } ( 6 \ \mathsf { w t } \% \ \mathsf { P E O z } ) /$ PEOz combination layers, respectively, despite the low-temperature thermal annealing process. A continuous irradiation test for $^ { 1 2 \mathrm { ~ h ~ } }$ under one sun condition (air mass 1.5G, $1 0 0 \mathrm { m W } \mathsf { c m } ^ { - 2 } )$ disclosed that the devices with the $Z n { \mathsf { O } } { : } { \mathsf { P E O } } z ( 6 \ \mathsf { w t } ^ { \circ } / _ { 0 } \ \mathsf { P E O } z ) /$ PEOz combination layers were more stable than those with the ZnO/PEOz layers.

For the metal oxide-based ECBLs, zinc oxide (ZnO) precursor routes were mostly employed because of suitable work function of ${ \tt Z n O }$ $( \approx 4 . 3 \ : \mathrm { e V } )$ for electron collection and wet-coating process using precursor solutions at room temperature.24-27] However, thermal annealing processes at high temperatures (up to $2 0 0 ^ { \circ } \mathsf { C } )$ were applied for securing high electron mobility and good film quality.28,291 This high-temperature process is a critical drawback in the advantageous roll-to-roll processes using flexible substrates.30] In this regard, ZnO nanoparticles were introduced as an ECBL, which required a mild thermal annealing process at $1 0 0 ^ { \circ } \mathsf { C }$ because their crystalline nanostructures could be already well made in the synthesis step.131-33] However, the varied size of ${ \tt Z n O }$ nanoparticles and resulting roughness in the layers of ${ \sf z n o }$ nanoparticles have been a drawback in terms of long-term durability of particle assemblies.34] As an alternative approach, hybrid films of ZnO and poly(2-ethyl-2-oxazoline) (PEOz) have been reported to still deliver high PCEs for the inverted-type polymer:nonfullerene solar cells even though they were thermally annealed at a temperature as low as 120c.35-37]

It has been reported that the interlayers in the invertedtype polymer:nonfullerene solar cells play a crucial role in increasing the built-in potentials of devices via work function changes caused by the formation of dipoles on the metal oxide layers (ECBLs).38-40 In this regard, materials with polar groups and/or permanent charges have been applied, including polymers such as poly(ethyleneimine) (PEl) or polyethyleneimine-ethoxylated (PEIE) $, ^ { [ 4 1 - 4 4 ] } \ P E O z , ^ { [ 4 5 ] }$ and polyimides (Pls).46,47] However, the thickness of most polymeric interlayers should be controlled below a several nanometer scale because of their electrical insulating characteristics.

In this study, we have attempted to further reduce the thermal annealing temperature down to $1 0 0 ^ { \circ } \mathsf { C }$ for the ZnO:PEOz hybrid ECBLs and form the PEOz interlayers on the low-temperature-processed $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ Iayers. As a BHJ layer, blends of poly[(2,6-(4,8-bis(5-(2-ethylhexyl)thiophen-2-yl)-benzo [1,2-b:4,5-b']dithiophene)-alt-(5,5-(1',3-di-2-thienyl-5',7-bis(2- ethylhexyl)benzo[1' $, 2 ^ { \prime } { \mathsf { - c } } : 4 ^ { \prime } , 5 ^ { \prime }$ -c'ldithiophene-4,8-dione))] (PBDBT) and 3,9-bis(6-methyl-2-methylene-(3-(1,1-dicyanomethylene)- indanone))-5,5,11,11-tetrakis(4-hexylphenyl)-dithieno[2,3-d: 2',3'- d']-s-indaceno[1,2-b:5,6-b']dithiophene (IT-M) were employed with a blend ratio of PBDB-T:IT-M $= 1 : 1$ by weight. To investigate the composition effect in the $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ layers, the PEOz content was varied from 0 to $1 2 \mathrm { \Delta w t } \%$ . Results showed that a maximum PCE of $1 0 . 5 9 \%$ could be achieved from the PBDB-T:IT-M solar cells with the $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P E O } } z / { \mathsf { P E O } } z$ combination layers at the $\mathsf { P E O z }$ content of $6 \mathrm { w t } \%$ The stability of optimized devices was investigated under continuous illumination of simulated solar light (one sun condition).

# Results and Discussion

As shown in Figure 1a, PBDB-T:IT-M solar cells were fabricated by employing ZnO:PEOz/PEOz combination layers. The ZnO:PEOz/PEOz combination layers were thermally annealed at $1 0 0 ^ { \circ } \mathsf { C }$ before spin-coating the BHJ layers (see details in the Experimental Section). The resulting solar cells have a device structure of glass/indium tin oxide (ITO)/ZnO:PEOz/PEOz/PBDB$\mathsf { T } { : } \mathsf { I T - M / M o O } _ { 3 } / \mathsf { A g }$ (see the energy band/level diagram of device in Figure 1b). As observed from Figure 1c (see Figure S1), the optical transmittance was very slightly changed with the $\mathsf { P E O z }$ content in the ZnO:PEOz/PEOz combination layers. Note that the relatively low transmittance $( < 7 5 \% )$ below a wavelength of $\lambda \approx 3 4 0 ~ \mathrm { n m }$ can be attributed to the optical absorption of the ZnO components (see the inset graph for the optical transmittance of pristine films). A detailed investigation disclosed that the variation of optical transmittance was approximately $1 . 6 5 \%$ at $\lambda { = } 6 0 0 ~ \mathsf { n m }$ according to the PEOz content. This small variation may more or less affect the actual intensity of solar light incident to the BHJ layers when it comes to the spectral range of simulated solar light $( \lambda = 4 0 5  – 1 0 0 0 \mathsf { n m } )$ [48]

The performances of the PBDB-T:IT-M solar cells with the $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z / { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ combination layers were measured under the illumination of simulated  solar light (air mass 1.5G, $1 0 0 \mathrm { m W } \mathsf { c m } ^ { - 2 } )$ . As shown in Figure 2a, the current densityvoltage $( J - W )$ curves were noticeably changed with respect to the PEOz content. Basically, the $J { - } V$ curve at $0 \mathrm { { w t } \% }$ $\mathsf { P E O z }$ exhibited a good shape without any sigmoidal part even though the ZnO/PEOz layers were annealed at $1 0 0 ^ { \circ } \mathsf { C } .$ As the $\mathsf { P E O z }$ content increased up to $6 \mathrm { w t } \%$ the $J { - } V$ curve became gradually shifted toward higher current density (see Figure S2 for the enlarged $J { - } V$ curves). Further increase of PEOz content (9 and $1 2 \mathrm { w t } \% )$ resulted in relatively poorer $J { - } V$ curves. However, the external quantum efficiency (EQE) spectrum of devices was almost similar irrespective of the PEOz content (see Figure S3). As a consequence, the power density-voltage (P-) curves showed that the highest power density of $1 0 . 6 2 \mathrm { \ m W } \mathrm { c m } ^ { - 2 }$ (at $0 . 7 6 \forall )$ was achieved at the PEOz content of $6 \mathrm { w t } \%$ (see Figure 2b and Figure S4).

The detailed trend of solar cell parameters was further investigated as shown in Figures 2c-f. The open-circuit voltage $( V _ { \mathrm { o c } } )$ of devices was almost similar without large variations even though the PEOz content was increased up to $1 2 \mathrm { \Delta w t } \%$ (see Table1 and Table S1). This result shows that the built-in potential in the devices was almost similarly set in the presence of the $\mathsf { P E O z }$ interlayers and no huge rise of electrical resistance was made by the increased PEOz amount in the $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ Iayers. In contrast, as mentioned above in Figure 2a, the shortcircuit current density $( J _ { \mathsf { S C } } )$ was gradually increased as the $\mathsf { P E O z }$ content increased up to $6 \mathrm { w t } \%$ and decreased by further increase of PEOz content (see the calculated $J _ { \mathsf { S C } }$ from the EQE spectra in the inset table of Figure S3). The highest $J _ { \mathsf { S C } }$ value can be explained by the lowest series resistance $( R _ { 5 } { = } 0 . 1 3 ~ \mathsf { kOmega } )$ at the PEOz content of $6 \mathrm { w t } \%$ (see Figure S5 and Table 1), which is in line with the previous result of thermal annealing at $12 0 ^ { \circ } \mathsf { C }$ [35] This trend is also supported by the dark $J { - } V$ curves that show the higher current density $( 0 . 9 { - } 1 . 2 \lor )$ at $6 \mathsf { w t } \%$ than 0 and $1 2 \mathrm { \Delta w t } \%$ (see Figure S6a), while the dark $J { - } V$ curves resulted in fairly good on/off ratios $( R _ { \mathrm { o n / o f f } } \approx 2 . 7 – 4 . 2 \times 1 0 ^ { 5 }$ at $\pm 1 \vee ;$ see Figure S6b).

In addition, as observed from the atomic force microscope (AFM) images in Figure3, the textured surface with some nanocrater structures in the ZnO:PEOz/PEOz combination layers $( 6 \mathrm { ~ w t } \% )$ might extend the area of interfacial contacts with the BHJ layers so that the electron transfer from the BHJ layers could be enhanced leading to the highest $J _ { \mathsf { S C } }$ at the $\mathsf { P E O z }$ content of $6 \mathrm { w t } \%$ . This is evidenced by the highest electron mobility $( \mu _ { \mathrm { e } } )$ at $6 \mathsf { w t } \%$ (see Figure S7), which was obtained from the space charge limited current (SCLC) model of electron-only devices $( 1 \mathsf { T O } / \mathsf { Z n O } : \mathsf { P E O } z / \mathsf { P E O } z / \mathsf { A l } )$ in the dark condition. At the higher PEOz contents, however, the $J _ { \mathsf { S C } }$ value was lowered because the texture of combination layers became less fine in addition to higher loadings of insulating PEOz components (note that the PEOz interlayers are considered to be conformally coated on the surface of the ZnO:PEOz ECBLs). A similar parabolic trend was obtained for the fill factor (FF). As a result, the highest PCE of $1 0 . 5 9 \%$ (maximum) could be achieved at the PEOz content of $6 \mathsf { w t } \%$ . Here it is noted that all devices show a similar range of shunt resistance $( R _ { \mathsf { S H } } )$ under the simulated solar light (Figure S5b), even though the intrinsic shunt characteristics of devices might be relatively poorer for the $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ Iayers than the pristine ${ \tt Z n O }$ layers (see Figure S6c for the shunt resistances in the dark).

To investigate the stability of devices, the PBDB-T:IT-M solar cells with the ZnO:PEOz/PEOz combination layers (0 and $6 \mathsf { w t } \%$ PEOz) were chosen and their performances were measured under continuous illumination with simulated solar light (air mass $1 . 5 6 ,$ $1 0 0 \mathrm { m W } \mathsf { c m } ^ { - 2 } )$ for $^ { 1 2 \mathrm { ~ h ~ } }$ . As shown in Figure 4 (see Figure S8), in the case of $0 \mathrm { { w t } \% }$ solar cells (ZnO/PEOz combination layers), the $J { - } V$ curve became gradually poor with the irradiation (exposure) time in the evolution of noticeable sigmoidal shape after $^ { 2 \mathfrak { h } }$ . When the exposure time reached $^ { 7 \mathrm { h } , }$ the $J { - } V$ curve did almost lose a proper shape of normal solar cells (see the $J { - } V$ curves up to $1 2 \mathrm { ~ h ~ }$ in Figure S8). A similar gradual deterioration in the $J { - } V$ curve shape was measured in the case of the $6 \mathrm { w t } \%$ solar cells $( Z \mathsf { n O } : \mathsf { P E O } z / \mathsf { P E O } z$ combination Iayers), but the sigmoidal shape appeared after $4 \ h ,$ which is a two-fold extended time compared to the $0 \mathrm { { w t } \% }$ solar cells. In addition, the $J { - } V$ curve shape at $^ { 7 \mathrm { ~ h ~ } }$ was obviously better for the $6 \mathrm { w t } \%$ solar cells than the $0 \mathrm { { w t } \% }$ solar cells (see Figure S8 for $1 2 \mathrm { ~ h ~ }$ cases). Basically, the fast decay of solar cell performances can be ascribed to the degradation in the BHJ (PBDB-T:IT-M) layers as reported in the previous works.47-49] Nevertheless, the slower decay for the $6 \mathrm { w t } \%$ solar cells than the $0 \mathrm { { w t } \% }$ solar cells can be attributed to the benefit of hybrid combination layers $( Z \mathsf { n O } : \mathsf { P E O } z / \mathsf { P E O } z )$ with the fine texture structures that could improve adhesion between the BHJ and combination Iayers (see AFM images in Figure 3).

To understand the quick decay in the solar cell performances, the samples (glass/ITO/ZnO:PEOz/PEOz/PBDB-T:IT-M) before $( 0 \mathsf { h } )$ and after exposure to the simulated solar light (air mass 1.5G, $1 0 0 \mathrm { m } \mathsf { W } \mathsf { c m } ^ { - 2 } )$ for $^ { 1 2 \mathrm { ~ h ~ } }$ were subjected to optical absorption measurements. [50] for the effect of polymer additive with high thermal stability in the active layer). Here it is worthy to note that the huge reduction in $J _ { \mathsf { S C } }$ cannot be explained by the optical absorbance change only after $^ { 1 2 \mathrm { ~ h ~ } }$ exposure under the simulated solar light. # Conclusion

The inverted-type PBDB-T:IT-M solar cells with the ZnO:poly(2- ethyl-2-oxazoline) (PEOz)/PEOz combination layers, which were thermally annealed at $1 0 0 ^ { \circ } \mathsf { C } ,$ were successfully fabricated by varying the PEOz content in the ZnO:PEOz electron-collecting buffer layers (ECBLs). The short-circuit current density $( J _ { \mathsf { S C } } )$ of devices was varied with the PEOz content, whereas the opencircuit voltage $( V _ { \mathrm { o c } } )$ value was almost independent of the $\mathsf { P E O z }$ content. The $\mathsf { P E O z }$ content of $6 \mathrm { w t } \%$ delivered the highest $J _ { \mathsf { S C } }$ values, but addition of more PEOz decreased the device current. The fill factor showed a similar trend as $J _ { \mathsf { S C } } ,$ leading to the highest power conversion efficiency of $1 0 . 5 9 \%$ at the $\mathsf { P E O z }$ content of $6 \mathsf { w t } \%$ The highest performance at the PEOz content of $6 \mathrm { w t } \%$ has been assigned to the improved electron transfer by the formation of increased interfacial contacts between the bulk heterojunction (BHJ) and combination layers due to the fine textured structures with some nanocrater shapes. The stability test showed that the performance of the present PBDBT:IT-M solar cells, irrespective of PEOz content, decayed quickly under continuous illumination with simulated solar light. However, the solar cell with. $Z _ { \mathsf { n } } { \mathsf { O } } : { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z / { \mathsf { P } } { \mathsf { E } } { \mathsf { O } } z$ combination layers $( \mathsf { P E O z } { = } 6 \mathsf { w t } \% )$ was relatively more stable than that with ${ \tt Z n O } /$ PEOz combination layers $( \mathsf { P E O z } { = } 0 \mathsf { w t \% } )$ . The low stability of devices has been attributed to the reduced optical absorption $( \Delta \mathsf { A b s } \approx 1 7 - 2 4 \% )$ of BHJ films under continuous solar light illumination, but this could not completely explain the huge reduction in $J _ { \mathsf { S C } }$ $( \Delta J _ { \mathsf { S C } }$ after $^ { 1 2 \mathrm { ~ h ~ } }$ exposure: 68.72 and $3 5 . 2 7 \%$ at $\mathsf { P E O Z } = 0$ and $6 \mathsf { w t } \% ,$ respectively). The relatively poor stability for the $0 \mathrm { { w t } \% }$ solar cells was explained by the much larger increase in series resistance with the exposure time, which might be caused by several reasons including interfacial degradations, even though the increase in series resistance was quite small for the $6 \mathrm { w t } \%$ solar cells thanks to the improved interfacial adhesion by the finely textured structures. The present study stresses that the ZnO:PEOz/PEOz combination Iayers play a crucial role in improving both efficiency and stability when the hybrid combination layers are thermally annealed even at a low temperature $( 1 0 0 ^ { \circ } \mathsf { C } )$

# Materials and solutions

PBDB-T (number-average molecular weight: $1 8 \mathsf { k D a }$ polydispersity index: 2.5) and IT-M were received from Solarmer Materials Inc. (China). Zinc acetate dihydrate, 2-methoxyethanol, ethanolamine, PEOz (weight-average molecular weight: $5 0 ~ \mathsf { k D a } _ { i }$ polydispersity index: 3.5), and all solvents including methanol and chlorobenzene were purchased from Sigma Aldrich (USA). The ZnO:PEOz precursor solutions were prepared by mixing zinc acetate dihydrate $( 1 0 0 ~ \mathsf { m g } )$ and $\mathsf { P E O z } ,$ by varying the weight ratio from 0 to $1 2 \mathsf { w t } \%$ in 2- methoxyethanol $( 1 ~ \mathsf { m L } )$ in the presence of ethanolamine $( 2 8 \mu \ L )$ The precursor solutions were stirred at $6 0 ^ { \circ } \mathsf { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ and then kept at $2 5 ^ { \circ } \mathsf { C }$ for $2 4 \mathrm { h }$ for completing sol-gel reactions. The pristine $\mathsf { P E O z }$ solution was prepared by dissolving PEOz (4 mg) in methanol $( 1 ~ \mathsf { m L } )$ . The blend (PBDB-T:IT-M) solutions were prepared by mixing PBDB-T $( 9 . 5 { \mathsf { m g } } )$ and IT-M $( 9 . 5 ~ \mathsf { m g } )$ in chlorobenzene, followed by addition of 1.8-diiodooctane $( 1 0 ~ \mu \ L )$ as an additive, and stirred at $2 5 ^ { \circ } \mathsf { C }$ for $4 8 \mathrm { ~ h ~ }$

# Film and device fabrication

The patterned ITO-glass substrates (sheet resistance $\approx 1 2 \Omega \mathsf { c m } ^ { - 2 } )$ - which were prepared using photolithography and etching processes, were cleaned sequentially in acetone and isopropyl alcohol using an ultrasonicator and dried under a nitrogen flow. The cleaned ITO-glass substrates were treated inside ultraviolet-ozone cleaner $( \mathsf { A C - } 6 ,$ Ahtech LTS) for $2 0 \mathsf { m i n }$ to remove any contaminated residues on the ITO surfaces. The ZnO:PEOz precursor solutions with $0 { - } 1 2 \mathrm { w t } \%$ PEOz contents were spun on the ITO-glass substrates at 4000 rpm for $3 0 ~ s$ and annealed at $1 0 0 ^ { \circ } \mathsf { C }$ for $1 \mathrm { ~ h ~ }$ to form the hybrid $( Z \mathsf { n O } : \mathsf { P E O z } )$ Iayers. The PEOz interlayers were formed on the ZnO:PEOz layers by spin-coating using the PEOz solution at 1500 rpm for 60 s and subjected to thermal treatment at $1 0 0 ^ { \circ } \mathsf { C }$ for $1 5 \mathrm { \sf m i n }$ . Next, the PBDB-T:IT-M (BHJ) layers were spincoated on the $\mathsf { P E O z }$ interlayer-coated samples inside a nitrogenfilled glovebox at 2500 rpm for $6 0 ~ 5$ and dried at $4 0 ^ { \circ } \mathsf { C }$ for $5 \mathsf { m i n }$ The samples were moved into a vacuum chamber system inside an argon-filled glovebox for the deposition of ${ \mathsf { M o O } } _ { 3 }$ layers $( 1 0 \mathsf { n m } )$ and Ag electrodes $( 8 0 \mathsf { n m } )$ at a base pressure of approximately $1 \times$ $1 0 ^ { - 6 }$ torr (vacuum). The fabricated devices with an active area of $0 . 0 5 2 ~ { \mathsf { c m } } ^ { 2 }$ were stored inside an argon-filled glovebox before for measurements. The electron-only devices $( \mathsf { I T O } / \mathsf { Z n O } : \mathsf { P E O } z / \mathsf { P E O } z / \mathsf { A l } )$ were fabricated by depositing $9 0 \mathsf { n m }$ -thick aluminum (Al) electrodes on the ZnO:PEOz/PEOz combination layers in the same vacuum chamber as used for the solar cell fabrications.

# Measurements

The optical transmittance and absorption spectra of film samples were measured using a Uv/Vis/NIR spectrometer (Lambda 750, Perkin Elmer). The thickness of films and metal electrodes was measured using a surface profiler (DektakXT-E, Bruker). The surface morphology of combination layers was measured using AFM (Nanoscope Illa, Digital Instruments). The capacitance of films was measured using an impedance analyzer (VersaSTAT 4, Ametek, Inc.). The dark $J { - } V$ curves of electron-only devices were measured using a source meter (Keithley 240o, Keithley Instruments), which were used for the calculation of electron mobility by employing an SCLC model. The performance of solar cells was measured using a solar cell measurement system equipped with a solar simulator (92250A100, Newport-Oriel, air mass 1.5G) and a source meter (Keithley 2400, Keithley Instruments). The intensity of simulated solar light $( 1 0 0 \mathsf { m w c m ^ { - 2 } } )$ was adjusted using a calibrated standard cell (BS520, Bunkoukeiki Co. Ltd). A sample holder filled with an argon and/or nitrogen gas was used for the solar cell measurements. The EQE spectra of devices were measured using a specialized EQE measurement system equipped with a light source (AsBN-w, Spectral Products, tungsten-halogen lamp, $1 5 0 W )$ and a monochromator (CM-110, Spectral Products). For the stability measurement, the same sample holder with solar cells was mounted underneath the solar simulator and the $J { - } V$ curves were measured with an interval of 1 h at room temperature.
