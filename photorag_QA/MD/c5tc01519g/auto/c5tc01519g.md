# From non-detectable to decent: replacement of oxygen with sulfur in naphthalene diimide boosts electron transport in organic thin-film transistors (OTFT)

Wangqiao Chen,ab Jing Zhang,a Guankui Long,a Yi Liuc and Qichun Zhang\*abd

Enhancing the electron mobility of organic conjugated materials without tedious modification or synthesis is highly desirable and practical. In this research, we demonstrated that the electron mobility of naphthalene dimide (NDI) in thin film transistors (TFTs) under ambient conditions can be dramatically enhanced through a simple step reaction by replacing oxygen atoms with sulfur atoms. The electron mobilities of the as-prepared compounds range from non-detectable (parent NDI), to $3 . 0 ~ \times$ $1 0 ^ { - 4 } \ c m ^ { 2 } \ \vee ^ { - 1 } \ \varsigma ^ { - 1 }$ (NDI-1S). $3 . 0 \times 1 0 ^ { - 3 } \mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } \mathsf { s } ^ { - 1 }$ (NDI-3S). $3 . 7 \times 1 0 ^ { - 3 } \mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } \mathsf { s } ^ { - 1 }$ (NDI-2S-cis), and $0 . 0 1 \ \mathsf { c m } ^ { 2 } \ \mathsf { V } ^ { - 1 } \ \mathsf { s } ^ { - 1 }$ (NDI-2s-trans) with on/off ratios as high as $4 \times 1 0 ^ { 5 }$ . Our primary result suggests that thionation could be a promising method to tune the band position and bandgap of organic semiconductors for high performance TFTs.

# Introduction

Organic semiconducting materials have been widely investigated for many organic electronic devices including organic field-effect transistors,1-5 sensors,6-11 and photovoltaics12-14 due to their desirable advantages such as solution processing, large-area manufacture, and easy chemical functionalization. Although a large number of $\pi$ -conjugated semiconductors have been designed and prepared for applications in organic electronics, exactly how to realize high performance organic electronic devices with reasonable stability and repeatability through simple modification or synthesis is still a big challenge. At present, compared with p-type organic semiconductors, the research on n-type organic materials is relatively slow. One well-known strategy to achieve an n-type material with ideal mobility and ambient stability is to design and obtain a novel molecule with a suitable LUMO energy and an ideal molecule packing for effective charge (electron) transport.15-18 It has been widely demonstrated that the electron affinity and the air stability of the OFET device will increase simultaneously upon introducing electron-withdrawing groups, such as cyano (-CN),19 chlorine (-C1),20 or perfluoroalkyl $\left( - \mathbf { C } \mathbf { F } _ { 2 }  – \right) ^ { 2 1 , 2 2 }$ on the $\pi$ conjugated backbone or the substituted alkyl chain. Another approach is to extend the $\pi$ conjugated core to achieve graphene-like oligomers with rigid and almost planar superstructures, which could lead to excellent electron transport characteristics.3-26 Unfortunately, these approaches generally require multi-step synthesis. Thus, finding a simple and convenient method to develop novel molecules for high-performance n-type OFET is still highly desirable.

Among the current n-type small molecule systems such as naphthalene diimides (NDIs), perylene diimides (PDIs),27,28 quinoidal oligothiophenes (QoTs),29-32 isoindigo33-44 and fullerenes,35-37 NDI has been demonstrated to be a promising candidate with varying mobility due to its molecular diversity.38 Meanwhile, introducing sulfur atoms into acene frameworks has been proven to be a general strategy to obtain high charge transport mobility.39-42 Thus, replacing O with S in an NDI system has been supposed to be a good strategy to address the issues of mobility and stability because: (1) the S. : .S interaction could enhance the stability of the molecular arrangement in space; (2) the absorption and lowest unoccupied molecular orbital (LUmO) energy can be easily tuned by controlling the number of sulfur atoms; and (3) thionation can be completed in a one step reaction by using Lawesson's reagent (LR). In this research, the four compounds 2,7-bis(2-ethylhexyl)-8-thioxo-7,8- dihydrobenzo[lmn][3,8]phenanthroline-1,3,6(2H)-trione (ND1-1S),

2,7-bis(2-ethylhexyl)-3,6-dithioxo-2,3,6,7-tetrahydrobenzo-[lmn][3,8]- phenanthroline-1,8-dione (NDI-2S-cis),2,7-bis(2-ethylhexyl)-3,8- dithioxo-2,3,7,8-tetrahydrobenzo-[lmn][3,8]phenanthroline-1,6-dione (NDI-2S-trans), and 2,7-bis(2-ethylhexyl)-3,6,8-trithioxo-2,3,7,8- tetrahydrobenzo-[lmn][3,8]phenanthroline-1(6H)-one (NDI-3S) have been synthesized. Our studies indicate that more sulfur atoms will result in a more red-shift absorption as well as a lower LUMO and energy gap. The mobilities of all these materials have been investigated in air and NDI-2s-trans showed the best mobility of $0 . 0 1 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ while controlled NDI showed almost no field-effect under ambient conditions.

# OTFT device fabrication and measurements

An n-type heavily doped Si wafer with a $\mathrm { S i O } _ { 2 }$ layer of $5 0 0 \ \mathrm { n m }$ and a capacitance of $7 . 5 ~ \mathrm { n F } ~ \mathrm { c m } ^ { - 2 }$ was used as the gate electrode and dielectric layer. The thin films $\left( 4 0 – 6 0 \ \mathrm { n m } \right)$ of S-NDI/NDI were deposited on octadecyltrichlorosilane (Ors)-treated $\mathrm { S i O } _ { 2 } /$ Si substrates by spin-coating of their $\mathrm { C H C l } _ { 3 }$ hexane solutions $\mathrm { 1 0 ~ m g ~ m L ^ { - 1 } }$ I. Next, the thin films were annealed at $6 0 ~ ^ { \circ } \mathbf { C } ,$ $1 0 0 \ { } ^ { \circ } \mathrm { C } ,$ or $1 4 0 ^ { \circ } \mathrm { C }$ Gold source and drain contacts ( $3 0 \mathrm { n m }$ in thickness) were deposited by vacuum evaporation on the organic layer through a shadow mask, affording a bottom-gate top-contact device configuration. The channel length $( L )$ and width (w) were $2 0 ~ { \mu \mathrm { m } }$ and $2 0 0 ~ { \mu \mathrm { m } }$ , respectively. Electrical measurements of OTFT devices were carried out at room temperature in air using a Keithley 4200 semiconductor parameter analyzer. The mobilities were determined in the saturation regime by using the equation $I _ { \mathrm { D S } } = ( \mu W C _ { \mathrm { i } } / 2 L ) ( V _ { \mathrm { G } } - V _ { \mathrm { T } } ) ^ { 2 }$ , where $I _ { \mathrm { D S } }$ is the drain-source current, $\mu$ is the field-effect mobility, $W$ is the channel width, $L$ is the channel length, $C _ { \mathrm { i } }$ is the capacitance per unit area of the gate dielectric layer, and $V _ { \mathrm { T } }$ is the threshold voltage.

# Results and discussion

The synthetic route to thionated derivatives of NDI is shown in Scheme 1. The parent NDI was synthesized according to a modified literature procedure and used as a control molecule throughout this study.43 By varying the reaction time and the ratio between LR and NDI, different degrees of thionation as well as different yields of the thionated derivatives were achieved. For instance, when NDI was treated with 2.0 eq. of LR and heated at $1 4 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { ~ h ~ } }$ , NDI-1S was isolated as the major product in $3 3 \%$ yield with a minor product of bis-thionated NDI (including NDI-2S-trans and NDI-2S-cis) in total $1 1 \%$ yield. No NDI-3S was observed. when LR was increased to 5.0 eq. with a longer reaction time $( 2 4 \mathrm { ~ h } )$ , no NDI-1S was observed, instead, NDI-2Strans, NDI-2S-cis and NDI-3S were obtained in $1 1 \%$ $9 \%$ and $4 . 6 \%$ yield, respectively. Although a lot of reaction conditions (temperature, ratio, reaction time) have been employed to approach NDI-4S, unfortunately, none of them worked. One possible reason is the much lower LUMO $\left( - 4 . 1 5 \ \mathrm { e V } \right.$ , Table 1) of NDI-3S; the reactivity of LR is not strong enough to replace the fourth oxygen on NDI-3S.

The $^ 1 \mathrm { H }$ NMR spectra of the as-prepared NDI-1S, NDI-2S-trans, NDI-2S-cis and NDI-3S are shown in Fig. 1. Compared with precursor NDI, the aromatic hydrogen atoms (H) on NDI-1S are split into three groups of peaks from 8.5 to $9 . 0 \ \mathrm { p p m }$ . Meanwhile, H on CH2-N also splits into two groups of peaks and one of them moves from 4.2 ppm to $4 . 7 ~ \mathrm { p p m }$ due to the strong electron-withdrawing property of the newly-formed $\mathrm { c } { = } \mathrm { s }$ bond. For NDI-2S-cis, because the environment of H on the same side of aromatic ring is the same, only two single peaks from 8.5 to 9.0 ppm are observed. As for NDI-2S-trans, because the environments of the H atoms on the same side of aromatic ring are different to each other (one is next to the $\scriptstyle \mathbf { C } = \mathbf { O }$ bond while the other is next to the $\mathrm { c } { = } \mathrm { s }$ bond), two double peaks from 8.5 to $9 . 0 \ \mathrm { p p m }$ are seen. Compared with H on CH2-N of NDI-2S, the H on CH2-N of NDI-3S shifts more to low field $\left( 5 . 5 \mathrm { p p m } \right)$ due to the effect of the additional sulfur substitution. The structures of all compounds were further confirmed by $^ { 1 3 } \mathrm { C }$ NMR, and HRMS (Fig. S4 and S5, $\mathrm { E S I \dag }$ ). Thermogravimetric analysis (TGA) indicated that NDI-2S-trans is the most stable compound decomposing at around $3 5 0 ~ ^ { \circ } \mathrm { C }$ while NDI, NDI-1S and NDI-2S-cis almost had the same decomposition temperature at $\sim 3 2 5 \ ^ { \circ } \mathrm { C } .$ It is worth noting that NDI-3S is the most unstable compound and decomposes at around $2 5 0 ~ ^ { \circ } \mathrm { C }$ (Fig. 2a). The differential scanning calorimetry (DSC) spectra suggest that the melting points of these thionated derivatives are between $1 8 3 ~ ^ { \circ } \mathrm { C }$ and $1 9 2 ~ ^ { \circ } \mathrm { C }$ , which are lower than that of the parent compound NDI $\left( 2 0 5 ~ ^ { \circ } \mathrm { C } \right)$ (Fig. 2b).

To investigate how the thionation of the parent compound NDI influences the electron transport properties over macroscopic dimensions, we fabricated and characterized thin-film field-effect transistors with a bottom gate top contact configuration and gold as the source/drain electrodes. Except NDI-3S with moderate solubility, all thionated derivatives had good solubility in common solvents (e.g. chloroform, toluene), making their solution processing easy to realize. Note that the solubility of thionated NDIs strongly depends on the degree of thionation: with more sulfur atoms, the solubility decreased. For a parallel comparison, chloroform/hexane has been chosen as the solvent for all device fabrication and the procedures are described in the experimental section. Typically, S-NDI solutions were spin-coated onto OTS-treated $\mathrm { S i O } _ { 2 }$ $( 5 0 0 \ \mathrm { n m } ) / \mathrm { n } ^ { + + } \mathrm { S i }$ substrates under ambient conditions. The resulting films were then subsequently annealed for about $6 0 \ \mathrm { m i n }$ at different temperatures in a vacuum oven.

The microstructures of all as-fabricated thin-films were investigated by using atomic force microscope (AFm) and twodimensional (2D) X-ray diffraction (XRD) techniques. All as-prepared s-NDI materials showed typical n-type characteristics under ambient atmosphere. Mobilities calculated from saturation regime, $I _ { \mathrm { o n } } / I _ { \mathrm { o f f } }$ ratios and threshold voltages are summarized in Table 2. Typical transfer curves of S-NDI-based devices are depicted in Fig. 5a-d. For NDI-1S based devices after annealing at $6 0 ~ ^ { \circ } \mathrm { C }$ nearly no mobility was measured, however, higher temperature annealing can increase electron mobility and the best mobility for NDI-1S-based devices was $3 . 0 \times 1 0 ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } s ^ { - 1 }$ at an annealing temperature of $1 4 0 ~ ^ { \circ } \mathrm { C }$ with an on/off current ratio up to $1 . 5 \ \times \ 1 0 ^ { 4 }$ . Note that the performance of the NDI-1S TFTS degraded on exposure to the atmosphere quickly and the repeatability of the devices was very poor. Different from NDI-1S, NDI-2s-trans and NDI-2S-cis have higher mobilities and, with increased annealing temperature, the mobility can be further enhanced $( \mu _ { \mathrm { m a x } } \ = \ 1 . 0 \ \times \ 1 0 ^ { - 2 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ $4 . 2 \times$ $1 0 ^ { - 3 } \thinspace \mathrm { c m } ^ { 2 } \thinspace \mathrm { V } ^ { - 1 } \thinspace s ^ { - 1 }$ with $1 4 0 ~ ^ { \circ } \mathrm { C }$ annealing). Although NDI-2S-trans and NDI-2S-cis exhibit better stability than NDI-1S, their performance and repeatability under ambient air conditions are still poor (Fig. 5e). For example, after operating several times, the threshold voltage of NDI-2S-cis increased from $_ { 3 0 \mathrm { ~ V ~ } }$ to ${ \mathbf { 7 0 } \mathrm { ~ V ~ } }$ and the field-effect mobility became much lower $\left( 8 . 8 \mathrm { \textrm { ~ } } \times \mathrm { \textrm { ~ } } \right.$ $1 0 ^ { - 4 } ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ compared to the original mobility of $4 . 2 \ \times$ $1 0 ^ { - 3 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } )$ . For NDI-3s, the best performance was obtained at $1 0 0 ~ ^ { \circ } \mathrm { C }$ ${ 7 . 3 ~ \times ~ 1 0 ^ { - 3 } ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 } }$ , this value was decreased to $3 . 0 \times 1 0 ^ { - 3 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ at temperatures higher than $1 0 0 ~ ^ { \circ } \mathrm { C }$ . Because of its lower LUMO energy level, NDI-3S was supposed to be more stable and display good repeatability as the least sensitive to oxygen and moisture. The device has been operated about ten times and no obvious decay was observed in the $I { - } V$ curves, as shown in Fig. 5f. The corresponding output curves of the devices are shown in Fig. S6 (ESIt) and there is no obvious contact resistance from the output curves. All of these results demonstrated that simple sulfursubstitution could be an effective method to achieve better charge transport properties.

# Conclusions

In conclusion, four novel thionated NDIs have been successfully synthesized and characterized through a one step reaction using the commercially available Lawesson's reagent. Our results indicate that the sulfur-substitution $\mathrm { c } { = } { } \mathrm { s }$ bond could significantly modulate the LUmo level, band gap, absorption and electron mobility. OTFT devices based on these materials were fabricated and all measured results indicate that all compounds are typical n-type semiconductors. The best performance observed was up to $0 . 0 1 \mathrm { c m } ^ { 2 } \mathbf { V } ^ { - 1 } \mathbf { s } ^ { - 1 }$ and an on/off ratio close to ${ { 1 0 } ^ { 5 } }$ Further research showed that NDI-3s displayed the best repeatability with the lowest LUmO level. Our research demonstrates that thionation should be a feasible way to tune the optical and electrical properties of carbonyl-containing compounds in the future.
