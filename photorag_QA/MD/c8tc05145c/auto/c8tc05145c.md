# New anthracene derivatives integrating high mobility and strong emission†

Jinfeng Li, Lei Zheng, Lingjie Sun, Chenguang Li, Xiaotao Zhang, Shanshan Cheng\* and Wenping Hu $\textcircled{1}$

Two new anthracene derivatives were designed and synthesized. Ant-Th-Ph and Ant-ThPh show high single crystal mobilities of $1 . 1 c m ^ { 2 } \vee ^ { - 1 } \mathsf { s } ^ { - 1 }$ and $4 . 7 \ \mathsf { c m } ^ { 2 } \ \mathsf { V } ^ { - 1 } \ \mathsf { s } ^ { - 1 }$ . Moreover, strong solid state emission was determined to be $3 6 . 5 2 \%$ and $3 3 . 3 2 \%$ for Ant-Th-Ph and Ant-ThPh respectively.

# Introduction

Organic electronics have gained great interest in the last decades, motivated by their features including low-cost and applications in flexible electronics such as transparent circuits and flexible displays.1 Numerous efforts have been devoted to the development of various $\pi$ -conjugated organic materials, which have endowed organic semiconductors with multifunctional properties and many attractive characteristics.2–10 One great potential device is organic light-emitting transistors (OLETs) which integrate organic light emitting diodes (OLEDs) and field-effect transistors (OFETs) in a single device. Good OFETs should combine high carrier mobility with efficient solid state emission. However, there is thereby an urgent need but it is still a significant challenge to design these materials. Organic semiconductors usually require molecules packed densely and periodically with intermolecular interactions to generate conducting pathways, but serious light emission quenching occurs in this way due to the formation of excimers or exciplexes.11–15

Nevertheless, a number of materials combining high carrier mobility with efficient solid state emission have been reported in recent years.16–19 For instance, the first anthracene based organic semiconductor based on 2-(4-hexylphenylvinyl)anthracene (HPVAnt) was reported in 2012 by Perepichka and co-workers, which integrated high mobility (hole mobility $\mu _ { \mathrm { S C } } = 2 . 6 2 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 } )$ and solid state emission $( \mathrm { P L Q Y } = 7 0 \%$ ).20 Moreover, our group developed 2,6-substituted anthracene molecules showing good performance, such as 2,6-diphenylanthracene (DPA) which exhibited a mobility up to $3 4 ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ and a PLQY of $4 1 . 2 \%$ in the solid state; and 2,6-di(2-naphthyl)anthracene (dNaAnt) which showed a mobility as high as $1 2 . 3 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ and a PLQY of $2 9 . 2 \%$ .21 From these results we can observe that much of these bifunctional materials are anthracene derivatives. In other words, anthracene, known as a highly luminescent molecule, plays an important role in high mobility and strong emission.

In this context, we report two anthracene derivatives 2-(anthracen-2-yl)-5-phenylthiophene and 2-(anthracen-2-yl)benzo[b]thiophene (Ant-Th-Ph and Ant-ThPh in Scheme 1). The two molecules exhibit both emissive and semiconducting properties and the molecular design is based on the following considerations: (i) anthracene is a highly luminescent molecule and its derivatives show good solid state emission and semiconductor mobility; and (ii) different conjugate modes lead to different emission and mobility performance. The results reveal that Ant-Th-Ph and Ant-ThPh show strong solid state emission of $3 6 . 5 2 \%$ and $3 3 . 3 2 \%$ respectively and high single crystal field-effect transistor mobility of $1 . 1 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ and $4 . 7 ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ respectively.

From thermogravimetric analysis (TGA) data (Fig. 1a and b) we can see that both Ant-Th-Ph and Ant-ThPh show good stability. Ant-Th-Ph and Ant-ThPh sublimated at $3 3 2 ~ ^ { \circ } \mathrm { C }$ and $3 2 2 ~ ^ { \circ } \mathrm { C }$ respectively $\mathrm { \Delta } T _ { \mathrm { d } } .$ corresponding to a $5 \%$ weight loss), and what’s more, both of the two materials show the same melting point of $2 8 3 \mathrm { ~  ~ { ~ \circ ~ } ~ } _ { \mathrm { ~ C ~ } }$ (Fig. 1c and d). Cyclic voltammetry was performed in dry dichloromethane $\left( \mathrm { C H } _ { 2 } \mathbf { C l } _ { 2 } \right)$ solution with a concentration of $1 0 ^ { - 3 } \textbf { M }$ (Fig. 1e and f), and onset oxidation potentials of Ant-Th-Ph and Ant-ThPh were measured to be $0 . 7 7 ~ \mathrm { e V }$ and $0 . 7 0 ~ \mathrm { e V }$ respectively. With the formula of $E _ { \mathrm { H O M O } } =$ $\left( E _ { \mathrm { o x } } + 4 . 8 \right)$ eV (here, $E _ { \mathrm { o x } }$ is the onset of oxidation potential of Ant-Th-Ph and Ant-ThPh), the highest occupied molecular orbital level (HOMO) of Ant-Th-Ph and Ant-ThPh can be calculated to be $- 5 . 5 0 ~ \mathrm { e V }$ and $- 5 . 5 7 \ \mathrm { e V }$ respectively.

As shown in Fig. 2a and b, the two curves show a wellstructured vibrational band of typical anthracene derivative peaks. Comparing the curve of the solid powder with the curve in solution using dichloromethane (DCM), both materials show an obvious bathochromic shift. Moreover, an increased ratio of the first vibration peak intensity compared with the second one was observed, suggesting J-aggregation formation in the solid.22,23 For Ant-Th-Ph (Fig. 2a), solid state peaks appear at $\lambda = 4 2 8 . 8$ , 403.1 and $3 8 2 . 7 ~ \mathrm { n m }$ corresponding to 0–0, 0–1 and 0–2 vibronic peaks, respectively. These peaks correspond to $\lambda = 4 0 4 . 6$ , 385.7 and $3 6 8 . 1 \ \mathrm { n m }$ in dry DCM solution, respectively. Moreover, as to Ant-ThPh (Fig. 2b), the solid state peaks appear at $\lambda = 4 1 9 . 3$ , 395.2 and $3 7 3 . 2 \ \mathrm { n m }$ corresponding to 0–0, 0–1 and 0–2 vibronic peaks, respectively. These peaks correspond to $\lambda = 3 9 5 . 2$ , 376.2 and $3 5 8 . 6 \ \mathrm { n m }$ in dry DCM solution respectively. Similar bathochromic shifts of about $2 4 ~ \mathrm { n m }$ can be calculated, indicating strong interactions between molecules of both materials in the solid state. Solid state photoluminescence peaks for Ant-Th-Ph (Fig. 2c) of $4 8 6 . 5 \ \mathrm { n m }$ and $5 1 3 ~ \mathrm { n m }$ are relative to $4 3 2 . 3 \mathrm { n m }$ and $4 4 8 . 2 \textrm { ~ n m }$ in solution, which correspond to 0–0 and 0–1 peaks. After calculating, the Stokes shift of the 0–0 peak in the solid state of about $2 7 6 5 . 9 ~ \mathrm { c m } ^ { - 1 }$ is much larger than the Stokes shift in solution of $\sim 1 5 8 3 . 7 ~ \mathrm { c m } ^ { - 1 }$ (Fig. S2, ESI†). As to the photoluminescence spectrum of Ant-ThPh (Fig. 2d), peaks appear at $4 6 5 ~ \mathrm { { n m } }$ and $4 8 9 . 2 \ \mathrm { n m }$ for the solid state and $4 0 9 . 4 ~ \mathrm { n m }$ and $4 3 1 ~ \mathrm { { n m } }$ in solution. The two peaks correspond to 0–0 and 0–1 peaks. After comparing with each other, the Stokes shift of the 0–0 peak in the solid state of about $2 3 4 4 . 1 ~ \mathrm { c m } ^ { - 1 }$ is much larger than the Stokes shift in solution of $\sim 8 7 7 . 6 ~ \mathrm { c m } ^ { - 1 }$ . The larger solid state Stokes shift is probably because of the larger configuration difference between the excited state and the ground state for the solid state than that for solution and more energy loss was obtained for the solid state.21 The photoluminescence quantum yield of Ant-Th-Ph and Ant-ThPh was $3 6 . 5 2 \%$ and $3 3 . 3 2 \%$ for single crystals, respectively, which is strong emission for high mobility materials. Another important parameter of Ant-Th-Ph and Ant-ThPh is the optical band gap $E _ { \mathrm { g } }$ which is measured to be 2.91 and 3.01 eV respectively $\left( E _ { \mathrm { g } } = 1 2 4 0 / \lambda _ { \mathrm { g } } \right)$ . So the lowest unoccupied molecular orbital level (LUMO) can be calculated to be $- 2 . 5 9$ and $- 2 . 5 6 \ \mathrm { e V }$ respectively using CV data with the formula of $E _ { \mathrm { L U M O } } = E _ { \mathrm { H O M O } } - E _ { \mathrm { g } } .$ The data are listed in Table 1.

The film semiconducting properties of Ant-Th-Ph and Ant-ThPh were explored by fabrication of bottom-gate/bottom-contact OFETs with thin films of Ant-Th-Ph and Ant-ThPh on OTS (octadecyltrichlorosilane) modified $\mathrm { S i O } _ { 2 } / \mathrm { S i }$ substrates. $\mathrm { S i O } _ { 2 } / \mathrm { S i }$ wafers containing a $3 0 0 \ \mathrm { n m }$ -thick $\mathrm { S i O } _ { 2 }$ layer were successively cleaned with deionized water, isopropanol, deionized water, piranha solution (70/30 vol./vol. $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 } / \mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ ), deionized water, isopropanol and oxygen plasma (10 min, 80 W). Surface modification of a $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ wafer with OTS was then carried out by the vapour deposition method in a vacuum chamber $\left( 0 . 1 \ \mathrm { P a } \right)$ . The $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ wafer was first dried at $9 0 ~ ^ { \circ } \mathrm { C }$ $( 1 . 5 \mathrm { h } )$ to remove the moisture and then kept at $1 2 0 ~ ^ { \circ } \mathrm { C }$ (2 h) to allow for the deposition of OTS. After cooling down to room temperature, the substrate was washed successively with $n$ -hexane, trichloromethane and isopropanol for the following device fabrication. Thin-films of Ant-Th-Ph and Ant-ThPh of about $4 0 \ \mathrm { n m }$ in thickness were prepared by vapour deposition (Fig. S1a and d). From typical output and transfer characteristics of Ant-Th-Ph obtained in air (Fig. S1b and c, $\mathrm { E S I \dag }$ ) we can calculate a mobility as high as $0 . 2 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { \thinspace s } ^ { - 1 }$ and the current on/off ratio to be $5 . 1 2 \times 1 0 ^ { 8 }$ . Moreover from typical output and transfer characteristics of Ant-ThPh obtained in air (Fig. S1e and f, $\mathrm { E S I \dag }$ ) we can calculate a mobility as high as $0 . 2 4 \thinspace \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \thinspace \mathrm { s } ^ { - 1 }$ and the current on/off ratio to be $1 . 4 3 \times { { 1 0 } ^ { 8 } }$ . The maximum current of the transfer curve matched well with that of the output curve, which is important for practical applications. Ant-Th-Ph and Ant-ThPh show a threshold voltage of about $- 4 0 \mathrm { ~ V ~ }$ and $- 3 0 \mathrm { ~ V ~ }$ for the film device respectively. Additionally, no deviation from linearity for the $\left( I _ { \mathrm { D S } } \right) ^ { 1 / 2 } - V _ { \mathrm { G } }$ plot at high $V _ { \mathbf { G } }$ was observed, which means that FET mobility is not overestimated.

In summary, two new anthracene derivatives were designed and synthesized. Ant-Th-Ph and Ant-ThPh combine a high mobility of $1 . 1 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ and $4 . 7 ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ with strong emission of $3 6 . 5 2 \%$ and $3 3 . 3 2 \%$ respectively. These two materials pave the way to design materials combining high mobility and strong emission, which could be used in new kinds of devices, such as OLETs and electric pump lasers. Further research on these materials is underway in our lab.
