# An Indium-Free Low Work Function Window Electrode for Organic Photovoltaics Which Improves with In-Situ Oxidation

Oliver S. Hutter, Helena M. Stec, and Ross A. Hatton\*

Organic semiconductors offer the prospect of truly low cost photovoltaics (PVs) with a very short energy payback time.[1-3] This potential can only be realised if: (i) low cost alternatives to conducting oxides (e.g., indium tin-oxide) are forthcoming as window electrodes; $[ 2 - 4 ]$ (ii) economically viable transparent barrier materials and desiccants are developed that are capable of slowing the ingress of water and oxygen enough to realise useful device lifetimes.5-7] Indeed, there is growing evidence that trace amounts of $\mathrm { O } _ { 2 }$ are problematic in OPVs,8] even for relatively stable organic semiconductors such as poly[N-9'-heptadecanyl2,7-carbazole-alt-5,5- $( 4 ^ { \prime } , 7 ^ { \prime }$ -di-2-thienyl- $^ { 2 ^ { \prime } , 1 ^ { \prime } , 3 ^ { \prime } }$ benzothiadiazole)] (PCDTBT).[9] Without advances in both of these areas the cost advantage associated with solution processing organic semiconductors will be off-set by the high cost of the window electrode and device encapsulation.[6]

Optically thin $( < 1 0 \ \mathrm { n m } )$ metal films are emerging as a viable class of transparent electrode for OPVs, since both micro-cavity effects[10-12] and refractive index matching[10,13] can be used to mitigate against the reduced far field transparency as compared to optimised conducting oxides.14] Advantages of optically thin metal films include compatibility with flexible substrates[15] low materials and processing cost (e.g. by decomposition of an organo-metal precursor deposited by slot-die coating,[1l or by thermal evaporation rather than sputtering, with no requirement for post-deposition annealing), ultra-low roughness[16,17] and chemical uniformity.16,18,19] Proven low cost manufacturing infra-structure is also available for vacuum deposition of metal films over large areas in the form of roll-to-roll vacuum evaporation systems currently used in the packaging industry.[20] Owing to its high electrical conductivity,[21] resistance to electromigration[22] and relatively low cost,[23] $\mathrm { C u }$ is widely used in the microelectronics industry and is receiving growing attention as an electrode material for OPv. Indeed, Cu offers comparable conductivity to Ag, is 1o00 times more abundant than In and is 100 times less expensive.[23]

Due to its relatively high work function () $: 4 . 5 { - } 4 . 6 ~ \mathrm { e V } , ^ { [ 2 4 ] }$ Cu is most suitable as the hole-extracting electrode in OPVs.[15,25] However, unlike Au or Pt its $\varphi$ is not high enough to render it resistant to oxidation under ambient conditions. Exposure to air at room temperature results in the formation of an insulating $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { C u O }$ layer at the surface of bulk Cu, the thickness of which is not self-limiting.[26] In the context of optically thin films this gradual conversion of $\mathrm { C u }$ to copper oxide results in a large increase in sheet resistance $( \mathrm { R } _ { \mathrm { S H } } )$ with increasing oxidation time. This is shown in Figure 1 for a $7 \ \mathrm { n m \ C u }$ film supported on glass. The performance of OPVs is critically dependent on the $\mathsf { R } _ { \mathsf { S H } }$ of the electrodes,[27] which for the transparent electrode cannot realistically exceed $1 5 { - } 2 0 \ \Omega \ \mathrm { s q } ^ { - 1 }$ [28] Increases in $\mathsf { R } _ { \mathsf { S H } }$ adversely impact the efficiency of current extraction to the external circuit due to the voltage drop in the plane of the electrode. Additionally once the surface oxide layer exceeds a thickness of ${ \sim } 1 ~ \mathrm { n m }$ it is no longer transparent to the transport of electrons across the interface between the metallic Cu and the organic semiconductor and so the efficiency of current extraction is eroded exponentially with increasing oxide thickness.[29] A further complication that arises when the surface of a Cu electrode oxidizes in-situ in an OPV device is the $42 \%$ increase in volume occupied by the oxide as compared to the metal[30] which increases the likelihood of delamination.[31] Cu electrodes therefore suffer from similar drawbacks to the low $\varphi$ metals used for electron extraction in OPVs such as Al and Ca, the oxidation of which is known to be a major mode of device degradation.132,33] To date two different approaches have been employed to mitigate against this problem: (i) The development of air stable electron-extracting layers incorporated at the electrode/organic semiconductor interface, most notably $\mathrm { T i O } _ { x } , { } ^ { [ 3 4 ] }$ ${ \mathrm { Z n O } }$ [35] and $\mathrm { A l { : } Z n O ^ { [ 3 6 ] } } .$ ; (ii) The use of increasingly sophisticated barrier/encapsulation layers to slow the inevitable ingress of oxygen and water from the atmosphere into the photoactive layer.[6]

To the authors knowledge $\mathrm { T i O } _ { x }$ deposited from a sol-gel is the only material that has been shown to actively scavenge $\mathrm { O } _ { 2 }$ and water in an organic electronic device,[37,38] although it has been tentatively suggested that a $5 { \mathrm { - } } 1 0 \ \mathrm { n m } \ \mathrm { C r O } _ { x }$ interfacial layer deposited under low vacuum may also offer this functionality.[39] In these cases the oxygen/water scavenging capability and electron transport properties both originate principally from oxygen deficiencies and so oxygen scavenging is at the expense of electron conductivity.

$\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ is known to be an effective encapsulant for organic electronics particularly when deposited by atomic layer deposition.(40,41] Gan et al. have also reported that ultra-thin $\mathrm { 0 . 3 \ n m }$ and $1 \mathrm { n m }$ $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ layers are effective at retarding the oxidation of Cu films heated in air for 30 seconds.42] Perez Lopez et. al. have very recently shown that $1 . 4 ~ \mathrm { n m }$ Al films can retard the diffusion of Cu into the high $\varphi$ oxide $\mathrm { M o O } _ { 3 }$ [43] In the context of OPV research, Cu electrodes are exclusively used as the holeextracting electrode and are capped with a high $\varphi$ oxide layer to optimise the interfacial energetics.[15,25,43]

Herein, we report an exceptionally robust Al:Cu alloy window electrode that simultaneously functions as the low $\varphi$ electron-extracting electrode, a sink for oxygen and water molecules in the photoactive layer, and a low cost window electrode in inverted bulk heterojunction OPVs. It is shown that when the electrode is exposed to air an ultra-thin self-limiting ternary oxide layer forms at its surface without any increase in surface roughness (which remains remarkably low) and the $\mathsf { R } _ { \mathsf { S H } }$ of the electrode actually decreases thereby improving the electrical properties of the electrode. This reduction in the resistance of the window electrode upon oxidation is used as a sensitive probe for electrode oxidation in-situ in OPV devices when the entire device is stored in air. It is shown that oxidation of the electrode surface at the buried interface, does not adversely impact the efficiency of electron extraction, even though the $\varphi$ increases by several hundred milli-electron volts from a very low starting value of ${ \sim } 3 . 1 \ \mathrm { e V }$ to a maximum of ${ \sim } 3 . 8 \mathrm { e V } .$ Indeed, as the surface of the electrode oxidises in-situ in the OPV device the reverse dark current characteristic is greatly improved.

Cu films on glass with a thickness of $7 \mathrm { n m }$ and $9 \mathrm { n m }$ were prepared using the mixed monolayer method developed by Stec et al. for Au films.16] The high affinity of Cu for amine and thiol moieties ensures that this approach works well for the preparation of optically thin Cu films, although this is the first time it has been demonstrated.23,44] The resistivity of the $9 \mathrm { n m }$ and $7 \mathrm { n m }$ films is $8 . 1 \times 1 0 ^ { - 8 } \Omega \mathrm { ~ m ~ }$ and $9 . 8 \times 1 0 ^ { - 8 } \Omega$ m respectively. These values are a factor of ${ \sim } 4 . 7$ and ${ \sim } 5 . 7$ times larger than bulk $\mathrm { C u } ( 1 . 7 \times 1 0 ^ { - 8 } \Omega \ \mathrm { m } ) ^ { [ 4 5 ] }$ respectively. Since these film thicknesses are ${ \sim } 4 . 4$ times and ${ \sim } 5 . 7$ times smaller than the mean free path of an electron in bulk $\mathrm { C u } ^ { [ 4 6 ] }$ this scaling of resistivity with thickness shows that scattering at the top and bottom surfaces of the Cu film is the primary determinant of film resistivity when the film thickness is so low. This result is consistent with the formation of films of uniform thickness,[11] which is corroborated by measurements of the surface roughness of these films made using an atomic force microscope (AFM); root-meansquare roughness ${ < } 0 . 6 \ \mathrm { n m }$ over $1 \times 1 \mu \mathrm { m }$ which is comparable to that of the underlying glass substrate. The $\mathrm { R } _ { \mathrm { S H } }$ of $7 \ \mathrm { n m \ C u }$ film is ${ \sim } 1 4 ~ \Omega ~ \mathrm { s q } ^ { - 1 }$ . However, Figure 1 shows that upon exposure to air $\mathrm { R } _ { \mathrm { S H } }$ increases rapidly within the first hour followed by a gradual continuous increase. By capping the Cu electrode with an $0 . 8 ~ \mathrm { n m }$ Al overlayer this increase in $\mathsf { R } _ { \mathsf { S H } }$ is prevented. Thinner Al overlayers were not sufficient to prevent an increase in $\mathsf { R } _ { \mathsf { S H } }$ upon exposure to air. Notably, the Cu $\left( 7 \mathrm { ~ \ n m } \right)$ : Al $( 0 . 8 \mathrm { n m } )$ films have a $4 . 5 ~ \Omega ~ \mathrm { s q } ^ { - 1 }$ higher starting resistance than Cu only, which is attributed to Al diffusion into the underlying Cu film, since Al doped $\mathrm { C u }$ is known to have a higher resistivity than pure Cu even at very low Al concentrations.47] However, the $\mathsf { R } _ { \mathsf { S H } }$ of the binary Cu (7 nm): Al $( 0 . 8 \ \mathrm { n m } _ { \ d } ^ { \dag }$ film decreases by ${ \sim } 1 5 \%$ $\left[ 3 \Omega \thinspace \mathrm { s q } ^ { - 1 } \right)$ upon oxidation. This increase in conductivity is attributed to migration of Al atoms dissolved in the Cu film to the film surface where they are oxidized. Since the $\mathsf { R } _ { \mathsf { S H } }$ of the oxidized $\operatorname { C u } ( 7 \mathrm { n m } )$ : Al $( 0 . 8 \mathrm { n m } )$ film converges to a value $1 . 5 \Omega \mathrm { s q } ^ { - 1 }$ above that of unoxidised Cu films, either some Al remains dis. solved in the bulk of the Cu film or the thickness of ${ \mathrm { C u } }$ film is reduced due to some Cu being bound up in the surface oxide layer. Whilst it is known that Al dissolved in Cu can diffuse at temperatures as low as $1 0 0 ~ ^ { \circ } \mathrm { C } ^ { [ 4 7 , 4 8 ] }$ it is quite unexpected that this process should occur so rapidly at room temperature. This effect is attributed to the suppression of the Cu melting point due to the low film thickness, since $1 0 \ \mathrm { n m \ C u }$ films have been observed to melt below $4 0 0 ~ ^ { \circ } \mathrm { C } .$ [49] which in turn suppresses the temperature at which Al atoms can diffuse.

The effectiveness of such a thin Al overlayer in protecting the underlying Cu towards oxidation cannot be rationalised in terms of the formation of an $0 . 8 \ \mathrm { n m \ A l _ { 2 } O _ { 3 } }$ capping layer since the thickness of the self-limiting oxide on Al is known to be greater than $2 \mathrm { n m }$ [50,51] Indeed it is the formation of this thick oxide layer at the Al/organic semiconductor interface that is the reason for the increase in series resistance in OPVs.[33,52] The surface sensitive technique of static secondary ion mass spectrometry reveals that for a Cu: Al $( 0 . 8 \mathrm { n m } )$ film the upper most surface includes copper oxide as well as aluminium oxide [Supporting information, Figure 1j. Even if the Al layer thickness is increased by more than a factor of five to $4 . 2 \ \mathrm { n m }$ copper oxide is still present at the surface [Supporting information, Figure 2] consistent with the formation of a dense ultra-thin $\mathsf { A l } _ { { x } } \mathsf { C u } _ { \gamma } \mathsf { O } _ { z }$ surface layer. $\varphi$ measurements made using a Kelvin Probe colocated in the same glove box as the evaporator corroborate this conclusion, since the $\varphi$ of oxidized $\operatorname { C u } \left( 7 \mathrm { n m } \right)$ : Al $( 0 . 8 \mathrm { n m } )$ films, $3 . 7 8 ~ \mathrm { e V } \pm 0 . 0 2$ (Figure 1), is too high to be $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ $3 . 4 5 \ \mathrm { e V \pm }$ 0.02) (Figure 1) and too low to be Al $( 4 . 3 3 \ \mathrm { e V } )$ [42] Cu (4.6 eV)[24] or CuO $( 4 . 5 4 \pm 0 . 0 2 ) $ . It is evident from Figure 1 that the $\varphi$ of the Cu:Al electrode is very low to begin with $( 3 . 1 1 \ : \mathrm { e V } )$ and after an initial very rapid increase converges to $3 . 7 8 \ \mathrm { e V } .$ This very low starting value is not unexpected, since $\mathrm { A l } _ { 2 } \mathrm { O } _ { 3 }$ has a very low $\varphi ^ { [ 5 3 ] }$ and it is known that an extremely thin oxide layer forms at the surface of freshly evaporated Al films within minutes at $1 0 ^ { - 6 }$ mbar (i.e. high vacuum) due to the high reactivity of Al towards $\mathrm { O } _ { 2 }$ [54] When exposed to the glove box environment, which is ${ \sim } 1 \mathrm { p p m } \mathrm { O } _ { 2 }$ a very thin oxide layer is therefore expected to form extremely rapidly. Importantly, when the work function and sheet resistance evolve with oxidation the surface roughness of the films remain unchanged at an exceptionally low root-mean-square value of $\leq 0 . 6 \ \mathrm { n m }$ (Figure 2) which is much lower than most conducting oxide electrodes.134,55] Furthermore, these electrodes are robust towards ultra-sonic agitation in toluene, isopropanol and water, with less than $2 \%$ change in $\mathsf { R } _ { \mathsf { S H } }$ (Supporting information, Table 1). The far field transmittance of these electrodes is also essentially identical to $7 \mathrm { n m } \mathrm { C u }$ films, consistent with the very low Al thickness and expectation that the surface oxide is a wide band gap material.56,57) (See Supporting Information, Figure 3.)

The low $\varphi$ and very low surface roughness of the Cu:Al $( 0 . 8 \mathrm { n m } )$ films combined with the decrease in $\mathsf { R } _ { \mathsf { S H } }$ upon oxidation and capacity to mop up oxygen and water bodes well for application as a transparent electron-extracting electrode and built-in desiccant in OPVs. However for this application the ternary oxide formed at the electrode upon in-situ oxidation must remain sufficiently thin to be transparent to the movement of electrons across the electrode-organic semiconductor interface and the change in $\varphi$ must not adversely impact the efficiency of electron-extraction to the external circuit.

To demonstrate utility in OPVs the electrode was incorporated into inverted OPVs with the structure: Cu (7 nm), Al $( 0 . 8 ~ \mathrm { n m } )$ ,PCDTBT:[6,6]-phenyl- $\mathrm { C } _ { 7 0 }$ butyric acid methyl ester $( \mathrm { P C } _ { 7 0 } \mathrm { B M } )$ $\mathrm { M o O } _ { 3 }$ $[ 1 0 \ \mathrm { n m } ]$ , Al $[ 7 0 \ \mathrm { n m } ]$ . A $7 \ \mathrm { n m \ C u }$ film was chosen because the $\mathsf { R } _ { \mathsf { S H } }$ is comparable to that of the ITO coated glass used in our laboratory for OPVs; $1 5 ~ \Omega ~ \mathrm { s q } ^ { - 1 }$ . Whilst, the power conversion efficiency of OPVs using a 7 nm Cu electrode $( \sim 4 . 0 \% )$ is ${ \sim } 1 5 \%$ lower than that achieved using a conventional ITO electrode $( \sim 4 . 7 \% )$ , due to the lower transparency of the former (Supporting Information Figure 3), it is important to note that in this study optical spacers have not been employed to maximise micro-cavity effects. All devices were fabricated in a nitrogen filled glove box with ${ < } 1 \ \mathsf { p p m } \ \mathrm { O } _ { 2 }$ and water. In-situ oxidation of the electrode was achieved by storing the entire

OPV in air at one atmosphere, standardised test protocol IsOSD-1 Shelf,[58] for 69 hours. Due to the low thickness of the Cu:Al electrode it is possible to monitor the extent of oxidation at the buried interface between the electron-extracting electrode and PCDTBT $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ layer via the decrease in resistance of the electrode. The beauty of this non-destructive in-situ measurement lies not only in its simplicity but in the fact that it allows changes in the state of the electrode surface to be probed independently of other changes in the OPV such as oxidation or doping of the photoactive layer.

It is well documented that the characteristics of un-encapsulated organic optoelectronic devices stored in air changes on the time scale of minutes to hours due to the ingress of water and molecular oxygen into the organic semiconductor layer(s) and oxidation of the low work function electrode.33,37,39,59] Since the top metal contact slows the rate of diffusion into the organic semiconductor[33] the OPVs fabricated in this study have a relatively small active area; ${ \sim } 0 . 1 3 ~ \mathrm { c m } ^ { 2 }$ , to help ensure rapid air ingress. Figure 3 shows representative $J / V$ characteristics for an OPV before and after storage in air for 69 hours. The $6 \%$ decrease in resistance of the electrode from $9 . 7 2 \ \Omega$ to $9 . 1 9 \ \Omega$ measured using the two point method indicates that the surface of the Cu:Al electrode has oxidized to a significant extent due to air ingress through the photoactive layer. The resistance of a reference comprising a Cu:Al electrode of identical geometry covered with a PCDTBT: $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ layer but without a top electrode also exhibited a $6 \%$ change confirming that the whole electrode surface is oxidised and not just the area near to the edges of the top electrode in OPV devices.

Crucially, this in-situ oxidation of the electrode at the buried interface with the photoactive organic semiconductor layer does not adversely impact $J _ { s c } ,$ $F F$ or $V _ { o c } ,$ which remain constant at $5 . 9 \mathrm { m A c m } ^ { - 2 }$ , 0.50 and $0 . 8 6 \mathrm { V }$ respectively. In fact, there is an order of magnitude decrease in the reverse dark current at $- 0 . 7 5 \mathrm { ~ V ~ }$ which represents a large improvement in the dark $J / V$ characteristic. Since the PCDTBT $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ layer is deposited immediately after removal of the Cu:Al electrode from the vacuum evaporation chamber the $6 \%$ reduction in $\mathsf { R } _ { \mathsf { S H } }$ of the electrode translates to a $3 0 0 { - } 3 5 0 \mathrm { m e V }$ increase in $\varphi$ of the electron-extracting electrode from $3 . 1 1 \ \mathrm { e V }$ to $3 . 4 3 \ \mathrm { \ e V }$ (Figure 1). However since the $\varphi$ of the electrode remains less than or equal to the electron affinity of $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ $( 3 . 7 ~ \mathrm { e V } ) ^ { [ 6 0 ] }$ it can be assumed that the degree of alignment between the electrode Fermi level and the LUmO of $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ remains unchanged, since ground state charge transfer from the electrode to $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ LUMO will occur pinning the LUMO near to the electrode Fermi level. It is not clear at this stage as to why the dark current characteristics improve so dramatically upon formation of the oxide layer, although this improvement does not translate to an increase in $V _ { o c } ^ { [ 6 1 ] }$ because it is already at the maximum achievable for this material system.[12]

In summary, these window electrodes are fabricated from low cost materials and simultaneously remove the requirement for a conducting oxide window electrode and conventional low $\varphi$ electrode. These electrodes also scavenge oxygen/water that permeates into the photoactive layer without any change in surface roughness - which remains exceptionally low at less than $0 . 6 \ \mathrm { n m }$ - or increase in electrode $\mathsf { R } _ { \mathsf { S H } }$ Indeed upon oxidation the $\mathrm { R } _ { \mathrm { S H } }$ of the film decreases by up to $\sim 1 5 \%$ . This improvement in the conductivity of the electrode is attributed to room temperature de-alloying. Crucially, it is shown that the evolution of the electrode $\varphi$ upon in-situ oxidation of the electrode surface does not adversely impact the process of electron-extraction to the external circuit. The desiccant property of this electrode is particularly important for OPVs since organic semiconductors are particularly susceptible to damage by low levels of molecular oxygen and the desiccant layer is in direct contact with the organic semiconductor layer.

# Experimental Section

Preparation of Ultra-thin Al:Cu films on glass: Glass microscope slides (VwR) were cleaned by ultra-sonic agitation for 15 min firstly in acetone, then a dilute aqueous solution of Decon Neutracon and finally 2-propanol before exposure to hot acetone vapor for ${ \mathsf { 1 0 ~ 5 } } .$ They were then $\mathsf { U V } / \mathsf { O } _ { 3 }$ treated to remove solvent residue for $9 0 0 \ \textup { s }$ and transferred to a desiccator where they were exposed to the vapor of APTMs (3-aminopropyltrimethoxysilane) and MPTMS (mercaptopropyltrimethoxysilane) at 5 mbar for 4 hours. The nanolayer derivatized electrodes were transferred to the evaporator for ${ \mathsf { C u } }$ and Al deposition at a deposition rate of $0 . 1 \ \mathsf { n m \ s ^ { - 1 } }$ . The thickness of deposited Cu and Al was measured using a carefully calibrated quartz-crystal microbalance mounted adjacent to the substrate.

OPV Fabrication and Testing: All chemicals were purchased from commercial sources and used without further purification. PCDTBT and $\mathsf { P C } _ { 7 0 } \mathsf { B M }$ (Ossila Ltd) were combined in a 1:3 mass ratio at a total concentration of $1 6 ~ \mathsf { m g } ~ \mathsf { m L ^ { - 1 } }$ in chloroform. The blend was stirred for one hour at $6 5 \ ^ { \circ } \mathsf C$ before filtering using a $0 . 2 ~ \mu \mathsf { m }$ PTFE filter. PCDTBT ${ \cdot } { \mathsf { P C } } _ { 7 0 } { \mathsf { B M } }$ bulk heterojunction flms were spin cast at 6000 r.p.m. for 1 min and allowed to dry at room temperature under nitrogen for $1 0 \mathsf { m i n }$ , before annealing at ${ 8 0 ~ ^ { \circ } C }$ for $3 0 \mathsf { m i n }$ . A $\mathsf { 1 0 \ n m \ M o O _ { 3 } }$ (Aldrich) film was evaporated at $\bar { 0 . 1 } \ \mathsf { n m } \ \mathsf { s } ^ { - 1 }$ followed by $1 0 0 \ \mathsf { n m }$ of Al deposited through a shadow mask. $J / V$ curves were measured in the dark and under 1 sun simulated solar illumination: $\mathsf { l o } 0 \mathsf { m } \mathsf { W } \mathsf { c m } ^ { - 2 }$ ; AM1.5G. The light intensity was calibrated using a PV Measurements Inc. calibrated silicon diode with KG5 color filter.

$\mathsf { R } _ { \mathsf { S H } }$ Measurement: $\mathsf { R } _ { \mathsf { S H } }$ measurements were made using the 4-point probe Van der Pauw method on square substrates. To ensure that the change in $\mathsf { R } _ { \mathsf { S H } }$ did not result from changes in the quality of the contacts, silver painted contacts were replaced with Al mechanical contacts and the same result was obtained.

Atomic Force Microscopy (AFM) Imaging: Tapping mode AFM measurements were performed in air using an Asylum Research MFP3D.

$\varphi$ Measurements (Kelvin Probe): All $\varphi$ measurements were made in a nitrogen-flled glovebox using a Kelvin probe referenced to freshly cleaved highly oriented pyrolytic graphite, $\varphi = 4 . 4 7 5 ~ \mathrm { e V } . ^ { [ 6 2 ] }$

Static - Secondary Ion Mass Spectrometry (s-Sims): s-Sims was performed using a KORE Surface Seer instrument using a ${ \mathsf { C } } { \mathsf { S } } ^ { + }$ primary ion source.

OpticalTransparency Measurement: Far-field transmittance measurements of Cu:Al flms on glass were made over the wavelength range $3 0 0 { - } 9 0 0 ~ \mathsf { n m }$ using a Perkin Elmer Lambda 25 UV Spectrometer. The reference material was a plain glass slide. The incident beam passed through the glass first of all, as is the case in an OPV device.
