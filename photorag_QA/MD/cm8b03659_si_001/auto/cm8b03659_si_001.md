# S3. UPS spectra of amorphous and crystalline $\mathbf { P C _ { 6 1 } B M }$ films

![](images/415aa95d2370d5a6368982f3007b1f4657ecb331dd07431f6e135db988a59d2e.jpg)  
Figure S3. (a) Representative UPS spectra of $a \mathrm { - }$ and $c \mathrm { - } \mathrm { P C } _ { \mathrm { 6 1 } } \mathrm { B M }$ films in the SECO (left panel) and valence (right panel) regions. (b) Schematic energy diagrams deduced from UPS measurements are illustrated. The LUMO levels of $a$ - and $c \mathrm { - } \mathrm { P C } _ { \mathrm { 6 1 } } \mathrm { B M }$ films were estimated from the energy gap determined with UPS and LEIPS1 .

The left panel of Figure S3(a) displays the representative UPS spectra of $a$ - and $c$ - $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ in the secondary electron cutoff (SECO) region, the spectral onsets of which were used to determine the work functions of the specimens. We measured the UPS spectra for several specimens and determined the average work functions of $a$ - and $c { \mathrm { - } } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ to be $4 . 6 \hat { 5 }$ and $4 . 4 \AA$ eV, respectively. The spectral onsets of the valence UPS spectra (right panel of Figure S3(a)) and the work functions yielded average ionization energies in the solid state $( I _ { \mathrm { s } } )$ of $6 . 1 _ { 6 }$ and $5 . 8 \mathrm { { q } }$ $\mathtt { e V }$ for $a$ - and $c { \mathrm { - } } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ , respectively (see energy diagrams in Figure 1(b)). The smaller value of $I _ { \mathrm { s } }$ for $c { \mathrm { - } } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ is consistent with the previous report1 , whereas the change in the work function was different. The work function of an organic sample can be easily altered, whereas the ionization energy and electron affinity are not. The reported work functions measured by SECO and the onset of the sample current were different1 . In this work, we carefully examined the work functions based on repeated measurements.

Zhong et al. examined both the HOMO and LUMO levels using UPS and low-energy inverse photoemission spectroscopy (LEIPS), respectively, and discussed the change in the energy levels upon crystallization in terms of the bandgap narrowing and the rigid shift. The bandgap narrowing of $0 . 1 \mathrm { e V }$ was explained by the increase in the electronic polarization energy associated with the increase in the film density, although the origin of the rigid shift of the energy levels was not clear1 . The authors proposed that the mechanism of the rigid energy shift was the de-doping of oxygen during thermal annealing and the change in the molecular orientation during crystallization. Next, we discuss the effect of these factors on the work function of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ to clarify the difference in the work function shift on crystallization.

Oxygen and water in the air strongly affect electronic structure2–4 , and, in extreme cases, induce chemical interactions with the host organic molecules5 . Thus, we focus on the effects of oxygen and water exposure on the electronic structure of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ . First, we discuss the effect of molecular oxygen on the electronic structure of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ . Bao et al. investigated the electronic structure of the oxygen-exposed $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ film5 . They found that the work function decreases and that the HOMO shifts downward as a function of the oxygen exposure time. There may be a similar effect on the electronic structure of the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ spin-coated film prepared under an ${ \Nu } _ { 2 }$ atmosphere because our $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and chloroform were stored in ambient air and oxygen may have been incorporated in the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ chloroform solution. Therefore, on thermal annealing, oxygen could desorb from the film and raise the energies of the vacuum level and HOMO. Water-induced modification of the electronic structure of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ is also possible, again because the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and chloroform used in this study were stored in ambient air. Exposing $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ to water gas can alter the chemical structure of $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ , as revealed by XPS5 and decrease the work function. Upon thermal annealing for the crystallization, the work function should increase through the desorption of water molecules from the film, which is similar to the effect of oxygen de-doping. However, in this work, the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ samples were transferred from a glove box to the introduction chamber of the UPS equipment using a glove bag filled with ${ \Nu } _ { 2 }$ . Therefore, the expected recovery of the work function through thermal treatment should be smaller than that observed by Zhong et al.

As described in the main text, we used UPS and MAES to confirm the formation of the dipole layer at the film surface. The exposure of the side chains formed the electrical dipole layer pointing toward the surface due to the permanent dipole of the molecule (Figure 1(c)). This effect decreases the work function. Therefore, the orientational change at the surface counteracts the increase in the work function upon the possible desorption of oxygen and water molecules from the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ film. Zhong et al. exposed the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ samples to ambient air. The change in the work function by the orientational change may have been balanced by the upward energy shift due to the de-doping of oxygen and water. In contrast, in this study, the effect of ambient gases on the electronic structure was suppressed by avoiding uptake of the ambient gases into the organic samples. Overall, the change in the energy of the vacuum level originating from the surface exposure of the side chains of the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ molecules resulted in the decrease in work function after crystallization.

# S4. Evolution of MAES spectra of 6T deposited on the $\mathbf { P C _ { 6 1 } B M }$ films

![](images/75cfe8feb0bf160fa2a0c1bc3f2e09e41d9a18913c4074dc94377964053e165d.jpg)  
Figure S4. (a) and (b) Contribution of 6T to the MAES spectra for $a \mathrm { - P C } _ { 6 1 } \mathrm { B M } / 6 \mathrm { T }$ and $c$ -

$\mathrm { P C } _ { 6 1 } \mathrm { B M } / 6 \mathrm { T }$ heterostructures, respectively, in the sub-monolayer coverage. The MAES spectra of the 6T thin films adopting an end-on orientation (prepared on $\mathrm { S i O _ { x } }$ , yellow curve) and a faceon orientation (prepared on HOPG, pink curve), and the calculated DOS of an isolated 6T molecule (green curve) are also plotted. The blue vertical lines at the bottom indicate the energy distributions of the MO of 6T. (c) and (d) Preferential interaction between $\mathrm { H e ^ { * } }$ and selected MOs that give MAES signals for 6T molecules adopting edge-on and face-on orientations, respectively.

As described in the main text, the overall spectral feature of the 6T overlayer on both the $a$ - and $c { \mathrm { - } } \mathrm { P C } _ { 6 1 } \mathrm { B M }$ films is kept unchanged as $d$ increases further to $1 6 \mathrm { n m }$ (Figure 2(a) and (b)). We noted that the relative intensity of the respective bands is similar to that of the MAES spectrum of the 4.8-nm-thick 6T layer on $\mathrm { S i O _ { x } }$ (top yellow curves in Figure 2(a) and (b)), where the long axis of 6T aligns to the surface normal6 . Therefore, a similar molecular orientation of the 6T layer in the heterostructures can be expected.

The MAES spectrum of 6T on $\mathrm { S i O _ { x } }$ exhibits photoemissions in regions (ii) and (iii) (yellow curves in Figure S4(a) and (b)), which originate from $\mathrm { ~ S ~ } 3 p$ orbitals (e.g., HOMO-10 in Figure S4(c)) and from C $2 p$ and $\sigma$ orbitals (e.g., HOMO-30 in Figure S4(c)), respectively. There is also smaller contribution from region (i), originating from the $2 p _ { \mathrm { z } }$ orbitals of the $\alpha$ - and $\beta$ -carbons (e.g., HOMO in Figure $\mathrm { S } 4 ( \mathrm { d } ) ) ^ { 7 }$ . These results suggest that the excited helium atoms preferentially interact with the $\sigma$ -orbitals rather than the $\pi$ -orbitals. Therefore, 6T molecules may stand upright rather than lie down, in good agreement with the results of the XRD profile (Figure 2(c) and (d)).

For comparison, we also measured the MAES spectrum of the 6T monolayer deposited on an HOPG substrate (pink curves in Figure S4(a) and (b)), where the molecules lie flat (faceon orientation)8 . The spectrum is different from that of the molecules standing upright (see Figure S4(a) and (b)). The flat molecules exhibit intense $\pi$ bands, particularly those originating from S $3 p _ { \mathrm { z } }$ orbitals between 2 and $3 \ \mathrm { e V }$ . Weaker signals in region (i) are also detected7 . The stronger signal attributed to S $3 p _ { \mathrm { z } }$ orbitals arise from their greater spatial extent than the C $2 p _ { \mathrm { z } }$ orbitals, which leads to a larger interaction between the excited helium and the MOs (Figure $\mathrm { S 4 ( d ) } ^ { 9 }$ . These measurements indicate that the 6T molecules on the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ films adopt an endon orientation.

We analyzed the MAES spectra further at sub-monolayer coverage. The 6T contributions in the interface spectra are indicated by the black curves in Figure S4(c) and (d), which were extracted by subtracting the $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ contribution from the MAES spectra measured for the heterostructures with $d \leq 1 . 2 \ \mathrm { n m }$ . The spectra are similar to those for 6T on $\mathrm { S i O _ { x } }$ , as characterized by the intense photoemission in region (iii) (Figure S4(c) and (d)). The band intensity in region (iii) for the $a \mathrm { - P C } _ { 6 1 } \mathrm { B M } / 6 \mathrm { T }$ interface (Figure S4(c)) is weaker than that for the $c { \bf - P C } _ { 6 1 } { \bf B M } / { 6 \mathrm { T } }$ interface (Figure S4(d)). The lower intensity of band (iii) means that $\mathrm { H e ^ { * } }$ interacts less with the $\sigma$ -orbitals. This result may suggest that at low 6T coverage, the 6T molecules on $a \mathrm { - P C } _ { 6 1 } \mathrm { B M }$ do not adopt a perfect end-on orientation because of the lower structural order on the amorphous film. However, when $d$ is increased to $1 . 2 \mathrm { n m }$ , the relative intensity of band (iii) is similar to that for larger $d$ , suggesting that the molecular orientation becomes similar to that of the thicker layer.
