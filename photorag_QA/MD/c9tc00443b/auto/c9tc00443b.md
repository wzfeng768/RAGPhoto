Enhancing charge injection from electrodes to the conducting channel and reducing the contact resistance $( R _ { \mathrm { c } } )$ are valid strategies not only to improve the performance of organic field-effect transistors (OFETs), but also to enable low-voltage operating devices with a short channel. In order to improve the charge injection efficiency, many efforts have been made to reduce the interfacial injection resistance $( R _ { \mathrm { c , i n t } } )$ in the past few decades, such as by adjusting the metal work function, inserting a buffer layer and so on. However, the method of decreasing the bulk injection resistance $( R _ { \mathsf { c , b u l k } } )$ in the vertical direction of the semiconductor layer is rarely studied. In this paper, twodimensional (2D) monolayer and multilayer single-crystal devices of 1,4-bis( $\bullet ^ { \prime }$ -hexyl- $^ { 2 , 2 ^ { \prime } }$ -bithiophen-5-yl)ethynyl)benzene (HTEB) were fabricated to study the dependence of the contact resistance of OFETs on crystal thickness. Devices based on monolayer molecular crystals (MMCs), and 4-layer and 15-layer single-crystal devices were found to have $\pmb { R _ { \mathrm { c } } }$ of 1.77 kX cm, $2 6 . 9 ~ \mathsf { k } \Omega$ cm and 5.15 MX cm, respectively. Thanks to the lower $\scriptstyle { R _ { \mathrm { c } } } ,$ the MMC devices possess more steady linear mobility at a varied $V _ { \mathsf { D S } } ,$ and a smaller deviation of the linear and saturation mobility. Finally, a low-voltage operating $( - 2 \mathsf { u } )$ HTEB MMC device was fabricated on a $3 0 \ \mathsf { n m } \ \mathsf { H f o } _ { 2 }$ insulating layer with an ultralow $\pmb { R _ { \mathrm { c } } }$ of $\pmb { 5 4 0 } \ \pmb { \Omega }$ cm.

# Introduction

With the development of materials science, abundant highmobility organic semiconductor materials have been designed and applied to high-performance organic field-effect transistors (OFETs) in the past few decades.1–7 However, there are many influencing factors that have negative effects on the device performance and should be paid particular attention to, such as the contact resistance $\left( R _ { \mathrm { c } } \right)$ . The $R _ { \mathrm { c } }$ is notorious but inevitable in most OFETs, and obstructs efficient charge injection and causes a voltage drop from the drain and source electrodes to the conducting channel.8–10 The unfavorable effects of $R _ { \mathrm { c } }$ become more obvious with decreased channel length $( L )$ , because of the independency of $R _ { \mathrm { c } }$ and dependency of the channel resistance $\left( R _ { \mathrm { c h } } \right)$ on $L$ .11 The contributions of the contact effects to the device performance become more significant when the semiconductors possess a higher intrinsic mobility, in which case $R _ { \mathrm { c h } } \ll R _ { \mathrm { c } } + R _ { \mathrm { c h } }$ because of the good channel conductivity. Compared with the low $R _ { \mathrm { c } }$ devices, the voltage distribution in the conducting channel decreases more obviously as the $L$ reduces in the case of large $R _ { \mathrm { c } }$ devices, which leads to greater performance degradation. Hence, obvious $R _ { \mathrm { c } }$ will hinder the reduction of the channel length of OFETs, and impede their miniaturization and integration. Thus, reducing $R _ { \mathrm { c } }$ is not only important for improving OFET performance, but also vital for the commercial applications of OFETs in low-voltage operating devices with a short channel.

In OFETs, $R _ { \mathrm { c } }$ consists of the interfacial injection resistance $\left( R _ { \mathrm { c , i n t } } \right)$ and the bulk injection resistance $\left( R _ { \mathrm { c , b u l k } } \right)$ .12–14 The former is caused by non-ohmic contact between the metal electrode and semiconductor, and the latter is related to the interlayer structure and thickness of the semiconductor. $R _ { \mathrm { c , i n t } }$ reflects the mismatch between the metal work function and the frontier molecular energy levels of semiconductors, which causes a potential barrier. As a result, an extra voltage drop is required at the metal/semiconductor interface.15,16 Many efforts have been devoted to reducing $R _ { \mathrm { c , i n t } }$ in the past few decades.17,18 For example, self-assembled monolayers (SAMs) were used to adjust the work function of electrodes,11,19,20 or buffer layers were introduced between the electrodes and semiconductors to improve the charge injection efficiency.21–24 However, few studies have been carried out specially on $R _ { \mathrm { c , b u l k } }$ due to the difficulty in achieving satisfactory balance between active layer thickness and $R _ { \mathrm { c , b u l k } } ,$ namely a thinner film is preferred for lowering $R _ { \mathrm { c , b u l k } } ,$ while sufficient thickness is required to ensure the continuity of the film. For thin film OFETs, the low degree of molecular arrangement order and abundant grain boundaries lead to inefficient charge transport, and high $R _ { \mathrm { c h } }$ and $R _ { \mathrm { c , b u l k } }$ . 25–27 Meanwhile, nanosheet two-dimensional (2D) materials (such as graphene28 and graphene-like materials29–31) have advantages for fabricating low $R _ { \mathrm { c } }$ devices, because of the integrity of the 2D material at monolayer thickness, which offers the benefit of low $R _ { \mathrm { c h } }$ as well as low $R _ { \mathrm { c , b u l k } }$ . Similar to the inorganic 2D crystals, organic single crystalline semiconductors possess a highly ordered molecular arrangement and few grain boundaries, which result in low $R _ { \mathrm { c h } }$ . 32 While the inter-layer transport, which is much weaker than the intra-layer transport in most of the organic semiconductors reported so far,14,33,34 results in a large $R _ { \mathrm { c , b u l k } }$ and hinders the charge transport. In some cases, the $R _ { \mathrm { c , b u l k } }$ can be much greater than the $R _ { \mathrm { c h } }$ .35 Thus, the integration of the efficient charge transport of bulk crystals and the low $R _ { \mathrm { c , b u l k } }$ of 2D materials calls for the preparation of monolayer molecular crystals (MMCs).36–43

It has been demonstrated that, 1,4-bis( $5 ^ { \prime }$ -hexyl- $^ { 2 , 2 ^ { \prime } }$ -bithiophen-5-yl)ethynyl)benzene $\left( { \mathrm { H T E B } } \right) ^ { 4 4 }$ can form layered 2D molecular crystals easily by a solution process.40 The 2D layered structure of HTEB might be partially related to the thiophene units which ensure strong intra-layer molecular interactions for efficient self-assembly of 2D growth, and the relatively weak inter-layer interactions of the alkyl chains for the layered structure.31,40,45 The layered crystals provide an ideal platform for studying the relationship between OFET performance and crystal thickness. Moreover, similar to monolayer graphene and graphene-like materials, HTEB MMCs have great potential for realizing low $R _ { \mathrm { c , b u l k } }$ and constructing low-voltage operating OFETs.

In this work, layered HTEB 2D molecular crystals were prepared on $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ by the drop-casting method (Fig. 1a and b). Firstly, the comparison study of monolayer, 4-layer and 15-layer HTEB 2D crystals with a thickness of $3 . 6 \mathrm { n m }$ , $1 3 . 8 \mathrm { n m }$ and $5 6 . 7 \mathrm { n m }$ was carried out, and the extracted $R _ { \mathrm { c } }$ values for the monolayer, 4-layer and 15-layer OFETs are $1 . 7 7 \ \mathrm { k } \Omega \ \mathrm { c m }$ , $2 6 . 9 \ \mathrm { k } \Omega$ cm and $5 . 1 5 ~ \mathrm { { \bf ~ M } } \Omega$ cm respectively, exhibiting the positive correlation between $R _ { \mathrm { c } }$ and crystal thickness. Afterwards, the OFETs based on MMCs and 4-layer crystals with different channel lengths were fabricated. It was found that the lower contact resistance of the MMC-based devices, compared with the 4-layer singlecrystal devices, resulted in a smaller mobility decrease when the $L$ is shortened. Specifically, the mobility decreased from 0.23 ${ \bigl ( } L = 1 1 . 8 ~ { \mu \mathrm { m } } { \bigr ) }$ to $0 . 1 0 \thinspace { \mathrm { c m } } ^ { 2 } \thinspace \mathbf { V } ^ { - 1 } \thinspace \mathbf { s } ^ { - 1 }$ ${ \it \Delta } L = 2 . 6 ~ { \mu \mathrm { m } } )$ for the MMC device, and from 0.19 ${ \big ( } L = 1 2 . 7 \mu \mathrm { m } { \big ) }$ to $0 . 0 3 7 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 } \left( L = 2 . 1 \mu \mathrm { m } \right)$ for the 4-layer crystal device. Furthermore, the MMC devices with low $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio possess more steady linear mobility at varied $V _ { \mathrm { D S } } ,$ and smaller difference between the linear mobility and saturation mobility. # Experimental

# Materials and 2D molecular crystal preparation

HTEB was synthesized and purified as reported in previous literature.44 HTEB was dissolved in chlorobenzene (Sigma-Aldrich) at the saturation concentration and then diluted 15 times. The $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ $\left( 3 0 0   \ \mathrm { n m } \right)$ substrates were first washed with water, and then washed successively with piranha solution $\left( \mathbf { H } _ { 2 } \mathbf { S } \mathbf { O } _ { 4 } : \mathbf { H } _ { 2 } \mathbf { O } _ { 2 } = \right.$ 7 : 3), deionized water, and isopropyl alcohol, and then blowdried under nitrogen. $\mathrm { H f O } _ { 2 }$ with a thickness of $3 0 \ \mathrm { ~ n m }$ was prepared by atomic layer deposition on heavily doped silicon. $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ and the $\mathrm { S i } / \mathrm { H f } \mathrm { O } _ { 2 }$ substrates were further treated with oxygen plasma for $5 \mathrm { { m i n } }$ . Afterwards, $3 0 ~  { \mu \mathrm { L } }$ diluted chlorobenzene solution of HTEB was drop-cast onto $1 \times 1 \mathrm { c m } ^ { 2 }$ substrates and the substrates were placed in Petri dishes at room temperature for at least 24 hours, after which large-area layered 2D crystals were obtained.

# Device fabrication

The thin Au electrodes ( $\sim 1 0 0 \ \mathrm { n m } )$ were glued onto the 2D crystals to fabricate the top-contact devices with the help of the mechanical probes. By this method, devices with variable channel lengths were fabricated on the $\mathrm { S i O } _ { 2 }$ and $\mathrm { H f O } _ { 2 }$ substrates. The 2D molecular crystals were scratched by the probe to ensure that the devices have similar channel width $( W )$ and to reduce the crosstalk between the edges of the electrodes.

# Results and discussion

The single crystalline films of HTEB can be cast-assembled efficiently on many kinds of substrates due to the strong intermolecular interactions. Similar to some organic molecules,34,45,48

HTEB molecules tend to stack with their long axis standing perpendicular to the substrates, resulting in layer-by-layer growth. Fig. 1b shows the OM image of layered HTEB 2D crystals, which demonstrates that the number of layers could be distinguished clearly from the optical contrast, the corresponding AFM image is shown in Fig. S1 $\bigl ( \mathrm { E S I \dag } \bigr )$ . Fig. 1c and d show the results of GIWAXS experiments performed on multilayer crystals, and exhibit the 2D GIWAXS pattern and 1D GIWAXS plots, respectively. A series of out-of-plane diffraction peaks (h00) are obtained with $d$ -spacing of $3 6 . 8 \mathrm { ~ \AA ~ }$ , which is consistent well with the AFM image of the layered 2D crystals (Fig. S1, ESI†). Besides, obvious in-plane diffractions are also obtained, indicating a high degree of crystallinity. To obtain the in-plane packing parameters, HR-AFM characterization was carried for the monolayer crystals. The HR-AFM image and the 2D fast Fourier transform (FFT) pattern are shown in Fig. 1e and f, respectively. The highly ordered unit cell could be clearly observed in the HR-AFM image. According to the 2D reciprocal lattice in the 2D FFT pattern, lattice constants are estimated to be, $b = 5 . 6 \mathrm { ~ \AA ~ }$ , $c = 7 . 5 \mathrm { ~ \AA ~ }$ with $\theta = 8 2 . 9 ^ { \circ }$ . The multilayer crystals were found to possess similar in-plane packing parameters on $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ (shown in Fig. S2, ESI†). The results of HR-AFM are almost consistent with the previous results derived from the TEM and XRD measurements.40

For the merits of the obviously layered structure of HTEB 2D crystals, it provides us the opportunity to study the relationship between semiconductor thickness and OFET performance. HTEB 2D crystals with different thickness were used to fabricate top contact OFETs on the $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ substrate. Fig. 2a–c show three HTEB 2D crystals of different thickness between the drain and source electrodes. Fig. 2d–f show the corresponding AFM images, from which the film thicknesses are determined to be $3 . 6 \ \mathrm { n m }$ , $1 3 . 8 \ \mathrm { n m }$ and $5 6 . 7 \ \mathrm { n m }$ , respectively. According to the estimated $d \cdot$ -spacing of $3 6 . 8 \mathring { \mathrm { A } }$ , the three crystals are monolayer, 4-layer and 15-layer crystals, respectively.

The electrical characterizations of the devices fabricated with monolayer, 4-layer and 15-layer crystals were then carried out. Fig. 3b and e depict the typical transfer and output characteristics of the 4-layer single-crystal device, respectively. The 4-layer singlecrystal device also exhibited an excellent off-state current, with the on/off current ratio of $7 . 4 \times 1 0 ^ { 5 }$ . It is expected that the device mobility of OFETs will be significantly dependent on the channel length when there is a large $R _ { \mathrm { c } }$ in the devices. In comparison, the device mobility should be little varied for devices with different channel lengths if the impact of the contact resistance is negligible. To see this effect, a detailed characterization of MMC devices with the channel lengths of $1 1 . 8 ~ \mu \mathrm { m }$ and $2 . 6 ~ \mu \mathrm { m }$ $\cdot W = 2 0 . 6 ~ \mu \mathrm { m }$ and $1 9 . 2 \mu \mathrm { m }$ respectively) and the 4-layer single-crystal devices with the channel lengths of $1 2 . 7 ~ { \mu \mathrm { m } }$ and $2 . 1 ~ \mu \mathrm { m }$ $W = 3 0 . 6 ~ { \mu \mathrm { m } }$ and $2 4 . 4 \mu \mathrm { m }$ respectively) was carried out. Typical transfer curves of these devices are shown in Fig. 4a and b, where $V _ { \mathbf { G } }$ was swept from 20 to $- 4 0 \mathrm { ~ V ~ } _ { ; }$ , with $V _ { \mathrm { D S } }$ ranging from $^ { - 1 }$ to $- 4 0 \mathrm { ~ V ~ }$ with a step of $- 1 \mathrm { \bf ~ V } .$ . As $V _ { \mathrm { D S } }$ increased from $^ { - 1 }$ to $- 4 0 \mathrm { ~ V ~ }$ , the transfer curves gradually turned into saturated behaviour from linear behaviour. With the decrease of the channel length, $I _ { \mathrm { D S } }$ increased in the MMC devices but decreased in the 4-layer single-crystal devices. Fig. 4c shows the mobility of these devices. The linear mobility was calculated with $V _ { \mathrm { D S } }$ ranging from $^ { - 1 }$ to $- 1 0 \mathrm { V }$ , and the saturation mobility was calculated with $V _ { \mathrm { D S } }$ ranging from $^ { - 3 1 }$ to $- 4 0 \ \mathrm { V } .$ . In the MMC device, the saturation mobility decreased slightly by 2.3 times from 0.23 to $0 . 1 0 \thinspace { \mathrm { c m } } ^ { 2 } \thinspace \mathbf { V } ^ { - 1 } \thinspace { \mathrm { s } } ^ { - 1 }$ when shortening the channel length from 11.8 to $2 . 6 ~ \mu \mathrm { m }$ . However, in the 4-layer single-crystal device, saturation mobility decreased by 5.14 times from 0.19 to $0 . 0 3 7 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \ s ^ { - 1 }$ as the channel length decreased from 12.7 to $2 . 1 ~ \mu \mathrm { m }$ . This phenomenon could be explained by the impact of the $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio on device performance. As seen in Fig. 3j, the $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio in the MMC devices only increased from 0.024 to 0.151 due to the low $R _ { \mathrm { c , b u l k } }$ in the MMC devices when the channel length was decreased from $8 5 . 3 ~  { \mu \mathrm { m } }$ to $9 . 7 \ \mu \mathrm { m }$ , while the $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio of the 4-layer single-crystal devices increased from 0.19 to 0.84 when the channel length is varied in similar ways. The obvious increase in $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio would cause smaller $V _ { \mathrm { D S } }$ distribution in the conducting channel, which leads to lower performance.11 Furthermore, it is worth noting that the low $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio MMC devices possess more steady and more reliable mobility at a varied $V _ { \mathrm { D S } } ,$ and smaller deviation of the linear and saturation mobility compared with the 4-layer single-crystal device, which indicates a more steady operation for the MMC devices over the large voltage scale. This is actually because the effect of contact resistance is also dependent on the $V _ { \mathrm { D S } }$ . Hence, the the MMCs might have an overwhelming advantage over the multilayer crystals for fabricating high-performance, short-channel devices.

Furthermore, low-voltage operating OFETs of HTEB MMCs were realized on the $\mathrm { S i / H f O } _ { 2 }$ $( 3 0 \ \mathrm { n m } )$ substrate. The OM image of the HTEB 2D crystal on the $\mathrm { H f O } _ { 2 }$ substrate is shown in Fig. 5a, and the crystals possess similar inter-layer crystal spacing along the out-of-plane orientation to the crystals on the $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ substrates (Fig. 5b). The high dielectric constant of the $\mathrm { H f O } _ { 2 }$ layer results in an efficient charge accumulation in the channel at a low $V _ { \mathbf { G } } , ^ { 4 9 }$ which promises low-operating voltage.41,42 Fig. 5c shows the MMC device with channel length and width of $1 . 8 \mu \mathrm { m }$ and $7 2 . 9 \mu \mathrm { m }$ . The transfer curve of the MMC device at a low operating voltage of $- 2 \textbf { V }$ is shown in Fig. 5d, exhibiting a high on/off current ratio of $4 . 1 \times 1 0 ^ { 5 }$ , and saturation mobility of $0 . 2 6 \thinspace \mathrm { c m } ^ { 2 } \thinspace \mathrm { V } ^ { - 1 } \thinspace s ^ { - 1 }$ with low $V _ { \mathrm { T } }$ of $\mathbf { 0 . 3 1 \ V }$ . The corresponding output curve is shown in Fig. 5e, in which the linear region at low $V _ { \mathrm { D S } }$ can be observed, implying small $R _ { \mathrm { c } }$ $\left( 5 4 0 \Omega \mathrm { c m } \right.$ , Fig. 5f). For comparison, the 4-layer single-crystal device with the channel length and width of $1 . 5 \mu \mathrm { m }$ and $8 3 . 5 \mu \mathrm { m }$ is shown in Fig. S6a and b (ESI†). The transfer curve (Fig. S6c, ESI†) exhibits the on/off current ratio of $2 . 0 \times 1 0 ^ { 4 }$ , and low saturation mobility of $0 . 0 1 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ with $V _ { \mathrm { T } }$ of $\mathbf { 0 . 6 4 V . }$ . The corresponding output curve (Fig. S6d, $\mathrm { E S I \dag }$ ) presents obvious S-type nonlinearity at low $V _ { \mathrm { D S } } ,$ implying large $R _ { \mathrm { c } }$ $2 4 . 5 \ \mathrm { k } \Omega \ \mathrm { c m }$ , Fig. S6e, ESI†). The 4-layer crystal device with a channel length of $1 . 5 ~ { \mu \mathrm { m } }$ possesses a high $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio of 0.95 (Fig. S6f, $\mathrm { E S I \dag }$ ), which indicates only $5 \%$ of the applied drain voltage drops in the conducting channel, resulting in a low device mobility.32 In contrast, the MMC device still keeps high performance at a channel length of $1 . 8 ~ \mu \mathrm { m }$ , owing to the low $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio of 0.31 (Fig. S6f, $\mathrm { E S I \dagger }$ ). The results again imply that the low $R _ { \mathrm { c , b u l k } }$ of HTEB MMC is critical to achieve short-channel OFETs with high performance. High-performance, low-voltage operating HTEB MMC devices with ultra-short channels $\left[ L < 1 0 0 \mathrm { n m } \right]$ ) could be expected by further optimizing the semiconductor/electrode interface and the dielectric layer.

# Conclusions

In summary, HTEB single-crystal OFETs with monolayer and multi-layer crystals were fabricated, and the $R _ { \mathrm { c } }$ was found to closely correlate with the crystal thickness. The low $R _ { \mathrm { c , b u l k } }$ of the MMC devices is beneficial in achieving low $R _ { \mathrm { c } }$ , and thus results in a low $R _ { \mathrm { c } } / R _ { \mathrm { t o t a l } }$ ratio, which endows the MMC-based devices with a high mobility at channel lengths smaller than $2 \ \mu \mathrm { m }$ , small deviation between the linear and saturation mobility, and stable performance over a large $V _ { \mathrm { D S } }$ scale. Afterwards, the lowvoltage operating HTEB MMC devices were fabricated on $\mathrm { H f O } _ { 2 }$ . The devices possess high mobility of $0 . 2 6 ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ and low $V _ { \mathrm { T } }$ of $0 . 3 1 \mathrm { V }$ at a channel length of $1 . 8 \mu \mathrm { m }$ . All these results point to the fact that the MMCs have great potential in the fabrication of short channel OFETs with high device performance.
