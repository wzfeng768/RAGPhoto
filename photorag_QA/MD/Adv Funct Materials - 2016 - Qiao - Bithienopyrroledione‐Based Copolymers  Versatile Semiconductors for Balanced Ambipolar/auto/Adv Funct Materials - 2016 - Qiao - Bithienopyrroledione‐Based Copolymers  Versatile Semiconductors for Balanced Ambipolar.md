# Bithienopyrroledione-Based Copolymers, Versatile Semiconductors for Balanced Ambipolar Thin-Film Transistors and Organic Solar Cells with $V _ { \infty } > 1 ~ \mathsf { V }$

Xiaolan Qiao, Qinghe Wu, Hongzhuo Wu, Jidong Zhang, and Hongxiang Li\*

Conjugated polymer semiconductors P1 and P2 with bithienopyrroledione (bi-TPD) as acceptor unit are synthesized. Their transistor and photovoltaic performances are investigated. Both polymers display high and balanced ambipolar transport behaviors in thin-flm transistors. P1-based devices show an electron mobility of $\mathsf { 1 . 0 2 c m ^ { 2 } V ^ { - 1 } } \mathsf { s ^ { - 1 } }$ and a hole mobility of $0 . 3 3 \mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } \mathsf { s } ^ { - 1 }$ , one of the highest performance reported for ambipolar polymer transistors. The electron and hole mobilities of P2 transistors are 0.36 and $0 . 7 6 \mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } s ^ { - 1 }$ , respectively. The solar cells with $\mathsf { P C } _ { 7 1 } \mathsf { B M }$ as the electron acceptor and P1/P2 as the donor exhibit a high $\pmb { V _ { \mathrm { o c } } }$ about $\bar { \mathsf { 1 . 0 } } \mathsf { V } ,$ and a power conversion efficiency of $6 . 4 6 \%$ is observed for P1-based devices without any additives and/or post treatment. The high performance of P1 and P2 is attributed to their crystalline films and short $\pi - \pi$ stacking distance $( < 3 . 5 \mathbb { A } )$ . These results demonstrate (1) bi-TPD is an excellent versatile electron-deficient unit for polymer semiconductors and (2) bi-TPD-based polymer semiconductors have potential applications in organic transistors and organic solar cells.

# 1. Introduction

Donor-acceptor (D-A) type conjugated copolymers are being intensely investigated for their promising applications in solution-processed organic thin-film transistors (OTFTs) and organic solar cells. Due to the efforts made in the exploration of new conjugation building blocks and the modification of side chains, high-performance D-A polymer transistors with hole and electron mobilities exceeding $1 0 \ \mathrm { \ c m } ^ { 2 } \ \mathrm { \ V } ^ { - 1 } \ \mathrm { \ s } ^ { - 1 }$ have been reported recently.[1,2] Comparing with the mono-polar polymer semiconductors, solution-processable ambipolar polymer semiconductors are beneficial to simplify the circuit design and fabrication process of organic complementary metal-oxide-semiconductor (CMOs)-like logic circuits.[3-5] A common belief about ambipolar semiconductors is that they should have suitable highest occupied molecular orbital (HOMO) and lowest unoccupied molecular orbital (LUMO) energy levels for Au electrode so as to facilitate the efficient hole/electron injection and transport. D-A polymers are good candidates for ambipolar semiconductors. Till now, most of the reported high-performance ambipolar polymer semiconductors are diketopyrolopyrrole (DPP) and isoindigo (IID)-based D-A polymers, a substantial part of which displays unbalanced hole and electron transport.[6-13] As an ideal ambipolar semiconductor, it should have not only high performance but also balanced hole and electron mobilities. Therefore, it is an urgent need to develop high-performance ambipolar polymer semiconductors with balanced hole and electron mobilities.

Thieno[3,4-c]pyrrole-4,6-dione (TPD) is a promising acceptor unit and has been used as building block in D-A polymers for organic photovoltaics (OPVs) and p-channel OTFTs.[14-22] Currently, a power conversion efficiency (PCE) of $7 . 5 \%$ and a hole mobility up to $1 . 3 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ have been reported for TPD-based polymer semiconductors.16-20,22] As a derivative of TPD, bithienopyrroledione (1,1-bithieno[3,4-c)pyrrole-4 $, 4 ^ { \prime } , 6 , 6 ^ { \prime }$ -tetraone, bi-TPD) has planar structure and exhibits stronger electron-withdrawing property than that of TPD,23-25] suggesting its potential applications in high-performance ambipolar polymer semiconductors. However, bi-TPD-based D-A polymers are rarely reported. In this paper, we designed and synthesized bi-TPDbased polymer semiconductors P1 and P2 and investigated their applications in OTFTs and solar cells. Both P1 and P2-based transistors exhibited ambipolar transport with balanced hole and electron mobilities. The maximum electron/hole mobilities were $1 . 0 2 / 0 . 3 3 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ for P1 and $0 . 3 6 / 0 . 1 2 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ for P2. Atomic force microscopy (AFM) and grazing incidence X-ray diffraction (GIXD) revealed that the films of P1 and P2 were continuous and high crystalline with short $\pi { - } \pi$ stacking distance $( < 3 . 5 \mathrm { ~ \normalfont ~ \AA ~ } )$ , being responsible for their high performances. Organic solar cells with P1 (P2): $\mathrm { \cdot P C } _ { 7 1 } \mathrm { B M }$ blend as active layers showed a high open-circuit voltage $( V _ { \mathrm { o c } } )$ about $1 . 0 \ \mathrm { V } ,$ which was mainly attributed to the low HOMO levels of P1 and

P2. The highest PCE of P1 and P2-based devices was $6 . 4 6 \%$ and $1 . 5 6 \%$ respectively. The above results highlight that (1) bi-TPD is an excellent versatile electron-deficient unit for polymer semiconductors and (2) bi-TPD-based polymers have great potential applications in organic electronics.

# 2. Results and Discussion

# 2.1. Syntheses and Characterization

The chemical structures and synthetic routes of P1 and P2 are shown in Scheme 1. P1 and P2 were synthesized through conventional Stille coupling of the dibrominated bi-TPD (compound 1) with corresponding bis-stannylated DTBT (compound 2) and DT2FBT (compound 3), respectively. The crude polymers were ultimately purified by precipitation into methanol followed by successive Soxhlet extractions with organic solvents. Their number-average molecular weights $( M _ { \mathrm { n } } )$ were measured with high temperature $( 1 5 0 ~ ^ { \circ } \mathrm { C } )$ gel-permeation chromatography (GPC) in 1,2,4-trichlorobenzene using polystyrene as standard. The $M _ { \mathrm { n } } / \mathrm { P D I }$ (polydispersity index) values were $6 2 . 5 ~ \mathrm { k D a } / 2 . 8 9$ for P1 and $6 1 . 3 \mathrm { { k D a } } / 4 . 3 8$ for P2. Both polymers exhibited good thermal stability measured by thermal gravimetric analysis (TGA) with a decomposition temperature over $4 3 5 ~ ^ { \circ } \mathrm { C }$

# 2.2. Optical and Electrochemical Properties

The UV-vis absorption spectra of P1 and P2 in hot dilute 1,2,4-trichlorobenzene solutions and as thin films are illustrated in Figure 1a,b. Both polymers showed classic dual band absorptions in solution, with the maximum absorption peak at $6 0 6 \ \mathrm { n m }$ for P1 and $5 9 2 ~ \mathrm { n m }$ for P2. Comparing with those of solutions, the maximum absorptions of P1 and P2 films were red-shifted about 14 and $1 0 \ \mathrm { n m }$ , respectively, and high intensity shoulder peaks at $6 6 7 ~ \mathrm { n m }$ for P1 and $6 4 6 ~ \mathrm { n m }$ for P2 were observed. The absorption changes suggested the better planar and ordered backbone conformation of P1 and P2 in films. The optical bandgap calculated from the initial film absorption was $1 . 7 1 \ \mathrm { e V }$ for P1 and $1 . 7 5 \ \mathrm { e V }$ for P2.

The electrochemical behaviors of P1 and P2 were investigated on thin films through cyclic voltammetry (CV). As shown in Figure 1c,d, both polymers exhibited quasi-reversible oxidation peaks and the onset oxidation of P2 was about $0 . 1 3 \mathrm { ~ V ~ }$ higher than that of P1 measured under the same conditions, ascribed to the stronger electron withdrawing property of 5,6-difluorobenzo[c][1,2,5]thiadiazole (2FBT) than that of benzo[c][1,2,5]thiadiazole (BT). The HOMO energy levels of P1 and P2 were determined to be $- 5 . 7 2$ and $- 5 . 8 5 \ \mathrm { ~ e V }$ by using ferrocene as the standard. The LUMO levels of P1 and P2 were $- 4 . 0 1$ and $- 4 . 1 0 \ \mathrm { e V } ,$ respectively, which were calculated from the HOMO energy levels and the optical bandgaps. The detailed optical and electrochemical properties of P1 and P2 are summarized in Table 1. Judging from the energy levels, when Au (with a work function of ${ \approx } 5 . 2 ~ \mathrm { e V }$ is utilized as the source and drain electrodes, the injection barriers of electron and hole from Au electrodes will be small enough. Therefore, P1 and P2 should be suitable to fabricate ambipolar transistors. Moreover, the low HOMO levels of P1 and P2 would be beneficial for high open-circuit voltage $\left[ V _ { \mathrm { o c } } \right]$ values in the bulk heterojunction polymer solar cells.

To elucidate the observed TFTs performance of P1 and P2 thin films, we explored the morphology and structural features of these films by atomic force microscopy (AFM) and grazing incidence X-ray diffraction (GIXD). Both P1 and P2 films showed good continuity and uniformity before and after thermal annealing (Figure 3). The root-mean-square (RMS) values of P2 films were larger than that of P1 films. With the aim to investigate the packing structures of P1 and P2 in films, 1D out-of-plane and in-plane GIXD diffractions were first performed on annealed P1 and P2 films (Figure 4a,b). For P1, strong diffraction peaks at $q = 0 . 2 4 1 \mathring { \mathrm { A } } ^ { - 1 }$ and weak peaks at $q = 1 . 8 0 6 \textup { \AA } ^ { - 1 }$ were presented both in the out-of-plane and inplane directions, corresponding to the (100) diffraction peaks with a lamellar stacking distance of 26.07 A and the (010) peak with a $\pi { - } \pi$ stacking distance of $3 . 4 8 \mathrm { ~ \AA ~ }$ respectively. These results suggested the coexistence of edge-on and face-on orientations in the film, which led to the formation of 3D charge transport pathways and facilitated charge carriers transport. For P2, the (100) diffraction peak, located at $q = 0 . 2 4 8 \mathring { \mathrm { A } } ^ { - 1 }$ with a lamellar stacking distance of $2 5 . 3 3 \mathring \mathrm { A }$ only appeared in the outof-plane direction. Besides, the (010) peak at $q = 1 . 8 1 1 \mathring { \mathrm { A } } ^ { - 1 }$ with $\pi { - } \pi$ stacking distance of $3 . 4 7 \mathring { \mathrm { A } }$ emerged in the in-plane direction. This indicated P2 adopted edge-on arrangement in films. The weak peaks at around $1 . 5 1 \ \mathring { \mathrm { A } } ^ { - 1 }$ were the diffractions of the polymer alkyl chains. As shown in Figure 4c-h, 2D-GIXD measurements of P1 and P2 films annealed at different temperatures were further carried out to fully analyze the relationship of device performances and aggregation structures. The as-spun films of P1 adopted face-on orientation. Upon annealing at $1 6 0 ~ ^ { \circ } \mathrm { C } ,$ the (100) peak was greatly enhanced in $q _ { \mathrm { x y } }$ axis and the $( h 0 0 )$ peaks up to third orders appeared in $q _ { z }$ axis. Moreover, faint (010) peaks were observed in both $q _ { \mathrm { x y } }$ axis and $q _ { z }$ -axis. This revealed the coexistence of edge-on and face-on orientations in film, agreeing well with the 1D-GIXD result (Figure 4a). Further increasing the annealing temperature to $2 0 0 ~ ^ { \circ } \mathrm { C }$ the (100) peak in $q _ { \mathrm { x y } }$ -axis and the (010) peak in $q _ { z }$ axis became weaker, indicating the deterioration of film crystallinity despite the comparable strong intensity $( h 0 0 )$ peaks along $q _ { z }$ -axis. The highest crystallinity at $1 6 0 ~ ^ { \circ } \mathrm { C }$ and the 3D charge transport pathways were consistent with the optimized OTFTs performance. For P2, high orders of (ho0) peaks were observed in the as-spun films along $q _ { z }$ -axis, suggesting its edge-on orientation and crystallinity property. The high crystallinity of P2 films before and after annealing agreed well with the almost unchanged device performances under different thermal annealing temperatures. These results indicated that the replacement of BT with 2FBT increased the interchain interactions of polymers, leading to different polymer packing behaviors in films.

# 2.4. Photovoltaic Performance and Thin-Film Microstructure Analysis

The photovoltaic properties of P1 and P2 were investigated by a conventional solar cell structure of ITO/PEDOT:PSS/P1 (P2) $\mathrm { \cdot P C _ { 7 1 } B M / C a / A l }$ The current density $( J )$ voltage (V) curves with various polymer/ $\mathrm { ^ { \prime P C } } _ { 7 1 } \mathrm { B M }$ weight ratios under AM 1.5G illumination are shown in Figure 5a, and the corresponding photovoltaic parameters are summarized in Table 3. The devices fabricated from P1 and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ blends exhibited a $V _ { \mathrm { o c } }$ of $1 . 0 2 { \mathrm { - } } 1 . 0 3 \ \mathrm { V } ,$ which was related to the large energy difference between the HOMO energy level of P1 and the LUMO energy level of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ . This high $V _ { \mathrm { o c } }$ $( > 1 . 0 \mathrm { ~ V ) }$ is rarely reported in polymer solar cells.29-33] The optimal weight ratio for P1 to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ was 1:1. Without any additive and post treatment, the best device performance based on $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ exhibited a PCE of $6 . 4 6 \%$ with $V _ { \mathrm { o c } } = 1 . 0 2 \mathrm { ~ V } ,$ $J _ { \mathrm { s c } } = 9 . 4 8 ~ \mathrm { m A } ~ \mathrm { c m } ^ { - 2 }$ and $\mathrm { F F } = 0 . 6 6 8$ . Similar to that of $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ -based devices also showed high $V _ { \mathrm { o c } }$ of $0 . 9 6 { - } 1 . 0 \mathrm { ~ V } .$ However, the $J _ { \mathrm { s c } }$ and FF of $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ cells were much lower than that of the $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ ones, which was due to its worse phase separation and will be discussed below. The highest PCE of $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ device was $1 . 5 6 \%$ with $V _ { \mathrm { o c } } = 0 . 9 6 \ \mathrm { V } ,$ $J _ { \mathrm { s c } } = 2 . 5 5 ~ \mathrm { m A } ~ \mathrm { c m } ^ { - 2 }$ , and $\mathrm { F F } = 0 . 6 3 6$ at a blend weight ratio of 1:1. Figure 5b illustrates the external quantum efficiency (EQE) curves of $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ and $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ devices prepared at blend weight ratio of 1:1. The $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ device showed a broad spectral response in the range of $3 0 0 { - } 7 3 0 ~ \mathrm { n m }$ and reached a maximum EQE value of $5 0 . 4 \%$ at $6 3 0 \mathrm { n m }$ . The theoretical $J _ { \mathrm { s c } }$ calculated through integration of EQE spectrum was $9 . 3 2 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ , being well consistent with the experimental value of $9 . 4 8 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ . The photoresponse region of $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ device was relatively narrow than that of $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ device, attributed to the blue shift of the absorption spectra of P2 film. Furthermore, the EQE value of $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ device was much lower than that of $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ device, demonstrating its low $J _ { \mathrm { s c } }$ value.

AFM and transmission electron microscopy (TEM) measurements were performed to investigate the blend film's morphological properties. The $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ blend films were consisted of small granular domains and exhibited smoother surface with a RMS value of $2 . 0 \ \mathrm { n m }$ (Figure 6a). Larger size domains were observed in $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ blend film with a RMS value of $1 4 . 0 \mathrm { n m }$ (Figure 6d). As shown in Figure 6b,e, their TEM images presented obvious dark and light domains, corresponding to the aggregations of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ and polymer, respectively. Interpenetrating networks throughout the whole film were observed in both blend films, whereas large-scale aggregation structures of the polymer (high brightness areas) and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ (dark porous) were formed in $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ blend films, suggesting the poor phase separation property of $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ bend films.

2D-GIXD diffraction measurement was carried out to figure out the crystalline and molecular packing natures of P1 and P2 in the pristine blend films. As shown in Figure 6c, (100) diffraction peak of P1 was observed in both $q _ { \mathrm { x y } }$ axis and $q _ { z }$ -axis. In addition, faint peak of (010) plane appeared in $q _ { z }$ -axis. The results indicated that edge-on and face-on orientations coexisted for P1 in the blend film. The face-on orientation was favorable for charge carriers transport in the polymer solar cells. In $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ blend film, (100) and (200) diffraction peaks of P2 were observed in $q _ { z }$ -axis (Figure 6f), corresponding to edge-on orientation. Obviously, the crystallinity of P2 was much stronger than that of P1 in blend films, which was coincident with the higher RMS value of $\mathrm { P } 2 { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ films and disadvantageous for the phase separation and in turn the $J _ { \mathrm { s c } } .$ These findings were in good agreement with the photovoltaic performances of $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ and $\mathrm { P } 2 { : } \mathrm { P } \mathrm { C } _ { 7 1 } \mathrm { B } \mathrm { M }$ -based devices.

# 3. Conclusion

Novel D-A type conjugated polymers P1 and P2 containing bi-TPD units were strategically designed and synthesized. Both polymers showed high and balanced ambipolar performances. P1-based devices showed an electron mobility of $1 . 0 2 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ and a hole mobility of $0 . 3 3 \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ , one of the highest performance reported for ambipolar polymer transistors. And P2-based devices exhibited an electron mobility of $0 . 3 6 ~ \mathrm { c m } ^ { 2 } ~ \mathrm { V } ^ { - 1 } ~ \mathrm { s } ^ { - 1 }$ and a hole mobility of $0 . 1 6 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ The outstanding performance of P1 and P2 was attributed to their continuous and crystalline films with strong $\pi - \pi$ interactions among the polymer chains. Moreover, these polymers can be functionalized as donor materials in OPVs. The solar cells fabricated with $\mathbf { P 1 } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ blend films exhibited a high $V _ { \mathrm { o c } }$ of $1 . 0 2 \mathrm { ~ V ~ }$ and a highest PCE of $6 . 4 6 \%$ . These results demonstrate (i) bi-TPD is an excellent versatile unit to offer multi-functional polymer semiconductors and (ii) bi-TPD-based polymers have greatly potential applications in organic electronics.

The thermal annealing of the device at different temperatures was conducted in nitrogenfilled glove box. The electrical performance of TFTs was tested in $\mathsf { N } _ { 2 }$ atmosphere using a Keithley 4200 semiconductor parametric analyzer. The field-effect mobility was calculated in the saturation regime using the following equation: $I _ { \mathsf { D } \mathsf { S } } = ( \mu \mathsf { W } C _ { \mathsf { i } } / 2 L ) ( V _ { \mathsf { G } } - V _ { \mathsf { T } } ) ^ { 2 }$ where $I _ { \mathsf { D } \mathsf { S } }$ is the drain-to-source current, $\mu$ is the mobility, and $V _ { \mathrm { { G } } }$ and $V _ { \intercal }$ are the gate voltage and threshold voltage, respectively.
