# Organic solar cells based on a Cu O/FBT-TH4 anode buffer layer with enhanced power conversion efficiency and ambient stability†

Yaxiong Guo,a Hongwei Lei,a Liangbin Xiong, $\textcircled { 1 0 } \textcircled { 2 }$ Borui Lia and Guojia Fang $\textcircled{1}$ a

rsc.li/materials-c

An organic–inorganic integrated hole transport layer (HTL) composed of a semicrystalline 5,6-difluorobenzothiadiazole based conjugated polymer FBT-TH4 and cuprous oxide $_ { ( \mathsf { C u } _ { 2 } \mathsf { O } ) }$ is successfully incorporated into conventional structured organic solar cells (OSCs). The optimized OSCs show a high power conversion efficiency of up to $9 . 5 6 \%$ and good stability under ambient conditions. The results highlight the potential application of this organic–inorganic integrated HTL in OSCs.

# 1 Introduction

Organic solar cells (OSCs) have attracted much attention in the past few decades due to their various advantages such as low cost, light weight, flexibility, and potential to be developed into large-area modules by a solution processing method.1–14 With the rapid progress in light harvesting materials and interfacial engineering, power conversion efficiencies (PCEs) over $1 2 \%$ have been achieved in single-junction OSCs.5,15–20 Besides the design and synthesis of narrow-bandgap polymer materials with higher absorption coefficients and charge mobilities, interfacial engineering provides a powerful strategy to enhance the efficiency and stability of OSCs. $^ { 7 - 9 , 1 1 , 2 1 - 2 9 }$ Hole transport materials (HTMs) play an important role in both extracting and transporting the photogenerated holes from the polymer materials to the anode, thus suppressing undesired recombination losses at the interfaces. Hence, the development of efficient HTMs has emerged as one of the hottest research areas in the field of OSCs. Poly(3,4-ethylenedioxythiophene):poly(styrenesulfonate acid) (PEDOT:PSS) has been the most commonly used anode interfacial material to date, particularly for the fabrication of conventional structured OSCs. However, previous studies have demonstrated that the weak acidity and low chargecarrier mobility of PEDOT:PSS significantly limit its potential for up-scaled applications of OSCs. Furthermore, samples of this material will re-absorb water if they are not used immediately.30–32 Therefore, it is of great importance to explore alternative HTMs with low cost, facile synthesis and high charge-carrier mobility relative to PEDOT:PSS. Recently, stable and easily-synthesized metal oxides, including molybdenum oxide $\left( \mathbf { M o O } _ { 3 } \right)$ , nickel oxide (NiOx), tungsten oxide $\left( \mathrm { W O } _ { 3 } \right)$ and copper oxide (CuOx), have been developed as HTMs.33–35 Among them, CuOx shows advantages including p-type conductivity, better conductivity and good electron-blocking ability.36,37 In our previous work, we investigated thoroughly a p-type copperbased oxide with mobility as high as $1 0 ^ { - 2 } { - } 1 0 ^ { 1 } \thinspace \mathrm { c m } ^ { 2 } \thinspace \mathrm { V } ^ { - 1 } \thinspace s ^ { - 1 }$ and fabricated OSCs with it as a HTM whose holes are induced by Cu vacancies and $^ \mathrm { o }$ interstitial defects. We also demonstrated that $\mathrm { C u } _ { 2 } \mathrm { O }$ is a very promising HTM candidate for improving the photovoltaic performance and fabricating cost effective OSCs.38

However, defects such as Cu vacancies $\left( \mathrm { V } _ { \mathrm { C u } } \right)$ and oxygen interstitials $\mathrm { ( O _ { i } ) }$ are always present at the surface of $\mathrm { C u } _ { 2 } \mathrm { O }$ and act as charge traps leading to the possibility of recombination of the photogenerated charges thus causing the degradation of the stability of solar cells. Another well-known feature of $\mathrm { C u } _ { 2 } \mathrm { O }$ defect states is their sensitivity to several adsorbates like oxygen species, which are always present in air-processed $\mathrm { C u } _ { 2 } \mathrm { O }$ films and have a negative impact on the photostability of the resulting solar cell. To address these issues, here, we attempt to explore an ultrathin layer of semicrystalline 5,6-difluorobenzothiadiazole based conjugated polymer FBT-TH4 to join with $\mathrm { C u } _ { 2 } \mathrm { O }$ . Although conjugated polymer FBT-TH4 has been extensively used as a p-type semiconductor in thin film field effect transistors and as the donor of polymer material PV devices due to favorable properties such as high hole mobility, as well as excellent thermal and chemical stability, its successful application in inorganic p-type hole transport materials has never been explored to the best of our knowledge.39,40

In this study, we employ an ultrathin layer of conjugated polymer FBT-TH4, as an interfacial modification layer to reengineer the surface of the sputter processed $\mathrm { C u } _ { 2 } \mathrm { O }$ HTM. Relevant measurements reveal that the $\mathrm { C u } _ { 2 } \mathrm { O } /$ FBT-TH4 HTM showed increased hole mobility and an up-shift in $W _ { \mathrm { F } } ,$ which are crucial for enhancing the hole collection from the active layer to the anode. The optimized average PCE of $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } { \cdot } \mathrm { T H } 4$ based OSCs achieved a maximum of $9 . 5 6 \%$ , which shows a significant enhancement in PCE compared with that of the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ hole transport layer (HTL) or PEDOT:PSS based OSCs. Our results show the great potential of FBT-TH4 modified $\mathrm { C u } _ { 2 } \mathrm { O }$ for fabricating highly efficient and low-cost OSCs.

# 2 Results and discussion

The optical properties of ITO glass covered with the anode buffer layer were determined using optical transmittance measurements. As shown in Fig. 1a, it can be seen clearly that the $\mathrm { C u } _ { 2 } \mathrm { O }$ layer with high optical transmittance will not cause additional loss of photons. Meanwhile, the additional FBT-TH4 layer does not significantly compromise the number of photons being absorbed by the photoactive layer.

The electrical properties of different anode buffer layers play an important role in determining the charge transfer and charge collection in OSCs. To estimate the electrical conductivities of $\mathrm { C u } _ { 2 } \mathrm { O }$ and $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } { \cdot } \mathrm { T H } 4$ thin films, the $J { - } V$ characteristics of the device with a structure of $\mathrm { I T O } / \mathrm { C u } _ { 2 } \mathrm { O }$ (or $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 } $ ) HTM/Au were investigated. As shown in Fig. 1b, the linear dependence J–V curves imply a well formed ohmic contact. The electrical conductivity of the $\mathrm { C u } _ { 2 } \mathrm { O }$ thin film and $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } { \cdot } \mathrm { T H } 4$ thin film is estimated to be $3 . 0 2 \times { { 1 0 } ^ { - 3 } }$ and $4 . 6 9 \times 1 0 ^ { - 3 } \mathrm { { S c m } ^ { - 1 } }$ , respectively. Compared with the pristine $\mathrm { C u } _ { 2 } \mathrm { O }$ film, such high electrical conductivity of the $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ ultrathin film would facilitate charge transport and reduce the series resistance for OSCs.

The surface of the $\mathrm { C u } _ { 2 } \mathrm { O }$ film becomes relatively smoother with FBT-TH4 layer modification, as shown in the atomic force microscopy (AFM) images of Fig. 1c. The root-mean square (RMS) roughness $\left( R _ { \mathrm { q } } \right)$ of the $\mathrm { C u } _ { 2 } \mathrm { O } \ \mathrm { H T L }$ is $7 . 1 \ \mathrm { n m }$ while that of the $\mathrm { C u } _ { 2 } \mathrm { O } /$ FBT-TH4 HTL is just $1 . 9 \mathrm { n m }$ , which is consistent with the SEM images (Fig. S1, $\mathrm { E S I \dagger }$ ). The SEM morphology are an untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ film and a FBT-TH4 modified $\mathrm { C u } _ { 2 } \mathrm { O }$ HTL surface fabricated from $1 \mathrm { m g } \mathrm { m L } ^ { - 1 }$ FBT-TH4 solution, respectively. No obvious $\mathrm { C u } _ { 2 } \mathrm { O }$ crystals and only a smooth surface can be detected using SEM.

We applied ultraviolet photoelectron spectroscopy (UPS) to measure the work function of the $\mathrm { C u } _ { 2 } \mathrm { O }$ surface. The work functions of the untreated and FBT-TH4 treated $\mathrm { C u } _ { 2 } \mathrm { O }$ surfaces are $- 4 . 9 8$ and $- 5 . 0 8 \ \mathrm { e V }$ , respectively. The valence band (VB) edges of $\mathrm { C u } _ { 2 } \mathrm { O }$ and FBT-TH4 treated $\mathrm { C u } _ { 2 } \mathrm { O }$ have been determined to be 5.20 and $5 . 2 5 \ \mathrm { e V }$ below the vacuum level, respectively (Fig. S2, $\mathrm { E S I \dagger }$ ). It was found that the $W _ { \mathrm { F } }$ of the $\mathrm { { C u } } _ { 2 } \mathrm { { O } } /$ FBT-TH4 layer is very close to the HOMO of the active layers. It is expected that a smaller energy level offset between the active layer and the anode will be formed when $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ was used as the anode buffer layer. It is well known that the small energy level offset is beneficial for the charge carrier extraction. Therefore, $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ will play a better bridging role in the cascade energy level sequence thus facilitating charge transfer more than a single $\mathrm { C u } _ { 2 } \mathrm { O }$ layer. The formation of $\mathrm { C u } _ { 2 } \mathrm { O }$ was also confirmed by X-ray diffraction data and X-ray photoelectron spectroscopy (Fig. S3, $\mathbf { E S I \dagger }$ ).

Fig. 2a shows the device architecture of a regular OSC based on FBT-TH4 treated $\mathrm { C u } _ { 2 } \mathrm { O }$ and the corresponding energy band diagram relative to the vacuum level. More details regarding the solar cell fabrication procedures and component parameters are described in the ESI.† The best performance was found when the thickness of $\mathrm { C u } _ { 2 } \mathrm { O }$ is $2 5 \ \mathrm { n m }$ (Fig. S4 and Table S1, $\mathrm { E S I \dag }$ ). Optimizations of the concentration of the FBT-TH4 and the PDINO layer suggested that $1 \ \mathrm { m g \ m L ^ { - 1 } }$ and $1 \ \mathrm { m g \ m L ^ { - 1 } }$ contributed to the best device performance, respectively (Fig. S5, S6 and Tables S2, S3, ESI†). The current density–voltage $\left( J - V \right)$ characteristics of the champion cell based on the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ HTM and the $\mathrm { C u } _ { 2 } \mathrm { O } /$ FBT-TH4 HTM are shown (Fig. 2b). The OSC using the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ HTM shows a $J _ { \mathrm { S C } }$ of $1 6 . 0 0 \mathrm { \ m A \ c m } ^ { - 2 }$ , a $V _ { \mathrm { O C } }$ of $0 . 7 6 ~ \mathrm { V } ,$ , an FF of $6 9 . 8 \%$ , and a PCE of $8 . 4 8 \%$ . The best photovoltaic performance of devices with $\mathrm { C u } _ { 2 } \mathrm { O } /$ FBT-TH4 HTMs achieves a $J _ { \mathrm { S C } }$ of $1 7 . 5 ~ \mathrm { m A } ~ \mathrm { c m } ^ { - 2 }$ , a $V _ { \mathrm { O C } }$ of $0 . 7 7 \mathrm { V } _ { : }$ , an FF of 70.7 and an enhanced PCE of $9 . 5 6 \%$ . The PCE obtained is also much higher than that of the reference device based on the most commonly used HTM, PEDOT:PSS, which exhibits a maximum average PCE of $8 . 2 \%$ (Fig. S7, $\mathrm { E S I \dag }$ . Meanwhile, a significant difference in $J _ { \mathrm { S C } }$ was observed when comparing OSCs based on pristine $\mathrm { C u } _ { 2 } \mathrm { O }$ and FBT-TH4 modified $\mathrm { C u } _ { 2 } \mathrm { O }$ . Considering the same fabrication procedure for all of the other layers, a possible reason may be related to the HOMO energy level and the morphology of the HTM. Fig. 2c shows the histogram of the PCEs obtained from over 100 cells with the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ and FBT-TH4 treated $\mathrm { C u } _ { 2 } \mathrm { O }$ as the HTMs. The histogram of the $V _ { \mathrm { O C } } , J _ { \mathrm { S C } } ,$ and FF is exhibited in Fig. S8 in the ESI. $^ { \dagger }$ The average PCE is $9 . 4 2 \%$ with an average $J _ { \mathrm { S C } }$ of $1 7 . 4 2 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ , a $V _ { \mathrm { O C } }$ of $0 . 7 7 \mathrm { V }$ , and an FF of 0.70, respectively (Table 1). In addition, the effect of the FBT-TH4 ultrathin layer with different thicknesses on the device performance is further investigated. Fig. S5 and Table S2 (ESI†) list device performance parameters of the OSCs with the $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ HTMs, where the thickness of FBT-TH4 is different. This is expected to optimize the charge transport through reengineering the thicknesses of the layers. Excessive thicknesses of FBT-TH4 drastically increase the internal series resistance while an extremely thin FBT-TH4 layer leads to poor coverage over the surface of $\mathrm { C u } _ { 2 } \mathrm { O }$ . The optimum concentration of ultrathin FBT-TH4 was determined as $1 \ \mathrm { m g } \ \mathrm { m L } ^ { - 1 }$ , which is the compromise of passivation of the surface trap states, and external conductivity for charge transport. The external quantum efficiency (EQE) spectra are shown in Fig. 2d, and by integrating the EQE spectra, $J _ { \mathrm { S C } }$ values of 15.45 and $1 6 . 9 8 \mathrm { m A c m } ^ { - 2 }$ are estimated from the device using the $\mathrm { C u } _ { 2 } \mathrm { O }$ and $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 }$ HTMs, respectively. These integrated $J _ { \mathrm { S C } }$ values are in good agreement with those observed from the $J$ –V characteristics. Note that the slight difference in $J _ { \mathrm { S C } }$ obtained using different methods is probably due to the imperfect solar spectrum of different solar simulators.

To understand the contribution from the FBT-TH4 polymer to the ameliorated charge transport properties within the solar cells, we further study the hole mobility and transient photocurrent response in the OSCs. The hole-only devices with an architecture of ITO/HTM/PffBT4T-2OD: $\mathbf { P C } _ { 7 1 } \mathbf { B M } / \mathbf { A u }$ are processed and tested. Fig. 3a shows the plot of the $J ^ { 1 / 2 }$ versus $\left( V _ { \mathrm { a p p l } } - V _ { \mathrm { b i } } \right)$ characteristic in the space charge limited region, and Child’s law is further employed to obtain the hole mobilities for both devices. The BHJ composite from the OSCs with $\mathrm { C u } _ { 2 } \mathrm { O }$ possesses a hole mobility of $2 . 3 \times 1 0 ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ , whereas the BHJ composite from the inverted device using $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 }$ exhibits a hole mobility of ${ 7 . 2 \times 1 0 } ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ . The higher hole mobilities of the $\mathrm { C u _ { 2 } O / F B T \cdot T H 4 } .$ -based devices decreased the probability of exciton recombination and resulted in the increased $J _ { \mathrm { S C } }$ values, which is in agreement with the photovoltaic parameters displayed in Table 1. The impedance spectra are further applied to study the underlying charge transport physics in the OSCs with different HTLs. The $R _ { S }$ incorporates the sheet resistance $\left( R _ { \mathrm { S h e e t } } \right)$ and the charge transfer resistance $\left( R _ { \mathrm { C T } } \right)$ . The $R _ { \mathrm { S h e e t } }$ is correlated with the electrodes, and the $R _ { \mathrm { C T } }$ is correlated with the resistance at the interface between the electrodes and the charge extraction layers, the charge extraction layers and BHJ photoactive layer, and inside of the BHJ photoactive layer. In this work, the difference in $R _ { \mathrm { C T } }$ is only at the interface between the HTM and the BHJ photoactive layer. Fig. 3b shows the Nyquist plots of the OSCs with the $\mathrm { C u } _ { 2 } \mathrm { O }$ and the $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } { \cdot } \mathrm { T H } 4$ HTLs. Smaller $R _ { \mathrm { C T } }$ from the OSCs using the $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 \ H T L }$ indicates that the charge transfer properties within the OSCs have been improved by employing the $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 \ H T L }$ . The reduced resistance in the OSCs using the $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 \ H T L }$ can be ascribed to the optimized interface between the HTL and active layer. Incorporation of the polymer FBT-TH4 can contribute to passivation of the trap states of inorganic $\mathrm { C u } _ { 2 } \mathrm { O }$ and help enable intimate contact between the HTM and the active layer. Furthermore, the FBT-TH4 ultrathin layer also benefits the charge behavior extraction owing to the reduced energy barrier induced by the enhanced hole mobility modification effect.

We think that $\mathrm { C u } _ { 2 } \mathrm { O }$ plays a core role in inorganic–organic integrated $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ HTMs, although $\mathrm { C u } _ { 2 } \mathrm { O }$ is somewhat better than most used PEDOT:PSS HTMs in terms of efficiency and stability. However it still has room for further improvement on the basis of its shortcomings. Based on its inherent p type conductivity, defects such as Cu vacancies $\left( \mathrm { V } _ { \mathrm { C u } } \right)$ and oxygen interstitials $\mathrm { ( O _ { i } ) }$ inevitably occur at the interface. Meanwhile, the strong diffusion ability of copper ions will also affect the long-term stability of the active layer, and the FBT-TH4 ultrathin layer plays a role in improving the interfacial smoothness, reducing the interfacial exciton recombination center and preventing ion diffusion. We also test the performance of the device with bare FBT-TH4 in Fig. S9 $\bigl ( \mathrm { E S I \dag } \bigr )$ ; the champion PCE is $7 . 8 \%$ , and the efficiency is even lower than our PEDOT:PSS based device, which is mainly restricted to $V _ { \mathrm { O C } }$ and FF. This may be due to the lower LUMO of FBT-TH4 (3.7 eV) as mentioned in the literature.

As shown in Fig. 4, the stabilities of the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ and $\mathrm { C u } _ { 2 } \mathrm { O } _ { / }$ FBT-TH4-based OSCs were compared by exposing them directly to the ambient environment at $2 5 ~ ^ { \circ } \mathrm { C }$ and with $2 0 \%$ humidity without encapsulation. The statistical data of the decay of the photovoltaic parameters are summarized in Table S4 $\left( \mathrm { E S I \dag } \right)$ .

The PCE of the $\mathrm { C u } _ { 2 } \mathrm { O } /$ FBT-TH4-based device maintained the majority $( 7 5 \% )$ of the original device performance up to $3 0 \textup { d }$ , whereas that of the untreated $\mathrm { C u } _ { 2 } \mathrm { O } { \cdot }$ -based device decayed dramatically from $\approx 8 . 5 \%$ to $4 . 5 \%$ within the first week. Similarly, the $J _ { \mathrm { S C } }$ , $V _ { \mathrm { O C } }$ , and FF values for the organic HTLbased device suffer a substantial degradation during the aging process as shown in Fig. 4b–d. The results show the advantages of using the $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 }$ HTL for the enhancement of the lifetime of the derived devices. As we know, the surface wettability of the HTM is an important factor that significantly affects the stability of PVSCs. The higher stability of the $\mathrm { { C u } } _ { 2 } \mathrm { { O } } /$ FBT-TH4 device was attributed to the high hydrophobicity of FBT-TH4. The contact angle tests showed that ITO/PEDOT:PSS and $\mathrm { I T O } / \mathrm { C u } _ { 2 } \mathrm { O }$ exhibited a contact angle of $2 3 . 0 ^ { \circ }$ and $3 6 . 5 ^ { \circ }$ to water droplets (Fig. S10, ESI†). As a sharp contrast, after deposition of FBT-TH4, the $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ sample exhibited a much larger contact angle of $1 0 5 . 1 ^ { \circ }$ . Such a hydrophobic HTL would ease the protection of moisture in air and is beneficial for long-term stability, which is different from PEDOT:PSS, since its feature of reabsorbing water, we might spin active layer as soon as possible.

# 3 Conclusions

In summary, organic–inorganic integrated HTLs consisting of the solution-processable FBT-TH4 and $\mathrm { C u } _ { 2 } \mathrm { O }$ have been successfully incorporated into conventional structured OSCs. By introducing the ultrathin layer of conjugated polymer FBT-TH4 on top of a compact $\mathrm { C u } _ { 2 } \mathrm { O }$ layer, an upward $W _ { \mathrm { F } }$ has been demonstrated for the $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 }$ integrated HTM film. The optimized $\mathrm { C u } _ { 2 } \mathrm { O } / \mathrm { F B T } \mathrm { - } \mathrm { T H } 4$ integrated HTL based OSCs display an impressive average PCE of $9 . 5 6 \%$ under $1 0 0 \mathrm { m W } \mathrm { c m } ^ { - 2 }$ AM 1.5G illumination, which is superior to that of the reference devices based on PEDOT:PSS HTM $\left( 8 . 2 \% \right)$ and higher than that of devices based on the untreated $\mathrm { C u } _ { 2 } \mathrm { O }$ HTLs $\left( 8 . 4 \% \right)$ . Remarkably, it was found that the employment of $\mathrm { C u _ { 2 } O / F B T \mathrm { - } T H 4 }$ as the HTL significantly improved the long-term stability of OSCs. This $\mathrm { { C u } } _ { 2 } \mathrm { { O } } /$ FBT-TH4 HTL can provide great potential for the low cost and simple fabrication of high performance OSCs.
