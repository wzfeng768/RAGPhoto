# 1. Introduction

The effective mass of the free electrons in metals or semiconductors is perhaps the most fundamental materials parameter needed to understand or engineer electronic devices. Effective mass, usually denoted $m ^ { * }$ , is the mass that the electrons appear to have based on analogy with classical physics. For example, in response to a force, an electron will accelerate allowing the deduction of an inertial mass: $F = m a$ . As it greatly simplifies the more general band theory of electrons, the effective mass is an important engineering parameter that influences measurable properties, such as the efficiency of a solar cell or the speed of electronic devices. However, there are other ways of defining mass through analogies to energy, $E = \frac { 1 } { 2 } m \nu ^ { 2 }$ , and momentum, $p = m \nu$ , and this leads to numerous possible definitions as well as uses for effective mass.

The most commonly discussed effective mass is the inertial effective mass tensor usually defined from the second derivative of the $E$ versus $k$ dispersion relation, even though the first derivative is more directly relevant to measurable phenomena such as cyclotron resonance and electron transport. The anisotropy of the band structure makes any effective mass defined from $E$ versus $k$ anisotropic, even more anisotropic than can be described by a simple tensor.!2l Measurable material properties often probe the average $E$ versus $k$ over a constant energy Fermi surface. Thus, each property is associated with a distinct definition of effective mass, which can change with doping and temperature, even for rigid bands. Despite the complexity, effective mass $m ^ { * }$ is the most useful descriptor of the band structure, as it is generally more constant for the relevant electrons than $E , p _ { \ast }$ or v. Additionally, $m ^ { * }$ usually has similar values (within an order of magnitude) when comparing the various ways to define or measure it.

There are two classes of effective masses used in solid state physics: the first describe an inertial effective mass that characterize the response of an individual electron and the second depend more on the density of electron states (DOS), and are hence called a DOS mass, $m _ { \mathrm { D O S } } ^ { \ast }$ . The DOS is another quantity that underpins most electronic properties. For example, the relationship between the electron concentration in a semiconductor and the Fermi level (average electron energy) depends on the available density of electronic states, $g ( E )$ . In metals, the DOs has historically been measured by the low temperature specific heat. The DOS mass, $m _ { \mathrm { D O S } } ^ { \ast }$ , is an energy-independent quantity used to characterize the density of states using the free electron (parabolic band) approximation

$$
g ( E ) = { \frac { 8 \pi { \sqrt { 2 } } } { h ^ { 3 } } } m _ { \mathrm { D O S } } ^ { * 3 / 2 } { \sqrt { E } }
$$

where $h$ is Planck's constant.

When there are multiple bands or multiple valleys (band minima or maxima in $E$ versus $k )$ the density of states is proportionally larger. Silicon, for example, has six equivalent valleys in the conduction band, making the density of states six times that of just one pocket. Because $g ( E ) \propto \dot { m } _ { \mathrm { D O S } } ^ { * 3 / 2 }$ , the DOS effective mass will be $6 ^ { 2 / 3 }$ times larger than the DOS mass of a single valley in n-type silicon.

The next section discusses an effective mass defined using the Seebeck coefficient and an estimate of the charge carrier concentration, which is termed the Seebeck effective mass $m _ { s } ^ { * }$ A major benefit of this transport parameter is that it is straightforward to derive from experimental measurements of the Seebeck coefficient and Hall effect. This work provides a simple and straightforward footing for an experimental $m ^ { * }$ to address fundamental questions related to charge transport, such as the debate over whether low or high effective mass is better for thermoelectric performance.[3,4]

# 2. Discussion

With the proliferation of Seebeck coefficient measurement systems, particularly in laboratories studying thermoelectric materials,[1011] Seebeck measurements are as common and easy to perform as Hall effect measurements and significantly simpler than a specific heat measurement at low temperature. Combining Hall effect, Seebeck coefficient, and electrical conductivity measurements to estimate a density of states effective mass is a common analysis technique for thermoelectric semiconductors.5,12,13] The Seebeck effective masses have been measured for many well-known thermoelectric semiconductors such as PbTe and PbSe,[14] $\mathrm { M g } _ { 3 } \mathrm { S b } _ { 2 }$ [15] $\mathrm { M g } _ { 2 } \mathrm { S i }$ [16] $\mathrm { C o S b } _ { 3 }$ Skutterudites,[17,18] $\mathrm { Y b } _ { 1 4 } M \mathrm { S b } _ { 1 1 }$ $\mathbf { \nabla } M = \mathbf { M } \mathbf { n }$ or $\mathsf { M g } ^ { [ 1 9 , 2 0 ] }$ $\mathsf { Z n } _ { 4 } \mathsf { S b } _ { 3 }$ [21] $\mathrm { Z n S b }$ [22] $\mathrm { B i } _ { 2 } \mathrm { T e } _ { 3 }$ ${ \mathrm { S b } } _ { 2 } { \mathrm { T e } } _ { 3 }$ [23] and BiCuSeO.[24,25] The methods vary slightly but give similar values for $m _ { s } ^ { * }$

Because Seebeck measurements can be performed at various temperatures, particularly at or above room temperature, $m _ { s } ^ { * }$ as a function of $T$ is often more relevant to the room temperature phase and band structure than other characterization techniques done at cryogenic temperatures. $m _ { s } ^ { * }$ may also indicate how the band structure may change with temperature in the temperature range of use.

The Seebeck mass can also be computed in cases where the actual charge carrier concentration $n$ is known better than $n _ { \mathrm { H } }$ For example, in highly resistive materials with low mobility, the Hall resistance can be difficult or even not possible to measure. In certain oxides, organic semiconductors and valence precise inorganic semiconductors,[26] the estimation of $n$ from the stoichiometry (i.e., obtaining n from donor or acceptor defect concentration) may be sufficient to estimate $m _ { s } ^ { * }$ . Additionally, materials with magnetic elements or impurities often have a Hall effect that is not as easily interpretable as charge carrier concentration. This is likely due to the anomalous Hall effect from the internal magnetism or magnetic impurities. For example, Heusler alloys[27] and rare-earth filled iron-based skutterudites[28] have Hall coefficients that do not correlate well with other electronic transport properties, but the estimation of $n$ from the nominal stoichiometry is sufficient to explain the observed transport properties and derive an effective mass.[27]

This method also provides a convenient way to report an effective mass from band structure calculations such as those from density functional theory (DFT).[29] By using calculations of the Seebeck coefficient from DFT band structures with the Boltzmann transport equation, $m _ { s } ^ { * }$ values have been tabulated for thousands of materials[30] (where a constant scattering time $\tau$ is used as opposed to a constant mean-free-path). The usage of $m _ { s } ^ { * }$ here is that of a scalar quantity,[29] which is appropriate as Seebeck is largely isotropic except when multiple bands are contributing.

Whether a material is well described by a single $m _ { s } ^ { * }$ (at a given temperature) is often examined using a $| S |$ versus $n _ { \mathrm { H } }$ (or n) "Pisarenko' plot. If the Seebeck measurements for samples of various $n _ { \mathrm { H } }$ all fall on the curve of $| S |$ versus $n _ { \mathrm { H } }$ for a constant $m _ { s } ^ { * }$ , then the material is well described by a single band effective mass model. Thus Equation (3) (or (4)) can be used to easily draw $| S |$ versus $n _ { \mathrm { H } }$ (or $n$ ) relations for constant $m _ { s } ^ { * }$ on a Pisarenko plot that is valid for high and low doping. However, rather than the Pisarenko plot, which shifts at different temperatures and depends on whether $n _ { \mathrm { H } }$ or $n$ is used, displaying $m _ { s } ^ { * }$ is a more convenient way to observe band structure changes. Subtle changes in the band structure or scattering are more easily seen in a plot of $m _ { s } ^ { * }$ (Figure 2) rather than [S| because it takes into account normally expected variations in temperature and doping. While $m _ { s } ^ { * }$ is constant with changes in temperature and doping level for an ideal parabolic band, the Seebeck coefficient and Hall Effect in nonideal materials can be affected by many mechanisms not accounted for in the free electron model, making $m _ { s } ^ { * }$ vary slightly with temperature and doping. Even small variations in $m _ { s } ^ { * }$ can be used to identify unusual phenomena in materials. For example, if the bands are not parabolic, $m _ { s } ^ { * }$ will vary with $n$ . When bands become more linear than parabolic, S is suppressed and $m _ { s } ^ { * }$ will be reduced.17] In special cases, dopants can produce distortions in the density of states, which can be interpreted as modifications of the single band effective mass and are measured as a shift in $m _ { s } ^ { * }$ , as observed in p-type Tl-doped PbTe[32] and n-type La-doped PbTe.[33]

Another example is the intrinsic, multi-band nature of $\mathrm { C o S b } _ { 3 }$ that is easily seen as an increase in $m _ { s } ^ { * }$ with doping (Figure 2a), where the filling of vacancies with $\mathrm { Y b } ^ { 2 + }$ atoms donates electrons to the conduction band. The presence of multiple bands, offset in energy, is not uncommon in good thermoelectric materials $( \mathrm { L a _ { 3 } T e _ { 4 } } , \mathrm { ^ { [ 3 4 ] } \ Y b _ { 1 4 } M S b _ { 1 1 } , ^ { [ 1 9 ] } \ P b { \cal { X } } ^ { [ 3 5 ] } } )$ . Changes in $m _ { s } ^ { * }$ with temperature or doping can also indicate complex, nonspherical Fermi surfaces[36] as well as nonparabolic dispersion.17] In addition, examining changes in $m _ { s } ^ { * }$ is particularly powerful for band engineering with alloying such as engineering band convergence in the lead chalcogenides[35] or $\mathrm { B i } _ { 2 } \mathrm { T e } _ { 3 }$ based semiconductors.23] The variation in doping from sample to sample or measurement temperature changes S but not $m _ { s } ^ { * }$ and enables the observance of an increase in DOS at band convergence such as that shown in Figure 2b for $\mathrm { B i } _ { 2 } \mathrm { T e } _ { 3 } { \cdot } \mathrm { S b } _ { 2 } \mathrm { T e } _ { 3 }$ alloys.[31]

In thermoelectric materials, the effective mass is known to influence both the Seebeck coefficient S and electrical conductivity $\sigma = n e \mu$ in contraindicated ways, both of which enter the thermoelectric figure of merit $z T = S ^ { 2 } \sigma T / \kappa ,$ where $\kappa$ is the thermal conductivity. A high effective mass reduces the electron mobility $\mu = e \tau / m _ { \mathrm { I } } ^ { * }$ not only because of the inertial effective mass $m _ { \mathrm { I } } ^ { * }$ but also because a high $m _ { \mathrm { D O S } } ^ { * } \approx m _ { \mathrm { S } } ^ { * }$ provides more ways to scatter electrons and therefore reduce $\tau$ [38] However a higher $m _ { s } ^ { * }$ allows a higher charge carrier concentration $n _ { \ast }$ and therefore $\sigma$ , at the same Seebeck (Fermi Level). To obtain the highest thermoelectric quality factor, which determines the maximum $z T ,$ a low inertial mass $m _ { \mathrm { I } } ^ { * }$ from dispersive (not fat) bands is desired,[39] where the large DOS comes from a high valley degeneracy (number of degenerate Fermi surface pockets).[38]

There are some well-understood ways in which the Seebeck coefficient and Hall effect change based on a material's transport characteristics. For example, different mechanisms of electron scattering are known to have an effect on Seebeck.[12] Scattering is often approximated with a power law form for the scattering time $\bar { \tau = } \ E ^ { \lambda - 1 / 2 }$ , where for acoustic phonon scattering $\lambda = 0$ (same as constant mean-free-path), ionized impurity scattering $\lambda = 3 / 2$ , etc.[43] For single parabolic bands with different scattering, the Seebeck mass would be related to the DOS mass as $m _ { \mathrm { s } } ^ { \mathrm { * } } = m _ { \mathrm { D O S } } ^ { \mathrm { * } } ( 1 + \lambda )$ in the degenerate limit and $m _ { \mathrm { s } } ^ { * } = m _ { \mathrm { D O S } } ^ { * } \exp ( 2 \lambda / 3 )$ in the nondegenerate limit.[12] For example, at low temperatures (typically ${ < } 1 0 0 \ \mathrm { K } { ] }$ and for materials with high lattice thermal conductivity, the Seebeck coefficient can be strongly affected by phonon drag. Complex metals with nonspherical Fermi surfaces further complicate the Hall effect. These effects make the electronic heat capacity a better measure of the electronic DOS in complex metals at low temperature.

More recent progress has been made to study the role of microstructure on electronic transport coefficients. Resistive grain boundaries can have a dramatic effect on electrical conductivityl44,45] such that the apparent mobility is dramatically reduced.9l However, both the Seebeck and Hall effects are largely unaffected by resistive grain boundaries[45,46] because interfacial effects are usually small.[47] This makes $m _ { s } ^ { * }$ measured in polycrystalline materials similar to that of large grain or single crystalline materials even when the Hall mobility and weighted mobilities are significantly reduced because of grain boundary resistance.[48]

Effects at higher temperature have also been studied, when minority carriers are excited, leading to bipolar conduction. Both the Seebeck and the Hall effects are reduced in compensated materials when both n-type and p-type charge carriers are present because both properties depend on the sign of the charge carriers.49] This will make the magnitude of S smaller but $n _ { \mathrm { H } }$ greater in comparison to that of the dominant charge carrier alone, leading to a deviation of $m _ { s } ^ { * }$ (Figure 3b) when the temperature is high enough for minority charge carriers to be thermally excited.

# 3. Conclusion

Because of the relative ease of Seebeck measurements, the Seebeck effective mass, $m _ { s } ^ { * }$ , could easily become the most common method to characterize the density of states effective mass in semiconductors, one of the most basic material parameters to describe electronic structures. Because both the Seebeck and Hall effects are relatively uninfluenced by resistive grain boundaries, $m _ { s } ^ { * }$ can be measured on polycrystalline samples but interpreted as a characteristic of the crystalline grains. The trends of $m _ { s } ^ { * }$ with temperature or doping at room temperature and above are readily interpreted with subtle changes in band structure or scattering such as band convergence in thermoelectric materials. While the absolute magnitude of $m _ { s } ^ { * }$ has known dependence on scattering and electronic structure different from the density of electronic states (DOs), it should be considered an effective DOS mass where even small changes represent important effects in the electronic structure or scattering.

For simplicity, it is recommended that Hall effect data is reported simply as $n _ { \mathrm { H } } = 1 / e R _ { \mathrm { H } }$ with the understanding that the actual charge carrier concentration $n$ will differ from this measured value. Similarly, it is recommended that the Seebeck effective mass be reported as described here with the understanding that the actual electron density of states will differ.

It was important to note that the definition of $m _ { S } ^ { * }$ using Equation (3) from the measured quantities S and $n _ { \mathsf H }$ did not require any assumptions. Nonparabolic, multiband, alternate scattering and other effects were not neglected they were manifested as deviations from the simple free electron model ( $m _ { 5 } ^ { * } =$ constant) that can be explained by incorporating the relevant physics in a model for $m _ { S } ^ { * }$ to be compared with the experimental values. $$

The numerator on the right side of Equation (3) $\left( \frac { 3 } { \pi ^ { 2 } } \frac { | S | } { k _ { \mathrm { B } } / e } \right)$ is the analytic result for the degenerate limit $( \eta \gg 0$ , metal). The numerator on the left side of Equation (3) $\left( \exp \left[ \frac { | S | } { k _ { \mathrm { B } } / e } - 2 \right] \right)$ is similar to the analytic result in the nondegenerate limit $( \eta \ll 0$ "intrinsic semiconductor) where Kang[52] found that subtracting the 0.17 enabled the function to accurately transition between degenerate and nondegenerate limits. The functions in the denominators are sigmoid functions with parameters (5 and 1) that give a maximum error of $3 \%$ (Figure 4) to the exact result using the Fermi integrals (Equations (5-7)).
