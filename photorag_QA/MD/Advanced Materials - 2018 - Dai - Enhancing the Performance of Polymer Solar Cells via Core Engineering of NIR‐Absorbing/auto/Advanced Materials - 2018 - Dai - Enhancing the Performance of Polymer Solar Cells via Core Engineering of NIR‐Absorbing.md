# Enhancing the Performance of Polymer Solar Cells via Core Engineering of NIR-Absorbing Electron Acceptors

Shuixing Dai, Tengfei Li, Wei Wang, Yiqun Xiao, Tsz-Ki Lau, Zeyuan Li, Kuan Liu, Xinhui Lu,\* and Xiaowei Zhan\*

In order to utilize the near-infrared (NIR) solar photons like silicon-based solar cells, extensive research efforts have been devoted to the development of organic donor and acceptor materials with strong NIR absorption. However, single-junction organic solar cells (OsCs) with photoresponse extending into $> 1 0 0 0 \ \mathsf { n m }$ and power conversion efficiency (PCE) $5 1 1 \%$ have rarely been reported. Herein, three fused-ring electron acceptors with varying core size are reported. These three molecules exhibit strong absorption from 600 to $1 0 0 0 \ \mathsf { n m }$ and high electron mobility $( > 1 \times 1 0 ^ { - 3 } \mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } \mathsf { s } ^ { - 1 } )$ . It is proposed that core engineering is a promising approach to elevate energy levels, enhance absorption and electron mobility, and finally achieve high device performance. This approach can maximize both short-circuit current density $( J { \mathsf { s c } } )$ and open-circuit voltage $( \boldsymbol { v } _ { \infty } )$ at the same time, differing from the commonly used end group engineering that is generally unable to realize simultaneous enhancement in both $\pmb { v } _ { \infty }$ and $J _ { s c }$ . Finally, the single-junction OsCs based on these acceptors in combination with the widely polymer donor PTB7-Th yield $J _ { s \mathsf { c } }$ as high as $2 6 . 0 0 ~ \mathsf { m A c m } ^ { - 2 }$ and PCE as high as $12 . 3 \%$ -.

As a promising alternative to silicon-based photovoltaic technology, organic solar cells (OsCs) show great potential for a cost-effective solar energy conversion platform with some advantages, such as semitransparency, flexibility, and lightweight.[1-3] In bulk heterojunction $\mathrm { ( B H J ) } ^ { [ 4 - 6 ] }$ OSCs, fullerene derivatives (e.g., $\mathrm { P C } _ { 6 1 } \mathrm { B M }$ and $\mathrm { P C } _ { 7 1 } \mathrm { B M } _ { j }$ are widely used electron acceptors that have achieved power conversion efficiencies (PCEs) of over $1 1 \%$ when paired with electron donating polymers or small molecules.17-9] However, they suffer from some shortcomings, such as limited energy level tunability, weak absorption in the visible region, and morphology instability, which impose constraints on the further development of BHJ OSCs.[10] In contrast, the absorption spectra and energy levels of nonfullerene acceptors can be readily tuned. Therefore, the development of OsCs has recently shifted to nonfullerene acceptors.[11-21]

In 2015, we developed the first fusedring electron acceptors (FREAs) with acceptor-donor-acceptor structure based on electron-donating fused aromatic cores coupled with strong electron-accepting end groups, such as ITIC.[22] FREA-based OSCs achieve higher PCEs and better stability than their fullerene-based counterparts.[23] Although several cores with different size, such as fused-5-ring,[24-29] fused-6-ring,[30] fused-7-ring,[22,31-36] fused-8-ring,[37,38] fused-9-ring,[39] and fused-10-ring,[40] have been used individually, effects of different cores have never been studied systematically. Most of these FREAs exhibit limited absorption in near-infrared (NIR) region (generally absorption edge $< 8 0 0 \ \mathrm { n m }$ ). Although there are a few FREAs with absorption edge at ${ \approx } 9 0 0 ~ \mathrm { n m }$ (bandgap $< 1 . 4 \ \mathrm { e V } _ { \cdot }$ , single-junction OSCs based on these FREAs generally show PCEs $< 1 1 \%$ [30,41,42]

In this work, we designed and synthesized three FREAsF6IC, F8IC, and F10IC (Figure 1)-based on fused-6-ring, fused-8-ring, and fused-10-ring electron-rich cores, respectively, end-capped with electron-deficient unit 2-(5,6-difluoro3-oxo-2,3-dihydro-1H-inden-1-ylidene)malononitrile (2FIC). Our molecular design rationale is as follows: (1) Fused-ring cores consist of one central thieno[3,2-b]thiophene ring and two terminal thiophene, thieno[3,2-b]thiophene, or dithieno[3,2-b:2',3'-d] thiophene rings, which are fused with two diarylcyclopentadiene rings. These thiophene-rich cores possess symmetrical, rigid, and coplanar structure, which is beneficial to molecular packing, while their extended conjugation length can enhance electrondonating property.30,38] (2) 2F1C has strong electron-withdrawing ability, ensuring appropriate the lowest unoccupied molecular orbital (LUMO) energy level for achieving charge separation with donors, and promotes intermolecular interactions through forming noncovalent F...S, $\operatorname { F } \cdot \cdot \cdot \pi ,$ and F...H bonds, facilitating charge transport.39] (3) The "push-pull' electronic structure can induce intramolecular charge transfer between electron-rich cores and electron-deficient end groups, leading to intense absorption throughout the visible and even NIR region.

All these molecules exhibit strong absorption in $6 0 0 { - } 1 0 0 0 ~ \mathrm { ~ n m }$ , very low bandgap (1.36-1.25 eV), and high electron mobilities $( > 1 \times 1 0 ^ { - 3 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } )$ . OsCs based on blends of these electron acceptors and a narrow-bandgap polymer donor PTB7-Th[43] (Figure 1) exhibit PCEs of $7 . 1 \mathrm { - } 1 0 . 9 \%$ Furthermore, we fabricated OsCs based on a ternary blend of $\mathrm { P T B 7 . T h } / \mathrm { F 8 I C } / \mathrm { P C } _ { 7 1 } \mathrm { B M }$ to further increase the device performance. A champion short-circuit current density $( J _ { \mathsf { S C } } )$ of $2 6 . 0 \mathrm { \ m A \ c m ^ { - 2 } }$ and a champion PCE of $1 2 . 3 \%$ were achieved. The PCE of $1 2 . 3 \%$ is among the highest for PTB7- Th-based single-junction OsCs. More importantly, with this series, we are able to investigate the effects of the core size on electronic properties, charge transport, film morphology, and photovoltaic properties. We proposed that core engineering is a promising strategy to upshift energy levels, enhance absorption and electron mobility, and finally achieve high efficiency. This strategy can maximize both $J _ { \mathrm { S C } }$ and open-circuit voltage $( V _ { \mathrm { O C } } )$ simultaneously, differing from the commonly used end group engineering that is generally unable to achieve synergistic enhancement in both $V _ { \mathrm { O C } }$ and $J _ { \mathrm { S C } }$

The detailed synthesis procedures are shown in the Supporting Information. The three compounds were fully characterized by spectroscopic methods and elemental analysis (see the Supporting Information). The three compounds exhibit good solubility in common organic solvents, such as chloroform and dichloromethane. The thermal stability of these three molecules was investigated using thermogravimetric analysis (Figure S1, Sup. porting Information). The decomposition temperatures $( T _ { \mathrm { d } } , \ 5 \%$ weight loss) of F6IC, F8IC, and F10IC are 314, 331, and $3 6 7 ~ ^ { \circ } \mathrm { C }$ respectively, which indicate good thermal stability.

In solution, F6IC, F8IC, and F10IC show gradually redshifted absorption spectra with peaks from 714 to $7 9 8 ~ \mathrm { n m }$ (Figure 2a), and similar molar extinction coefficients from $1 . 8 \times 1 0 ^ { 5 } \ \mathrm { { M } ^ { - 1 } \ \mathrm { { c m } ^ { - 1 } } }$ to $2 . 3 \times 1 0 ^ { 5 } ~ \mathrm { { M } ^ { - 1 } ~ c m ^ { - 1 } }$ at maximum absorption peaks (Table 1). In thin films, all three molecules show redshifted and broadened absorption spectra relative to their solutions; in particular, F8IC film exhibits more significant redshift than F6IC and F10IC films, suggesting that F8IC film has stronger aggregation. The absorption peaks of these three compounds are 800, 862, and $8 6 2 ~ \mathrm { { \ n m } }$ respectively (Figure 2b). F10IC shows a very similar absorption profile with F8IC, implying that further extending the core is unable to further extend the absorption. The optical bandgaps of F6IC, F8IC, and F101C are calculated to be 1.36, 1.27, and $1 . 2 5 \ \mathrm { e V }$ from the absorption edge, respectively (Table 1).

The electrochemical properties of F6IC, F8IC, and F10IC were measured using cyclic voltammetry (Figure 2c). Three compounds exhibit irreversible reduction waves and oxidation waves. The highest occupied molecular orbital (HOMO) and LUMO energy levels are calculated from the onset oxidation and reduction potentials, assuming the absolute energy level of $\mathrm { F e C p } _ { 2 } { } ^ { + / 0 }$ to be $4 . 8 \ \mathrm { e V }$ below vacuum. The LUMO levels of F6IC, F8IC, and F101C are estimated to be -4.02, $- 4 . 0 0$ , and $- 3 . 9 6 \mathrm { e V } ,$ respectively, while the HOMO levels are $- 5 . 6 6$ $- 5 . 4 3$ , and $- 5 . 2 6 \ \mathrm { e V } _ { \mathrm { : } }$ respectively (Figure 2d). Increase in core size significantly upshifts the HOMO level, while slightly upshifts the LUMO level. According to theory calculation,44] the HOmO orbital is mainly located at the electron-donating core, while the LUmO orbital is delocalized across the entire molecule with more focus on the electron-withdrawing end groups. When the central core size increases, the HOMO level significantly upshifts due to the stronger electron-donating ability of the core, while the central core affects the LUMO to less extent.

The electron mobilities of F6IC, F8IC, and F10IC were measured to be $1 . 0 \times 1 0 ^ { - 3 }$ $1 . 5 \times 1 0 ^ { - 3 }$ , and $1 . 1 \times 1 0 ^ { - 3 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } .$ respectively, using the space charge limited current $ { ( \mathrm { S C L C } ) ^ { [ 4 5 ] } }$ method (Table 1 and Figure S2, Supporting Information). These electron mobilities are very close to those (in the order of $1 0 ^ { - 3 } \thinspace \mathrm { c m } ^ { 2 } \thinspace \mathrm { V } ^ { - 1 } \thinspace \mathrm { s } ^ { - 1 } )$ of fullerene acceptors[46] and can ensure effective electron transport to the cathode.

Grazing-incidence wide-angle X-ray scattering (GIWAXS) measurements were carried out to probe the molecular packing information of these thin films. Pure PTB7-Th film is known to be "face-on' oriented. However, this favorable feature is weakened after mixing with $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ as shown by the ring-like lamellar peak (Figure S8, Supporting Information). In contrast, the PTB7-Th/F6IC, PTB7-Th/F8IC, and PTB7-Th/F10IC blended films exhibit an obvious $\pi - \pi$ peak along the $q _ { z }$ -axis (at 1.72, 1.84, and $1 . 8 1 \mathring { \mathrm { A } } ^ { - 1 }$ , respectively), demonstrating the existence of the favorable "face-on' oriented domains in these films (Figure 5a-f). Grazing-incidence small-angle X-ray scattering (GISAXS) measurements were carried out to probe the nanoscale phase separation information of the thin films. Figure 5f shows the GISAXS intensity profiles and best fittings along the in-plane direction. The corresponding 2D GISAXS patterns are presented in Figure S9 (Supporting Information), together with those of pure acceptors and donor films. We adopted Debye-- Anderson-Brumberger and fractal-like network models, to account for the scattering contribution from intermixing amorphous phases and acceptor domains, respectively.[59] The correlation lengths of the amorphous intermixing phases are 38.5, 20.1, 20.2, and $2 1 . 1 \ \mathrm { n m }$ for PTB7-Th/F6IC, PTB7-Th/F8IC, PTB7-Th/F10IC, and $\mathrm { P T B 7 { \cdot } T h } / \mathrm { F } 8 \mathrm { I C } / \mathrm { P C } _ { 7 1 } \mathrm { B M }$ films, respectively, while the corresponding acceptor domain sizes $( 2 \mathrm { R _ { g } } )$ are fitted to be 54.2, 18.5, 14.8, and $1 1 . 0 \ \mathrm { n m }$ , respectively. Except the PTB7-Th/F6IC film, the domain sizes of other films are comparable to the theoretical exciton diffusion length, leading to more efficient exciton dissociation and charge collection and therefore relatively better device performance.

In binary blend devices, $V _ { \mathrm { O C } }$ increases from 0.611 to 0.732 V with extending the core size from 6 to 10 rings, due to the upshift of the acceptor LUMO level. However, $J _ { \mathrm { S C } }$ does not linearly correlate with the core size, and F8IC-based devices exhibit the highest $J _ { \mathrm { S C } }$ of $2 5 . 1 2 \mathrm { \ m A \ c m ^ { - 2 } }$ The main contributions to this highest $J _ { \mathrm { S C } }$ in F8IC-based devices are: (a) Relative to F6IC and F10IC, F8IC exhibits stronger absorption, which is beneficial to higher EQE and higher $J _ { \mathrm { S C } } .$ (b) The GIWAXS shows that the PTB7-Th/F8IC film exhibits the smallest $\pi - \pi$ stacking distance among the binary blends, facilitating charge transport. Indeed, the PTB7-Th/F8IC blend shows faster and more balanced charge transport, which is partially responsible for higher $J _ { \mathrm { S C } }$ and higher FF. (c) Relative to the PTB7-Th/F6IC film, the domain sizes of PTB7-Th/F8IC and PTB7-Th/F10IC are comparable to the theoretical exciton diffusion length, which is beneficial to exciton dissociation. Indeed, F8IC-based devices show more efficient exciton dissociation and charge collection, as well as higher carrier density among three binary OsCs, which accounts for the higher $J _ { \mathrm { S C } }$ . Finally, since PTB7-Th donor and F8IC acceptor exhibit complementary absorption, matched energy levels, and matched mobilities, the OsCs based on PTB7-Th/F8IC blend exhibit small domain size, small energy loss, yet efficient exciton dissociation and charge collection, negligible bimolecular recombination, and finally higher $J _ { \mathrm { S C } } ,$ higher FF, and higher PCE than PTB7-Th/F6IC and PTB7 $\mathrm { \cdot T h } /$ F10IC blends. The OSCs based on PTB7-Th/F8IC blend show the best PCE of $1 0 . 9 \%$ higher than those of PTB7-Th/F6IC $( 7 . 1 \% )$ and PTB7-Th/F10IC $( 1 0 . 2 \% )$

We used $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ as a third component to fabricate ternaryblend device to further improve performance of F8IC-based OSCs. When the $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ weight ratio in acceptor component is $20 \%$ $J _ { \mathrm { S C } }$ reaches the maximum of $2 6 . 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ . The higher $V _ { \mathrm { O C } }$ is attributed to the higher LUMO level of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ in comparison with F8IC. The main reasons for the higher $J _ { \mathrm { S C } }$ are: (a) $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ exhibits stronger absorption in $3 0 0 { - } 5 5 0 ~ \mathrm { n m }$ that complements absorption of PTB7-Th:F8IC blend. (b) The GIWAXS suggests the co-existence of preferentially "face-on' oriented PTB7-Th and F8IC domains in the ternary blend, and the ternary blend shows slightly better and balanced charge transport, contributing to the higher $J _ { \mathrm { S C } }$ and FF. (c) The ternary device has a higher carrier density than the binary blend.

In summary, we designed and synthesized three new nonfullerene electron acceptors, F6IC, F8IC, and F10IC, based on fused-6-ring, fused-8-ring, and fused-10-ring cores end-capped with strong electron-withdrawing 2FIC. With this series, we systematically investigated the effects of the core size on electronic properties, charge transport, film morphology, and photovoltaic properties. Three molecules have strong visible-NIR absorption $( 6 0 0 - 1 0 0 0 \ \mathrm { n m } )$ with high extinction coefficients of $1 . 8 – 2 . 3 \times 1 0 ^ { 5 } \mathrm { { M } ^ { - 1 } \mathrm { { c m } ^ { - 1 } } }$ and very low bandgaps (1.36-1.25 eV). F8IC and F10IC exhibit $6 2 \mathrm { n m }$ redshift of absorption peaks relative to F6IC, due to larger extended $\pi$ conjugation cores with stronger electron-donating ability. However, F10IC shows a very similar absorption profile to F8IC, implying that further extending the core is unable to further extend the absorption. Increasing core size from 6 rings to 10 rings significantly upshifts the HOMO level from $- 5 . 6 6$ to $- 5 . 2 6 \ \mathrm { e V } ,$ while slightly upshifts the LUMO level from $- 4 . 0 2$ to $- 3 . 9 6 \ \mathrm { e V } ,$ leading to the bandgap lowering from 1.36 to $1 . 2 5 \ \mathrm { e V } .$ Higher LUmO level is beneficial to higher $V _ { \mathrm { O C } } ,$ while lower bandgap is beneficial to higher $J _ { \mathrm { S C } }$ This core engineering can simultaneously enhance $V _ { \mathrm { O C } }$ and $J _ { \mathrm { S C } }$ differing from the typical end group engineering that generally induces tradeoff between $V _ { \mathrm { O C } } \mathrm { a n d } J _ { \mathrm { S C } }$ For example, fluorination of the end groups 2-(3-oxo-2,3-dihydro-1H-inden-1-ylidene)malononitrile downshifts both LUMO and HOMO energy levels, leading to lower bandgap. Therefore, fluorination of the end groups increases $J _ { \mathrm { S C } }$ but decreases $V _ { \mathrm { O C . } } ^ { } ^ { [ 3 9 ] }$ The electron mobilities of these nonfullerene acceptors $( 1 . 0 \times 1 0 ^ { - 3 }$ to $1 . 5 \times 1 0 ^ { - 3 } \ : \mathrm { c m } ^ { 2 } \ : \mathrm { V } ^ { - 1 } \ : \mathrm { s } ^ { - 1 } )$ are comparable to those of fullerene acceptors, resembling the absorption trend, the electron mobility does not have a linear correlation with the core size, and F8IC exhibits the highest mobility due to the stronger $\pi - \pi$ stacking. We found that core engineering in FREAs appears to be a promising approach to elevate energy levels, enhance absorption and electron mobility, and finally achieve high device performance. This approach can maximize both $J _ { \mathrm { S C } }$ and $V _ { \mathrm { O C } }$ at the same time, differing from the commonly used end group engineering that is generally unable to realize synergistic enhancement in both $V _ { \mathrm { O C } }$ and $J _ { \mathrm { S C } }$ . Finally, the ternary-blend OSCs based on PTB7-Th/F8IC/ $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ yielded $J _ { \mathrm { S C } }$ as high as $2 6 . 0 0 \mathrm { m A c m } ^ { - 2 }$ and PCE as high as $1 2 . 3 \%$
