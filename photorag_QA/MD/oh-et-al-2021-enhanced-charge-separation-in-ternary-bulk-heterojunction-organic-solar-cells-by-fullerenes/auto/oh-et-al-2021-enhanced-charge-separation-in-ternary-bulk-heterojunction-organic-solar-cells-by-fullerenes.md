ABSTRACT: Carrier generation dynamics in binary PTB7-Th:CO,8DFIC (1:1.5) and ternary PTB7-Th:CO,8DFIC: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ (1:1.05:0.45)  composites were investigated to identify the origins of high power conversion efficiencies (PCEs) in ternary bulk-heterojunction (BHJ) organic solar cells. Steady-state photoluminescence and time-resolved photoinduced absorption spectroscopic analyses revealed that the ternary composite exhibited faster hole transfer from ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ to PTB7-Th (8 ps compared to 21 ps in the binary composite), which led to an improved exciton separation yield in ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ $9 4 \%$ compared to $6 8 \%$ in the binary composite). Improved intermixing of the component materials and efficient electron transfer from ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ facilitated enhancement in the hole transfer rate. The CO,8DFIC-to- $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ electron transfer promoted an electron transport cascade over PTB7-Th, $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ and $\mathrm { P C } _ { 7 1 } \mathrm { B M } ,$ which efficiently deactivated back-electron transfer (carrier recombination loss) from ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ to PTB7-Th at ${ \sim } 1 6 0$ ps and assisted in improving the PCE of the ternary BHJ cell $1 3 . 4 \%$ compared to $1 0 . 5 \%$ in the binary BHJ cell).

The photoactive layer of OSCs typically consists of bicontinuous networks of electron-donating polymers and electron-accepting monomers. Upon irradiation with sunlight, excitons are generated at the bulk polymer and monomer networks, diffuse to the interface of the networks, and dissociate by ultrafast electron-and-hole transfer processes between the polymer and monomer. Dissociated free carriers, that are, positive and negative polarons, move to the anode and cathode owing to a built-in potential in the OSCs and generate a photoinduced short-circuit current $\left( J _ { \mathrm { s c } } \right)$ and open-circuit voltage $\left( V _ { \mathrm { o c } } \right)$ However, carrier recombination occurs before the arrival of carriers at each electrode and generally limits the power conversion efficiency (PCE) in several OSCs, particularly by decreasing $J _ { \mathrm { s c } }$ and fill factor (FF).3-5

Several efforts have been made to improve the PCE of OSCs. In particular, nonfullerene acceptors (NFAs) have been designed to obtain high $J _ { \mathrm { s c } }$ and $V _ { \mathrm { o c } }$ by utilizing extended photoabsorption in the near-infrared regime and small differences in the lowest unoccupied molecular orbitals of polymers and monomers; NFAs have resulted in improved PCEs in recent OSCs.6-11 However, the low electron mobility of NFAs, compared to that of fullerenes, limits $J _ { \mathrm { s c } }$ and FF in several NFAbased OSCs.12-14

To observe the detailed dynamics responsible for the improved $J _ { s }$ c and FF in the ternary PTB7- $\mathrm { T h } { \cdot } \mathrm { C O } _ { i } 8 \mathrm { D F I C } { \cdot } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ (1:1.05:0.45) composite, we focused on studying carrier generation using ultrafast spectroscopy. In this study, the PCE of the binary PTB7-Th:CO,8DFIC (1:1.5) composite was found to be significantly limited by the insufficient yield $( 6 8 \% )$ and sluggishness $( 2 1 \ \mathrm { \ p s } )$ of hole transfer from $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ to PTB7-Th following photoexcitation. The hole transfer process improved drastically upon the addition of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ to the BHJ, as evidenced by the hole transfer yield of $9 4 \%$ and time of 8 ps. Atomic force microscopy (AFM) as well as photoluminescence (PL) and photoinduced absorption (PIA) spectroscopic analyses of the $\mathrm { C O } _ { i } 8 \mathrm { D F I C } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ (1.05:0.45) composite revealed that the accelerated hole transfer rate resulted from the enhanced intermixing of PTB7-Th and ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ by $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ and more importantly from an efficient electron transfer process from ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ The CO,8DFIC-to- $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ electron transfer process led to an electron cascade over the three components, which efficiently deactivated back-electron transfer (carrier recombination) from ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ to PTB7-Th at ${ \sim } 1 6 0$ ps (Scheme 1). Our results on enhanced charge separation yield via electron transfer to fullerenes may provide new insight into the role of fullerenes in ternary BHJ composites.

The origin of enhanced $J _ { \mathrm { s c } }$ was investigated by plotting the PL spectra obtained after dividing their intensities by the absorption intensity of the material at $6 5 0 \mathrm { n m }$ (photoexcitation wavelength, Figure 1d). To obtain the absorption intensities of the individual components at $6 5 0 \mathrm { n m }$ the absorption spectra of the binary and ternary composites between 600 and $8 0 0 ~ \mathrm { { \ n m } }$ were fit by multiplying arbitral factors with the absorption spectra of pristine PTB7-Th and $\mathrm { C O } _ { i } 8 \mathrm { D F I C } _ { \mathrm { \Omega } }$ integrating the two spectra, and considering the absorption intensity at $6 5 0 \mathrm { n m }$ . Dividing the PL spectra by the respective absorption intensities of PTB7-Th and ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ at $6 5 0 \mathrm { n m }$ reveals that the PTB7-Th PL peak at $7 6 5 \mathrm { n m }$ is quenched by 98.9 and $9 9 . 6 \%$ in the binary and ternary composites, respectively, whereas the CO,8DFIC PL peak at 910 nm is quenched by 68.1 and $9 3 . 8 \%$ respectively. The drastic enhancement in PL quenching of ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ in the ternary composite is indicative of more efficient exciton separation within $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ after photoexcitation, which might be responsible for the enhanced $J _ { \mathrm { s c } }$

The enhanced CO,8DFIC PL quenching may result from morphological changes in the BHJ. The addition of PCBM is known to improve the intermixing property of the polymer donor and nonfullerene acceptors3-2 Figure 1e,f indicates that the ternary composite exhibits a smaller root-mean-square roughness $\left( 3 . 1 9 \ \mathrm { n m } \right)$ than that of the binary composite (6.08 nm), which is consistent with previous studies and is indicative of smaller and, consequently, better mixing of donor and acceptor phases.

The hole transfer from ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ to PTB7-Th following photoexcitation was characterized by measuring PIA decay in the $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ exciton regime (Figure 3b). When probed at $1 0 3 0 \mathrm { n m }$ ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ exhibits single-exponential PIA decay with a time constant of 65 ps, whereas the binary and ternary composites show multiexponential PIA decay with time constants of 21 $( 4 0 \% )$ , 161 $( 5 3 \% )$ , and ${ > } 1 3 0 0 0$ ps $( 7 \% )$ as well as 8 $( 4 3 \% )$ , 161 $( 3 1 \% )$ , and ${ > } 1 3 0 0 0$ ps $( 2 6 \% )$ , respectively (Table 1). The 65 ps time constant is attributed to the lifetime of singlet ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ excitons, whereas those of 21 and 8 ps possibly result from hole transfer from CO,8DFIC to PTB7-Th, considering the similarities with the enhanced PL quenching results in the binary and ternary composites. Extremely long PIA decay times $\left( > 1 3 0 0 0 \mathrm { p s } \right)$ , which are beyond the detection limits in our study, are attributed to long-lived polarons. By contrast, the relatively fast PIA decay time $( { \sim } 1 6 { \bar { 0 } } ~ \mathrm { p s } )$ is indicative of carrier recombination after photoexcitation.

The origin of the $\sim 1 6 0$ ps time-decay components was addressed by measuring PIA decays at $9 2 0 \ \mathrm { n m }$ , that is, in a regime where the $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ exciton PIA is the lowest. When probed at $9 2 0 \mathrm { n m }$ , PIA spectra of binary and ternary composites exhibit time-decay constants of 20 (rise), 161 $( 9 0 \% )$ , and ${ > } 1 3 0 0 0$ ps $( 1 0 \% )$ as well as 8 (rise), 163 $( 3 8 \% )$ , and ${ > } 1 3 0 0 0$ ps $( 6 2 \% )$ , respectively. The PIA rise times of 20 and 8 ps are consistent with the hole transfer times characterized by PIA decays at $1 0 3 0 \ \mathrm { n m }$ indicating that the $\sim 1 6 0$ ps time-decay components result from carrier recombination following hole transfer from ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ to PTB7-Th. More details regarding the ${ \sim } 1 6 0$ ps component were obtained by measuring PIA decays at various pump intensities (Figure S4). An increase in the pump-light intensity in the $2 { - } 1 0 \mu \mathrm { J } / \mathrm { c m } ^ { 2 }$ range leads to a systematic decrease in the decay time in the PIA decays of PTB7-Th:CO,8DFIC at $9 2 0 \mathrm { n m }$ from 161 to 144 and 88 ps. The shortened PIA decay times are indicative of nongeminate recombination of charge carriers in the BHJ composites, probably at the long-range CT states generated at the interface of the polymer and monomer aggregates.30,33-35

The relative contribution of the ${ \sim } 1 6 0$ ps component to the PIA decays shown in Figure 3c,d is noted to significantly decrease in the ternary composite, compared to that of the binary composite. This result hints at the significant deactivation of carrier recombination after photoexcitation. The parameters listed in Table 1 indicate that the carrier recombination loss at $\sim 1 6 0$ ps decreases by ${ > } 5 0 \%$ in the ternary composite. Additionally, the ${ \sim } 1 3 0 0$ ps time-decay component, which was attributed to the CT state of PTB7-Th $\mathrm { \cdot P C } _ { 7 1 } \mathrm { B M }$ (Figure S3), was not detected in the ternary P' $\mathrm { T B 7 - T h : C O } _ { i } \mathrm { 8 D F I C : P C _ { 7 1 } B M }$ composite. These observations consistently indicate the deactivation of carrier recombination at the interface of the polymer and monomer aggregates, which may contribute to the improved $J _ { \mathrm { s c } }$ and FF in the ternary BHJ cell.

To investigate the underlying dynamics of enhanced charge separation in the ternary composite, the absorption and PL spectra as well as PIA decays obtained for the ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ and $\mathrm { C O } _ { i } 8 \mathrm { D F I C } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ (1.05:0.45) films were compared (Figure 4). When divided by the absorption intensity at $6 5 0 ~ \mathrm { \ n m }$ (photoexcitation wavelength), the CO,8DFIC PL is quenched by $5 4 \%$ in the binary composite. Additionally, a rapid 6 ps timedecay component, which is comparable to the 8 ps hole transfer time for the ternary composite, is observed at $1 0 3 0 \mathrm { n m }$ that is, in the CO,8DFIC exciton PIA regime. These observations indicate the occurrence of electron transfer from $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ following photoexcitation. The observed $\mathrm { C O } _ { i } 8 \mathrm { \dot { . } }$ DFIC-to$\mathrm { P C } _ { 7 1 } \mathrm { B M }$ electron transfer completes the electron transfer cascade over the three components, which possibly decreases the residence time of the carrier at the interface of the material aggregates and thereby decreases the carrier recombination yield, as evidenced by the reduced hole transfer time (8 ps) in the ternary composite compared to that of the binary composite $( 2 1 { \mathrm { ~ p s } } )$ . Efficient electron transfer from ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ may also be responsible for the enhanced exciton separation yield $( 9 4 \% )$ in the ternary composite, because CO,8DFIC PL can be quenched by both hole and electron transfer processes to PTB7-Th and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ respectively. Therefore, electron transfer from PTB7-Th to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ likely increases the exciton separation yield within ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ and decreases carrier recombination loss at the aggregate interface, eventually contributing to the improved $J _ { \mathrm { s c } }$ FF, and PCE, in addition to changing the BHJ morphology and enhancing electron mobility. In summary, steady-state PL and time-resolved PIA spectroscopic analyses of the binary PTB7-Th:CO,8DFIC (1:1.5) and ternary $\mathrm { P T B 7 - T h : C O } _ { i } 8 \mathrm { D F I C : P C _ { 7 1 } B M }$ (1:1.05:0.45) composites revealed that the ternary composite exhibited an improved $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ exciton separation yield $( 9 4 \% )$ and fast hole transfer (8 ps) from ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ to PTB7- Th, compared to their binary counterparts ( $6 8 \%$ and 21 ps, respectively). Additionally, the carrier recombination loss at ${ \sim } 1 6 0$ ps decreased by ${ > } 5 0 \%$ in the ternary composite. A comparison of PL and PIA signals obtained from the ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ and $\mathrm { C O } _ { i } 8 \mathrm { D F I C } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ films revealed that efficient electron transfer occurred from $\mathrm { C O } _ { i } 8 \mathrm { D F I C }$ to $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ following photoexcitation. This electron transfer process was found to complete an electron transfer cascade over PTB7-Th, ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } } ,$ and $\mathrm { P C } _ { 7 1 } \mathrm { B M } ,$ accelerate the exciton separation rate from ${ \mathrm { C O } } _ { i } { \mathrm { 8 D F I C } }$ to PTB7-Th, decrease carrier recombination loss by reducing the carrier residence time at the aggregate interface, and eventually contribute to improving $J _ { \mathrm { s c } }$ FF, and PCE, along with enhancing the BHJ morphology and electron mobility. The insufficient exciton dissociation within ${ \mathrm { C O } } _ { i } { 8 \mathrm { D F I C } }$ and carrier recombination at ${ \sim } 1 6 0$ ps limits the efficiency of $\mathrm { C O } _ { i } 8 \mathrm { D }$ FIC-based OsCs; therefore, further optimization of the BHJ morphology can assist in resolving this issue.
