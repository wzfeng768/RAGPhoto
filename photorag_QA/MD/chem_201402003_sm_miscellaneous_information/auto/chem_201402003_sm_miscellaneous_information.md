# 1. Synthesis and Characterization

# General considerations

The following chemicals were purchased from commercial sources and used as received: 6,13- pentacenequinone (Alfa Aesar), phenylacetylene (Aldrich), phenyllithium (Acros), 2-bromo-1,3- dimethylbenzene (Aldrich), 2-bromo-1,3-diethylbenzene (Alfa Aesar), $n$ -butyllithium (Aldrich), ammonium chloride (Alfa Aesar) and tin(II) chloride dihydrate (Alfa Aesar). Dry tetrahydrofuran (THF) was obtained using a column purification system.

All synthetic manipulations were performed under standard air-free conditions under an atmosphere of argon gas with magnetic stirring unless otherwise mentioned. Flash chromatography was performed using silica gel (230-400 mesh) as the stationary phase. NMR spectra were acquired on a Bruker Avance III 500. Chemical shifts are reported relative to residual protonated solvent (7.27 ppm for $\mathrm { C H C l } _ { 3 }$ ). High-resolution mass spectra (HRMS) were obtained at the MIT Department of Chemistry Instrumentation Facility using a peak-matching protocol to determine the mass and error range of the molecular ion. All DFT calculations were performed using the B3LYP functional and the 6-311(d,p) basis set using the Gaussian 09 package.1

# Synthesis

General procedure for the synthesis of pentacene derivatives. $0 . 7 3 ~ \mathrm { m L }$ (1.2 mmol) nbutyllithium $( 1 . 6 \mathrm { M } )$ in hexanes was added to a solution of $0 . 1 3 \mathrm { ~ g ~ } ( 1 . 3 \mathrm { m m o l } )$ phenylacetylene in $4 \mathrm { m L }$ dry THF dropwise at $\mathrm { - 7 8 ~ \ ^ { \circ } C }$ and stirred vigorously at $\mathrm { - 7 8 ~ \ ^ { \circ } C }$ for 45 minutes. The reaction mixture was added dropwise to $0 . 4 \mathrm { g } \left( 1 . 3 0 \mathrm { m m o l } \right)$ of 6,13-pentacenequinone in $5 \mathrm { m L }$ dry THF at $\mathrm { - 7 8 ~ ^ { \circ } C }$ . The solution was then allowed to slowly warm up to room temperature and stirred overnight. The reaction mixture was filtered and the solid in the filter was washed with $2 0 ~ \mathrm { m L }$ THF: $_ \mathrm { H _ { 2 } O }$ (1:1, v/v). The filtrate was mixed with $3 0 ~ \mathrm { m l }$ of $\mathrm { N H } _ { 4 } \mathrm { C l }$ saturated aqueous solution and vigorously stirred for 30 minutes. The suspension was then extracted with dichloromethane and dried over $\mathrm { M g S O _ { 4 } }$ . The crude product was purified via flash chromatography on silica gel using $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ : hexanes $( 1 { : } 1 , \mathbf { v } / \mathbf { v } )$ and then recrystallized from dichloromethane and hexanes. 13- hydroxy-13-(phenylethynyl)pentacen-6(13H)-one $( 0 . 3 5 \ : \mathrm { g } , 6 6 \% )$ $\mathrm { ^ 1 H }$ NMR ( ${ 5 0 0 } \mathrm { M H z }$ , CDCl3): δ 8.90 (s, 2H), 8.72 (s, 2H), 8.09-8.07 (d, 2H), 8.03-8.02 (d, 2H), 7.68-7.65 (t, 2H), 7.62-7.59 (t, 2H), 7.53-7.51 (d, 2H), 7.36-7.34 (m, 3H), 3.17 (s, 1H).

A 2-bromo-1,3-disubstituted benzene derivative was dissolved in dry THF. $n$ -Butyllithium in hexanes was added at $\mathrm { - 7 8 ~ ^ { \circ } C }$ and stirred vigorously at $\mathrm { - 7 8 ~ ^ { \circ } C }$ for 30 minutes. 13-hydroxy-13- (phenylethynyl)pentacen- $6 ( 1 3 H )$ -one above was then added to the aryllithium suspension above at $\mathrm { - 7 8 ~ \ ^ { \circ } C }$ and vigorously stirred overnight. The reaction mixture was quenched by $2 0 ~ \mathrm { m l }$ of $\mathrm { N H } _ { 4 } \mathrm { C l }$ saturated aqueous solution, followed by extraction with $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ and drying over $\mathrm { M g } \mathrm { S O } _ { 4 }$ . The reaction mixture was then dissolved in THF and treated with $10 \%$ $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ aqueous solution saturated with $\mathrm { S n ( I I ) }$ chloride dihydrate and vigorously stirred at room temperature for 3 hours before extraction with dichloromethane and drying over $\mathrm { M g S O _ { 4 } }$ . The crude product was purified via flash chromatography on silica gel using $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ : hexanes $( 1 { : } 2 , \mathbf { v } / \mathbf { v } )$ and then recrystallized from dichloromethane and hexanes. 6,13-diphenylpentancene $( 1 ) ^ { 2 }$ and 6, 13- bis(phenylethynyl)pentacenes $\left( 2 \right) ^ { 3 }$ were prepared as previously reported.

# 2. Optical Experiments

Electronic absorbance spectra were acquired with a Varian Cary-100 spectrophotometer in double-beam mode using a solvent-containing cuvette for background subtraction spectra. Irradiation of the methylene blue photosensitizer to generate ${ } ^ { 1 } \mathrm { O } _ { 2 }$ was performed with a 200 W $\mathrm { H g / X e }$ lamp (Newport-Oriel) equipped with a condensing lens, water filter, manual shutter, with a $4 0 0 \mathrm { n m }$ high-pass filter, a $6 6 5 \mathrm { n m }$ high-pass filter and a focusing plano-convex lens (focal length $1 5 \mathrm { c m }$ ) in the light path.

# Kinetics

A stock solution of methylene blue was prepared in $\mathrm { C H C l } _ { 3 }$ to give an absorbance of 1.0 at its peak. 1-5 were dissolved in $\mathrm { C H C l } _ { 3 }$ respectively at a concentration of 0.005 M. 9, 10- diphenylanthracene was used as reference for 1-5. When the $0 . 0 0 5 \mathrm { { M } }$ solution was diluted 100- fold with the methylene blue stock solution, the final concentration of the acene in the sample was $0 . 0 5 \mathrm { m M }$ . For the solution, a Cary 100 UV-Vis spectrophotometer was used along with the $\mathrm { H g / X e }$ lamp. With the sample placed $1 5 \mathrm { { c m } }$ from the light source, the solution was irradiated using a $6 6 5 \mathrm { n m }$ high-pass filter and a $4 0 0 \mathrm { n m }$ high-pass filter and convex lens with; the absorbance spectrum was measured after each interval of irradiation.

# Direct Irradiation

Compounds 1-5 were dissolved in $\mathrm { C H C l } _ { 3 }$ at a concentration of 0.005 M. When the $0 . 0 0 5 \mathrm { { M } }$ solution was diluted 100-fold with $\mathrm { C H C l } _ { 3 }$ , the final concentration of the acene in the sample was $0 . 0 5 \mathrm { m M }$ . For the solution, a Cary 100 UV-Vis spectrophotometer was used along with the $\mathrm { H g / X e }$ lamp. With the sample placed $1 5 \mathrm { { c m } }$ from the light source, the solution was irradiated using a $4 0 0 \mathrm { n m }$ high-pass filter; the absorbance spectrum was measured after each interval of irradiation.

# X-ray Crystallography

Low-temperature diffraction data were collected on a Bruker-D8 Quest diffractometer coupled to a Photon CMOS detector with Mo $\mathrm { K } \alpha$ radiation $ \left( \lambda = 0 . 7 1 0 7 3 \mathrm { ~ \AA ~ } \right)$ ) from a fine-focus sealed tube source. A full sphere of reflection was collected, performing $\boldsymbol { \Phi }$ -and ω-scans. The structures were solved by direct methods using SHELXS4 and refined against $F ^ { 2 }$ on all data by full-matrix least squares with SHELXL- $9 7 ^ { 5 }$ and CRYSTALS6 following established refinement strategies. 7 All non-hydrogen atoms were refined anisotropically. All hydrogen atoms were included into the model at geometrically calculated positions and refined using a riding model. The isotropic displacement parameters of all hydrogen atoms were fixed to 1.2 times the U value of the atoms they are linked to (1.5 times for methyl groups). The presence of a dichloromethane molecule disordered around one of the inversion centers of the unit cell, compromises the statistics of the structure, but has no apparent effect on the structure of the molecule. This molecule is both disordered and only partially occupied (SOF refines to 0.73). It was modeled by a single molecular position, and refining the carbon $( \mathrm { S O F } = 0 . 5 )$ ) and chlorine positions and the overall site occupancy factor. The large and anisotropic thermal parameters indicate that there remains significant deviation from this simple model. The four highest peaks in the residual density occur near this molecule, the next six peaks are all in reasonable positions for bonding density in the aromatic rings. Based on these observations we feel that further modeling of the dichloromethane disorder is not warranted.
