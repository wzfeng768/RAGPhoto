# An S-shaped thienoacene semiconductor forming unique cruciform lamellar packing via a 2D interaction network of $\pmb { \pi }$ -stacking and chalcogen bonding†

Tatsuya Mori,\*ab Yuji Yamaguchi,c So Kawatac and Takuma Yasuda ab

rsc.li/materials-c

A crooked S-shaped thienoacene, S-B2T4, consisting of four fused thiophene rings and two benzene rings can self-organize into a unique cruciform lamellar packing. In each lamellar layer, adjacent S-B2T4 molecules are orthogonally arranged to form a cruciform molecular array. The extended 2D interaction network via $\pi$ -stacking and chalcogen bonding is crucial for stabilizing such molecular packing. Effective electronic couplings in the S-B2T4 molecular array lead to high hole mobilities of up to 1.5 $\mathsf { c m } ^ { 2 } \mathsf { V } ^ { - 1 } \mathsf { s } ^ { - 1 }$ in solutionprocessed thin-film transistors.

Thiophene-based ladder-type $\pi$ -conjugated molecules, the so-called thienoacenes, are representative organic semiconductors for organic field-effect transistors (OFETs).1 Over the past decade, intensive efforts have been devoted to the exploration of numerous functional thienoacenes for improving their charge transport properties.2,3 Molecular packing plays a pivotal role in determining the electronic functions such as charge carrier mobility. Thus, it is crucial to understand the arrangement of the $\pi$ -conjugated molecules and the type of intermolecular interactions preserved in the condensed states.

Dinaphtho[ $, 3 \cdot b : 2 ^ { \prime } , 3 ^ { \prime } \cdot f ]$ thieno[3,2-b]thiophenes $\left( C _ { n } { \mathrm { - D N T T } } \right.$ , Fig. 1a),3b which consist of two linearly-fused thiophenes and four benzene rings, are representative p-type OFET materials with high hole mobilities. $C _ { n } – \mathbf { D N T T }$ adopts a typical herringbone packing in the crystalline state, which is stabilized by $\mathrm { C H } \cdot \cdot \pi$ interactions with edge-to-face arrangements. Recently, our group reported the crooked isomers of $C _ { n } – \mathrm { D N T }$ , based on S-shaped dinaphtho[2,1- $\cdot b { : } 2 ^ { \prime } , 1 ^ { \prime }$ -f]thieno[3,2-b]thiophenes (S-DNTT-n,

Fig. 1b).3k In contrast to linear $C _ { n } – \mathbf { D N T }$ , S-DNTT-n adopts a slipped $\pi$ -stacking mode in single crystals, while forming a herringbone packing in solution-processed thin films. This polymorphic selforganization is attributed to the specific geometry of the $\pi$ -core. The crooked $\pi$ -core of S-DNTT- $^ { - n }$ can be regarded as a quasi-2D planar structure, which preferentially facilitates $\pi$ -stacking in the condensed state. The fact that aromatic molecules with a large $\pi$ -core (e.g., coronene) adopt a $\pi$ -stacking mode supports this notion.4 However, the relationship between the primary molecular structures and self-organized condensed structures of functional thienoacenes remains to be explored.

In this study, we designed and synthesized a new crooked thienoacene, S-B2T4 (Fig. 1c), by fusing four thiophene and two benzene rings in an S-shaped configuration and attaching two terminal octyl chains. Although unsubstituted [1]benzothieno $[ 3 ^ { \prime \prime } , 2 ^ { \prime \prime } ; 4 ^ { \prime } , 5 ^ { \prime } ] \mathrm { t h i e n o } [ 2 ^ { \prime } , 3 ^ { \prime } ; 4 , 5 _ { \cdot }$ ]thieno[2,3-b][1]benzothiophene has been reported,5 less attention has been paid so far because of its unknown single-crystal structure and poor hole mobilities $( 0 . 0 5 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } )$ in thin-film OFETs. Here, we elucidated the single-crystal structure of S-B2T4, which features layer-by-layer packing with a cruciform arrangement via a 2D interaction network of $\pi$ -stacking and chalcogen bonding. Additionally, S-B2T4 showed excellent solution processability despite the highly extended six-ring-fused $\pi$ -core. As a result, S-B2T4-based thin-film OFETs exhibited hole mobilities as high as $1 . 5 \ : \mathrm { c m } ^ { 2 } \ : \mathrm { V } ^ { - 1 } \ : s ^ { - 1 }$ .

As outlined in Scheme 1, we established a new synthetic route to S-B2T4 (see $\mathbf { E S I \dagger }$ for detailed synthesis procedures and characterization data). Starting from 5-octyl-3-bromobenzo[b]thiophene, the key acetylene-linked intermediate 3 was synthesized via Sonogashira–Hagihara cross-coupling reactions. Finally, the central thieno[3,2-b]thiophene moiety was constructed via a two-step procedure:6 dilithiation with $n$ -BuLi, followed by the addition of elemental sulfur, and reduction with Cu powder. S-B2T4 was fully characterized by $^ 1 \mathrm { H }$ and $^ { 1 3 } \mathrm { C }$ NMR spectroscopy, mass spectrometry, and elemental analysis, and its structure was confirmed by X-ray crystallographic analysis.

The highest occupied molecular orbital (HOMO) energy level of S-B2T4 was determined to be $- 5 . 4 1$ eV based on cyclic voltammetry $\left( \mathrm { E S I \dag } \right)$ . The optical energy gap $\left( E _ { \mathrm { g } } \right)$ estimated from the absorption edge in the thin film was $3 . 5 0 \mathrm { e V }$ , which is larger than that of S-DNTT- $n$ $( 3 . 2 2 - 3 . 2 3 ~ \mathrm { e V } ) ,$ 3k presumably because of the cross-conjugation character of the S-B2T4 $\pi \cdot$ -core derived from the syn-fused thiophenes. Thermogravimetric analysis demonstrated the high thermal stability of S-B2T4, with a $5 \%$ weight-loss temperature $\left( T _ { \mathrm { d } } \right)$ of $3 7 1 ~ ^ { \circ } \mathrm { C }$ under a ${ \bf N } _ { 2 }$ atmosphere.

X-Ray crystallographic analysis revealed the unique molecular assembly of S-B2T4. At a single-molecular level (Fig. 2a), two attached alkyl chains are oriented toward the short axis of the $\pi$ -core and deviate from the $\pi$ -conjugated plane. In the aggregation state (Fig. 2b), S-B2T4 adopts a layer-by-layer structure, in which the alkyl chains and $\pi$ -core are segregated alternately. Interestingly, in the intralayer packing in the $a { - } b$ plane, the adjacent molecules are orthogonally arranged to form a cruciform molecular array. This cruciform arrangement is reinforced by close sulfur–sulfur (S  S) intermolecular interactions (pink lines in Fig. 2b). The neighboring intermolecular S  S distance is $3 . 5 5 \mathrm { ~ \AA ~ }$ , which is shorter than the sum of the van der Waals radii (3.60 Å).7,8 Meanwhile, $\pi$ -stackings with a distance of $3 . 4 7 \mathring { \mathrm { A } }$ were observed along the $b$ -axis direction. Accordingly, two distinct noncovalent interactions, i.e., S  S interactions and $\pi$ -stackings, are extended along the transverse directions ( $a \mathrm { - }$ and $^ { b }$ -axes), forming a 2D interaction network. Based on the single-crystal structure, intermolecular transfer integrals were calculated to be $^ { - 9 }$ meV along the $a$ -axis (S  S interaction direction) and $- 2 9 \ \mathrm { m e V }$ along the $^ { b }$ -axis ( $\overset { \cdot } { \pi }$ -stacking direction).9 The relatively isotropic electronic couplings within the $a { - } b$ plane will be favorable for efficient charge transport in the transverse directions.

For an in-depth understanding of intermolecular noncovalent interactions, natural bond orbital (NBO) analysis was performed using a pair of S-B2T4 molecules along the $a$ -axis in the single-crystal structure.10 The key NBOs describe the charge-transfer interactions between the lone-pair orbital of the sulfur atom $\left( \mathbf { n } _ { \mathrm { s } } \right)$ in molecule A and the antibonding orbital of the $\mathrm { \bf s } { - } \mathrm { \bf C }$ bonds $\scriptstyle \left( \sigma ^ { * } _ { \mathbf { S } - \mathbf { C } } \right)$ in molecule B, with stabilization energies of 0.28 and $0 . 5 1 \mathrm { k c a l m o l } ^ { - 1 }$ (Fig. 3a), which are characteristic of typical chalcogen bondings.11 The back-donating interactions from molecules B to A were also estimated (Fig. 3b). Similar interactions were observed for U-shaped $\pi$ -conjugated thienoacene derivatives.3h,l Thus, the syn-fused thiophene moieties play a crucial role in inducing such effective intermolecular chalcogen bonds, triggering the cruciform lamellar packing.

The solubility of S-B2T4 was much higher $\mathit { \Omega } > 5 \mathrm { g } \mathrm { L } ^ { - 1 }$ at $2 5 ~ ^ { \circ } \mathrm { C }$ in toluene) than those of other six-ring-fused thienoacenes such as $\mathbf { C _ { 1 0 } } \mathbf { - D N T }$ $\left( \sim 0 . 0 8 \ \mathrm { g } \ \mathrm { L } ^ { - 1 } \right.$ at $6 0 ~ ^ { \circ } \mathrm { C }$ in toluene)3b and S-DNTT- $n$ $\left( n = 8 { : } 0 . 2 0 \mathrm { ~ g ~ L ~ } ^ { - 1 } \right.$ , $n = 1 0 { : } 0 . 2 7 \mathrm { ~ g ~ L } ^ { - 1 }$ at $2 5 ~ ^ { \circ } \mathrm { C }$ in toluene).3k This feature is advantageous for the fabrication of thin films via facile solution processes. $\mathbf { C _ { 1 0 } } \mathbf { - D N T }$ is required for complex techniques,3c and the more readily soluble S-DNTT-10 requires a hot solution $\left( 5 0 ~ ^ { \circ } \mathbf { C } \right)$ for dip coating.3k In contrast, continuous thin films based on S-B2T4 can be produced by dip coatin $\underset { ^ { \star } } { { r } ^ { 3 h - l , 1 2 } }$ $[ 5 \mathrm { ~ g ~ L ~ } ^ { - 1 }$ toluene solution) onto $\mathrm { S i } / \mathrm { S i O } _ { 2 }$ substrates at room temperature. As shown in Fig. 4a, the out-of-plane X-ray diffraction (XRD) pattern revealed the highly crystalline nature of the dip-coated S-B2T4 films. The series of intense (00h) diffraction peaks with a $d$ -spacing of $2 . 4 4 ~ \mathrm { { \ n m } }$ in the XRD pattern indicated that the S-B2T4 molecules are oriented vertically with respect to the substrate. The $d$ -spacing is consistent with the value obtained by subtracting the molecular length from the single-crystal structure of S-B2T4 $\left( \sim 2 . 5 \ \mathrm { n m } \right)$ . Moreover, atomic force microscopy (AFM) images revealed a terraceand-step structure with a similar step height of approximately $2 . 8 ~ \mathrm { n m }$ (Fig. 4b), supporting the edge-on molecular orientation on the substrates. Polarized optical microscopy (POM) observation indicated that the crystal growth with a stripe-like texture was aligned with the pulling direction in the dip-coated thin film $\left( \mathrm { E S I \dag } \right)$ . The POM image was dark when the pulling direction was aligned with the polarizer or analyzer, whereas it turned bright when the sample was rotated by $4 5 ^ { \circ }$ .13

The charge transport properties of the S-B2T4 thin films were evaluated by fabricating top-contact OFETs with four crossed gold electrodes on top of the semiconductor layer (Fig. 5a). The anisotropy in charge transport was evaluated by measuring the transfer and output characteristics along the parallel ( ) and perpendicular $( \perp )$ directions with respect to the sample pulling directions. As is evident from the transfer characteristics (Fig. 5b), the thin-film OFETs based on S-B2T4 showed typical p-type transistor behavior with negligible hysteresis between forward and reverse sweeps, on/off current ratios $\left( I _ { \mathrm { o n } } / I _ { \mathrm { o f f } } \right)$ of ${ 1 0 ^ { 4 } } { - 1 0 ^ { 5 } }$ , and threshold voltages $\left( V _ { \mathrm { t h } } \right)$ of approximately $- 2 0 \mathrm { ~  ~ V ~ }$ . The hole mobilities were 1.1 and $1 . 0 \ : \mathrm { c m } ^ { 2 } \ : \mathrm { V } ^ { - 1 } \ : \mathrm { s } ^ { - 1 }$ for the $\parallel$ and $\perp$ directions, respectively, which are much higher than that of the parent unsubstituted S-shaped thienoacene $\left( 0 . 0 5 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } \right.$ in vacuum-deposited thin-film OFETs).5 The maximum hole mobilities of the S-B2T4- based OFETs reached $1 . 5 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } \ \left( \mathrm { E S I } { \dagger } \right)$ . The directionindependent transport behavior could be ascribed to the 2D intermolecular interactions of S-B2T4 in the crystalline state (Fig. 2). In general, efficient charge transport was achieved with herringbone and bricklayer packing motifs. However, S-B2T4 exhibited high carrier mobilities $\left( > 1 . 0 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } \right)$ with unprecedented cruciform lamellar packing. Therefore, the present results demonstrate the excellent application potential of the crooked $\pi$ -core and unconventional packing motif for optoelectronic functions.

# Conclusion

In summary, a new six-ring-fused thienoacene, S-B2T4, with an overall S-shaped geometry and solubilizing alkyl chains, was developed as a new organic semiconductor. S-B2T4 formed lamellar packing with a unique cruciform arrangement in each layer, where adjacent molecules were orthogonally arranged, and the 2D interaction network of $\pi$ -stacking and sulfur–sulfur (S  S) interactions was extended in the transverse direction. By exploiting the excellent solubility and self-organization ability of S-B2T4, highly crystalline continuous thin films were fabricated via a facile dip-coating method at room temperature. The thin-film OFETs based on S-B2T4 showed p-channel behavior with high hole mobilities of up to $1 . 5 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ .
