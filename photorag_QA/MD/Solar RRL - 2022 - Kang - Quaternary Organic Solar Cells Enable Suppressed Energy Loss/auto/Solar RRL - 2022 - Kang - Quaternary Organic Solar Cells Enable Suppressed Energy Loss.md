# Quaternary Organic Solar Cells Enable Suppressed Energy Loss

Hui Kang, Bing Zheng, Yanxun Li, Shilin Li, Huiqiong Zhou, Lijun Huo,\* and Yuan Zhang\*

Multi-component organic solar cells (OsCs) composing of more than two donor and acceptor materials have attracted increasing attention, due to the possibilities to further mitigate voltage loss $( \Delta V _ { \mathrm { o c } } )$ for the gain of open-circuit voltage $( V _ { \mathrm { o c } } )$ . However, the control of phase morphology in multi-component blend systems that critically impacts $\Delta V _ { \mathrm { o c } }$ and the ultimate power conversion efficiency (PCE) is still a challenge. Here, we report a quaternary blend-based strategy for non-fullerene OSCs by using two polymer donors (PM6 and L20) along with acceptors of a non-fullerene (Y6) and $\mathsf { P C } _ { 7 1 } \mathsf { B M }$ , leading to concurrent improvements of the $V _ { \infty }$ device fill factor and eventual PCE. The quaternary OSC exhibits the advantages of a higher charge collection efficiency, expedited charge carrier sweep-out, and reduced charge recombination losses. The suppression on $\Delta V _ { \mathrm { o c } }$ is attributed to the reduced radiative recombination loss below the bandgap (0.143 V) and non-radiative voltage loss (0.216 v). These properties are linked to synergies of modified energetics and flm morphology of the quaternary blends. This work demonstrates that incorporating suitable donor and acceptor guest molecules to organic binary blend systems is a highly viable approach for Iowering the energy loss in organic bulk heterojunctions towards the boost of photovoltaic performance for realistic energy conversion applications.

# 1. Introduction

As a potential technology to utilize solar energy, organic solar cells (OsCs) have exhibited the advantages of long-term sustainability compared to silicon and other photovoltaic technologies.1 Owing to the specific material properties (light weight, flexible, high optical transparency etc.), organic bulk heterojunctions (BHJ) have also shown attractive application perspectives in transparent solar cells, flexible, and indoor photovoltaic devices.] In recent years, OsCs have achieved great progress in recent years, thanks for the rationale material design and device engineering.3] The power conversion efficiency (PCE) of OSCs is approaching to the $1 9 \%$ regime.4 As a general guidance for the PCE enhancement in single junction-based OsCs relies on the widening of absorption by the photoactive layer with regard to the solar spectrum. This practice, while could be helpful for the increase in the short-circuit current $( J _ { \mathrm { s c } } )$ , is often traded-off by unfavorable reductions in the opencircuit voltage $( V _ { \mathrm { o c } } )$ [5] which limits the photovoltaic efficiency of OsCs. Moreover, due to the relatively narrow absorption profile of organic semiconductors, the absorption width of binary bulk heterojunction (BHJ) would be insufficient for the targeted enhancement of $J _ { \mathrm { s c } } ,$ especially considering the relative low absorption coefficient of organic semiconductive materials.6

Ternary and quaternary blend-based strategies have been showed with the effectiveness in improving the absorption width of OSCs, in which the introduced guest molecules are intended to provide complementary absorptions to the host binary system.71

Apart from the favored broadening of photo-absorption, it has been found that the added components can bring additional advantages in improving $V _ { \mathrm { o c } } , { } ^ { [ 8 ] }$ and/or device fill factor (FF),[9] as well as the charge transport balance between the two carriers, or reducing charge trapping.[10] In typical multi-component BHJ blends, e.g., the widely adopted ternary system, the incorporated molecular guest, either an electron donor or an acceptor are designed to render the effect of generating more efficient charge transfer and transport in the BHJ. To achieve these goals, the molecular and morphological compatibilities or energy matching (e.g., by forming finer energetic cascades) with regard to the binary hosts need to be considered. The established understandings on ternary systems have enabled additional handles on controlling the morphology to modify the photovoltaic device characteristics. In comparison to ternary BHJs, the concept of quaternary BHJs has the merit in a way that the introduced two guests may serve different functionalities to synergistically improve the $J _ { \mathrm { s c } } ,$ $V _ { \mathrm { o c } } ,$ and FF with mitigated trade-offs between these device parameters.11] Unfortunately, constructing efficient quaternary blend systems is often challenging, given the presence of multiple components in which the interplays between the optical, photophysical and electronic properties likely induce the penalty for the device performance. This could explain the rareness of reported successes in quaternary OSCs, except for a few examples.[9,12] In comparison to the wealth of understandings on ternary OsCs, the $\Delta V _ { \mathrm { o c } }$ and morphological management based on the multicomponent concept is yet sparsely explored,[11,12] which critically restrains the development of high-efficiency OSCs.

In this contribution, we report a highly efficient quaternary blend as the photoactive layer for OsCs by utilizing two polymeric donors, namely PM6 (4,8-bis(5-(2-ethylhexyl)-4- fluorothiophen-2-yl)benzo[1,2-b:4,5-b']-dithiophene (BDT-F) (1,3- bis(thiophen-2-yl)-5,7-bis(2-ethylhexyl) benzo-[1,2-c:4,5-c'] dithiophene-4,8-dione (BDD)) and L20 (poly[(2,6-(4,8-bis(3-(2- ethylhexyl)-5-fluorophenyl)benzo[1,2-b:4,5-b']dithiophene))-alt-(1,3- bis(2-ethylhexyl)-5,7-di(thiophen-2-yl)-4H,8H-benzo[1,2-c:4,5-c'] dithiophene-4,8-dione)), together with two acceptors, namely non-fullereneY6(2,20-(2Z,20Z)-((12,13-bis(2-ethylhexyl)-3, 9-diundecyl-12,13-dihydro-[1,2,5]thiadiazolo[3,4-e] thieno $[ 2 , ^ { \prime } 3 0 ^ { \prime } { : } 4 ^ { \prime } , 5 0 ]$ thieno [20,30:4,5] pyrrolo [3,2-g] thieno[20,30:4,5]thieno[3,2-b]indole-2,10-diyl)bis(methanylylidene))bis(5,6-difluoro-3-oxo-2,3-dihydro-1H-indene-2,1 diylidene))dimalononitrile) and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ .With morphological analysis, we find that by co-mixing the L20 and PM6 donors $( \mathrm { L } 2 0 { : } \mathrm { P M } 6 = 0 . 1 { : } 0 . 9 )$ , network-like morphology could be obtained to facilitate the hole transport that better matches with that of the electron counterpart in the blends, leading to a more satisfactory mobility balance. These merits favorably weaken the charge recombination with more efficient charge collection in the quaternary devices. We further discover that the co-presence of L20 and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ is crucial for attaining the desired hierarchical morphology for the boost of device efficiencies. Favorably, the demonstrated $\mathrm { P M 6 ; L 2 0 : Y 6 : P C _ { 7 1 } B M }$ quaternary device exhibits a lowered voltage/energy loss compared to the corresponding binary and ternary devices, due to the below-bandgap radiative and nonradiative recombination losses that both decrease. Our combined results highlight that through proper selection of the guest components coupled with rational device engineering, the phase morphology can be regulated satisfactorily to arrive at modified charge carrier transport and recombination properties with greater device efficiencies in OSCs.

# 2.3. Charge Generation and Recombination Dynamics

Now we turn to explore charge recombination processes in these OSCs under device operational conditions. We first examined the charge collection efficiency $( P _ { \mathrm { C } } )$ based on the analysis of photocurrent density $( J _ { \mathrm { p h } } )$ versus effective voltage $( V _ { \mathrm { e f f } } )$ characteristics solar cells (see results in Figure 4a,b). Here $J _ { \mathrm { { p h } } }$ is defined as $J _ { \mathrm { p h } } { = } J _ { \mathrm { L } } { - } J _ { \mathrm { D } }$ , where $J _ { \mathrm { L } }$ is the current density under illumination and $J _ { \mathrm { D } }$ is that in the dark. $V _ { \mathrm { e f f } }$ is defined as $V _ { \mathrm { e f f } } = V _ { 0 } - V _ { \mathrm { c o r } }$ with $V _ { 0 }$ being the voltage when $J _ { \mathrm { p h } }$ is equal to 0, and $V _ { \mathrm { c o r } }$ is calculated by $V _ { \mathrm { c o r } } = V _ { \mathrm { a p p l i e d } } - J R _ { \mathrm { s e r i e s } }$ [9] In general, at a high effective voltage $( V _ { \mathrm { e f f } } )$ , typically greater than $2 \mathrm { V }$ , the saturation current density $( J _ { \mathrm { { s a t } } } )$ is limited only by the maximal charge generation rate $\left( G _ { \mathrm { m a x } } \right)$ [16] Hence, $J _ { \mathrm { s a t } }$ is simply written to $J _ { \mathrm { s a t } } { = } q L \mathrm { G } _ { \mathrm { m a x } }$ (here $q$ .5 the elementary charge and $L$ is thickness of the active layer). The charge collection efficiency $( P _ { \mathrm { C } } )$ is estimated by using the relation, $P _ { \mathrm { C } } = J _ { \mathrm { p h } } / J _ { \mathrm { s a t } }$ [20] As seen from the determined $P _ { \mathrm { C } }$ as a function of bias (see Figure 4b, and Table S4, Supporting Information), the highest $P _ { \mathrm { C } }$ of $9 8 . 1 1 \%$ (short-circuit condition) associated with a weaker electric field (E) was found in the quaternary device, versus a $P _ { \mathrm { C } }$ of $9 6 . 8 9 \%$ in the binary device and $P _ { \mathrm { C } }$ of $9 7 . 2 6 \%$ in the ternary device. The properties of higher charge collection probability accompanied with the attenuated E-dependence can be mainly responsible for the observed larger FF in our quaternary device.21] In addition, we note that the current leakages (see regime I depicted in Figure S6, Supporting Information) of the quaternary cell are the lowest, which could result in an enlarged shunt resistance.22] This will add another merit for the enhancement of device FF in our champion cell.[22]

To evaluate charge-carrier recombination dynamics in the devices, $J { - } V$ curves under different light intensities $( P _ { \mathrm { l i g h t } } )$ were measured (see Figure S8, Supporting Information), from which the dependencies of $J _ { \mathrm { s c } }$ and $V _ { \mathrm { o c } }$ on $P _ { \mathrm { l i g h t } }$ were quantified, as shown in Figure 4a,b, respectively. The relationship between $J _ { \mathrm { s c } }$ and $P _ { \mathrm { l i g h t } }$ can be expressed as $J _ { \mathrm { s c } } \propto P _ { \mathrm { l i g h t } } ^ { \mathrm { \alpha } } { } ^ { \propto }$ with the power $\alpha$ representing the bimolecular recombination degree.23] In short, an $\alpha$ value equaling the unity reflects the extreme case where all the free carriers are swept out and collected at the electrodes before recombination.15j $\alpha < 1$ can be caused by space charge effects of imbalanced mobilities.24] Based on the fitting to the $J _ { \mathrm { s c } }$ versus $P _ { \mathrm { l i g h t } }$ characteristics (Figure 4a), slopes of 0.973, 1.000, and 0.994 were obtained for binary, ternary, and quaternary BHJ devices, respectively, which are indicative of negligible bimolecular recombination losses in all these systems under short-circuit condition. Regarding the ternary and quaternary devices, the increase of slopes toward the unity also hints that the mobility balance gets improved. The presence of trap-assisted Shockley-Read-Hall (SRH) recombination can be distinguished from the ideality factor n manifested by the slope of the $V _ { \mathrm { o c } }$ versus $P _ { \mathrm { l i g h t } }$ characteristics,23] following the general relation, $V _ { \mathrm { o c } } \propto n k _ { \mathrm { B } } T / q \mathrm { l n } ( P _ { \mathrm { l i g h t } } )$ where $k _ { \mathrm { B } }$ and $T$ denote for the Boltzmann constant and temperature, respectively. In the $V _ { \mathrm { o c } }$ versus $P _ { \mathrm { l i g h t } }$ plots, a slope equaling the unity of $k _ { \mathrm { B } } T / q$ indicates the dominance of bimolecular charge recombination, while an upper (or lower) deviation of slope from $1 k _ { B } T / q$ points to the role of trap-assisted SRH recombination (or surface charge recombination or SCR) in the device.15] Through fittings (see Figure 4b), $n$ values of 1.382, 1.373 and 1.251 were determined, respectively, for the binary, ternary, and quaternary BHJ devices, indicating that the quaternary BHJ device suffers from the lowest trapassisted recombination. While we cannot exclude the role of SCR in these devices, it seems to play a minor role in affecting the ideality factor n or the slope of $V _ { \mathrm { o c } }$ versus $P _ { \mathrm { l i g h t } }$ plots, given the relatively low non-radiative recombination loss for $V _ { \mathrm { o c } }$ in these OsCs (will be discussed the following section). On this basis, the results reveal that the modification of the PM6:Y6 binary devices via the incorporated L20 donor and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ acceptor favorably reduces the density of traps in the BHJ film with suppressed SRH recombination, which accounts for the FF and PCE enhancement.

We speculate that the differentiated BHJ film morphologies can intimately influence on the behavior of charge transport processes in the devices. To this end, we carried out transient photocurrent (TPC) and photovoltage (TPV) measurements.

Based on the TPV decay traces (open-circuit condition, see Figure 4e), the charge recombination time manifested by the TPV decay time constant $\tau _ { \mathrm { T P V } }$ was evaluated on these OSCs (see results of $\tau _ { \mathrm { T P V } }$ in Table S4, Supporting Information). A considerable increase of $\tau _ { \mathrm { T P V } }$ was found in the quaternary device, pointing to the retardation on charge recombination. We further evaluated charge extraction in these devices at short-circuit condition. The charge sweep-out time $( \tau _ { \mathrm { e x t r } } )$ in these BHJ OSCs determined from the TPC measurement (Figure 4f) is given in Table S4 (Supporting Information). Consistently, the ternary and quaternary devices exhibit shortened charge sweep-out processes $( \tau _ { \mathrm { e x t r } } = 3 8 . 1 0$ and $\tau _ { \mathrm { e x t r } } = 3 9 . 7 2 \mathrm { n s }$ , with regard to that in the binary cell $( \tau _ { \mathrm { e x t r } } = 4 1 . 1 7 \mathrm { n s } )$ . These tendencies evidence that in the ternary and quaternary devices, charge carrier extraction is prompted, which is in line with the higher charge collection efficiency discussed earlier. The more rapid charge extraction can help inhibit the competing process of recombination, thus higher EQEs and FFs.25]

# 2.4. Voltage Loss Analysis

At last, we attempted to investigate the mechanisms behind the increase of $V _ { \mathrm { o c } }$ in the quaternary device through analyzing on the specific voltage loss parts constituting the total $\Delta V _ { \mathrm { o c } }$ . Results of detailed energy losses in the binary, ternary, and quaternary devices are shown in Table 2. According to the previously reported method based on Shockley-Queisser (SQ) limit,5,26] the total energy loss $( \Delta E _ { \mathrm { l o s s } } = q \Delta V _ { \mathrm { o c } } )$ arises from the three parts $( \Delta E _ { 1 - 3 } )$ described as

$$
\begin{array} { r l } & { \Delta E _ { \mathrm { l o s s } } = E _ { \mathrm { g } } - V _ { \mathrm { o c } } } \\ & { \qquad = ( E _ { \mathrm { g } } - q V _ { \mathrm { o C } } ^ { \mathrm { S Q } } ) + ( q V _ { \mathrm { O C } } ^ { \mathrm { S Q } } - q V _ { \mathrm { O C } } ^ { \mathrm { r a d } } ) + ( q V _ { \mathrm { O C } } ^ { \mathrm { r a d } } - q V _ { \mathrm { O C } } ) } \\ & { \qquad = \Delta E _ { 1 } + \Delta E _ { 2 } + \Delta E _ { 3 } } \end{array}

# 3. Conclusion

In summary, we have proposed a codonor and coacceptor concept for fabricating quaternary OsCs based on a newly synthesized polymer guest donor L20 and small molecule $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ In the quaternary BHJ films, the realized hierarchy and network-like morphology with appropriate phase separation and reduced molecular aggregation enable to obtain enhanced photovoltaic efficiencies. The combined investigations with GIWAXS, AFM, and TEM indicate that the peculiar phase morphology could balance the phase separation and material crystallization to promote exciton dissociation and charge carrier transport. These merits favorably weaken charge recombination and facilitate charge collection in the quaternary devices, which attributes to the improvement of device FF. We further found that the quaternary devices based on $\mathrm { P M 6 ; L 2 0 : Y 6 : P C _ { 7 1 } B M }$ possessed lowered voltage/energy losses compared to the corresponding binary and ternary devices, owing to the concurrently suppressed below-bandgap radiative and nonradiative recombination. Our work highlights that the strategy of multicomponent BHJs with proper selection of guest molecules can enrich our morphology control reservoirs to arrive at modified charge carrier transport and recombination properties toward greater photovoltaic efficiencies.
