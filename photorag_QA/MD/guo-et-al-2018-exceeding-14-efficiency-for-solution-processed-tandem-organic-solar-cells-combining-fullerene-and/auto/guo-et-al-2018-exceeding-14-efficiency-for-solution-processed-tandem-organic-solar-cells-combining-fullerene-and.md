ABSTRACT: For a highly efficient tandem organic solar cell, it is important for the subcells to minimize the absorption overlap and generate high and balanced currents. Considering the strong absorption and high external quantum efficiency at the short wavelength, developing a highly efficient blend system with a wide-bandgap (wBG) polymer as the donor and a fullerene derivative as the acceptor in the front cell would be an effective strategy. However, it is a challenge to obtain a high short-current density $\left( J _ { s c } \right)$ for this blend system. Here, we develop a WBG polymer (PBD1) with an optical bandgap of $\mathbf { 1 . 8 8 \ e V . }$ The PBD1: $\mathbf { P C } _ { 7 1 } \mathbf { B M }$ blend system

S There has great progress made in this field, and power conversion efficiencies (PCEs) of over $1 3 \%$ in the single-junction OSCs have been reported.6-8 The full solar spectrum is difficult to obtain, considering the limited absorption range and the thickness of the active layer in single-junction cells. Tandem OSCs composed of two or more subcells with complementary absorption stacked together have been designed to utilize the solar radiation more effectively.9-11 Since the breakthrough in all solution-processed tandem OSCs was reported by Heeger and co-workers in $2 0 0 7 , ^ { 1 2 }$ additional research has been devoted to develop novel photovoltaic materials and interconnecting layers $\begin{array} { l } { { \left( \mathrm { I C L s } \right) , ^ { 1 3 - 2 7 } } } \\ { { \mathrm { v . } ^ { 2 8 - 3 3 } } } \end{array}$ where PCEs of over $1 3 \%$ were achieved recently.28-33'

The most common tandem OsC devices are based on a two-terminal monolithic geometry, where two subcells are connected in series by highly transparent ICLs and photogenerated electrons from one subcell recombine with holes that are arriving from the subcell on the opposite side of the ICL.34 The open-circuit voltage $( V _ { \mathrm { o c } } )$ of a tandem device is determined by the sum of all of their subcell voltages, whereas the short-circuit current density $\left( J _ { \mathrm { s c } } \right)$ is limited by the smaller $J _ { \mathrm { s c } }$ throughout the two subcells, indicating that the balanced and high possible current between the subcells is essential when achieving a high $J _ { \mathrm { s c } }$ and PCE in tandem devices.35 Therefore, minimizing the overlap between the absorption spectra of the front and rear cells is critical. It would be feasible to use the active layers with the wide-bandgap (wBG) and the low-bandgap (LBG) photoactive materials in the front and rear cells, respectively. The front cell is responsible for utilizing the high-energy photons and obtaining a high $V _ { \mathrm { o c } }$ while the rear cell collects the low-energy photons and provides a matched $J _ { \mathrm { s c } }$ with the front cell. Recently, nonfullerene (NF) OSCs were developed very quickly,36-38 and the rapid development of NF acceptors with a low bandgap of ${ \sim } 1 . 3 ~ \mathrm { e V }$ provides new opportunities to achieve high eficiency for tandem OsCs.39-43 Notably, the single-junction devices based on $\mathrm { P T B 7  – T h } ^ { 4 4 }$ as the donor material and $^ { 2 , 2 ^ { \prime } }$ $( 2 Z , 2 ^ { \prime } Z )$ -(((4,4,9,9-tetrakis(4-hexylphenyl)-4,9-dihydro$s$ indaceno $[ 1 , 2 - b ; 5 , 6 - b ^ { \prime } ]$ dithiophene-2,7-diyl)bis(4-((2-ethylhexyl)- oxy)thiophene-5,2-diyl))bis(methanylylidene))bis(5,6-difluoro-3- oxo-2,3-dihydro-1H-indene-2,1-diylidene))dimalononitrile (IEICO-4F)31 or (4,4,10,10-tetrakis(4-hexylphenyl)-5,11-(2-ethylhexyloxy)-4,10-dihydro-dithienyl $[ 1 , 2 - b : 4 , 5 b ^ { \prime }$ benzodithiophene-2, 8-diyl)bis(2-(3-oxo-2,3-dihydroinden-5,6-dichloro-1-ylidene)- malononitrile) $\mathrm { ( B T \mathrm { - } C I C ) ^ { 4 0 } }$ as acceptor materials can yield PCEs of over $1 1 \%$ with a high $J _ { \mathrm { s c } }$ of over $2 0 \mathrm { \ m A \ c m } ^ { - 2 }$ . Furthermore, the tandem devices with PTB7-Th:IEICO-4F as the LBG active layer reported by Hou and co-workers gave a high PCE exceeding $1 4 \%$ 31 Considering the strong absorption and high external quantum efficiency at the short wavelength, a blend system of WBG polymers and fullerene derivatives as the active layer in the front cell should be an effective strategy to minimize the absorption overlap of the subcells. However, it is difficult to obtain a high $J _ { \mathrm { s c } }$ for the WBG polymer:fullerene derivative systems, which is generally limited by narrow absorption spectra and the small thickness of the blend film.

Hence, in this work, we focused on developing a new WBG conjugated polymer with thick films for highly efficient tandem OSCs. This WBG polymer, referred to as PBD1 (Figure 1a), exhibited a wide optical bandgap $\left( E _ { \mathrm { g } } ^ { \mathrm { \ o p t } } \right)$ of $1 . 8 8 \ \mathrm { e V } $ a low-lying highest occupied molecular orbital (HOMO) energy level of $- 5 . 3 9 \ \mathrm { e V } ,$ and a high hole mobility of $1 . 4 \times 1 0 ^ { - 3 } \ \mathrm { c m ^ { 2 } \ V ^ { - 1 } } \ s ^ { - 1 }$ The OSC device based on PBD1:[6,6]-phenyl- $C _ { 7 1 }$ -butyric acid methyl ester $\left( \mathrm { P C } _ { 7 1 } \mathrm { B M } \right)$ ,with a thickness of over $2 0 0 ~ \mathrm { { n m } }$ exhibited excellent photovoltaic performance with an outstanding PCE of $9 . 8 \%$ The device also afforded a high $J _ { \mathrm { s c } }$ of $1 4 . 6 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ and a fill factor (FF) of $7 4 \%$ Considering that the blend film of $\mathrm { P B D 1 : P C _ { 7 1 } B M }$ exhibited strong absorption at a short wavelength of $3 0 0 { - } 6 5 0 \ \mathrm { n m }$ and the corresponding high external quantum efficiency (EQE) values of over $7 0 \%$ in this region, the tandem devices were fabricated by using PTB7-Th:IEICO4F as the LBG active layer for the complementary absorption (see Figure 2a). The best performance of the tandem cell gave $J _ { \mathrm { s c } }$ of $1 2 . 3 \mathrm { \ m A \ c m ^ { - 2 } }$ a $V _ { \mathrm { o c } }$ of $1 . 6 1 \mathrm { V } _ { \mathrm { i } }$ and a high FF of $7 2 \%$ resulting in an overall PCE of $1 4 . 2 \%$ as it benefited from the high EQE and FF of the WBG subcell. The values were among the highest values reported in solution-processed tandem OSCs to date.

The new polymer PBD1 was synthesized by a Stille coupling reaction, as shown in Scheme S1 in the Supporting Information. The polymer exhibited a number-average molecular weight $\left( M _ { \mathrm { n } } \right)$ of $5 7 . 5 \mathrm { k D a }$ and polydispersity index (PD1) of 1.95. As shown in Figure 1c, the UV-vis absorption spectra of PBD1 in the chloroform solution and the thin film displayed a strong absorption between 400 and $6 5 0 \ \mathrm { n m }$ The thin-film absorption spectrum of PBD1 shifted slightly to the red compared to that in solution. It is worth noting that obvious vibronic shoulder peaks at $6 0 0 \ \mathrm { n m }$ were observed in both the solution and the thin film, which suggested that strong aggregation of the polymer chains already existed in the solution.

The $E _ { \mathrm { g } } ^ { \mathrm { \ o p t } }$ that was estimated from the absorption edge $\left( \lambda _ { \mathrm { e d g e } } \right)$ of the thin flm was $1 . 8 8 ~ \mathrm { e V }$ $\left( E _ { \mathrm { g } } ^ { \mathrm { \ o p t } } = 1 2 4 0 / \bar { \lambda } _ { \mathrm { e d g e } } \right)$ The HOMO energy level of PBD1 was determined by cyclic voltammetry (CV), as shown in Figure 1d. The onset oxidation potential $( \varphi _ { \mathrm { o x } } )$ of PBD1 was $0 . 6 8 \ \mathrm { \ e V } ,$ corresponding to a HOMO energy level value of $- 5 . 3 9 \mathrm { ~ \ e V } _ { ; }$ according to the equation $\mathrm { H O \bar { M } O } = - e \big ( \varphi _ { \mathrm { o x } } + 4 . 7 1 \big )$ (eV). The deep HOMO value was beneficial for a high $V _ { \mathrm { o c } }$ in OSCs. The crystallinity and the molecular orientation of the PBD1 film were studied by two-dimensional grazing-incidence X-ray diffraction (GIXD) measurements.45 As shown in Figure 1b, a sharp and intensive (o10) diffraction peak was found in the out-ofplane direction at ${ \sim } 1 . 6 9 \mathrm { \AA } ,$ suggesting that the polymer had a preferential face-on orientation relative to the substrate with a $\pi - \pi$ stacking distance of $3 . 7 3 \mathrm { ~ \AA } .$ In addition, the hole mobility of PBD1 was measured by the space-charge-limited current (SCLC) method, where a value of $\mathbf { \dot { 1 } } . 4 \times 1 0 ^ { - 3 } \thinspace \mathrm { c m } ^ { 2 } \thinspace \mathrm { V } ^ { - 1 } \thinspace s ^ { - 1 }$ was obtained (Figure S1, Supporting Information).

Photovoltaic properties of the new polymer PBD1 were investigated by fabricating devices with a structure of indium tin oxide (ITO)/poly(3,4-ethylenedioxythiophene):polystyrenesulfonate (PEDOT:PSS)/PBD1:PC,BM/zinc oxide nanoparticles (ZnO-NPs)/Al. The photovoltaic performance can be enhanced with 1,8-diiodooctane (DIO) additive and thermal annealing treatment (Figure S2 and Table S1, Supporting Information). As shown in Table 1, the optimized device that was based on PBD1: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ with a thickness of $2 3 0 ~ \mathrm { n m }$ exhibited a high PCE of $9 . 8 \%$ with a high $J _ { \mathrm { s c } }$ of $1 4 . 6 ~ \mathrm { m A ~ c m } ^ { - 2 }$ a $V _ { \mathrm { o c } }$ of $0 . 9 1 \mathrm { V } ,$ and a FF of $7 4 \%$ . This efficiency was among the highest values reported so far for the WBG polymer:fullerene-based singlejunction OSCs. Figure 2c shows the current density-voltage $\left( J - V \right)$ characteristics of PBD1: $\mathrm { \cdot P C } _ { 7 1 } \mathrm { B M }$ and PTB7-Th:IEICO4F-based single-junction devices. The corresponding EQE curve of the optimized device is shown in Figure 2d. The $\mathrm { P B D 1 : P C _ { 7 1 } B M }$ based device exhibited a high response in the range of $3 0 0 { - } 7 0 0 ~ \mathrm { n m }$ and a maximum EQE of $7 8 . 8 \%$ at $4 9 0 \mathrm { n m }$ was recorded. The morphologies of the blend flms were investigated using atomic force microscopy (AFM) and transmission electron microscopy (TEM). The root-mean-square (RMS) roughness increased to $1 . 4 4 \ \mathrm { n m }$ after the DIO and thermal annealing treatment (Figure S3, Supporting Information). Compared to the as-cast blend film, the film with DIO and thermal annealing treatment showed a continuous interpenetrating network with fibrous features, which is beneficial for exciton dissociation and charge transport in the devices (Figure S4, Supporting Information). Clearly, PBD1 is a promising photoactive material that produced a high $J _ { \mathrm { s c } }$ and FF and has good potential for making WBG subcells in the tandem OSCs.

The PTB7-Th:IEICO- $\cdot 4 \mathrm { F } ^ { 3 9 }$ blend system was used as the LBG active layer to make full use of the solar spectrum (Figure 2a). As seen in Figure 2b, the PTB7-Th:IEICO-4F film extended the absorption response to the near-infrared region of ${ \sim } 1 0 0 0 \mathrm { n m }$ The PBD1 $\mathrm { \cdot P C } _ { 7 1 } \mathrm { B M }$ film showed a relatively narrow absorption spectrum, covering the visible region within $3 0 0 { - } 6 5 0 \ \mathrm { ~ n m }$ Therefore, the two active layers nearly covered the sunlight spectrum between 300 and $1 0 0 0 \ \mathrm { n m }$ . More importantly, there was only a slight overlap between the absorption spectra in the two subcells, which was beneficial when obtaining high and balanced current densities within each subcell. The PTB7- Th:IEICO-4F-based device gave a PCE of $1 0 . 2 \%$ with a high $J _ { \mathrm { s c } }$ of $2 1 . 3 \mathrm { \ m A \ c m } ^ { - 2 }$ (Table 1). As shown in Figure 2d, the PTB7-Th:IEICO-4F-based device exhibited a broad response in the range of $3 0 0 { - } 1 0 0 0 ~ \mathrm { n m }$ . Importantly, the PTB7-Th:IEICO4F-based device exhibited excellent EQE values within $6 5 0 { - } 1 0 0 0 ~ \mathrm { n m }$ where the $\mathrm { P B D 1 : P C _ { 7 1 } B M }$ based device had its most diminished EQE. These results indicated that if these two active layers were used in the tandem cells, one could expect high EQE values in a wide range.

The PBD1: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ and PTB7-Th:IEICO-4F blend systems were used as the WBG and the LBG active layers to fabricate tandem OSCs. As shown in Figure 2e, the tandem devices were fabricated using solution processing, except for the Al electrode. The corresponding energy level diagram of the materials is presented in Figure 2f. The ICL consisted of a $3 0 \ \mathrm { n m }$ layer % $\mathrm { \dot { Z } n O - N P s } ^ { 4 6 }$ processed from $n$ butanol and a $3 0 ~ \mathrm { { n m } }$ layer of pH-neutral poly(3,4-ethylenedioxythiophene):polystyrene sulfonate (N-PEDOT:PSS)21 spin coated by water/isopropanol.

The thickness adjustment of the active layers in the subcells is essential for overall $J _ { \mathrm { s c } }$ enhancement of the tandem solar cells. We initially conducted optical simulations of the electric field distribution within the device by using the transfer-matrix modeling method, which provided guidance for selection of the optimal thicknesses of the subcells.,4 The refractive index $( n )$ and the extinction coefficient $( k )$ values for the materials in each layer that was used in our tandem device were obtained using variable-angle spectroscopic ellipsometry (Figure S5, Supporting Information). The spectrally averaged internal quantum efficiency (IQE) values for each active layer were $9 5 \%$ for $\mathrm { P B D 1 : P C _ { 7 1 } B M }$ and $8 5 \%$ for PTB7-Th:IEICO-4F, which were determined as the ratio between the experimental $J _ { \mathrm { s c } }$ and the absorbed photon flux.49 It was assumed that there were no losses in the interconnecting layer. The modeling results of the simulated $J _ { \mathrm { s c } }$ that was generated in the tandem solar cells as a function of the active layer thickness are shown in Figure 3a. The optical simulation showed that an optimum value of over $1 2 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ was obtained when the optimal thicknesses of the active layers in the front and rear cells were 230 and $1 1 0 \ \mathrm { n m }$ respectively. The simulated distribution of the normalized optical electric field and the energy dissipation rate in the tandem device with an optimized active layer thickness of $2 3 0 / 1 1 0 \ \mathrm { n m }$ in the front and rear cells are displayed in Figures S6 and 3b. The simulation showed that the energy distribution in the front cell was primarily located at a wavelength of $3 0 0 { - } 6 5 0 ~ \mathrm { \ n m } ,$ while the rear cell had a small fraction of energy that dissipated in that region but was primarily located in the region of $6 5 0 { - } 1 0 0 0 ~ \mathrm { n m }$

It is worth mentioning that the optimized tandem device performance was reproducible with low variations for the key photovoltaic parameters, where an average PCE of $1 3 . 8 \pm 0 . 2 \%$ was obtained for the 30 tandem cells obtained from three batches (Figure S7, Supporting Information). The results measured under the AM 1.5G condition were verified by taking EQE measurements of the front cell and the rear cell in the tandem device. As shown in Figure 4b, the front cell absorbed most of the high-energy photons within the range of $3 0 0 { - } 6 5 0 \ \mathrm { \ n m }$ and a maximum EQE value of $7 5 . 2 \%$ at $4 9 0 \ \mathrm { n m }$ was recorded. The rear cell exhibited a broad spectrum with a relatively low response in the visible region and a high response in the near-infrared region within $6 5 0 { - } 1 0 0 0 ~ \mathrm { n m } ,$ which agreed well with the simulated results. The integral current densities obtained from the EQE measurements were $1 1 . 9 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ for the front cell and $1 1 . 7 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ for the rear cell, which were balanced and consistent with the tandem device in the $J { - } V$ measurement.

In summary, we introduced a highly efficient WBG polymer PBD1 as the donor material in the front cell of the tandem device. Through optical simulation and device optimization, a remarkably high PCE of $1 4 . 2 \%$ with a $V _ { \mathrm { o c } }$ of $1 . 6 1 \ \mathrm { V } ,$ a $J _ { \mathrm { s c } }$ of $1 2 . 3 ~ \mathrm { m A } ~ \mathrm { { c m } ^ { - 2 } }$ , and a high FF of $7 2 \%$ was observed, which was among the highest values reported in the solutionprocessed tandem OSCs. These results indicated that PBD1 is a promising WBG polymer donor for applications in tandem OSCs. The overall performance could be further enhanced by selecting better-suited photoactive materials in the near future.
