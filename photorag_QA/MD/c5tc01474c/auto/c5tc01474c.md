# High mobility flexible polymer thin-film transistors with an octadecyl-phosphonic acid treated electrochemically oxidized alumina gate insulator

Sheng Sun, Linfeng Lan,\* Peng Xiao, Zhenhui Chen, Zhenguo Lin, Yuzhi Li, Hua Xu, Miao Xu, Junwu Chen, Junbiao Peng and Yong Cao

Flexible solution-processed polymer thin-film transistors (PTFTs) with a low band-gap (LBG) donoracceptor (D-A) conjugated polymer as the active layer and electrochemically oxidized alumina $( { \mathsf { A l O } } _ { x }$ :Nd) as the gate insulator are fabricated on polyethylene naphthalate (PEN) substrates. The $\mathsf { A l O } _ { x }$ :Nd insulator exhibits excellent insulating properties with low leakage current, a high dielectric constant and a high breakdown field. To improve the interface coupling between the polymer active layer and the $\mathsf { A l O } _ { x : } \mathsf { N d }$ insulator, the $\mathsf { A l O } _ { x }$ Nd insulator is treated with octadecyl-phosphonic acid (ODPA), forming self-assembled monolayers (SAMs) on the surface, and great improvement in TFT performance with the highest mobility of $2 . 8 8 \ c m ^ { 2 } \ \vee ^ { - 1 } \mathsf { s } ^ { - 1 }$ is attained. The performance improvement is attributed to the smoother surface and lower surface energy of the ODPA-treated $\mathsf { A l O } _ { x }$ :Nd compared to those of bare $\mathsf { A l O } _ { x }$ Nd. In addition, the flexible PTFT exhibits only small shifts in the transfer curves at bending curvatures $( R )$ at $3 0 \ m \mathsf m$ but the device shows larger threshold voltage and higher off current $( I _ { \mathrm { o } \mathsf { f } \mathsf { f } } )$ after bent at $R = 5 { - } 2 0 ~ \mathrm { m m }$ which may be attributed to the damage in the insulator-semiconductor interface.

# Introduction

In recent years, considerable interest has been focused on solution-processed polymer thin-film transistors (PTFTs) because of their potential applications in flat-panel displays, radio frequency identification tags, e-paper, and sensors due to their low cost, low temperature, large-area manufacture, and flexibility.1-6 PTFTs with donor-acceptor (D-A) conjugated copolymers have demonstrated high mobility above $1 0 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 } . ^ { 7 }$ 10 Also, some groups achieved mobility above $2 0 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ using macroscopic aligned semiconducting polymers.1 However, most of these high-mobility PTFTs still need a large operating voltage (50-100 v) and are fabricated on glass or silicon wafers, which limits low-power applications and the intrinsic flexibility of polymer semiconductors. To take advantage of their flexible nature, soluble PTFTs should be fabricated on flexible substrates, e.g., polyimide (P1),1 polyethylene terephthalate $\left( \mathrm { P E T } \right) ^ { 1 3 }$ and polyethylene naphthalate (PEN).14,15 However, it is difficult to realize flexible, high-performance PTFTs with low operating voltage, which is highly desirable for low-cost, flexible, organic electronics. One of the most challenging tasks for flexible PTFTs is the preparation of low-temperature and high-reliability gate insulators with good electrical insulation to increase the on/offcurrent ratio of a TFT and high capacitance to lower the operating voltages and to reduce the power consumption. Poly(4-vinylphenol) (PVP) is one of the most heavily used organic dielectric materials because of its good insulating characteristics and excellent filmforming properties with smooth surfaces. However, it should experience high cross-link temperatures at around $2 0 0 ~ ^ { \circ } \mathrm { C }$ in order to avoid damage during subsequent solution-based processes.16 Such high temperatures are unacceptable when using lowtemperature plastic substrates, like PET or PEN.

Li et al.17,18 have fabricated a high. $\kappa$ polymer as the gate dielectric of flexible OTFT and got excellent results. Another method to realize low-voltage OTFT operation is to develop several high $\kappa$ inorganic or inorganic-organic hybrid blend dielectrics.19,20 Among high- $\kappa$ inorganic dielectrics, $\mathbf { \delta A l O } _ { x }$ is an outstanding insulator material due to its room-temperature and environmental friendly process, high dielectric constant (8-12), low leakage current, and low cost. For example, Sekitani et al.21,22 and Zschieschang et al.23 have fabricated ultrathin $\mathbf { \mathbf { \mathbf { A l O } } } _ { x }$ using brief oxygen plasma as the gate dielectric. However, the side face coverage characteristics (sFcC) of the dielectric over the side face of the gate electrode (SFGE) is poor and the reliability is not good for the plasma oxidation process.24-26 In the last few years, we have developed zinc oxide-based TFTs with this anodization technology, attaining high-mobility and high-reliability.27 In this work, we managed to fabricate flexible PTFTs using $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ as gate insulator on the PEN substrate. However, the surface of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ film is rough and covered with hydroxyl groups, leading to reduced performance in organic devices fabricated on this unmodified layer. To solve these problems, self-assembled monolayers (sAMs) prepared with octadecyl-phosphonic acid (ODPA) was used to modify the surface of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$

# Experimental

# Metal-insulator-metal (MIm) device fabrication for capacitance characteristics

To evaluate the capacitance at various voltages and frequencies and the leakage current density of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ with and without ODPA dielectric layers, we fabricated two MIM capacitors with $\mathrm { A l } { : } \mathrm { N d } / \mathrm { A l O } _ { x } { : } \mathrm { N d }$ , modified with or without ODPA/Au, respectively. In this research, test voltages ranged from $- 1 8 \mathrm { ~ V ~ }$ to $^ { 1 8 \mathrm { ~ V ~ } }$ and frequencies from $1 \ \mathrm { k H z }$ to $1 0 0 ~ \mathrm { k H z }$

# Results and discussion

To suppress hillock formation and reduce the surface roughness, Al:Nd was used as the gate instead of pure Al.29 It can be seen from the TEM images that there are Nd clusters (dark areas) segregated in the Al-Nd film. The segregated Nd is important for releasing compressive or tensile strength during bending. The dielectric properties of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ with and without ODPA were assessed by fabricating MIM capacitors (as shown in Fig. 2). The capacitance density $\left( C _ { \mathrm { i } } \right)$ of the $\mathbf { \mathbf { \mathbf { A l O } } } _ { x }$ :Nd film is $4 2 . 0 ~ \mathrm { n F ~ c m } ^ { - 2 }$ and the $C _ { \mathrm { i } }$ of the $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ with ODPA film is $4 1 . 6 ~ \mathrm { n F ~ c m } ^ { - 2 }$ . The slow decrease of the measured capacitance with frequency indicating low defect density such as oxygen vacancies in the thin film.3 Accordingly, the leakage current is relatively low $( \approx 2 \times$ $1 0 ^ { - 8 } \mathrm { A } \mathrm { c m } ^ { - 2 } )$ at an electric field $( E )$ of as high as $3 . 0 \ \mathrm { m V \ c m ^ { - 1 } }$ which was lower than those of many other high- $\kappa$ dielectrics, and $\pm 2 \mathrm { m m }$ under gate field of $2 \mathrm { m V } \mathrm { c m } ^ { - 1 }$ , (not shown) showing good bending flexibility and reliability. These results showed that anodized $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ with ODPA is suitable for use in a gate dielectric layer.

Although the anodic $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ has good insulating properties, the hydroxyl groups on the surface and the relatively high surface roughness are the two main drawbacks for PTFT applications. To solve these problems, the surface of the anodic $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ was modified by ODPA SAM. Fig. 3 displays high-resolution transmission electron microscopy (HRTEM) images with the ODPAtreated OFET cross-section to examine the interface of the thin film layers. It can be seen that the insulator-semiconductor interface was uniform and continuous without pinholes or hillocks. The thicknesses of Al:Nd, $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ and FBT $\mathrm { \cdot T h } _ { 4 } ( 1 , 4 )$ were measured to be 150, 200 and $2 5 \ \mathrm { n m }$ , respectively, which were closed to those measured with ellipsometer or step profiler. The fast Fourier transform (FFT) pattern for FBT- $\cdot \mathrm { T h } _ { 4 } ( 1 , 4 )$ is indicated in the inset of Fig. 2c, revealing the presence of nanocrystalline domains.

The ODPA SAM is too thin to be distinguished in the TEM images. Thus, energy dispersive X-ray spectroscopy (EDS) experiments were performed to confirm the existence of the ODPA SAM. Three different points were detected, and signals belong to phosphorus can only be detected in the insulator-semiconductor interface, as shown in Fig. 4. Therefore, it can be deduced that a SAM with ODPA was formed in the surface of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$

Fig. 5a shows the output characteristics of FBT- $\mathrm { \cdot T h } _ { 4 } ( 1 , 4 )$ TFTs on PEN substrates. The device exhibited typical $p { \cdot }$ channel saturated behaviour with an operation voltage of $^ { 1 8 \mathrm { ~ V ~ } }$ , lower than those of many other PTFTs with traditional low- $\kappa$ gate insulators.

Fig. 5b shows the corresponding transfer characteristics. The threshold voltage was $\approx - 5 . 4 \mathrm { ~ V ~ }$ and the on to off current ratio $\left( I _ { \mathrm { o n } } / I _ { \mathrm { o f f } } \right)$ is ${ \approx } 1 0 ^ { 5 }$ .The highest field-effect mobility $( \mu )$ of $2 . 8 8 \ \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ and the average mobility of $\approx 1 . 1 0 ~ \mathrm { c m } ^ { 2 } \mathrm { \mathbf { V } } ^ { - 1 } \mathrm { \mathbf { \Lambda } } s ^ { - 1 }$ were attained when measuring 20 devices (Fig. 5c). It was worth noting that the PTFT device without ODPA treatment showed a mobility of only $0 . 2 4 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ (not shown). Moreover, the hysteresis was reduced from 2.5 to $\mathbf { 0 . 3 \ V }$ after ODPA modification, implying that the hydroxyl groups of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ are reduced after modified with ODPA.

The performance enhancement by ODPA modification was ascribed to the changes of surface roughness and surface energy of the anodic $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ gate insulators. The surface roughnesses of the $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ before and after ODPA modification were evaluated by atomic force microscope (AFM) experiments. Fig. 6a and b show the AFM images of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ without and with ODPA modification layer, respectively. The root mean square (RMS) roughness of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ was reduced from 3.6 to $2 . 0 \ \mathrm { n m }$ after modified with ODPA. The gate insulator with rough surface is believed to reduce mobility in organic semiconductors due to the disorder induced in the accumulation order. Furthermore, the surface roughness of gate insulator has an important effect on the morphology of the organic semiconductors deposited on it, and can disturb $\pi - \pi$ stacking, which is critical to efficient charge transport.31 Fig. 6c and d show the AFM images of FBT$\mathrm { T h } _ { 4 } ( 1 , 4 )$ on bare $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ and ODPA-treated $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ , respectively. It is known that there are lots of hydroxyl groups on the surface of oxide films, indicating that the surface energy of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ is high. In general, high surface energy is not good for carrier transport in organic TFTs.32 To evaluate the surface energy of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ with and without ODPA treatment, water contact measurement was performed. Fig. 7a and b show the water contact angle measurement images of bare $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ and ODPA-treated $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ , respectively. The water contact angle for bare $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ was $6 6 ^ { \circ }$ , showing hydrophilic characteristic which originated from the hydroxyl groups on the surface. After ODPA treatment, the water contact angle increased to $1 0 3 ^ { \circ }$ . According to the Young's equation,33 the surface energy greatly reduced after ODPA modification. Therefore, ODPA treatment can reduce the surface roughness and lower the surface energy, and in turn, improve the performance of PTFTs.

The bending flexibility of FBT $\Gamma \mathrm { - T h } _ { 4 } ( 1 , 4 )$ TFTs with ODPAtreated $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ gate insulator is shown in Fig. 8. To test the bending flexibility under more harsh conditions, the transfer curves were recorded at a gate voltage as high as $- 3 0 { \mathrm { ~ V } } .$ The PTFT device exhibited only small shifts in the transfer curves at bending curvatures $( R )$ larger than $3 0 \mathrm { m m }$ , but the device decayed apparently with larger threshold voltage and higher off current $\left( I _ { \mathrm { o f f } } \right)$ after bent at $R = 5 { - } 2 0 ~ \mathrm { m m }$ , which may be attributed to the damage in the insulator/semiconductor interface.

# Conclusions

In summary, flexible PTFTs on a PEN substrate with an ODPAtreated electrochemically oxidized $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ gate insulator and an $\mathrm { { F B T - T h } _ { 4 } ( 1 , 4 ) }$ active layer were fabricated. The $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ insulator exhibited excellent insulating properties with low leakage current, high dielectric constant and high breakdown field.

OTFTs without ODPA exhibited a mobility of $0 . 2 4 ~ { \mathrm { c m } } ^ { 2 } \mathrm { \mathbf { V } } ^ { - 1 } ~ \mathrm { \mathbf { s } } ^ { - 1 }$ while the one with ODPA exhibited higher mobilities with the highest mobility of $2 . 8 8 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ . The better performance of the ODPA-modified OTFT was attributed to the smoother surface and lower surface energy of the ODPA-treated $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ The surface roughness of $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ reduced from 3.6 to $2 . 0 \ \mathrm { n m }$ after modified by ODPA. Meanwhile, the water contact angles were $6 6 ^ { \circ }$ and $1 0 3 ^ { \circ }$ before and after ODPA treatment, respectively, implying lower surface energy after ODPA modification. In addition, the ODPA-modified OTFT was able to maintain the relatively stable performance under a certain degree of bending. These results indicate that ODPA-treated $\mathbf { A l O } _ { x } { \mathrm { : N d } }$ represents a promising approach for the gate insulator for flexible PTFTs.
