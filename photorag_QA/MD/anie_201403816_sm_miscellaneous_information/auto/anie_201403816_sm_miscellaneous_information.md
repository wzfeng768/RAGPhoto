# Section A. Materials / General Methods / Instrumentation

All reagents were purchased from commercial suppliers (Aldrich or Fisher) and used without further purification. Cobaltocene $\textstyle ( \mathbf { C o C p } _ { 2 } )$ was handled and stored in an Argon Glovebox. While small amounts of $( R R )$ - and (SS)-trans-1,2-cyclohexanediamine $[ ( R R ) \cdot$ - and (SS)-2] were also purchased from Aldrich Chemical Company, large amounts of enantiopure $( R R ) – 2$ were obtained by resolving racemic trans-1,2-cyclohexanediamine with $L \mathrm { - } ( + )$ -tartaric acid, as described in the literature.[S1] Analytical high pressure liquid chromatography (HPLC) was performed on reverse phase-HPLC (RP-HPLC) instruments, using a biphenyl and a binary solvent system (MeCN and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ with $0 . 1 \%$ $\mathrm { C F } _ { 3 } \mathrm { C O } _ { 2 } \mathrm { H } ,$ ). Thin layer chromatography (TLC) was performed on silica gel 60 F254 (E. Merck). Column chromatography was carried out on silica gel 60F (Merck 9385, 0.040– $0 . 0 6 3 \mathrm { m m }$ ). High-resolution mass spectra were measured on an Agilent 6210 Time of Flight (TOF) LC-MS, using an ESI source, coupled with Agilent 1100 HPLC stack, using direct infusion (0.6 $\mathrm { { m L } } / \mathrm { { m i n } } ,$ ). UV/Vis/NIR absorption spectra were recorded using a UV-3600 Shimadzu spectrophotometer. Circular dichroism (CD) measurements were carried out on a Jasco J-815 spectrometer. Steady-state and time resolved emission spectra were acquired using HORIBA FluoroMax $\textsuperscript { \textregistered }$ -4 equipped with a TCSPC module (diode laser excitation at $\lambda = 3 7 5 \ \mathrm { n m }$ ) and an integrating sphere for absolute photoluminescence quantum yield determination. Nuclear magnetic resonance (NMR) spectra were recorded on a BrukerAvance 600 and Varian P-Inova 500 spectrometers, with working frequencies of 600 and ${ 5 0 0 } \ \mathrm { M H z }$ . Chemical shifts are reported in ppm relative to the signals corresponding to the residual non-deuterated solvents (CDCl3: $\delta 7 . 2 6$ ppm). Continuous wave EPR and ENDOR spectra were acquired at X-band $( 9 . 5 \operatorname { G H z } )$ ) fields with a Bruker Elexsys E580 spectrometer, fitted with the DICE ENDOR accessory, an EN801 resonator, and an ENI A-500 RF power amplifier. Applied RF powers ranged from 200 to $4 0 0 ~ \mathrm { W }$ across the 7 MHz scanned range, and the microwave power ranged from 2 to $2 0 \mathrm { m W }$ . EPR spectra were recorded with $0 . 0 1 0 \mathrm { m T }$ modulation amplitude. The sample temperatures were controlled by a liquid nitrogen flow system. Samples were reduced using $\operatorname { C o C p } 2$ as the chemical reductant and loaded into $1 . 4 ~ \mathrm { m m }$ I.D. quartz tubes, which were sealed with epoxy resin in an argon filled glovebox. A spline fit baseline correction was applied to the ENDOR spectra following integration. Cyclic voltammetry (CV) experiments were carried out at room temperature in argon-purged solutions of DMF with a Gamry Multipurpose instrument (Reference 600) interfaced to a PC. All CV experiments were performed using a glassy carbon working electrode $( 0 . 0 7 1 \ \mathrm { c m } ^ { 2 } )$ . The electrode surface was polished routinely with $0 . 0 5 ~ { \mu \mathrm { m } }$ alumina-water slurry on a felt surface immediately before use. The counter electrode was a Pt coil and the reference electrode was an $\mathrm { A g / A g C l }$ electrode. The concentration of the sample and supporting electrolyte, tetrabutylammonium hexafluorophosphate $( \mathrm { T B A P F } _ { 6 }$ ), were $1 . 0 \mathrm { m M }$ and $0 . 1 { \bf M }$ , respectively. The CV cell was dried in an oven immediately before use, and argon was continually flushed through the cell as it was cooled down to room temperature to avoid condensation of water. Spectroelectrochemical (SEC) experiments were carried out using a custom-built optically transparent thin layer electrochemical (OTTLE) cell with an optical path of $2 \mathrm { m m }$ , using a Pt grid as working electrode, an Pt wire as counter electrode and a $\mathbf { A } \mathbf { g }$ wire pseudo-reference electrode. The optical images were acquired using Olympus BX53 upright microscope in transmission or fluorescence mode. The fluorescence image with spectral resolution was acquired by using a confocal laser scanning microscope (Leica TCS SP5), coupled to a CW diode laser $( \lambda = 4 0 5 \mathrm { n m }$ ).

# Section D. Spectroscopic and Spectrometric Characterizations

# 1) UV/Vis spectroscopy upon chemical reduction

The UV/Vis spectra for the reduced states of $( - )$ -2NDI, obtained by spectroelectrochemical methods (Figure 3c), were confirmed with stepwise chemical reduction of $( - )$ -2NDI with the oneelectron reductant cobaltocene $\textstyle ( \mathbf { C o C p } _ { 2 } )$ . The spectroscopic titration (Figure S4) of $\mathbf { C o C p 2 }$ into a $1 0 \mu \mathrm { M }$ solution of $( - )$ -2NDI in $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ was carried out in a glovebox under an Argon atmosphere. The addition of the reductant produces highly featured adsorption spectra, which display the characteristic peaks of radical anions. The long wavelength adsorption peaks for the monoradical anion $\left[ ( - ) { \ - } 2 \mathbf { N } \mathbf { D } \mathbf { I } \right] ^ { \bullet - }$ display the same shifts as observed in the UV/Vis spectroelectrochemical experiments. The UV/Vis spectrum of $( - )$ -2NDI, upon the addition of 1.0 equivalent of the reductant, can be compared with the spectra for the reference compound $\left[ \mathbf { R e f - N D I } \right] ^ { \bullet }$ (Figure S4a). Dramatic changes in adsorption was observed for spectra of $\left[ ( - ) / - 2 \mathbf { N } \mathbf { D } \mathbf { I } \right] ^ { - }$ , supporting the hypothesis that electron delocalization among the NDI-units is taking place in the $\left[ ( - ) { \ - } 2 \mathbf { N } \mathbf { D } \mathbf { I } \right] ^ { - }$ radical anion. Moreover the IVCT band in the NIR is (Figure S4b) invariant upon solvent polarity change, which is consistent of delocalized character of the mixed valence state.

# 2) Fluorescence spectroscopy

Steady state and time resolved fluorescence spectroscopies were performed in $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ at $2 9 8 \mathrm { K }$ in aerated and de-aerated conditions. The excimer-like state lifetime was determined by the fluorescence decay, which can be fitted as a monoexponential function to give $\tau _ { 0 } = 2 0 . 0 \pm 0 . 1$ ns. The absolute fluorescence quantum yield in $\mathrm { C H } _ { 2 } \mathrm { C l } _ { 2 }$ at $2 9 8 \mathrm { ~ K ~ }$ , determined by the use of an integrating sphere, was $( 4 . 7 \pm 0 . 6 ) \%$ .

# Section E. Quantum Mechanical Calculations

Density Functional Theory (DFT) calculations were performed using the Jaguar software package.[S3] The pseudospectral methodology,[S4] which significantly speeds up the SCF iterations, was employed in all calculations. Default grids and SCF convergence criteria, as implemented in Jaguar, were used. Structures were optimized at the $\mathrm { M 0 6 { - } 2 X ^ { [ S 5 ] } / 6 { - } 3 1 G ^ { * * } }$ level of theory in their neutral as well as their mono- and dianionic forms.
