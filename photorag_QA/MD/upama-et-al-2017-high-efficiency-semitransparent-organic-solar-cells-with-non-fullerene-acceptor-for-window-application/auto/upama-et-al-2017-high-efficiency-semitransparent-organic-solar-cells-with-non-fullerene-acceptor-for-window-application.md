ABSTRACT: Organic solar cels possess multiple desirable traits, such as low cost, flexibility, and semitransparency, which opens up potential avenues unavailable to other solar technologies, a prime example of this being window applications. For this specific application, a delicate balance between the transmission of light through the device and power conversion eficiency (PCE), dependent on the amount of light absorbed, must be optimized. Here, we report a high-effciency semitransparent device based on a novel fullerene-free material system. Using an active layer based on the material system PBDB-T:ITIC, optimized devices exhibited PCEs exceeding $7 \%$ while also achieving an average visible transmittance (AVT) of $2 5 \%$ . The concurrent demonstration of high efficiency with an AVT of $2 5 \%$ represents a notable step forward for semitransparent organic solar cells. Additionally, the influence f the active layer thicknes on the color rendering properties of these clls was studied. Optimization of the active lyer thickness can lead to high-effciency cells with high visible transmission as well as the ability to display an image accurately.

There is a variety of possible approaches to fabricate transparent electrodes.is Carbon nanotubes are a suitable candidate, as they can be produced cheaply and exhibit good mechanical flexibility.19 Another carbon-based solution, graphene, has been explored as both a top and bottom electrode and has been demonstrated in semitransparent organic solar cells. Liu et al.2o incorporated a doped graphene layer as the top electrode into a P3HT:PCBM semitransparent solar cell, which achieved an efficiency of $2 . 7 \%$ . However, these electrodes have relatively low conductivity and require additional chemical doping.20,21 S Single or multiple pairs of one-dimensional photonic crystals have been used as top electrode to achieve $5 \mathrm { - } 6 \%$ efficiency at an average visible transmittance (AVT) of $2 5 \%$ , the construction of which involves deposition of multiple layers of metal oxide $( \mathbf { M o O } _ { 3 }$ or ${ \mathrm { W O } } _ { 3 } ) / { \mathrm { L i F } }$ pairs.15,22,23 Another possible choice for the top electrode is a dielectric/ metal/dielectric $\left( \mathrm { D } / \mathrm { M } / \mathrm { D } \right)$ structure. This is advantageous due to its relatively simple construction and fabrication technique, unlike alternative approaches such as photonic crystals or graphene-based electrodes.1,20,22 This approach has been used in this study.

One of the key metrics for a semitransparent solar cell used in window applications is the AVT.,10,16 A fundamental tradeoff exists between the desire to maximize both the transmittance and generated photocurrent. Multiple reports have indicated that a minimum AVT of $2 5 \%$ is required for window applications.t,1s,16 The transmission of the cell can also be used to calculate the color rendering index (CRI). This parameter describes the accuracy of the depiction of colors in the transmitted light, compared to a standard illuminant, as perceived by the human eye. This is considered important for solar cells in window applications, such that the image outside is accurately displayed inside. Recently, non-fullerene small-molecule acceptors have emerged as attractive alternatives to conventional fullerene acceptors used in OSCs as electron collector.6,25-30 The superior performance of fullerene-free OsCs originates from the enhanced optical and electronic properties of non-fullerene acceptors including easily tunable molecular energy levels62631,32 superior optical asorption properties,3 and lower synthetic costs compared to fullerene acceptors.6,25,26 These advantageous properties have accelerated the improved performance exhibited by OSCs over the past few years. The non-fullerene acceptor 3,9-bis(2-methylene-(3-(1,1- dicyanomethylene)indanone))-5,5,11,11-tetrakis(4- hexylphenyl)dithieno $[ 2 , 3 \mathrm { - } \mathrm { d } ; 2 ^ { \prime } , 3 ^ { \prime } \mathrm { - } \mathrm { d } ^ { \prime } ]$ $s$ -indaceno $\left[ { 1 , 2 - b : 5 , 6 - { b } ^ { \prime } } \right]$ 1 dithiophene (ITIC) has shown particularly promising results. This novel small-molecule material has a high-lying LUMO level $( - 3 . 7 8 ~ \mathrm { e V } )$ which leads to high open-circuit voltage $( V _ { \mathrm { o c } } )$ 26 When coupled with the novel polymer poly[(2,6-(4,8- bis(5-(2-ethylhexyl)thiophen-2-y1)benzo[1,2-b:4,5-b']- dithiophene))- $a l t$ -(5,5- $^ { \prime } { } _ { 1 } \prime { } _ { , 3 } \prime$ -di-2-thienyl- $5 ^ { \prime } , 7 ^ { \prime }$ -bis(2- ethylhexyl)benzo $\left[ 1 ^ { \prime } , 2 ^ { \prime } { - } c { : } 4 ^ { \prime } , 5 ^ { \prime } { - } c ^ { \prime } \right]$ dithiophene-4,8-dione)) (PBDB-T), efficiencies exceeding $1 1 \%$ have been recorded. When combined, these materials have complementary absorption profiles and well-aligned electronic structure, leading .to. high $V _ { \mathrm { o c } }$ and short-circuit current density Usc).6,26,33,34

In this work, we demonstrated the use of a non-fullerene material system in an inverted semitransparent solar cell architecture. The PBDB-T:ITIC material system achieved an efficiency of more than $7 \%$ one of the highest reported values in a semitransparent device. Importantly, this high efficiency was achieved in a device with an AVT of $2 5 \%$ , which is crucial for window applications. At the time of writing, this is the highest reported efficiency at an AVT of $2 5 \%$ for singlejunction OSCs. $\mathbf { M o O _ { 3 } } / \mathbf { A g } / \mathbf { M o O _ { 3 } }$ was used as transparent anode. Additionally, the CRI was calculated as a function of the direction of illumination. This provides insights into the color rendering properties from the perspective of both viewers inside and outside of a building. The analysis provides compelling insight into future architectural applications.

# RESULTS AND DISCUSSION

The inverted device structure used for this study was ITO/ ZnO/PBDB-T:ITIC, $\mathrm { { ' M o O } _ { 3 } / A g / M o O _ { 3 } } ,$ as shown in Figure la. $\mathbf { M o O } _ { 3 } / \mathbf { A g } / \mathbf { M o O } _ { 3 }$ $( 6 / 1 0 / 4 0 ~ \mathrm { \ n m } )$ acts as a transparent top electrode; the inner $\mathbf { M o O } _ { 3 }$ layer also acts as the hole transport layer. A sol--gel processed ${ \mathrm { Z n O } }$ layer was used as the electron transport layer, and ITO is the transparent bottom electrode. A novel polymer, PBDB-T, and a non-fullerene small molecule, ITIC, as shown in Figure 1b, were selected as the donor and acceptor, respectively. The highest occupied molecular orbital (HOMO) and lowest unoccupied molecular orbital (LUMO) energies of the materials used are displayed in Figure 2a. The combination of PBD-T and ITIC in an opaque device structure has previously shown excellent photovoltaic performance with a PCE exceeding $1 1 \%$ 26 When it was employed in the semitransparent (ST) structure (Figure 1a), a $\mathrm { P C E } > 7 \%$ was achieved at $2 5 \%$ AVT. Figure 2b exhibits the transmission of the $\mathbf { M o O } _ { 3 } / \mathbf { A g } / \mathbf { M o O } _ { 3 }$ anode. The anode has sufficiently high transmission with a maximum transmission of $6 3 . 7 \%$ at $\lambda = 4 8 5$ nm. The sheet resistance is $3 7 . 3 \ \Omega / \boxed { \bigtriangledown } ,$ which is on the same order as that of commercial indium tin oxide (ITO) thin films $( 3 6 ~ \Omega / \bigsqcup )$ 35 This indicates that the electrode is conductive enough to extract charge from the device and yield highefficiency ST devices.

In order to optimize the device structure, a range of ST devices were fabricated with various active layer thicknesses, ranging from 53 to $1 4 3 ~ \mathrm { n m }$ Different thicknesses were achieved by changing the spin rate from 1200 to $6 5 0 0 ~ \mathrm { r p m }$ The thickness decreases with increasing spin speed; this relationship is shown graphically in Figure S1. The $J { - } V$ characteristics curves are illustrated in Figure 3a. The figure clearly indicates that all the ST devices have a similar $V _ { \mathrm { o c } }$ which is close to 0.9 V. The value is ${ \sim } 0 . 2 \mathrm { ~ V ~ }$ higher than that of devices containing traditional fullerene acceptors, due to the high-lying LUMO of non-fullerene acceptors.,26 This is a major factor contributing to the enhanced photovoltaic performance of this material system. As the active layer thickness was increased, the $J _ { \mathrm { s c } }$ also increased. As the active layer thickness was increased from 53 nm to $1 4 3 \ \mathrm { n m } ,$ the $J _ { \mathrm { s c } }$ almost doubled; it increased from 6.85 $\mathrm { m A } / { \mathrm { c m } ^ { 2 } }$ to $1 3 . 8 2 ~ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ These values are displayed in Table 1. The absorption of the active layer film, for various film thicknesses, is shown in Figure 3b. This displays a clear trend: as the film thickness is increased, the absorption increases over the entire wavelength range. To link the absorption to the $J _ { \mathrm { s c } }$ we have also measured the external quantum efficiency (EQE) for all semitransparent devices, in a bottom illumination configuration. These EQE spectra are displayed in Figure 3c. The trend at long wavelengths $\left( > 5 0 0 \ \mathrm { n m } \right)$ directly matches the trend displayed in the absorption curves. Increasing the thickness causes an increase in the EQE, which is conclusively shown to be related to increased photon absorption. For short wavelengths ( $\left( < 5 0 0 \ \mathrm { n m } \right)$ , the trend is less clear. For small active layer thicknesses $\leq 1 0 0 \ \mathrm { n m }$ , the trend matches that seen in long wavelengths; the EQE increases as the thickness increases. As the thickness increases beyond $1 0 0 \ \mathrm { n m } ,$ the EQE sharply reduces. A peak at ${ \sim } 3 8 0 ~ \mathrm { n m }$ is seen in all spectra. According to the absorption of the individual components, ITIC contributes very little photocurrent generation in this region.26 The reduced EQE in this region is largely related to some reduction in photocurrent generated in the PBDB-T phase. The exact mechanism causing this is not clear; we believe this may be due to increased recombination in the thick film, which leads to reduced carrier collection.34 In contrast, the fill factor (FF) declined with the increment in active layer thickness. The peak FF $\left( { > } 6 6 \% \right)$ occurred in devices with a 59 and $5 5 \ \mathrm { n m }$ active layer. Although the $J _ { \mathrm { s c } }$ is highest for a $1 4 3 ~ \mathrm { n m }$ thick active layer, at this thickness, the FF is at a minimum value of $4 9 . 6 \%$ We believe the reduced FF for larger thicknesses, as well as the reduced EQE at short wavelengths, is related to increased recombination. The drop in FF is linked to an increase in series resistance $\left( R _ { s } \right)$ and a decrease in shunt resistance $\left( R _ { \mathrm { s h } } \right)$ values. As a result, an optimum thickness is determined by the increased $J _ { \mathrm { s c } }$ for thicker films and increased FF for thinner films. The optimum PCE is obtained at $1 0 0 ~ \mathrm { { n m } }$ active layer thickness $\left( 2 0 0 0 ~ \mathrm { r p m } \right)$ with a maximum PCE value of $7 . 4 \%$ . To the best of our knowledge, this PCE is one of the few reported PCEs exceeding $7 \%$ for a single-junction semitransparent OsC. The $J _ { \mathrm { s c } }$ $V _ { \mathrm { o c } }$ and FF of the best device are $1 3 . 7 \ \mathrm { \bar { m A } } / \mathrm { c m } ^ { 2 }$ $0 . 8 8 3 \mathrm { ~ V } ,$ and $6 0 . 9 \%$ respectively. A comparison of the ST champion cell, with an opaque device of the same active layer thickness, is shown in Figure S2. The $V _ { \mathrm { o c } }$ and FF are almost the same (Table S1), which suggests that the transparent $\mathbf { D } / \mathbf { M } / \mathbf { D }$ top electrode can make good electrical contact. The efficiency of the ST cell $( 7 . 4 \% )$ is $67 \%$ of the efficiency of the opaque cell $( 1 1 \% )$ . The main difference in the efficiency comes from the reduced $J _ { \mathrm { s c } }$ for the ST cell, caused by the transparent top electrode, which reduces the path length of incident light in the active layer. The ST device is capable of retaining $7 1 \% J _ { \mathrm { s c } }$ of its opaque counterpart.

In building integration, it is important to find the device transparency from both top and bottom sides. Sometimes it is ideal for the window to be transparent enough from both inside and outside of a building such that people standing on both sides have similar visibility. Hence, we measured the total device transmittance under top illumination (light incident from top $\mathbf { M o O } _ { 3 } / \mathbf { A g } / \mathbf { M o O } _ { 3 }$ electrode side) as well. Figure 5b shows the device transmission for both top and bottom illumination, for $2 0 0 0 ~ \mathrm { r p m }$ devices. It is interesting to find that the transmittance spectra do not vary when the direction of illumination is changed; this trend is applicable to all the fabricated ST devices. The total device transmittance spectra of all the ST devices under top illumination are shown in Figure S3. As a result, the AVT values under top and bottom illumination, listed in Table 2, are essentially the same. Figure 5c shows photographs of the UNSw logo with and without the ST device. As can be seen from the figure, the photographs, with the same ST device in front of the logo, look similar regardless of the direction of illumination. Despite similar transmission from top and bottom illumination, the photovoltaic performance, including the device $J _ { s c }$ is vastly different when the direction of illumination is changed. The photovoltaic performance of the ST devices under top illumination is summarized in Table S2 in order to compare with the device performance under bottom illumination. Although $V _ { \mathrm { o c } }$ is independent of both active layer thickness and direction of illumination, $J _ { \mathrm { s c } }$ and FF decreased under top illumination. The main reason behind the lower $J _ { \mathrm { s c } }$ under top illumination is expected to be the lower exciton generation rate under this circumstance. It is well known that organic thin film solar cells act as multilayer optical cavities where the optical field distribution is governed by the optical interference effect, due to reflections of the incident light at the layer interfaces.36,37 When light enters through the $\mathbf { D } / \mathbf { M } / \mathbf { D }$ electrode under top illumination, the maximum optical field intensity is located close to the anode/active layer interface, followed by a steady decrease along the optical path of incident light.17,37 The behavior is representative of the Beer-Lambert law, causing an exponential reduction in exciton generation rate, which explains the drastic reduction in device $J _ { \mathrm { s c } }$ compared to that under bottom illumination. For devices with a thicker active layer $\left( > 1 0 0 \ \mathrm { n m } \right)$ , the FF was lower due to increased series resistance, which could be related to the uneven distribution of exciton generation inside the active layer (most excitons being generated near the anode/active layer interface) and subsequent carrier transport toward respective electrodes.

Hence, these devices can produce high-quality light transmission with near-white sensation to the human eye without altering the original color of an object. However, as the active layer thickness increases ${ \ ' t } _ { \mathrm { a c t i v e l a y e r } } \geq 1 0 0 ~ \mathrm { n m } ,$ , the color coordinates move in the direction of the intersection of cyan and blue color of the CIE chromaticity diagram. For the device with the best PCE and AVT, the active layer thickness is 100 nm and its color coordinates are slightly distant from the achromatic point; nevertheless, the device does not alter the transmitted light by a large extent. From Figure Sc, it can be seen that, in the transmitted image, the original colors of the objects (logo background, font color, building, sky) are almost correctly represented, with a slight hint of the color blue. This slight bluish tone in the photograph correlated with the position of this device in the CIE color space. The images are accurately represented; however, the intensity of the image is slightly reduced when viewed through the ST device. The photographs of the UNSw logo taken for all the fabricated ST devices are presented in Figure S4. The device with the thickest active layer ( $1 4 3 \ \mathrm { n m }$ at $1 2 0 0 \ \mathrm { r p m } ,$ is situated at the farthest location $\begin{array} { r } { { \bf \nabla } _ { x } = 0 . 2 3 . } \end{array}$ $y = 0 . 2 6 ,$ in the CIE diagram from the achromatic point. As a result, a strong blue tone can be seen in the photograph taken in front of this device in Figure S4. The light intensity is the lowest in this case; however, the image is still recognizable.

The CRI provides an objective analysis of the color rendering properties of a device. Essentially, the CRI, which is expressed as a percentage, provides a description of the ability of a device to accurately present an image, as compared to a standard illuminant, such as daylight. The CRI was calculated according to the CIE 13.3 1995 protocol.5,38 To calculate the CRI, the $\left( x , \right.$ y) coordinates from the CIE 1931 color space must first be converted to $\left( u , \ \nu \right)$ coordinates in the CIE 1960 color space. These coordinates must then be modified according to the 8 test color samples, as specified in the CIE standard. Each test color sample provides a special CRI. The average of these 8 special CRI values gives the general CRI. Full details of the methodology used are shown in ref 16. This value, referred to as CRI, is shown in Table 2, for all active layer thicknesses. The CRI value for the $1 2 0 0 ~ \mathrm { r p m }$ device is very low $( 1 4 \% )$ . As the thickness is reduced, a clear trend appears. The CRI increases up to a maximum value of $7 6 \%$ for bottom illumination. The CRI value is dependent on the transmission. As the transmittance value is very similar for both bottom and top illumination, the CRI values for top illumination, which are also shown in Table 2, are almost identical.

In the CIE protocol, 8 test color samples are specified, which cover the visible spectrum. The reflection from each sample, when illuminated by the D65 illumination source, accounts for the different colors of the solar spectrum. The CRI depends on the interaction between the light and that sample in all regions of the solar spectrum. To analyze the light passing through the sample in specific regions, these test color samples are used. In Figure 6b, both a "ref' and "test" image are shown for the 8 test color samples. The ref sample represents the specific test colors when illuminated by the D65 illuminant. The test sample represents light reflected from the test color samples and then transmitted through the ST solar cell. In the figure, three different ST solar cell thickness are compared with the test color samples. For the $1 2 0 0 ~ \mathrm { r p m }$ case, where the active layer is thick, in each portion of the spectrum, the light is modified such that it appears bluer than the original color. This provides a physical depiction of the reason causing the low CRI. For the $2 0 0 0 ~ \mathrm { r p m }$ case, which provided the highest efficiency, the color rendering properties are improved. It can be clearly seen that the view of the test colors is more accurate than for the 1200 rpm case; however, a bluish tinge is still observed across all colors. This correlates with the position on the CIE 1931 color space, shown in Figure 6a. For the $5 0 0 0 ~ \mathrm { { r p m } }$ case, corresponding to a film thickness of $5 9 \ \mathrm { n m }$ , the depiction of the reflected light from the test color samples, after it has transmitted through the ST device, is very accurate. Across the entire wavelength spectrum, the bluish tinge is significantly reduced. For this case, where the active layer is thin, the generated photocurrent was limited, leading to an efficiency of $5 \%$ .The result presented here represents a noticeable enhancement; however, future work should focus on achieving high efficiencies with excellent color rendering properties.

# CONCLUSIONS

In summary, we have demonstrated high-efficiency semitransparent fullerene-free organic solar cells with a $\mathbf { D } / \mathbf { M } / \mathbf { D }$ top electrode. The novel polymer:non-fullerene system (PBDB-T:ITIC) was used as the photoabsorbing layer, which contributed to high $V _ { \mathrm { o c } }$ and $J _ { \mathrm { s c } }$ resulting in enhanced device performance. The top electrode included a simple $\mathbf { D } / \mathbf { M } / \mathbf { D }$ layer construction that does not require sophisticated nanostructures or dielectric mirrors. By varying the active layer thicknesses, the device efficiency and overall device transmittance were controlled. An optimum thickness was achieved that yielded an average PCE of $7 . 3 \%$ with a remarkably high AVT of $2 5 \%$ . The optimized ST OSC is one of the few reported ST OSCs with a PCE value greater than $7 \%$ The combination of high PCE and an AVT of $2 5 \%$ represents an appreciable step forward for this technology. In addition, the color rendering properties of the fabricated ST devices were analyzed by their position in CIE 1931 color space and CRI values. As with PCE and AVT, the color coordinates and CRI values of the devices varied significantly with the active layer thickness. The optimum ST device had a CRI value of 44 with a slight bluish tone on the transmitted image, whereas devices with a $5 9 \ \mathrm { n m }$ thick active layer exhibited the highest CRI of 76 with the most accurate interpretation of the transmitted colors. We also analyzed the color rendering property as a function of the direction of illumination (both top and bottom illumination). The fabricated ST devices showed similar CRI values under both top and bottom illumination, implying that these devices are capable of rendering the true color of an object irrespective of the viewer's position from the device. All the advantages suggest that an inverted semitransparent OsC based on the high-efficiency material system PBDB-T:ITIC can provide sufficient transparency and color rendering property suitable for window applications.

# METHODS

Device Fabrication. PBDB-T (donor polymer) and ITIC (non-fullerene acceptor) were purchased from Solarmer Energy, Inc., and used as received. Patterned ITO-coated glass substrates from Lumtec were used for all films and devices. These substrates were first cleaned by ultrasonication in soapy deionized (DI) water, DI water, acetone, and 2- propanol. Sol-gel processed $_ { \mathrm { Z n O } }$ electron transport layer was fabricated on top of an ITO/glass substrate in a process reported in our earlier works.9  In brief, the $_ { \mathrm { Z n O } }$ sol-gel solution $( 0 . 4 8 \mathrm { ~ M } )$ was prepared by dissolving zinc acetate dihydrate $\mathrm { ( Z n ( C H _ { 3 } C O O ) _ { 2 } { \cdot } 2 H _ { 2 } O , }$ Sigma-Aldrich, ${ > } 9 9 . 0 \%$ $0 . 1 0 9 \ \mathrm { g } )$ and ethanolamine $( \mathrm { N H } _ { 2 } \mathrm { C H } _ { 2 } \mathrm { C H } _ { 2 } \mathrm { O H } ,$ Sigma-Aldrich, ${ > } 9 9 . 5 \%$ $3 2 ~ \mathrm { \ m L }$ ) in 2-methoxyethanol $\mathrm { ^ C H } _ { 3 } \mathrm { O C H } _ { 2 } \mathrm { C H } _ { 2 } \mathrm { O H } ,$ Sigma-Aldrich, $9 9 . 8 \%$ anhydrous, $1 ~ \mathrm { m L }$ ) under vigorous stirring for at least $2 4 \ \mathrm { h }$ . The $_ { \mathrm { Z n O } }$ solution was spin-cast on top of the precleaned ITO glass substrates at $4 0 0 0 \mathrm { r p m }$ for ${ \boldsymbol { 6 0 } } { \boldsymbol { s } } .$ The samples were then annealed at $1 7 0 ~ ^ { \circ } \mathrm { C }$ for $3 0 \ \mathrm { m i n }$ . An active layer solution of PBDB-T:ITIC (1:1 weight ratio) was prepared with the concentration of $2 0 ~ \mathrm { m g / m L }$ by blending in chlorobenzene/DIO (99.5:0.5 volume ratio) from SigmaAldrich. Subsequently, the active layer was spin-coated on top of the $_ { \mathrm { Z n O } }$ layer at different spin rates for $_ { 6 0 \mathrm { ~ s ~ } }$ to achieve various thicknesses within the $5 3 - 1 4 3 \ \mathrm { n m }$ range. Finally, the active layer coated substrates were loaded in a vacuum chamber $( 1 0 ^ { 6 } ~ \mathrm { m b a r } )$ , where $\mathbf { M o O } _ { 3 } / \mathbf { A g } / \mathbf { M o O } _ { 3 }$ layers were deposited by thermal evaporation through a shadow mask. The device area was $0 . 1 2 ~ \mathrm { c m } ^ { 2 }$

Device Characterization. The film thickness was measured by an Alpha-Step D600 profiler. The resistivity of the $\mathbf { M o O _ { 3 } } / \mathbf { A g } / \mathbf { M o O _ { 3 } }$ electrode was measured by using a four-point probe system (Jandel model RM3). The current density-- voltage $\left( J - V \right)$ measurements were performed using an IV5 solar cell $I { - } V$ testing system from PV Measurements, Inc. (using a Keithley 2400 source meter) under an illumination power of $1 0 0 \mathrm { \ m W / c m } ^ { 2 }$ by an AM 1.5G solar simulator (Oriel model 94023A; $1 0 0 \mathrm { \ m W / c m ^ { 2 } }$ ). For optical characterization of the electrodes, a UV-vis-NIR spectrometer (PerkinElmerLambda 950) was used. EQE measurements were performed using a QEX10 spectral response system from PV Measurements, Inc. During the $J { - } V$ measurements of the semitransparent cells, the illumination was always from the ITO side (bottom illumination). For CRI calculation, device transmission from both top and bottom sides was measured.
