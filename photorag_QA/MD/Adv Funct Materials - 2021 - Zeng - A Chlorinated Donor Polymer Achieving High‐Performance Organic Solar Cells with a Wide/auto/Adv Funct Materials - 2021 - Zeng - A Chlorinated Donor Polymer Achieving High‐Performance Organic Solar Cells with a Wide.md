# A Chlorinated Donor Polymer Achieving High-Performance Organic Solar Cells with a Wide Range of Polymer Molecular Weight

Anping Zeng, Xiaoling Ma, Mingao Pan, Yuzhong Chen,\* Ruiie Ma, Heng Zhao, Jianquan Zhang, Ha Kyung Kim, Ao Shang, Siwei Luo, Indunil Chathurangani Angunawela, Yuan Chang, Zhenyu Qi, Huiliang Sun, Joshua Yuk Lin Lai, Harald Ade, Wei Ma, Fujun Zhang,\* and He Yan\*

In the field of non-fullerene organic solar cells (OsCs), compared to the rapid development of non-fullerene acceptors, the progress of high-performance donor polymers is relatively slow. The property and performance of donor polymers in OsCs are often sensitive to the molecular weight of the polymers. In this study, a chlorinated donor polymer named D18-Cl is reported, which can achieve high performance with a wide range of polymer molecular weight. The devices based on D18-Cl show a higher open-circuit voltage $( \boldsymbol { v } _ { \infty } )$ due to the slightly deeper energy levels and an outstanding short-circuit current density $\pmb { \lvert { \ j } _ { \mathsf { s c } } \rvert }$ owing to the appropriate long periods of blend films and less ([6,6]-phenyl-C71-butyric acid methyl ester) $( \mathsf { P C } _ { \mathsf { \Pi } } _ { \mathsf { N } } \mathsf { B } \mathsf { M } )$ in mixed domains, leading to the higher efficiency of $1 7 . 9 7 \%$ than those of the D18-based devices $( 1 7 . 2 1 \% )$ . Meanwhile, D18-Cl can achieve high efficiencies $( 7 7 . 3 0 \mathrm { - } 7 7 . 9 7 \% )$ when its number-averaged molecular weight $( M _ { \mathfrak { n } } )$ is ranged from 45 to $7 2 k \mathsf { D } \mathsf { a }$ -. In contrast, the D18-based devices only exhibit relatively high efficiencies in a narrow $M _ { \mathfrak { n } }$ range of ${ \approx } 7 0$ kDa. Such property and performance make D18-Cl a promising donor polymer for scale-up and low-cost production.

# 1. Introduction

Organic solar cell (OsC) is one of the most promising third-generation solar technology as organic solar panels are fexible, lightweight, and can be printed using roll-to-roll production processes.[1-8] Conventional OsCs based on fullerene derivatives as acceptors can achieve efficiencies of up to $1 1 . 7 \%$ [9-11] However, in the past few years, the emergence of non-fullerene acceptors (NFAs) has revolutionized the Osc field since they have easily tunable chemical structure, excellent absorption property as well as simple synthetic procedures.[2-21] With the help of NFAs, the efficiency of non-fullerene OSCs has been increased to beyond $1 7 \%$ , showing the bright future of this technology.[22-33]

Compared to the enormous varieties of excellent NFAs now, in the past few years, the development progress of donor polymers is relatively slow. The examples of high- performance donor polymers that can match with NFAs include (poly([2,6'-4,8-di(5- ethylhexylthienyl)benzo[1,2-b;3,3-b]dithiophene]{3-fluoro-2[(2- ethylhexyl)carbonyl]thieno[3,4-b]thiophenediyl}))-Th, (poly[(2,6-(4,8-bis(5-(2-ethylhexylthio)-4-fluorothiophen-2-yl)- benzo[1,2-b:4,5-b']dithiophene))-alt-(5,5- $^ { 1 ^ { \prime } , 3 ^ { \prime } }$ -di-2-thienyl- $^ { 5 ^ { \prime } , 7 ^ { \prime } }$ bis(2-ethylhexyl)benzo[1',2'-c:4',5'-c'ldithiophene-4,8-dione)]) (PM6),  and poly[(2,6-(4,8-bis(5-(2-ethylhexyl-3-fluoro)thiophen-2-yl)-benzo[1,2-b:4,5-b'ldithiophene))-alt-(2-butyloctyl) thiophen-2-yl)-8-(4-(2-butyloctyl)-5-methylthiophen-2-yl)dithieno $3 ^ { \prime } , 2 ^ { \prime } { : } 3 , 4 ; 2 ^ { \prime \prime } , 3 ^ { \prime \prime }$ :5,6]benzo[1,2-c|[1,2,5]thiadiazole)])(D18).34 40] For many of these donor polymers, the device performance is highly sensitive to their molecular weight.41-44] For example, in our previous work, it is found that devices based on (poly[4,8- bis[5-(2-ethylhexyl)-4-chloro-2-thienyl]benzo[1,2-b:4,5-b']dithiophene-2,6-diyl]-2,5-thiophenediyl[5,7-bis(2-ethylhexyl)-4,8-dioxo4H,8H-benzo[1,2-c:4,5-c'|dithiophene-1,3-diyl]-2,5)-thiophenediyl] (PM7), one of the commonly used donor polymers for nonfullerene OsCs, can only achieve relatively high efficiency with number-averaged molecular weight $( M _ { \mathrm { n } } )$ of ${ \approx } 6 0 \mathrm { k D a }$ [45] With the variations of the molecular weight, the performance of the PM7- based devices decreased significantly. Similarly, it was shown that only PM6 of high molecular weight was able to quench the composition in the polymer-rich amorphous domains to have an acceptor concentration above the charge percolation threshold.[46] Under these circumstances, no commercial suppliers are able to provide these donor polymers with good performance at a large scale (above $1 0 \ \mathrm { g } )$ and at a low cost, which limits the further applications for non-fullerene OsCs. One of the successful methods to address this problem is to employ a random polymerization strategy, which can reduce the crystallinity of the original polymer so that the properties of the random polymer are less sensitive to the molecular weight.45] However, the addition of the third monomer makes the synthetic procedure more complicated and increases the cost. Therefore, it is important to develop homopolymers that can obtain high performance and are not sensitive to their molecular weight.

In this paper, we report a new donor polymer named (poly[(2,6-(4,8-bis(5-(2-ethylhexyl-4-chloro-2-thienyl)-benzo[1,2- b:4,5-b']dithiophene))-alt-(2-butyloctyl)thiophen-2-yl)-8-(4- (2-butyloctyl)-5-methylthiophen-2-yl)dithieno[ $3 ^ { \prime } , 2 ^ { \prime } { : } 3 , 4 ; 2 ^ { \prime \prime } , 3 ^ { \prime \prime } { : } 5 , 6 ]$ benzo[1,2-c][1,2,5]thiadiazole)]) (D18-Cl), which can achieve high-performance non-fullerene OsCs with a wide range of molecular weight.47,48] This polymer is based on the structure of D18 and chlorination strategy is used to replace the fluorine atoms of D18. We compare the optoelectronic properties and photovoltaic performance of D18 and D18-Cl. It is found that the D18-Cl-based devices can achieve a higher open-circuit voltage $( V _ { \mathrm { O C } } )$ since the chlorine atoms can slightly downshift the highest occupied molecular orbital (HOmO) and the lowest unoccupied molecular orbital (LUMO) levels. At the same time, the D18-Cl blend shows a suitable long period and less ([6,6]-phenyl-C71-butyric acid methyl ester) $( \mathrm { P C } _ { 7 1 } \mathrm { B M } )$ in the mixed domain for an outstanding short-circuit current density $( J _ { \mathsf { S C } } )$ Thanks to the similar conformation of D18 and D18-Cl, the molecular packing of D18-Cl blends shows no significant difference from that of D18, leading to the high and balanced charge mobility of the corresponding devices for a decent fill factor (FF). As a result, the D18-Cl-based devices can realize an excellent power conversion efficiency (PCE) of $1 7 . 9 7 \%$ . More importantly, the performance of D18-Cl is relatively insensitive to its molecular weight. When the $M _ { \mathrm { n } }$ of the polymer varies from $4 5 \mathrm { k D a }$ to $7 2 \mathrm { k D a }$ , the polymer can achieve PCEs of $1 7 . 3 0 -$ $1 7 . 9 7 \%$ . On the contrary, the performance of the D18-based devices is quite sensitive to the molecular weight.

Temperature-dependent UV-vis  absorption  measurements were taken to investigate the reason for the molecular-weight insensitivity of D18-Cl. In the past, it has been demonstrated that introducing temperature-dependent aggregation property is an effective approach to achieve optimal OPV morphology.[11,56,57] Similarly, it is found that the D18 and D18-Cl also exhibit similar temperature-dependent aggregation property which has been demonstrated in previous donor polymers. For example, as shown in Figure S6, Supporting Information, at different temperatures, the UV-vis absorption spectra of the polymer solution can change significantly. Therefore, we can compare the temperature-dependent aggregation property of D18 and D18-Cl to explain their different properties at different molecular weights.

We first compared the temperature-dependent aggregation property of D18 with low, medium, and high molecular weight. As shown in Figure S7, Supporting Information, the absorption onset of the low-molecular-weight D18 shifted from 636 to $6 1 2 ~ \mathrm { n m }$ when the solution was heated from 30 to $7 0 ~ ^ { \circ } \mathrm { C }$ which means that at $7 0 ~ ^ { \circ } \mathrm { C }$ the polymer effectively disaggregated. However, for the medium-molecular-weight D18, as the temperature increased from 30 to $7 0 ~ ^ { \circ } \mathrm { C } .$ the absorption onset changed from 636 to $6 1 8 ~ \mathrm { n m }$ , which indicates that at $7 0 ~ ^ { \circ } \mathrm { C }$ the mediummolecular-weight D18 showed a little stronger aggregation than the low-molecular-weight one. For the high-molecular-weight D18, when the temperature of the solution was increased from 30 to $7 0 ~ ^ { \circ } \mathrm { C }$ , the absorption onset exhibited minimal changes, which means that $7 0 ~ ^ { \circ } \mathrm { C }$ was not sufficient to break the aggregation of the high-molecular-weight D18. As demonstrated in previous reports, the temperature-dependent aggregation property reflects the morphology of the donor polymers. This change of temperature-dependent aggregation property of D18 with different molecular weights indicates the dependence of morphology on its molecular weight, which should be the main reason for its sensitivity to the molecular weight. On the other side, for the D18-Cl, we also compared the temperaturedependent aggregation property of the low, medium, and high molecular weight polymers. It is found that these polymers exhibited a very similar temperature-dependent aggregation property that is independent of their molecular weight. This should be a strong support for its molecular-weight-insensitive performance. As a result, the D18-based devices can only achieve the excellent morphology in a small range of $M _ { \mathrm { n } }$ for high $J { \bf s } { \bf c }$ and FF while the D18-Cl-based devices can keep the ideal morphology for high Jsc and FF in a relatively larger range of $M _ { \mathrm { n } }$

To further investigate the effects of chlorination on morphology, we studied the molecular packing of D18 and D18-Cl with the help of the grazing incidence wide-angle X-ray scattering (GIWAXS).[58] The 2D GIWAXS patterns and the corresponding $1 0 ^ { \circ }$ sector averaged 2D-GIWAXS profiles are shown in Figure 4 with the peak information summarized in Table 3. Both neat polymer films of D18 and D18-Cl exhibit (100) peaks at ${ \approx } 0 . 3 0 \ \mathring { \mathrm { A } } ^ { - 1 }$ in the in-plane direction while strong (010) peaks at ${ \approx } 1 . 6 4 \mathrm { \mathring { A } } ^ { - 1 }$ in the out-of-plane direction, corresponding to the lamellar stacking distances of ${ \approx } 2 0 $ A and $\pi \mathfrak { - } \pi$ stacking distances of ${ \approx } 3 . 8 \mathrm { ~ \AA ~ } .$ The 2D GIWAXS patterns of D18 and D18-Cl demonstrate their preferential face-on orientation. Using the space-charge-limited current (SCLC) method, the hole mobility of the pristine D18 and D18-Cl films were calculated as $\approx 1 . 2 \times 1 0 ^ { - 4 } \ : \mathrm { c m } ^ { 2 } \ : \mathrm { V } ^ { - 1 } \ : \mathrm { s } ^ { - 1 }$ (Figure S8a, Supporting Information and Table 1). The similar hole mobility reflects the similar GIwAXS results of the two neat films. Compared to the neat films, in the blend films, intense (010) peaks located at ${ \approx } 1 . 7 2 \mathring \mathrm { A } ^ { - 1 }$ appear in the out-of-plane direction, indicating both blends take faceon orientation relative to the substrate, which is known as the better orientation for charge transport in the vertical direction.[59] Besides, the coherence length of (010) peak in the D18-Cl blends (34.6 A) shows no significant difference compared to that of the D18 blends $( 3 6 . 9 \mathrm { ~ \AA ~ } )$ . Due to the similar molecular packing and face-on orientation, the hole/electron mobility $( \mu _ { \mathrm { h } } / \mu _ { \mathrm { e } } )$ of D18 and D18-Cl blends (Figure S8b,c, Supporting Information) are similar as $5 . 8 6 \times 1 0 ^ { - 4 } / 3 . 8 7 \times 1 0 ^ { - 4 } \mathrm { c m } ^ { 2 } \mathrm { V } ^ { - 1 } \mathrm { s } ^ { - 1 }$ and $6 . 2 3 \times 1 0 ^ { - 4 } / 4 . 1 0 \times 1 0 ^ { - 4 } \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ respectively (Table 2), which can help achieve an efficient and balanced charge transport in the corresponding devices. The GIwAXS and sCLC results demonstrate that the chlorination does not change the molecular packing and orientation of the polymers so that the D18-Cl-based devices can maintain relatively high and balanced mobility for the excellent FF.

The D18: Y6: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ blend film shows a larger long period $( 5 5 \ \mathrm { n m } )$ compared to that of the D18-Cl: Y6: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ blend film $\left[ 3 8 \mathrm { n m } \right]$ . The long period of the D18-Cl blends is close to the ideal one $( \approx 4 0 \ \mathrm { n m } )$ for optimal OSC operation, which likely explains the higher $J _ { \mathrm { s c } }$ achieved by D18-Cl based devices.161,62] Determining the number of domains and their composition in ternary devices is a very complex issue and difficult to probe, as the R-SoXS scattering is typically dominated by the $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ distribution.[25] The observed difference in scattering intensity can thus not be translated readily into a partitioning of the Y6 and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ and the Y6 and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ concentration in the polymer-rich amorphous domains. The scattering contrast is also very low, making it difficult to determine the background with confidence. The integrated scattering intensity seems to be higher for D18-Cl, indicating that more $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ in the mixed domains for the D18 than the D18-Cl, which might increase the charge recombination probability for D18-based devices.[63]

This conjecture was confirmed by considering their interaction parameters through surface tension calculations enabled by contact angle measurement.127,64,65] The water and ethylene glycol steady-state contact angles on D18-Cl, D18, Y6, and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ neat films are shown in Figure 5b-e. As summarized in Table S5, Supporting Information, their surface tensions were determined by Wu's method to be 19.18, 22.47, 21.31, and $2 5 . 4 4 \mathrm { ~ N ~ m ~ } ^ { - 1 }$ , respectively, based on which we can analyze the interactions between them thermodynamically. The FloryHuggins parameters $\left( \chi \right)$ are accordingly estimated to be 0.056 for D18-Cl:Y6, 0.015 for D18:Y6, 0.441 for D18-Cl: $\mathrm { \cdot P C } _ { \mathrm { 7 1 } } \mathrm { B M }$ 0.092 for $\mathrm { D 1 8 : P C _ { 7 1 } B M }$ and 0.183 for $\mathrm { Y 6 { : } P C _ { 7 1 } B M }$ . Hence, D18 prefers to mix with Y6 and $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ simultaneously instead of driving them to form two mixed phase with each other. In contrast, $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ tends to mix with Y6 more than D18-Cl, and D18-Cl is less miscible with Y6 than D18, implying stronger phase separation between host donor and acceptor. This can be the reason for the larger pure domain of D18-Cl in the blend film, which reduces the charge recombination in the D18-Cl systems.

To better understand the differences of the exciton dissociation and charge collection properties in the D18- and D18-Clbased devices, we studied the relationship between photocurrent density $\left( J _ { \mathrm { p h } } \right)$ and effective voltage $( V _ { \mathrm { e f f } } )$ as shown in Figure 2d. Here, $J _ { \mathrm { p h } }$ is defined as the difference between $J _ { \mathrm { L } }$ and $J _ { \mathrm { D } }$ in which $J _ { \mathrm { L } }$ and $J _ { \mathrm { D } }$ are current densities values under standard illumination condition and in the dark condition, respectively. Besides, $V _ { \mathrm { e f f } }$ is determined as the difference between $V _ { 0 }$ and $V _ { \mathrm { b i a s } }$ where $V _ { 0 }$ is the voltage values when $J _ { \mathrm { p h } }$ is zero and $V _ { \mathrm { b i a s } }$ is the external voltage bias values.66] As shown in Figure 2d, the $J _ { \mathrm { p h } }$ of the two devices reached saturation when $V _ { \mathrm { e f f } }$ is above $1 \mathrm { V } .$ Therefore, we chose the $J _ { \mathrm { p h } }$ values when $V _ { \mathrm { e f f } }$ is $1 . 3 5 \mathrm { V }$ as the saturated current density $\left( J _ { \mathrm { s a t } } \right)$ . The exciton dissociation probability $( \eta _ { \mathrm { d i s s } } )$ and charge collection efficiency $( \eta _ { \mathrm { c o l l } } )$ of the two devices are summarized in Table S6, Supporting Information, where $\eta _ { \mathrm { d i s s } }$ and $\eta _ { \mathrm { c o l l } }$ are the ratio between $J _ { \mathrm { p h } }$ and $J _ { \mathrm { s a t } }$ under short-circuit condition and maximum power output, respectively.[67] D18 and D18-Cl-based devices show the same and high $P _ { \mathrm { d i s s } }$ values of $9 9 . 3 \%$ , indicating the efficient exciton dissociation of the two devices. The $P _ { \mathrm { c o l l } }$ value of the D18-Cl-based devices is slightly higher $( 9 1 . 1 \% )$ than that of the D18-based ones $( 9 0 . 6 \% )$ , which contributes to the higher $J _ { \mathrm { s c } }$ values of the D18-Cl-based devices. The higher relative domain purity of D18-Cl blends leads to weaker charge recombination, and thus enhances the charge collection efficiency.

The charge recombination process of the two blends is further studied by measuring the impact of light intensity $( P _ { \mathrm { l i g h t } } )$ on $J _ { \mathrm { S C } }$ and $V _ { \mathrm { O C } }$ in Figure 2e,f, respectively. Based on the relationship of $J _ { \mathrm { S C } } { \propto } P _ { \mathrm { l i g h t } } { } ^ { \alpha }$ where $\alpha$ can be used to evaluate the bimolecular recombination, both the $\alpha$ values of the two devices calculated from Figure 2e are ${ \approx } 1$ indicating that the degree of bimolecular recombination is negligible.68,69] According to $V _ { \mathrm { o c } } \propto n ( K T / q ) \mathrm { l n } ( P )$ , the $n$ values of the two devices were calculated from Figure $2 \mathrm { f . } ^ { [ 7 0 ] }$ The D18-Cl-based devices have a slightly lower $n$ value of 1.03 than that of the D18-based ones (1.06), suggesting weaker trap-assist recombination in the D18-Cl-based devices. The overall lower charge recombination of the D18-Cl blends contributes to the $\mathrm { \ h i g h \ : } J _ { \mathrm { s c } }$ of the devices.[71]

# 3. Conclusion

In summary, a new polymer named D18-Cl was designed and synthesized on the basis of the high-performance polymer D18. The chlorination on D18 downshifts the HOMO level, which is beneficial for a higher $V _ { \mathrm { O C } }$ The replacement of fluorine atoms with chlorine atoms does not change the conformation of the polymer backbone and the molecular packing so that the D18-Cl based devices can maintain a decent FF. The D18-Cl blend has a suitable long period and less $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ in mixed domains, resulting in the slightly weaker charge recombination and better charge collection efficiency for high $J _ { \mathrm { S C } }$ All these parameters combined contribute to a higher PCE of $1 7 . 9 7 \%$ for the D18-Cl-based devices than that of the D18-based devices $( 1 7 . 2 1 \% )$ . More importantly, the D18-based devices can only achieve their best efficiencies when the $M _ { \mathrm { n } }$ of D18 is in a narrow range $( { \approx } 7 1 \ \mathrm { k D a } )$ while the D18-Cl-based devices can maintain PCE of over $1 7 . 3 \%$ as the $M _ { \mathrm { n } }$ of D18-Cl varies from $4 5 ~ \mathrm { k D a }$ to $7 2 \ \mathrm { k D a }$ . The high performance and insensitivity to molecular weight of D18-Cl should facilitate the large-scale applications of this chlorinated polymer compared to D18.
