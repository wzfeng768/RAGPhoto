# Aggregation-Induced Electrochemiluminescence of Carboranyl Carbazoles in Aqueous Media

Xing Weit, Meng-Jiao Zhut, Zhe Cheng, Mengjeu Lee, Hong Yan,\* Changsheng Lu,\* and JingJuan Xu\*

Abstract: The aggregation-induced electrochemiluminescence (AIECL) of carboranyl carbazoles in aqueous media was investigated for the first time. Quantum yields, morphologies, and particle sizes were observed to determine the electrochemiluminescence (ECL) performance of these aggregated organic dots (ODs). All compounds exhibit much higher ECL stability and intensity than the carborane-free compound, demonstrating the essential role of the carboranyl motif. Moreover, the results of cyclic voltammetry (CV) suggest that oxidation/reduction reactions take place at the carboranyl motif. The excited states of ODs were proposed to be generated by the mechanism of surface state transitions. More importantly, these compounds show a reductive-oxidative mechanism in contrast to other organic materials that show oxidative-- reductive mechanisms. Our experiments and data have established the relation between AIE organic structures and ECL properties that has a strong potential for biological and diagnostic applications.

$\pmb { o }$ Carborane (1,2-closo-dicarbadodecaborane $( \mathbf { C } _ { 2 } \mathbf { B } _ { 1 0 } \mathbf { H } _ { 1 2 } ) ) ^ { [ 1 ] }$ features a 12-vertex icosahedral core-structure embedded with two carbon and ten boron atoms. In recent years, great efforts in carborane functionalization?] have been made in order to conveniently explore the properties and applications of carborane derivatives. Carborane-based materials have been employed in bioimaging,l] biochemical targeting,4l and other bio-applications.] Carborane derivatives are also medical candidates for boron neutron capture therapy (BNCT).[] Furthermore, the non-negligible carborane-based luminescence of phosphorescent iridium(II) complexes,7] organic single-molecule white emitters,8] aggregationinduced compounds,[9] thermally activated delayed fluorescence (TADF) materials,[10] and aggregation-induced delayed fluorescence materials[11] have been studied in details. Among various luminescence sources, aggregation-induced emission (AIE), in which emission efficiency is greatly boosted by aggregation[12] has drawn our attention.

AIE, which can prevent aggregation-induced quenching behavior, has carved out an innovative avenue for biomedica[13] and pharmaceutical applications.4] Considering its unique 3D bulkiness, $^ o$ -carborane could be treated as a structural motif in aggregation-induced emission fluorogens (AIEgens). Additionally, the electron withdrawing nature of $^ o$ -carborane (when substituted at a C site) can efficiently induce charge transfer emission.9a,b] It is noteworthy that the novel characteristic of AIE makes it possible for hydrophobic organic compounds to emit fluorescence in aqueous media. So far, extensive studies on carborane-based aggregationinduced photoluminescent molecules or assemblies have been reported,4b,9,15] but electrochemiluminescence (ECL) induced by aggregated organic dots remains unexplored, especially in aqueous media.

ECL, also known as electrogenerated chemiluminescence, is essentially a chemiluminescence reaction on the surface of electrodes.16] ECL is superior to photoluminescence in many respects, which has extremely low detection limits, a wide range of analytes, and high sensitivity, thus leading to widespread applications in bioanalysis, diagnostics, and cancer therapies.[16a,17] However, organic ECL materials118] have to be handled in organic solvents that are incompatible with biological environments. In aqueous media, there are two ways to solve solubility problems. One is to use common organic luminophores and emulsion systems,[19] and the other is to synthesize water-soluble compounds.[20] The biocompatiblity in aqueous media for organic materials remains a challenge. Only recently have the investigations of metal complexes[21] and polymer dots (Pdots)[22] been focused on aggregation-induced ECL properties, both of which should be classified as oxidative-reductive (O-R) mechanisms.[23] Reductive-oxidative (R-O) ECL of organic dots (ODs) in aqueous media has never been observed, and neither have the fabricating principles. Considering the complexity of bioanalytical environments in which it is hard to detect analytes by using O-R ECL materials[24] and the well-known toxicity of quantum dots as R-O ECL sources,[25] it is urgent to develop novel biocompatible R-O ECL organic materials.

It is well-known that carbazole is an excellent donor moiety for the design of photoluminescent materials, such as in fluorescent organic light-emitting diodes[26] and polymer solar cells.27] Herein, we demonstrate a series of $^ o$ carboraneappended carbazoles as shown in Scheme 1, in which efficient and stable R-O ECL has been observed under AIE conditions in aqueous media. These metal-free compounds are distinguished from traditional QDs and other ECL materials, and can be classified as aggregation-induced electrochemiluminescence (AIECL) materials, similar to the nomenclature of platinum complex assemblies from the De Cola group.[21a]

The ECL intensities of T-3 under $2 0 \%$ $6 0 \%$ $8 5 \%$ , and $9 5 \%$ $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ provide an excellent indication of AIECL (Figure1a). For further micromesh research, the ECL intensity variation of T-3 with different water fractions was measured to ascertain the AIECL property. With the increase of water fraction, the ECL intensity increased, which is in accordance with the increase of AIE intensity (Figure 1b). However, fluorescent emission of T-3 remained weak until the water fraction reached $8 5 \%$ ,over which ECL intensity dramatically increased. The diameters of the aggregates in solutions with different water content were measured to be $2 . 2 \mu \mathrm { m }$ $( 7 0 \% )$ $1 8 1 . 9 \mathrm { n m }$ $( 8 0 \% )$ $1 0 9 . 7 \mathrm { n m }$ $( 8 5 \% )$ $1 0 2 . 4 \mathrm { n m }$ $( 9 0 \% )$ , and $1 0 0 . 7 \mathrm { n m }$ $( 9 5 \% )$ (Figure 1c and Figures S10 and S11) respectively, as shown by transmission electron microscopy (TEM). Dynamic light scattering (DLS) measurements of T-3 with or without TOAB showed the same trend as TEM (Figures S12 & S13). The formation of aggregates can provide a large increase in quantum yield (QY); that is, the particle size dominates ECL behavior under these conditions. A smaller nanoparticle size leads to higher ECL intensity. For similar particle sizes, for example, T-3 in $9 0 \%$ and $9 5 \%$ $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ content, the QY has a decisive impact on ECL behavior. In the ECL spectrum (Figure 1d), the emission peak (at $5 8 2 \mathrm { n m }$ ) exhibits a red shift of $3 5 \mathrm { n m }$ in comparison with fluorescence (FL, $5 4 7 \mathrm { n m }$ . Like the ECL mechanisms of quantum dots,[23] we assume that the excited states of ECL for T-3 might be generated by the mechanism of surface state transitions with lower energy rather than the band gap, in which the ECL spectrum would be the same as the FL spectrum. Under the mechanism of surface state transitions, the morphology and size of organic dots are extremely important.

To gain insight into the connection between molecular structure and ECL, ECL measurements based on the individual structural component of T-3 were performed (Figure S17). The reason why T-3 has excellent ECL might be ascribed to the B-3 motif (1,2-diphenyl- $^ { \cdot } o$ -carboranyl), which is able to enhance the back-donation into antibonding orbitals.29] This result also indicates that the reversible redox of the carboranyl derivatives could take place. But no discernible redox peaks could be clearly observed under the same conditions (Figure S18). Thus, cyclic voltammograms were recorded by using $N , N$ -dimethylformamide (DMF) with tetrabutylammonium perchlorate (TBAP), as reported in the literature.30 Two characteristic peaks of T-3 at $- 1 . 0 6 \mathrm { V }$ and $- 1 . 3 4 \mathrm { V }$ are likely attributed to B-3 (1,2-diphenyl- $^ { \cdot o }$ carborane) ( $- 1 . 1 3 \mathrm { V }$ and $- 1 . 3 8 \mathrm { V } ,$ ) rather than A (9,9'-(1,3-phenylene)bis- $\cdot 9 H$ -carbazole) (Figure 2c,d). In addition, the individual concentration-dependent experiment of the model and A indicates that both the reduction peaks are at around $- 0 . 8 \mathrm { V } .$ But the oxidation peak is shown at around $- 0 . 5 \mathrm { V }$ at the high concentrations of model and A, which is hardly observed at a low concentration in DMF (Figures S19 and S20). Therefore, the reduction peak of T-3 at $- 0 . 8 \mathrm { V }$ and the corresponding oxidation peak at around $- 0 . 6 \mathrm { V }$ should belong to the conductive reagent rather than A. In exploring those subtle distinctions in structures and CVs, we propose that the carboranyl motif might be responsible for redox in ECL, as shown in Figure S21. Further investigation of this hypothesis may provide guidance for design of efficient carborane-based organic AIECL materials.

As different experimental conditions had to be selected to observe CV and ECL, control experiments were necessary to decide if the redox reaction of carboranyl carbazoles took place in ECL. The control experiments (Figure 3) clearly indicate that compound T-3 could generate ECL even in the absence of ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ .The T-3-modified GCEs (blue and magenta) display lower currents owing to the poor conductivity of the organic compound. In comparison of the magenta and red traces in the left inset of Figure 3b, the reductive peak potential at around $- 1 . 0 \mathrm { V }$ might be ascribed to ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 } .$ The reductive peak signal of $\mathbf { T } { \cdot } 3$ in PBS is at $- 1 . 5 \mathrm { V } ,$ as shown in the right inset of Figure 3b. As a result, the reductive peak at $- 1 . 6 \mathrm { V }$ (magenta) should be attributed to T-3, in which the ECL intensity starts to increase rapidly.

Based on the analyses of Figure 2c and Figure 3, we proposed the ECL mechanism of these carborane-based organic dots in the presence of ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ as shown in Equations (1)-(5):

$$
\begin{array} { l } { { \mathrm { O D s ~ + ~ n e ^ { - } \to ~ n O D s ^ { - * } ~ } } } \\ { { \ } } \\ { { \mathrm { O D s ^ { - * } ~ + ~ n e ^ { - } \to ~ n O D s ^ { 2 - } ~ } } } \\ { { \ } } \\ { { \mathrm { S _ { 2 } O _ { 8 } ^ { 2 - } ~ + ~ e ^ { - } \to ~ S O _ { 4 } ^ { 2 - } ~ + ~ S O _ { 4 } ^ { - } ~ } } } \\ { { \ } } \\ { { \mathrm { O D s ^ { 2 - } ~ + ~ S O _ { 4 } ^ { - * } \to ~ O D s ^ { - * * } ~ + ~ S O _ { 4 } ^ { 2 - } ~ } } } \\ { { \ } } \\ { { \mathrm { O D s ^ { - * * } \to ~ O D s ^ { - * } + h v ~ } } } \end{array}
$$

When the initial potential becomes sufficiently negative, the organic dots immobilized on the working electrode are firstly reduced to the species $\mathrm { O D s ^ { - \bullet } }$ [Eq. (1)], then further reduced by another electron injection to form $\mathrm { O D s } ^ { 2 - }$ [Eq. (2)]. In the meantime, the co-reactant ${ \mathrm { K } } _ { 2 } { \mathrm { S } } _ { 2 } { \mathrm { O } } _ { 8 }$ is reduced to $\mathrm { S O } _ { 4 } ^ { 2 - }$ and $\mathrm { S O } _ { 4 } ^ { - \bullet }$ at the electrode [Eq. (3)]. Finally, the $\mathrm { O D s } ^ { 2 - }$ and $\mathrm { S O } _ { 4 } ^ { - \bullet }$ species react on the electrode surface to form the exited state $\mathrm { O D s } ^ { - \bullet }$ [Eq. (4)], which would return to the ground state $\left( \mathrm { O D s } ^ { - \bullet } \right)$ , accompanied by the emission of luminescence [Eq. (5)].

In conclusion, the aggregation-induced organic dots of the new carboranyl carbazoles are able to emit efficient ECL in ambient aqueous media in contrast to a carborane-free control compound. Different substituents tune particle size and morphology as well as quantum yield, all of which considerably contribute to the stable and enhanced R-O ECL. These carboranyl carbazoles are promising complements to the existing library of reductive-oxidative ECL materials. However, the R-O ECL study in biocompatible media using AIE organic materials is still in its infancy. In the future, more AIE organic materials may be applied to ECL in aqueous media and biological applications will be explored.
