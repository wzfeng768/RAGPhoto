Chemical doping is a key process for controlling the electronic properties of molecular semiconductors, including their conductivity and work function. A common limitation of n-doped polymers is their instability under ambient conditions, which has imposed restrictions on the characterisation and device application of n-doped polymers. In this study, sequential n-doping with organometallic dopants was performed on thin films of polymeric semiconductors with naphthalene diimide and perylene diimide-based backbones. Moderate ambient stability was achieved with $( { \mathsf { R u C p } } ^ { \star } { \mathsf { M e s } } ) _ { 2 } ,$ $\{ C p ^ { \star } =$ pentamethylcyclopentadienyl; $M e s = 1 , 3 , 5$ -trimethylbenzene}, which is in striking contrast to the unstable, n-doped state obtained with cobaltocene, a simple oneelectron reductant. The highly cathodic, effective redox potential of $( { \mathsf { R u C p } } ^ { \star } { \mathsf { M e s } } ) _ { 2 } ,$ ca. $- 2 . 0 \ \mathsf { V }$ vs. ferrocene, suppresses the back electron transfer reaction and the subsequent dopant loss in air, which gives rise to the observed air stability. It also allows a perylene diimide-based polymer to be reduced to a state in which the repeat units are largely dianionic. Photoelectron measurements show that the ionization potential of the heavily doped polymer is ca. 3.9 eV. Our findings show that chemical doping with $( { \mathsf { R u C p } } ^ { * } { \mathsf { M e s } } ) _ { 2 }$ is an effective method to produce highly stable, n-doped conjugated polymers.

In a conventional solution-doping process, the dopant and semiconductor molecules are mixed in a solution (Scheme 1a), which is then cast on substrates by drop-casting, spin-coating, or other solution-based techniques. The limitations of this method may include a poor solubility of the doped systems and uncontrolled aggregation of the semiconductor and dopant molecules, which can limit the attainable doping efficiency and electrical properties. Some of these limitations can be overcome by employing a more recently developed 'sequential doping' technique. In this technique, a thin film of polymeric semiconductor is fabricated, which is then exposed to a dopant vapour or solution (Scheme 1b and c).6,7 when an effective combination of the semiconductor and dopant is used, intercalation of the guest dopant into the host polymer occurs, which leads to a high doping level throughout the thin film.7-9

The electronic devices such as photovoltaics and organic light-emitting diodes, which make use of an electron-transporting layer, can benefit from n-doping to enhance the electron extraction/injection and transport.3,10 Naphthalene diimide (NDI) and perylene diimide (PDI) are representative $\pi$ conjugated units that show good electron-transporting behavior.11-13 P(ND12OD-T2) (Fig. 1a), an NDI-containing polymer, has been widely studied in devices such as field-effect transistors and photovoltaic cells.12,14 The doping of P(ND12OD-T2) with a suitable reducing agent results in conductivities of $1 0 ^ { - 1 } – 1 0 ^ { - 5 } \mathrm { { S c m } ^ { - 1 } }$ in an inert atmosphere.15,16 A common difficulty in employing n-doped polymeric semiconductors in optoelectronic devices is that many of these materials are sensitive to ambient air, which necessitates their processing and handling in an inert atmosphere.' For this reason, recent research efforts have focused on achieving ambient-stable n-doping through the development of novel dopants and polymers.17-19 However, the role of different dopants in imparting stability to doped films from a given polymer is not yet clear.

As an organometallic dopant, cobaltocene $\mathbf { ( C o C p _ { 2 } }$ $\mathrm { C p ~ } =$ cyclopentadienyl) is a strong reducing agent, which is highly reactive and degrades rapidly upon exposure to ambient air2 due to reaction with oxygen and/or water. The stability of strongly reducing organometallic dopants has been increased by developing dimeric dopants such as $\left( \operatorname { R h C p } _ { 2 } \right) _ { 2 }$ and $\big ( \mathrm { R u C p } ^ { * } \mathrm { M e s } \big ) _ { 2 }$ $\{ { \bf C p ^ { * } } =$ pentamethylcyclopentadienyl; $\mathbf { M e s } =$ 1,3,5-trimethylbenzene} (Fig. 1a). A few minutes of exposure to ambient air before their use does not cause any discernible decomposition.21,22 However, little is known about the stability of polymer thin films containing such dopants.

Here, we report the sequential doping of $\mathrm { P } ( \mathrm { N D I } 2 \mathrm { O D } { - } \mathrm { T } 2 ) ^ { 1 2 }$ and a PDI-based polymer, $\mathrm { P } ( \mathrm { P D I } \mathbf { \cdot } \mathbf { E B } ) ^ { 2 3 }$ (Fig. 2a), with $\mathrm { C o C p } _ { 2 }$ and $\mathrm { { ( R u C p ^ { \star } M e s ) _ { 2 } } ^ { 2 1 , 2 2 , 2 4 } }$ (Fig. 1a) to evaluate their electrical properties and stability. Intriguingly, $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ -doped P(PDI-EB) exhibits a moderate air stability, despite an ionization potential of $3 . 9 \ \mathrm { e V } .$ In addition, the UV-vis and vibrational spectroscopy results suggest that P(PDI-EB) is approaching the dianion state by $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ doping. The differences in the ambient stability of ${ \mathrm { C o C p } } _ { 2 } .$ and $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ doped films are discussed based on the chemical equilibrium of the charge-transfer reactions.

# Results and discussion

Sequential doping was conducted by exposing P(NDI2OD-T2) thin films to dopant solutions containing $\mathrm { C o C p } _ { 2 }$ or $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ The thin films were first prepared on $1 ~ \mathrm { c m } ^ { 2 }$ glass substrates by spin-coating of a pristine polymer solution in chloroform followed by thermal annealing at $2 0 0 ~ ^ { \circ } \mathrm { C } .$ In the case of chemical doping through the immersion method (Scheme 1b), the pristine thinfilm samples were immersed in 1 mL n-butyl acetate (nBA) inside a glass vial, with the sample facing upwards. while heating the system at $8 0 ~ ^ { \circ } \mathrm { C }$ $3 0 { \mathrm { - } } 4 0 ~ \mu \mathrm { L }$ of $2 \mathrm { m M }$ solution of dopant in nBA was added to the vial. After one min, the thin-film samples were removed from the vial and dried at $8 0 ~ ^ { \circ } \mathrm { C }$ prior to characterisation. An alternate method is drop-casting of a $2 \mathrm { m M }$ dopant solution in nBA onto the thin films at $8 0 ~ ^ { \circ } \mathrm { C }$ (Scheme 1c). All of the thin-film fabrications and doping processes were conducted in an Ar atmosphere.

Fig. 1b shows the UV-vis spectra of the P(NDI2OD-T2) thin films before and after doping with $\mathrm { C o C p } _ { 2 }$ measured in air. The $\mathrm { C o C p } _ { 2 }$ doped sample without encapsulation shows features corresponding to the undoped state. We observed that the $\mathrm { C o C p } _ { 2 }$ -doped film without encapsulation changed its colour after air exposure at a time scale of $1 \ \mathrm { m i n }$ , which was ascribed to dedoping. To obtain the UV-vis spectra of the doped state, encapsulation was conducted after $\mathrm { C o C p } _ { 2 }$ doping in an Ar atmosphere, where the top surface of the doped film was covered with a CyTOP polymer and an additional glass substrate (see the Methods section). The spectrum of the encapsulated sample was consistent with the previous reports of the n-doped P(NDI2OD-T2).25

The time scale of the dedoping process was dramatically prolonged when $\big ( \mathrm { R u C p } ^ { * } \mathrm { M e s } \big ) _ { 2 }$ was employed as the dopant for a P(NDI2OD-T2) thin film. Here, the P(NDI2OD-T2) thin films were doped with $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ using the immersion method. The UV-vis spectra were measured in air without encapsulation with time (Fig. 1c). The spectrum obtained after air exposure was consistent with that of the doped state of P(NDI2OD-T2). The spectra obtained in air over time indicated that most of the dedoping process occurred within approximately $2 0 0 \mathrm { { m i n } }$ , which is two orders of magnitude longer than in the case of $\mathrm { C o C p } _ { 2 }$ doping.

The dedoped films showed very similar absorption spectra to that of a pristine film for both the $\mathrm { C o C p } _ { 2 }$ and $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ doping, which suggests that the dedoping process involves a charge-transfer reaction and no significant changes in the chemical structure of the polymer occur. Interestingly, thermal annealing of the dedoped films resulted in the recovery of the doped states (Fig. S1, ESI) in the $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ -doped samples, which further indicates that the dedoping process does not alter the chemical structure of the polymer. For a charge transfer reaction that does not cause chemical degradation, the chemical equilibrium is a key factor for understanding the doping and dedoping kinetics. when the redox potentials of the dopant and semiconductor are comparable, as in the case of the semiconductors examined here and $\mathrm { C o C p } _ { 2 }$ (ca. $- 1 . 3 \mathrm { V }$ vs. $\mathrm { F e C p } _ { 2 } ^ { + } / \mathrm { F e C p } _ { 2 } )$ , both forward and reverse electron-transfer processes may occur. The back electron transfer process is endergonic by only ca. $0 . 3 \ : \mathrm { e V }$ implying that some fraction of the dopant is in the neutral state at all times. Given that the neutral $\mathrm { C o C p } _ { 2 }$ is known to degrade in air,2o the neutral fraction of $\mathrm { C o C p } _ { 2 }$ in a doped film undergoes decomposition, which would drive the equilibrium, ultimately leading to rapid dedoping of the thin film. This hypothesis is consistent with the reported air stability of ${ \mathrm { C o C p } } _ { 2 } ^ { + }$ salts formed with redox-inactive anions (e.g., $\mathrm { P F _ { 6 } } ^ { - }$ - and with less-easily oxidised anions (e.g., the radical anion of tetracyanoquinodimethane, TCNQ),20,26 where $\mathrm { C o C p } _ { 2 }$ is expected to remain in the cation state.

In the case of doping with $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ , an air-stable 18- electron ${ \mathrm { R u C p } } ^ { * } { \mathrm { M e s } } ^ { + }$ is produced, with a reduction potential of ca. $- 2 . 7 \mathrm { ~ V ~ }$ vs. $\mathrm { F e C p _ { 2 } } ^ { + } / \mathrm { F e C p _ { 2 } } ; ^ { 2 7 }$ thus, the back electron transfer from the doped polymer is a considerably endergonic reaction. This essentially eliminates the back electron transfer from the doped polymer to ${ \mathrm { R u C p } } ^ { * } { \mathrm { M e s } } ^ { + }$ followed by the degradation of the neutral dopant species as a dedoping pathway.

Another expected dedoping process is the direct oxidation of an n-doped polymer to a neutral compound by oxygen in the air.1o The redox reactions between an n-doped polymer and oxygen in the air would occur for $\mathrm { C o C p } _ { 2 ^ { - } }$ and $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 } .$ doped polymers in a similar manner. Thus, very fast dedoping only in ${ \mathrm { C o C p } } _ { 2 }$ doped polymers is likely due to the dedoping process through the back electron transfer discussed above, which proceeds only for the $\mathrm { C o C p } _ { 2 }$ doped polymers.

When the drop-casting method was employed with $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ to P(NDI2OD-T2), doping proceeded further (Fig. S2, ESIt) to achieve a more heavily doped state, similarly to a spectroelectrochemical study.25 It is noted that the observation of this heavily doped state of P(NDI2OD-T2) through UV-vis measurements required encapsulation of the thin film owing to the instability of this state. The two-fold changes upon chemical doping with $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ were also examined for a P(PDI-EB) thin film, in which the observed moderate air stability allowed for a detailed analysis. The peaks at 632 and $7 2 8 \ \mathrm { n m }$ were observed after $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ doping of a P(PDI-EB) thin film (Fig. 2b), which are attributed to the more heavily doped state. An air exposure for $1 7 6 ~ \mathrm { m i n }$ resulted in the observation of peaks at 733, 822, and $1 0 0 0 \ \mathrm { n m }$ (Fig. 2b), which characterise the less heavily doped state. Further air exposure resulted in a recovery to the neutral state, in which the pristine thin film without doping showed peaks at 586 and $6 4 3 \mathrm { n m }$ (Fig. 2c). A very similar absorption strength of the observed peaks in the dedoped and pristine thin films in the range of $3 5 0 \mathrm { - } 7 0 0 \ \mathrm { ~ n m }$ suggests that the dedoping process converts an n-doped polymer predominantly to the original neutral polymer without chemical deformation. The more heavily doped state was also observed when P(PDI-EB) was doped with $\mathrm { C o C p } _ { 2 }$ in which the doped film immediately dedoped to a neutral state, likely owing to the instability of $\mathrm { C o C p } _ { 2 }$ (Fig. S3, $\mathrm { E S I \dagger }$ ). Similar to the results for the P(NDI2OD-T2) samples, the lifetime of the doped state of $\mathbf { P ( P D I - E B ) }$ was prolonged by two orders of magnitude by using $( \mathrm { R u C p } ^ { \star } \mathbf { M e s } ) _ { 2 }$ instead of $\mathrm { C o C p } _ { 2 }$

The less heavily doped state observed in $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ -doped P(PDI-EB) showed the characteristic absorption peaks with maximum intensities at 733, 822, and $1 0 0 0 \ \mathrm { n m }$ which are consistent with the radical anion state of the perylene diimide species.28 The observation of a radical anion state is expected to appear when $5 0 \mathrm { \ m o l \% }$ of $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ dopant added to the polymer undergoes cleavage and charge-transfer reactions, which were verified by employing mixed-solution doping in our study. The UV-vis absorption spectra of a thin film dropcast from a mixed solution containing both P(PDI-EB) and 50 mol% $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ (i.e. potentially able to contribute 1 electron per monomer after cleavage) were consistent with the less heavily doped state observed in sequential doping (Fig. 2e). The small differences in the absorption spectra of samples prepared by mixed-solution and sequential doping were observed, which is likely due to the morphological differences. These results show that the less heavily doped state corresponds to P(PDI-EB) with each PDI unit reduced to its radical anion.

The peak positions in the absorption spectrum of the more heavily doped state were blue-shifted compared to that of the less heavily doped state, which is consistent with the changes from radical anions to dianions observed in the PDI small molecules.28 The more heavily doped state was generated by mixed-solution doping with $1 0 0 ~ \mathrm { \ m o l \% }$ of $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ in which the introduced dopants were potentially able to contribute 2 electrons per monomer (Fig. 2d). This result suggests a possibility that the observed more heavily doped state corresponds to the dianion state of P(PDI-EB).

The doped states were further examined by Fourier-transform infrared spectroscopy (FTIR). Thin films were fabricated on glass substrates by drop-casting mixed solutions of P(PDI-EB) and $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ . The spectra were measured from the front side of thin-films in an attenuated total reflection (ATR) mode in air. The intensity of the spectra was normalised based on the peak area of the $2 8 0 0 { - } 3 0 0 0 ~ \mathrm { c m } ^ { - 1 }$ region. These peaks originated from the vibrational modes of aliphatic chains present mainly in the side chains of P(PDI-EB), which are likely to be least affected by doping. To assign vibrational modes of the carbonyl groups, which are often used to quantitatively estimate the doping level,29 these vibrational modes were simulated by density functional theory (DFT) calculations performed on a model small molecule that represents a monomer of P(PDI-EB) in neutral, radical anion, and dianion states. The B3LP functional, $6 { \cdot } 3 1 { \cdot } + \mathbf { G } ( \mathbf { d } )$ basis set, and reported scaling factors to correct vibrational frequencies30 were applied. The optimised structures and other details are given in Fig. S4 (ESI+).

The FTIR spectrum of the pristine film agreed well with the simulated peak of the neutral model compound in the range of $1 4 0 0 { - } 1 8 0 0 \ \mathrm { c m } ^ { - 1 }$ (black lines in Fig. 3a). The peak labeled v1 is a vibrational mode mainly associated with the conjugated ring, while v2 and v3 are associated with the stretching of carbonyl groups (Tables S1-s3, Esi). It is noted that each vibrational mode was split into two peaks owing to the structural asymmetry introduced by the diethynylbenzene group in the model compound. The introduction of $( \mathrm { R u C p } ^ { \star } \mathrm { M e s } ) _ { 2 }$ up to $5 0 ~ \mathrm { m o l \% }$ (i.e. potentially able to contribute 1 electron per monomer) results in the redshift of the v1-v3 peaks, which is consistent with the n-doping of P(PDi-EB), leading to the formation of the radical anion state. This suggests that the introduced $5 0 \ \mathrm { \ m o l \% }$ of dopant quantitatively reduces the neutral polymer into the radical anion state via the formation of a cleaved ${ \mathrm { R u C p } } ^ { * } { \mathrm { M e s } } ^ { + }$ which is consistent with our UV-vis absorption measurements. When the amount of $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ was increased from $5 0 ~ \mathrm { m o l \% }$ to $1 0 0 \mathrm { m o l \% }$ , the observed peak positions shifted further towards lower wavenumbers, which is consistent with the changes from the radical anion to the dianion state in our calculations. Although the observed peaks overlap with each other around $1 5 2 0 { - } 1 6 0 0 ~ \mathrm { c m } ^ { - 1 }$ with the exception of the v3 peak, the observed spectra did not contradict the simulated dianion state. Overall, UV-vis-NIR, FTIR, and DFT calculations suggest the formation of the dianion states of P(PDI-EB) when doped with $( \mathrm { R u C p } ^ { * } \mathrm { M e s } ) _ { 2 }$ . A previous study proposed that 6,13- bis(triisopropylsilylethynyl)pentacene is doped into a dianion in solution through a redox reaction with a dimerized metallocene,31 and our findings suggest that the doping of P(PDI-EB) with $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ up to the dianion state is feasible, even in a solid-state thin film.

The ionization potentials $( I P s )$ of the pristine and $( \mathbf { R u C p } ^ { * } \mathbf { M e s } ) _ { 2 } { \scriptscriptstyle - }$ doped thin films were determined using photoelectron yield spectroscopy (PYs) measurements, which gives us an insight into energetics of doping. The immersion method was used for both P(ND12OD-T2) and P(PDI-EB) polymer films fabricated on the ITOcoated glass substrates. The thin-film samples were placed into a vacuum chamber to measure the threshold energy giving rise to a photoelectron current, which corresponds to $\boldsymbol { { \mathit { I P } } }$ It is noted that the work function is equal to or less than the $\boldsymbol { { \mathit { I P } } }$ of the doped films evaluated in our experiments.

The $I P$ of the pristine polymeric semiconductor films is at the edge of the density of states originating from the highest occupied molecular orbital (HOmO). In our study, the pristine P(ND12OD-T2) and P(PDI-EB) films showed a large $I P$ (Fig. 4a), which agrees with the deep HOmO levels expected for electrontransporting materials; the obtained values are similar to those previously reported from UV photoelectron spectroscopy $( 5 . 5 \mathrm { e V } ^ { 3 2 }$ for P(NDI2OD-T2) and $6 . 1 \ \mathrm { e V } ^ { 2 3 }$ for P(PDI-EB). The thin films doped with $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ by the immersion method showed a large shift in $I P$ owing to the filling of their empty density of states through chemical doping (Fig. 4b). Based on our UV-vis study with $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ immersion doping, the P(NDI2OD-T2) thin film was in its less heavily doped state while the P(PDI-EB) thin film was in its more heavily doped state. Considering the observed shallow $I P s$ , the charge transfer reaction with the oxygen in the air is anticipated for the $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ -doped polymers,1o which is likely the main cause of dedoping observed in the UV-vis measurements. Finally, we show that control over the initial doping level is feasible in our immersion method. Similar to the standard immersion method, a polymeric semiconductor film on a glass substrate was immersed in pure nBA kept in a vial. While heating the vial, the diluted $\left( \mathrm { R u C p } ^ { * } \mathbf { M e s } \right) _ { 2 }$ solution $\left( 0 . 0 5 \ \mathrm { m M } \right)$ was added to the vial with a micropipette. Here, $1 0 ~ \mu \mathrm { L }$ of solution containing $0 . 5 \mathrm { n m o l }$ of $( \mathrm { R u C p } ^ { \star } \mathrm { M e s } ) _ { 2 }$ was added repeatedly to the system, which was a sufficiently small amount to tune the extent of doping of the polymer semiconductor thin film. Indeed, a $\mathbf { P ( P D I - E B ) }$ thin film doped using this method showed conductivity dependent on the amount of added dopant solution (Fig. 5). Compared to a thin film without doping $( 2 \times 1 0 ^ { - 7 } \mathrm { ~ S ~ c m ^ { - 1 } } )$ doped films show higher conductivity values. After the initial increase of the conductivity with the introduced amount of dopant, the conductivity decreases with increasing amount of dopant, which is consistent with the reported doping level dependence of conductivity for the n-type polymeric semiconductors.15,33 This method could help tune the amount of doping and electronic properties of electron-transporting molecule semiconductors.

# Conclusion

We have demonstrated strong, stable, and controllable n-type sequential doping of polymeric semiconductors with $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ . A highly cathodic reduction potential for ${ \mathrm { R u C p } } ^ { * } { \mathrm { M e s } } ^ { + }$ inhibits the back-charge transfer process, which results in a moderate ambient stability of the doped polymers. This is in contrast to doping with $\mathrm { C o C p } _ { 2 }$ in which the charged and neutral states coexist in a chemical equilibrium, providing pathways for decomposition via the neutral dopant species in ambient air. The vastly different dedoping kinetics resulted in the $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ doped samples showing a timescale of dedoping over two orders of magnitude longer than that of the ${ \mathrm { C o C p } } _ { 2 }$ doped samples. Although the generation of a heavily doped state has been previously reported only in electrochemical studies with high applied biases, here we observed that sequential doping with $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ was able to generate this state in P(ND12OD-T2) thin films. Furthermore, the heavily doped state observed in $\big ( \mathrm { R u C p } ^ { \star } \mathbf { M e s } \big ) _ { 2 }$ -doped P(PDI-EB) is thought to be the dianion state of this polymer. The photoelectron measurements show that the ionization potentials of the polymers considerably decrease upon $\big ( \mathrm { R u C p } ^ { \star } \mathrm { M e s } \big ) _ { 2 }$ doping owing to filling of empty density of states. These attractive features reduce the limitations of processing and handling of n-doped materials. We anticipate that our findings will promote the development of other dopant-semiconductor combinations for increasingly air-stable doped materials.

# Experimental methods

P(ND12OD-T2) was purchased from Ossila. P(PDI-EB) $( M _ { \mathrm { w } } \sim 4 5 0 0 0$ Da and $\mathrm { P D I } \sim 3 . 3 0 ) ^ { 2 3 }$ and $\left( \mathrm { R u C p } ^ { * } \mathrm { M e s } \right) _ { 2 } ^ { 3 4 }$ were synthesized as described elsewhere. Glass substrates were used for UV-vis and FTIR measurements. For the PYS measurements, the ITO-coated glass substrates were used. For the conductivity measurements, glass substrates with thermally deposited $\mathrm { { C r / A u } }$ contacts were used, in which the sample geometry was in an in-plane, 2-terminal configuration with a channel length of $2 0 0 ~ { \mu \mathrm { m } }$ and a width of $2 \ \mathrm { m m }$

All film-fabrication processes were performed in protective ${ \bf N } _ { 2 }$ or Ar atmospheres. For sequential doping, the thin films were fabricated from $0 . 6 ~ \mathrm { w t \% }$ polymer solutions in chloroform by spin-coating at $3 0 0 0 ~ \mathrm { r p m }$ . The films were then dried at $1 2 0 ~ ^ { \circ } \mathrm { C }$ for $5 \ \mathrm { m i n }$ and annealed at $2 0 0 ~ ^ { \circ } \mathrm { C }$ for $3 0 \ \mathrm { \ m i n }$ . The thickness of the films was $7 0 \pm 5 \ \mathrm { n m }$ , as measured with an atomic force microscope. In the immersion method, the thin films were placed in a small vial with $1 \ \mathrm { m L }$ of nBA. While heating the system at $8 0 ~ ^ { \circ } \mathrm { C }$ $3 0 { \mathrm { - } } 4 0 ~ \mu \mathrm { L }$ of $2 \mathrm { m M }$ dopant solution in nBA was added to the vial. In the drop-casting method, the dopant solution was drop-cast onto thin films at $8 0 ~ ^ { \circ } \mathrm { C }$ For the encapsulation of ${ \mathrm { C o C p } } _ { 2 }$ -doped thin films, the top surface of the doped film was covered with CTL-809M and a glass substrate to sandwich the thin film between two glass substrates.

In the mixed-solution doping for FTIR and UV-vis studies, $o \mathrm { \cdot }$ dichlorobenzene solutions with $2 . 6 \mathrm { m M }$ of P(PDI-EB) and varying amounts of $( \mathrm { R u C p } ^ { \star } \mathrm { M e s } ) _ { 2 }$ with the specified molar ratio were prepared. The thin films were fabricated by drop-casting on a $1 0 0 ~ ^ { \circ } \mathrm { C }$ hot plate followed by annealing at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for $4 5 \mathrm { { m i n } }$ . The absorption spectra of the thin films fabricated using the mixedsolution method were encapsulated by sandwiching the film with glass substrates sealed at the edges using vacuum grease.

The absorption spectra were obtained in air using a V-670 (JAscO) instrument. The electrical conductivity of the samples was measured using an Agilent E5270B system in an Ar atmosphere. The PYS measurements were conducted with a SUMITOMO PYS-202 system under vacuum using a turbomolecular pump system, in which a deuterium lamp or xenon lamp was used to characterise the pristine or doped films, respectively.
