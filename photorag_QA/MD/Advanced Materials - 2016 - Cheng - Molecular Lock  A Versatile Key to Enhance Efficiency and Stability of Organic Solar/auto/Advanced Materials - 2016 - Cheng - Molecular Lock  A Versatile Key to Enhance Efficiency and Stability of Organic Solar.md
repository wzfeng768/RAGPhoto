# Molecular Lock: A Versatile Key to Enhance Efficiency and Stability of Organic Solar Cells

Pei Cheng, Cenqi Yan, Tsz-Ki Lau, Jiangquan Mai, Xinhui Lu,\* and Xiaowei Zhan\*

Due to the gradual depletion and environmental problem of traditional fossil energy sources, developing renewable clean energy technologies has become the focus of the 21st century. Especially, bulk heterojunction organic solar cells (OsCs) have attracted considerable attention in recent years because they present some advantages, such as low cost, light weight, flexibility, and large-area fabrication.1-9] For both academic and industrial purposes, obtaining high power conversion efficiency (PCE) and good stability is the major goal for OSCs.

Numerous strategies have been employed to achieve high PCE: synthesizing new electron donor/acceptor materials;[10-17] incorporating a third component in active layer (ternary blend);[18-34] using thermal or solvent annealing, volatile or nonvolatile additives and layer-by-layer solution process to control the morphology of active layer;[35-40] employing interlayers or invert structures;[41,42] and fabricating tandem or parallel structure.[43,44]

Compared with achieving high PCE, there is much less study on device stability although it is also very important.45,46] In recent years, researchers have started to pay more attention to this important issue and developed some strategies to improve device stability, such as purifying materials to reduce burn-in loss or remove organic impurities,[47,48] employing air stable electrode like gold, silver, or copper to replace calcium/ aluminum mixed cathode,49,50] using nonfullerene acceptors to replace fullerene acceptors which are easy to aggregate under light, thermal, or long-term conditions,51,52] and employing modified or crosslinked fullerenes as a third component to suppress the excessive aggregation of [6,6]-phenyl-C61-butyric-acidmethyl-ester (PCBM).[53,54]

However, there are rare methods to improve efficiency and stability of OsCs simultaneously. For example, solvent additives such as 1,8-diiodooctane (DIO) and chloronaphthalene are used in OsCs to improve PCE, but they seriously reduce the device stability.558 Nonfullerene acceptors are developed to replace fullerene acceptors since they can enhance device stability and lower cost,[59] but afford lower PCEs than fullerene counterpart.[60]

Most of the widely used, highly efficient, and classical donors contain fluorine (F) atoms, such as PTB7,[61] PTB7-th,[62] PffBT4T-2OD,[12] and $\mathrm { \ p { - } D T S { ( F B T T h _ { 2 } ) _ { 2 } } }$ [63] For future industrial production, a simple, general, and effective approach that can simultaneously enhance the efficiency and stability of OsCs based on these F-containing donors is highly desired.

In this work, we develop a novel and simple strategy to enhance the efficiency and stability of OsCs simultaneously. $4 , 4 ^ { \prime }$ Biphenol (BPO; Figure 1a), a common, cheap chemical, is employed as a "molecular lock" in blends of F-containing polymer and small molecule donors and fullerene acceptors to lock donor via hydrogen bond formed between the donor and BPO. This versatile molecular lock can enhance the efficiency of OsCs by promoting aggregation of donor and improve the device stability by freezing morphology of the blended films (Figure 1b).

To test the molecular lock BPO and to investigate the effect of hydrogen bond, six classical polymer or small molecule donors are chosen to blend with fullerene acceptor $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ (Figure 1a); four donors (PTB7, PTB7-th, PffBT4T-2OD, and $\mathrm { \ p { \cdot } D T S { ( F B T T h _ { 2 } ) _ { 2 } } }$ have F atoms and the other two (PBDTTT-C-T and P3HT) do not have. In order to understand the effect of BPO on film morphology, grazing-incidence wide-angle and small-angle X-ray scattering (GIWAXS and GISAXS) measurements are carried out. GIwAXs provides molecular-level structural information such as lattice constant and orientation of polymer packing,[65,66] while GISAXS provides larger length-scale phase separation information up to hundreds nanometers.[62,67] Figure 4a shows 2D GIWAXS patterns of PT $\mathsf { B 7 } \mathrm { : P C } _ { 7 1 } \mathrm { B M }$ and $\mathrm { P T B 7 : B P O : P C _ { 7 1 } B M }$ blended films before and after heating at $1 3 0 ~ ^ { \circ } \mathrm { C }$ for $1 2 0 ~ \mathrm { m i n }$ . In contrast to the films without BPO, both the films with BPO fresh-made and heated show an obvious $\pi { - } \pi$ stacking peak $( q \approx 1 . 7 \mathrm { \mathring { A } } ^ { - 1 } )$ along the $q _ { z }$ -axis, indicating an enhanced $\pi { - } \pi$ ordering in "face-on' orientated polymer domains induced by the addition of BPO. Strong "face-on' oriented $\pi { - } \pi$ stacking was reported for pure PTB7 film previously.[34] However, after blended with $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ , this $\pi { - } \pi$ ordering is greatly reduced as indicated by the disappearance of $\pi { - } \pi$ stacking peak (Figure 4a). Thus, the observation of "face-on" $\pi { - } \pi$ stacking in the ternary films must result from the addition of BPO. It might be reasonably attributed to the hydrogen bonds formed between polymer and BPO that provide more driving force for $\pi { - } \pi$ stacking (not obvious in PBDT'TT-C-T:BPO: $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ films; Figure S4, Supporting Information). Note that the strong $_ { \mathrm { O - H . . . F } }$ bond formed in $\mathrm { P T B 7 { : } B P O { : } P C _ { 7 1 } B M }$ system could survive after heating and contribute to the remarkably stable device performance.

Figure 4b presents the corresponding 2D GISAXS patterns. The in-plane scattering intensity profiles are shown in Figure 4c. By fitting them with the model adopted by Liao et al.[62] we could roughly estimate the average domain size of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ clusters $( R _ { \mathrm { g - } } \mathrm { P C } _ { 7 1 } \mathrm { B M } )$ . For $\mathrm { P T B 7 : B P O : P C _ { 7 1 } B M }$ system, it remains unchanged $( \approx 1 2 ~ \mathrm { n m } )$ before and after heating. However, it increases from ${ \approx } 7$ to ${ \approx } 1 9 ~ \mathrm { ~ n m }$ for PBDTTT-C$\mathrm { T } { : } \mathrm { B P O } { : } \mathrm { P C } _ { 7 1 } \mathrm { B M }$ system. The hydrogen bond can induce stable polymer networks which can suppress the diffusing of fullerenes during continuous heating, resulting in the unchanged domain size of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ clusters. Since the device performance could be very sensitive to the domain size of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ [68] this also supports the observed stable device performance of PTB7:BPO:PC,BM system under heating.

In summary, the molecular lock BPO is employed as the dual functional third component in F-containing donor/fullerene blends. Through hydrogen bond between F-containing donor and BPO, the donors are interconnected, the dense donor network is formed, and the film morphology is frozen. The absorption and hole mobility of active layer are enhanced due to enhanced $\pi { - } \pi$ stacking and aggregation of donor. Moreover, the vertical phase separation of active layer is optimized since dense donor network suppresses the migration of donors to the top surface. Enhanced absorption, higher hole mobility, and optimized vertical phase separation lead to higher PCE of OSCs. Furthermore, the stability of OsCs is enhanced since the hydrogen bond freezes the donor aggregate state and suppresses the excessive aggregation of $\mathrm { P C } _ { 7 1 } \mathrm { B M }$ . Our results demonstrate that molecular lock is a versatile key to enhance efficiency and stability of organic solar cells simultaneously.
