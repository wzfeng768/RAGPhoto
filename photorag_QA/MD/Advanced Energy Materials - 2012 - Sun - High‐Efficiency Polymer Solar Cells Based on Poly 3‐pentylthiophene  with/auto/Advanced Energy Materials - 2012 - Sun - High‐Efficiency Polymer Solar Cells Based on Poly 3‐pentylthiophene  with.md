# High-Effi ciency Polymer Solar Cells Based on Poly(3-pentylthiophene) with Indene- $\textcircled { \textcircled { 7 0 } }$ Bisadduct as an Acceptor

Yeping Sun , Chaohua Cui , Haiqiao Wang , and Yongfang Li \*

Bulk-heterojunction (BHJ) polymer solar cells (PSCs) have drawn great attention in recent years [1–12] due to their advantages of easy fabrication, low cost, light weight, and the possibility for them to be fabricated into fl exible devices. PSCs are commonly composed of a photoactive blend layer of a conjugated polymer donor and a fullerene derivative acceptor, sandwiched between a transparent indium-tin-oxide (ITO) positive electrode and a low workfunction metal negative electrode. Regioregular poly(3- hexylthiophene) (P3HT) and [6,6]-phenyl-C61 butyric acid methyl ester $( \mathrm { P C } _ { 6 0 } \mathrm { B M } )$ are the most representative donor and acceptor materials, respectively, and PSCs based on $\mathrm { P 3 H T : P C _ { 6 0 } B M }$ have demonstrated power-conversion effi ciencies (PCE) of over $4 \%$ . [13,14] However, further improvement of the photovoltaic performance of the PSCs based on $\mathrm { P 3 H T : P C _ { 6 0 } B M }$ is limited by the relatively large energy loss during exciton dissociation due to the too-low lowest unoccupied molecular orbtial (LUMO) energy level of $\mathrm { P C } _ { 6 0 } \mathrm { B M }$ , which results in a lower open-circuit voltage $( V _ { \mathrm { o c } } )$ of around $0 . 6 \mathrm { V } .$ To improve the photovoltaic performance of P3HT-based PSCs, we recently synthesized indene- $C _ { 6 0 }$ bisadduct $( \mathrm { I C } _ { 6 0 } \mathrm { B A } ) ^ { [ 1 5 ] }$ and indene- $\mathrm { C } _ { 7 0 }$ bisadduct $( \mathrm { I C } _ { 7 0 } \mathrm { B A } ) ^ { [ 1 6 ] }$ with higher-lying LUMO energy levels, which are 0.17 and $0 . 1 9 \ \mathrm { e V }$ up-shifted, respectively, from that of $\mathrm { P C } _ { 6 0 } \mathrm { B M }$ . The PCE of a PSC based on $\mathrm { P 3 H T / I C _ { 6 0 } B A }$ after optimization reached $6 . 4 8 \%$ with a high $V _ { \mathrm { o c } }$ of $0 . 8 4 \mathrm { V } _ { \mathrm { } } ^ { [ 1 7 ] }$ the optimized PSC based on $\mathrm { P 3 H T : I C _ { 7 0 } B A }$ by using solvent additive demonstrated an even higher PCE of $6 . 6 9 \%$ with $V _ { \mathrm { o c } }$ of 0.86 V. [18]

Poly(3-pentylthiophene) (P3PT) is a P3HT-analogue polymer with similar crystalline characteristics and a similar absorp tion spectrum. [19,20] Jenekhe et al. completed detailed studies on the physicochemical properties of regioregular P3PT. [19] They found that regioregular P3PT fi lm possesses a lamellar structure with an interlayer $d _ { 1 0 0 }$ spacing of $1 . 5 1 \ \mathrm { n m }$ and a $\pi - \pi$ stacking $d _ { 0 1 0 }$ spacing of $0 . 3 7 4 \mathrm { n m }$ , which are smaller than those of P3HT. The fi eld-effect transistor (FET) hole mobility of P3PT fi lm reached as high as $0 . 1 0 \ \mathrm { c m } ^ { 2 } \ \mathrm { V } ^ { - 1 } \ \mathrm { s } ^ { - 1 }$ . They also investigated the photovoltaic properties of P3PT. The PSC based on P3PT as a donor and $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ as an acceptor exhibited a PCE of $3 . 7 0 \%$ under AM1.5, $1 0 0 \mathrm { m W } \mathrm { c m } ^ { - 1 }$ , [2,19] which is close to the photovoltaic performance of P3HT. Gadisa et al. also observed a similar photovoltaic performance of P3PT $( \mathrm { P C E } = 4 . 3 \% )$ ) in comparison with P3HT $( \mathrm { P C E } = 4 . 6 \% )$ . [20] Based on the similarities between P3PT and P3HT, it is natural to consider that the photo voltaic performance of P3PT could be improved by using the new fullerene acceptors $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ and $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ with higherlying LUMO levels. To extend the application of the new acceptors, we here investigate the photovoltaic properties of PSCs based on P3PT as a donor and $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ or $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ as an acceptor, as compared with PSCs based on $\mathrm { P } 3 \mathrm { P T } / \mathrm { P C } _ { 6 0 } \mathrm { B M }$ (or $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ ). Figure 1 shows the molecular structures of $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ , $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ , $\mathrm { P C } _ { 6 0 } \mathrm { B M }$ , $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ , and P3PT. We found that the photovoltaic performance of P3PT was indeed improved signifi cantly by using $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ or $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ as the acceptor.

P3PT, [19] $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ , [15] and $\mathrm { I C } _ { 7 0 } \mathrm { B A } ^ { [ 1 6 ] }$ were synthesized in our laboratory according to literature methods. The molecular weight of P3PT was determined by gel permeation chromato graphy (GPC) using polystyrene as standard in tetrahydrofuran (THF): $\overline { { M } } _ { \mathrm { n } } = 9 6 5 0 \ \mathrm { g \ m o l ^ { - 1 } }$ , $\overline { { M } } _ { \mathrm { W } } = 1 9 ~ 0 0 0 ~ \mathrm { g ~ m o l ^ { - 1 } }$ and dispersity $= 1 . 9 6$ . Electronic energy levels of P3PT were measured by cyclic voltammetry, as shown in Figure S1 in the Supporting Information (SI). Based on the onset oxidation potential and the onset reduction potential from Figure S1, the highest occupied molecular orbital (HOMO) and LUMO energy levels of P3PT were estimated to be $- 4 . 8 2$ and $- 2 . 6 1 \ \mathrm { e V } ,$ respectively. The HOMO level of P3PT is around $0 . 0 6 \mathrm { e V }$ deeper than that of P3HT $( - 4 . 7 6 \ \mathrm { e V } ^ { [ 2 1 ] } )$ .

PSCs were fabricated with a conventional sandwich structure of ITO/PEDOT:PSS/P3PT:fullerene $\mathrm { \ C a } / \mathrm { A l }$ , where PEDOT:PSS is poly (3,4-ethylenedioxythiophene):poly(styrene sulfonate) and the fullerene acceptors used included $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ , $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ , $\mathrm { P C } _ { 6 0 } \mathrm { B M }$ , and $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ . Solvent annealing [13,22] for $3 0 \mathrm { m i n }$ was performed for all the devices during device fabrication.

The optimization of the PSC devices was carried out by changing the weight ratios of polymer donor to fullerene acceptor and thermal annealing at different temperatures. [14,17] The results of the optimization are shown in the SI, Figures S2–S10 and Tables S1–S4. The optimized weight ratios are 2:1 for the active layer of $\mathrm { P 3 P T / I C _ { 6 0 } B A }$ and 1.5:1 for that of $\mathrm { P 3 P T / I C _ { 7 0 } B A }$ . $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $1 0 \mathrm { m i n }$ is the best pre-thermal annealing condition.

To check the contribution of the absorptions of the donor and acceptor materials to the photocurrent, we measured the external quantum effi ciencies (EQEs) of the PSC devices, as shown in Figure 3 . The EQE curves cover a broad wavelength range between 350 and $6 5 0 \mathrm { n m }$ , indicating that both absorptions of the P3PT donor and fullerene acceptors contributed to the photocurrent. The PSC based on $\mathrm { P } 3 \mathrm { P T } / \mathrm { I C } _ { 7 0 } \mathrm { B A }$ exhibited the highest EQE values among the four devices, with a maximum EQE of approximately $60 \%$ . The EQE values are consistent with the $J _ { \mathrm { S C } }$ values of the PSCs shown in Table 1 .

In order to further investigate the effect of thermal annealing on the interpenetrating network structure of the active layers, we measured the X-ray diffraction (XRD) patterns of the blend fi lms of $\mathrm { P 3 P T / I C _ { 6 0 } B A }$ (2:1, $\mathbf { w } / \mathbf { w } )$ and $\mathrm { P } 3 \mathrm { P T } / \mathrm { I C } _ { 7 0 } \mathrm { B A }$ (1.5:1, w/w) with or without pre-thermal annealing at $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $1 0 \ \mathrm { m i n }$ , as shown in Figure 4 . The XRD peaks appear at a 2 θ of approximately $5 . 8 ^ { \circ }$ for the $\mathrm { P 3 P T : I C _ { 7 0 } B A }$ blend fi lms and $\mathrm { P 3 P T / I C _ { 6 0 } B A }$ without annealing. There are obvious ‘shoulder’ peaks for the blend fi lm treated by pre-annealing at $1 5 0 ~ ^ { \circ } \mathrm { C }$ as opposed to the nonannealed blend fi lm, indicating the increased crystallinity of P3PT achieved through thermal annealing, which agrees with the increased absorbance of the blend fi lms as mentioned above. The XRD peak of P3PT fi lm at approximately $2 \theta = 5 . 8 ^ { \circ }$ corresponds to the interlayer $d$ -spacing of P3PT ordered aggregations. Interestingly, the XRD peak of the $\mathrm { P 3 P T / I C _ { 6 0 } B A }$ (2:1, w/w) blend fi lm with annealing at $1 5 0 ~ ^ { \circ } \mathrm { C }$ shifted from $2 \theta = 5 . 8 2 ^ { \circ }$ (corresponding to an interlayer $d$ -spacing of $1 5 . 1 1 \mathrm { \AA }$ to $2 \theta = 5 . 8 8 ^ { \circ }$ (corresponding to interlayer spacing of 15.01 Å), and the XRD peak of the $\mathrm { P 3 P T / I C _ { 7 0 } B A }$ (1.5:1, w/w) blend fi lm with annealing at $1 5 0 ~ ^ { \circ } \mathrm { C }$ shifted to $5 . 9 8 ^ { \circ }$ (corresponding to an interlayer $d$ -spacing of 14.76 Å). The reduction of the interlayer $d$ -spacing after thermal annealing could be helpful for charge transportation in the corresponding PSC devices. The results of the XRD patterns reveal that the crystallinity of P3PT was enhanced by the thermal annealing treatment.

In summary, we used the indene bisadduct of fullerenes with higher-lying LUMO levels— $\mathrm { \cdot I C _ { 6 0 } B A }$ and $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ —as acceptors in P3PT-based PSCs, and compared the resulting preformance to the conventional fullerene acceptors of $\mathrm { P C } _ { 6 0 } \mathrm { B M }$ and $\mathrm { P C } _ { 7 0 } \mathrm { B M }$ . Under optimized conditions, the PSC based on $\mathrm { P 3 P T / I C _ { 7 0 } B A }$ (1.5:1, w/w) demonstrated a PCE of $5 . 4 3 \%$ with a $V _ { \mathrm { o c } }$ of $0 . 8 8 \mathrm { V } ,$ a $J _ { \mathrm { s c } }$ of $9 . 2 2 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ , and a FF of 0.67, under illumination of AM1.5G, $1 0 0 \mathrm { ~ m W ~ c m } ^ { - 2 }$ . The PSC based on $\mathrm { P 3 P T / I C _ { 6 0 } B A }$ (2:1, w/w) exhibited a PCE of $4 . 5 0 \%$ with a $V _ { \mathrm { o c } }$ of $0 . 8 9 \mathrm { ~ V ~ } ,$ a $J _ { \mathrm { s c } }$ of $8 . 3 7 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ , and a FF of 0.604. The PCE values of the control PSCs based on $\mathrm { P } 3 \mathrm { P T } / \mathrm { P C } _ { 6 0 } \mathrm { B M }$ (2:1, w/w) and $\mathrm { P } 3 \mathrm { P T } / \mathrm { P C } _ { 7 0 } \mathrm { B M }$ (1.5:1, w/w) were $2 . 3 2 \%$ and $3 . 1 0 \%$ , with $V _ { \mathrm { o c } }$ of 0.64 and $0 . 6 6 ~ \mathrm { V } ,$ respectively. The PCE of $5 . 4 3 \%$ is the highest value for the P3PT-based PSCs reported in the literature so far. $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ and $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ have been proven to be remarkable high effi ciency acceptors for P3HT-based PSCs. [15–18] The results indicate that $\mathrm { I C } _ { 6 0 } \mathrm { B A }$ and $\mathrm { I C } _ { 7 0 } \mathrm { B A }$ are superior acceptors for PSCs based on an alternative polymer donor of P3PT.
