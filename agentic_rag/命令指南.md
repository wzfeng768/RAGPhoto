# Agentic RAG 系统 - 命令使用指南

## 📚 系统简介

Agentic RAG v2 是一个智能问答系统，结合了向量检索、知识图谱和迭代式精化策略，能够对光电和太阳能电池领域的学术文献进行精确问答。

**核心特性**：
- 🔄 **迭代式检索**：自动多轮检索和反思，提高答案质量
- 🧠 **知识图谱增强**：利用结构化知识提供更全面的答案
- 📊 **重排序优化**：使用 qwen3-reranker-8b 对检索结果重新排序
- ✅ **答案验证**：自动检测和修正答案中的不精确信息
- 🎯 **动态参数调整**：根据问题类型自动优化检索策略

## 💻 命令使用

### 模式一：单次查询

直接提问并获得答案：

```bash
python run_agentic.py "钙钛矿太阳能电池的效率是多少？"
```

**参数说明**：
- 第一个参数：查询问题（必须）

**完整示例**：
```bash
# 基础查询
python run_agentic.py "What is perovskite solar cell efficiency?"

# 带详细输出
python run_agentic.py "TPA-An 和 TBA-An 的 PLQY 是多少？" --verbose

# 自定义迭代次数和质量阈值
python run_agentic.py "如何制备钙钛矿薄膜？" \
    --max-iterations 5 \
    --quality-threshold 0.8 \
    --verbose
```

### 模式二：交互式问答

进入交互模式，可连续提问：

```bash
python run_agentic.py --interactive
```

或使用快捷方式：
```bash
python run_agentic.py -i
```

**交互式命令**：
- 直接输入问题进行查询
- 输入 `example` 查看示例问题
- 输入 `config` 查看当前配置
- 输入 `exit` 或 `quit` 退出

**示例会话**：
```
🔍 Query [1]: 什么是 PCE？
[系统回答...]

🔍 Query [2]: TPA-An 的迁移率是多少？
[系统回答...]

🔍 Query [3]: example
📝 Example Queries:
  1. What is perovskite solar cell efficiency?
  2. How to fabricate perovskite thin films?
  ...

🔍 Query [4]: exit
👋 Goodbye!
```

### 模式三：批量评估

对多个查询进行批量处理：

```bash
python run_agentic.py --evaluate --sample-size 10
```

**参数说明**：
- `--evaluate` / `-e`：启用批量评估模式
- `--sample-size N`：处理前 N 个查询（0 表示全部）
- `--output FILE`：保存结果到 JSON 文件

**完整示例**：
```bash
# 评估 10 个查询
python run_agentic.py --evaluate --sample-size 10

# 评估所有查询并保存结果
python run_agentic.py -e --sample-size 0 --output results.json

# 评估 20 个查询，使用详细输出
python run_agentic.py -e --sample-size 20 --verbose
```

## ⚙️ 命令行参数详解

### 查询参数

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `query` | 查询问题（位置参数） | - | `"什么是钙钛矿？"` |

### 模式选择（互斥）

| 参数 | 简写 | 说明 |
|------|------|------|
| `--interactive` | `-i` | 交互式模式 |
| `--evaluate` | `-e` | 批量评估模式 |

### Agent 配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--max-iterations` | int | 3 | 最大迭代次数 |
| `--quality-threshold` | float | 0.7 | 质量阈值（0-1） |
| `--enable-web-search` | flag | False | 启用网络搜索 |
| `--verbose` / `-v` | flag | False | 详细输出模式 |

### 评估选项

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--sample-size` | int | 10 | 评估查询数量（0=全部） |

### 输出选项

| 参数 | 类型 | 说明 |
|------|------|------|
| `--output` / `-o` | str | 保存结果到 JSON 文件 |

## 💡 使用技巧

### 1. 针对不同问题类型优化

系统会自动检测问题类型并优化检索：

**数值问题**（自动优化）：
```bash
python run_agentic.py "TPA-An 和 TBA-An 的 PLQY 分别是多少？"
# 系统会：
# - 减少检索数量（提高精度）
# - 优先检索 results/performance 章节
# - 验证答案是否包含精确数值
```

**方法问题**（自动优化）：
```bash
python run_agentic.py "如何制备 TPA-An 晶体？"
# 系统会：
# - 优先检索 methodology/experimental 章节
# - 验证答案是否包含具体方法名
```

**对比问题**（自动优化）：
```bash
python run_agentic.py "比较 TPA-An 和 TBA-An 的性能"
# 系统会：
# - 增加检索数量（需要更多上下文）
# - 验证答案是否包含两组数据
```

### 2. 调整迭代策略

**快速查询**（1 次迭代）：
```bash
python run_agentic.py "什么是 PCE？" --max-iterations 1
```

**深度查询**（5 次迭代）：
```bash
python run_agentic.py "分析钙钛矿太阳能电池的稳定性机制" \
    --max-iterations 5 \
    --quality-threshold 0.85
```

### 3. 调试和优化

**查看详细过程**：
```bash
python run_agentic.py "你的问题" --verbose
```

**保存结果分析**：
```bash

```

## 🎯 常见问题

### Q1: 如何提高答案精确度？

**A**: 系统已自动启用答案验证，会检测和修正不精确的信息。如需手动调整：
```bash
# 增加迭代次数
python run_agentic.py "问题" --max-iterations 5

# 提高质量阈值
python run_agentic.py "问题" --quality-threshold 0.85

# 查看验证过程
python run_agentic.py "问题" --verbose
```

### Q2: 系统返回 "close to 100%" 而非 "98% and 99%"？

**A**: 这不应该发生了！系统已增强：
1. ✅ 提示词强调使用精确数值
2. ✅ 答案验证会检测缺失的精确值
3. ✅ 自动修正机制会注入精确信息

如仍出现，检查：
```bash
# 确认验证已启用
grep ENABLE_ANSWER_VALIDATION .env
# 应该显示：ENABLE_ANSWER_VALIDATION=true
```

### Q3: 检索结果不相关怎么办？

**A**: 系统已优化检索阈值（0.15 → 0.30），会自动过滤低质量结果。如需手动调整：
```bash
# 编辑 .env
MIN_SIMILARITY_THRESHOLD=0.35  # 更严格的过滤
```

### Q4: 如何禁用某些功能？

**A**: 通过环境变量：
```bash
# 禁用答案验证
ENABLE_ANSWER_VALIDATION=false

# 禁用动态检索参数
DYNAMIC_RETRIEVAL_PARAMS=false

# 禁用重排序
ENABLE_RERANKING=false
```

### Q5: 系统运行很慢？

**A**: 检查以下因素：
1. 迭代次数（默认 3，可减少到 1-2）
2. 答案验证（增加了一次 LLM 调用，可禁用）
3. 重排序（可禁用以提速）

```bash
# 快速模式
python run_agentic.py "问题" --max-iterations 1
```
